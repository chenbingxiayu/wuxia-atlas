## 二、人物页主档策略（用户已拍板）

### 2.1 成因结论（为什么原来 3,930 页）

1. 生成规则无门槛：dossier = 出现过即成页；实测 1 次 1,247 人（32%）、≤4 次 2,109 人（54%）、≥100 次仅 52 人；
2. 表层字符串直通 canonical（registry 3,030/3,098 停在 proposed，approved 仅 68）：一瓢×6 簇、霍天都×3 簇、上官天野×3 簇；站点 canonical 中 1,231 个不在 registry；
3. 称谓/亲属/泛称 393 个成页（二姨父/师伯/汪公公/大人/公主…）；
4. OCR 变体 ≥24 组（江海大/唐经夭/玉鸣坷/毕擎夭…）+ ≤2 字截断名 618 个（晓澜/承珠/在宽）各成一页；
5. 实质内容仅集中于 **202 人**（key_events 196 / 武功 55 / 门派线索 27 / 武评 8），77% 页面 <400 字；
6. 设计前提漂移：设计文档写于 436 页时代，9 倍膨胀后"全保留"性价比崩塌。

### 2.2 主档规则（构建期计算，阈值进 meta 不硬编码）

```
顺序：registry 归并映射（含 kb/校订 TSV）→ 表层字符串归 canonical
     → 7 书过滤 → 频次重算（归并后）
     → 主档圈定：total≥30 ∪ 有 key_events/lineage/combat/arts
     → dossiers.json（主档 438 条）+ entity-index[].page = true/false（存目 875）
meta：major_rule = {"min_total":30, "content_bearing":true, "scope":"tianshan-demo"}
```

### 2.3 存目人物的呈现规则（"对质"承诺由定位符承担）

| 位置 | 主档人物 | 存目人物 |
|---|---|---|
| 书页人物区/回目事件流 | 链接 | **纯文本 + 定位符**（不链接） |
| PathFinder 节点 | 链接 | 纯文本节点（仍可作路径中间点） |
| QA 答案 | 链接 | 文本（口径注不涉及） |
| 人物总览 | 可点 chip | 灰 chip（tooltip 显示出场数），搜索仍可命中（结果显示"存目 · 出场 N 次"） |
| 搜索索引 | page:true | page:false（可搜、无页） |

### 2.4 一致性说明

设计决策 1"436 页全保留"在 4 书年代的真实含义是"有内容的人物全保留"——主档 438 页正是该口径在 7 书数据下的重算（巧合近乎相等），属忠实还原；分层/别名搜索/存目可搜对质全部仍在设计框架内。
