使用

  • 直接下载：点击上表文件 → GitHub 页面右上角下载按钮（或 raw.githubusercontent.com 直链）；
  • 整站克隆：git clone https://github.com/chenbingxiayu/wuxia-atlas —— 数据在 site/data/；
  • schema 文档：site/README.md（各 schema 字段级说明与重建命令）。

更新节奏：kb 管线每点亮一部书 / 修复数据后重跑，版本日期见各文件 meta.generated。
