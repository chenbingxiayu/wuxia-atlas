人工考订通道（本地）

数据里的「考订」结论（锚点/归并/配对/评语）都出自下列人工校定底表——逐行核订、 status=校定 才入站，存疑行一律不入（宁缺毋滥）。这批底表在仓库 kb/校订/， 属人工考订通道（本地）：含定位符与引文，按版权纪律不入库、不随站发布； 上表 JSON 即它们对外的开放产物。

使用

  • 直接下载：点击上表文件 → GitHub 页面右上角下载按钮（或 raw.githubusercontent.com 直链）；
  • 整站克隆：git clone https://github.com/chenbingxiayu/wuxia-atlas —— 数据在 site/data/；
  • schema 文档：site/README.md（各 schema 字段级说明与重建命令）。

更新节奏：kb 管线每深度解析一部书 / 修复数据后重跑，版本日期见各文件 meta.generated。

本站为基于原著图谱数据的原创研究站点，严格限于小说文本、不做史料考证； 引用内容（定位符与短引文）版权归原作权利人所有。数据版本见 关于页。
