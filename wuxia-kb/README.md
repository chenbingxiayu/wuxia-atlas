## 一句话定位

**搬的是"化工厂"，不是"化工产品"**：shiji-kb 可复用的是方法（九步管线、标注不改正文的格式、lint 硬门槛、反思循环、SKILL 沉淀、治理规则），武侠的实体类型、事件模型、时间轴、跨书宇宙则要按小说领域重构。现有 kb/ 的 76,848 处标注与 shiji 语法同源，是资产不是负债——迁移=升级，不是重标。
