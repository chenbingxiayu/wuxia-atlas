## 二、执行器设计（scripts/annotate_chapter_llm.py）

1. **提示词**：运行时从 `SKILL_03a` §二 ````text 围栏提取（本次 v1.8，10,519 字），
   脚本不复制规则文本 → 规则改动只改 SKILL。
2. **上下文包**：书名/回号/块号/规则版本 + 《已核准映射表》（251 条，= registry 的 @ 类
   映射 ∪ 001-019 过审 tagged 中实际使用的管道；批次前冻结为 `logs/mapping_frozen_20261104.json`）。
3. **分块**：连续段落贪心打包 ≤1100 字/块（单段超限独立成块），段号 `[N]` 随块保留。
4. **两遍标注**：P1 首标；P2 以 P1 为底稿做"自检补标与类型校正"（器物/地点/数量/时间
   四类漏标 + ☆/#/;、= /◆、%/ $ 混淆 + 管道同名 + 动词边界）。
5. **回锚保真**（核心）：LLM 输出被解析为"令牌 + 剥标文本"，用 difflib 把令牌映射回
   **struct 原文坐标**，锚定失败/重叠的令牌丢弃，输出文本由底本原文重建 →
   **转写错误零进入成品**（DEF-02/DEF-09 类缺陷结构上免疫）。
6. **结构校验与机械修复**：类型码白名单 15+6、闭括号归一、嵌套/重叠摘除、管道纪律
   （仅 @/%/动词可挂管道；@ 同名管道摘除；% 仅 时点/时长/年龄）、逐段剥标 == 底本。
7. **修辞层**：复用 `annotate_rhetoric_llm` 的候选索引/裁决，逐回落 `〘※〙`；落标后回读断言。
8. **计费**：逐次记录 usage（prompt/cache hit/completion、UTC 时间、peak 判定），按
   `.token_cost_config.json` 的 deepseek-flash 非高峰价（入 $0.15 / 出 $0.60 / 缓存命中
   $0.003 每百万 token）计费，高峰窗口 ×2（口径同 `annotate_rhetoric_llm.py`——
   UTC 周一至周五 01:00-04:00、06:00-10:00）。逐回落 `logs/token_usage/annotate_<书>_<回>_<时间>.json`。
