## 七、合理性总判

| 维度 | 判定 | 依据 |
|---|---|---|
| **结构/格式** | ✅ 合理 | 文本保真 0 差异；类型码/闭合/嵌套/管道纪律全合法（脚本内复验 PASS） |
| **类型判断** | ✅ 较强 | 26 处类型冲突中 21 处新标注更符合 v1.8；错处集中在 ◎ 并称与 ◆/= 语义 |
| **边界/粒度** | ✅ 良好 | 命中中 94% 完全一致；62 处边界差异多为修饰含入；2 处 DEF-12 待修 |
| **实体召回** | ⚠️ 不足 | 通名类 `#` R=0.14、`•` 0.29、`$` 0.35、`^` 0.08；扣除旧口径后整体 R≈0.60 |
| **动词质量** | ⚠️ 偏松 | P=0.52（过标微动作/移动），R=0.67（漏具体事件动词 37 处）；两头都要治 |
| **口径一致性** | ✅ 优于金标准 | 金标准 212 处旧口径 over-tag（D1/身体部位/事件量），新标注按 v1.8 不标 |

**一句话**：**新标注是一份"格式合规、类型判断可靠、通名召回不足、动词偏松"的 v1.8 初稿；
既有金标准是一份"召回较全但口径偏旧"的早期精标。** 两稿不能互相取代：
- 对新标注：按 docs/39 的 S1（通名词表）+ 动词负例表（微动作）+ DEF-12 示例补齐；
- 对金标准：212 处旧口径 token 应作为"负样本"清理/标注 legacy，不能直接用于 v1.8 训练与评测。

## 八、对 docs/39 补标方案的修正（本次对比新增的 3 条）

1. **评测集必须先做 v1.8 口径复核**：直接拿 001-019 当金标准会同时惩罚"正确的不标"和"错误的标注"
   （本次 212/1966 ≈ 10.8% 的 gold token 是旧口径）。建议先按 SKILL_03a v1.8 对 001 做一次
   "口径清洗"，得到 ~1,758 token 的 v1.8 校准集，再算 P/R（对应 docs/39 S4）。
2. **映射表评估要 holdout**：@ 层 99.4% 泄漏说明"用金标准管道做映射表再评金标准"是循环论证。
   评测时应剔除待评回自身的管道，或只统计"映射表未覆盖的别名"。
3. **动词需要"微动作负例表"**：本次 `■勒马/拨过/贴/退/退过一边/走来` 等 ~7 处过标，
   与 v1.8"姿态微动作不标"冲突；同时漏标 `卸任/辞官/赴京/提解/掏/接/丢/打开/化开/受/结果` 等
   事件动词。建议在 SKILL_03a §二 增加"微动作 vs 事件入口"正反对照例（S2 一并做），
   并在 `wordlists/` 增加 verb 负例表（reuse 现有 verbs.json 的 negative 字段）。
