## 三、关键分歧裁决（逐项给理由）

### D1 "灭门寻仇"是否独立成类 —— 采 V1（拆除）

V2 保留"灭门寻仇"并定义为"⊠+群体死伤（≥2 人死亡）"。问题：①它与"生死杀伐（子型灭门/血洗）"完全同信号，区分维度只剩"人数≥2"，这不是情节功能而是规模属性；②"寻仇"是跨回因果链（v1 归恩怨链），塞进单一行为单元类型会造成"三十年前的灭门"与"今天的寻仇"共用一类的粒度混乱。V1 的拆除归宿（灭门→生死杀伐子型；寻仇→恩怨链）与 3.3 优先级、8.3 链设计自洽。**合并采 V1。**

### D2 "奇遇授艺"是否独立成类 —— 采 V1（拆除，机缘落 manner）

V2 保留"奇遇授艺"（非正式传授：偶遇/梦中/遗书/偷学）。V1 指出"奇遇"是**取得方式**不是行为语义：得谱→夺宝争谱（子型机缘取得）、高人传功→拜师传艺（子型非正式传艺）、服灵药→练功突破（子型机缘突破），"机缘"落 manner 字段。V2 自己也承认其判定信号与拜师学艺只差"是否有正式名分"——这一差异用"正式性标记"（V1 模板二已有）承载即可，不值得一个独立类型。**合并采 V1，正式/非正式由子型+正式性标记表达。**

### D3 主类型优先级：比武较技置顶（V2） vs 战争优先、致命压过切磋（V1）—— 采 V1

V2 把比武较技排在最高，裁决"打斗中死人 → 主类型=比武较技，子事件=死亡事件"。后果：①"比武致死"与"仇杀致死"在战绩评分、问答"谁杀了 X"、死伤统计里被切磋性质掩盖——死亡改变冲突性质（致死即非切磋），与 04f"结果决定主域"的哲学同构；②V2 的优先级链里"武林大会＞死亡事件"把容器混入单元竞争（V1 明确容器不参与竞争）。V1 序（P1 起义战争→P2 朝廷剿抚→P3 生死杀伐→…）与 shiji"战争优先、继位次之"的经验同构。**合并采 V1 序；并保留 V1 对"打斗中死人归生死杀伐（子型比武致死）""围剿死人归朝廷剿抚"的点名裁决。**

### D4 拆分判据的宽严 —— 采 V1 三判（叙事线切换不拆）

V2 允许"叙事线切换"与"铜棍卫士退出"触发拆分。前者会把被插叙打断的同一交手单元拆成两个事件（密度统计失真），后者与"逐招不拆"哲学冲突——卫士退出但冲突目的、场景、对抗关系未变，按 V1 的"参与者变更判"须同时满足"旧对手退场＋新对手形成独立交手"才切界。V1 的"锚定切多区间、事件不拆"精确处理插叙。V2 独有的"时间跳转"条件并入场景切换判的说明（长时间跳跃本身伴随场景收束）。**合并采 V1。**

### D5 battle_id 是否并轨 event_id —— 采 V1（并轨）

V2 的 battle_id"格式同 event_id"，等于保留两套编号但对账靠人。V1 直接裁定 battle_id=event_id（战斗=事件记录的战斗模板实例），由"类型筛选＋模板字段"承担 05e WAR 编号的检索职能，消除双轨对账。**合并采 V1。**

### D6 叙述可靠性矩阵的语义 —— 采 V1（声称不入问答）

V2 矩阵对"来源声称"放行"可入问答（标注存疑）"，且表格本身 markdown 错位不可渲染。01g 未知原则明文："未核实声称不进入确定性问答答案"——问答是"永不幻觉"页（应用蓝图），声称入问答等于把传闻当答案发布。V1 矩阵（声称/存疑/冲突 → 问答✗ 评分✗，编年仅传闻轨，索引✓）逐格给出理由，并与负规则十二（书信死讯不关闭生存状态）、穿帮雷达两线检查衔接。**合并采 V1 矩阵。**

### D7 事件链登记时机 —— 采 V1（抽取时登记槽位 + 事后归纳）

V2 主张链"纯抽取后归纳"。V1 的折中（单回抽取只填 chain_type/prev/next 最小槽位，全链归纳归后处理）保留了局部信号，避免后处理在全量数据里重新猜邻接关系；链成员仍是独立事件、链不产生新事件。**合并采 V1，并吸收 V2 增补的战争链/情感链为候选链型（附录 B5 扩充说明）。**
