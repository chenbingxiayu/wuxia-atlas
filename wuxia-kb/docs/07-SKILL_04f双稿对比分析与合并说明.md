### 2.3 与 v1 的"表面分歧、实质一致"

- **动词性招式名"双标"**：v2 称"强制双标"，v1 称"招式名标☆、同句独立攻击动词标⊞"——两者示例完全相同（`一招〖☆旋风扫叶〗⟦⊞扫⟧向…`），实质都是"招式名→实体、相邻动作动词→动词触发词"，**同一字符不得承担两种标注**。合并稿统一表述为后者。
- **废武功双标**：v2 建议同一词形双触发（`⟦⊠废⟧⟦▣废⟧`）违反"最小触发单位"（同字符两用）；v1 按"身体路径⊠ / 技术路径▣，双事实分句分标"处理。合并稿采 v1，v2 方案记入分析存档。

## 3 · v1（GLM）逐条评审

### 3.1 亮点

1. **连续交锋合并标注**（§6.1）：同一交手单元只标交锋起止+关键结果，主干叙事每段 1-6 处、>10 处回查——武打语料标注可运营的关键规则，v2 缺失；
2. **"结果决定主域"速查表**（§3.1）：动+死→⊠、动+退→⊞、动+走→⊟、动+成→▣——把 01g"结果补语保留"统一成一个原理，替代史记"单字优先"铁律的判别标准三问；
3. 习得阶段 `achieved` 字段（看过/听过/记住/修习/练成分档）——直接支撑武功页传习链；
4. 借/还/押解**方向字段**强制（神兵流转链的数据前提）；
5. V0 纪律（反思不改格式、计数只增不减）写入错误模式库；
6. 联动三铁律：候选非定论 / 强制缺失降级待审 / 四类人物关系不进联动（防共现误推）。
