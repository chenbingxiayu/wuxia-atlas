### 任务 1｜武侠实体类型体系与符号分配（★★★，全体系地基）

- **目标**：定版武侠名词实体类型表（约 20 类）、动词域衔接（与任务 2 对齐）、每类的判断原则、边界规则、负规则（不标清单）。
- **交付物**：`SKILL_01g 武侠版设计稿`——武侠符号宪法。
- **必须回答的设计问题**：
  1. 类型定版：以 doc 03 §五建议稿（shiji **18 类**保留 + ☆武功/▲擒控/▷传授新增；勘误：初稿误作 19 类，参考件实体表实为 18 类）为起点逐类裁决——哪些保留/扩语义/删除？`^`名物改"武学名物（内力/穴道/经脉）"是否成立？`:`礼仪承接"江湖规矩"是否成立？
  2. 符号分配：新增类型的符号从 shiji 01g 的 100 候选符号库中选，须过"形状系列分离"与"0.5 秒视觉区分测试"两项硬约束；给出每个候选的取舍理由。
  3. **同形异类规则**（G1 核心）："小李飞刀"（人名/武功/兵器）、"金刀寨主"（绰号 vs 职衔）、"降龙十八掌第十三式"（整体 vs 拆分）——给出同形异类的判定顺序与上下文信号。
  4. **规范矛盾裁决**（须给出建议方案+理由供拍板）：对话中"已具名者的惯用称谓"标不标（doc 02 决策 D1，实验中唯一越修越糟的问题）；集体泛称（"麦氏三雄"）归 `@`/`◆`/不标（D2）。

### 任务 2｜武侠动词域与动词-实体联动规范（★★★）

- **目标**：定版武侠动词分类域、每域词表框架、动词标注语法细则、动词与实体的联动规范。
- **交付物**：`SKILL_04f 武侠版设计稿` + 动词词表框架（外置 JSON 格式定义 + 各域种子词表结构）。
- **必须回答的设计问题**：
  1. 动词域划分：建议起点 ◈打斗/◉杀伐/○拜盟册封/◇赠换交易/▲擒控救援/▷传授学习（doc 05 §五），是否增删？"疗伤/运功/点穴"归哪域？
  2. **招式名 vs 出招动作的区分**：`〖☆一招"怪蟒翻身"〗`（实体）vs `⟦◈刺⟧`（动词）——给判定信号；引号内招式、招式含数字（十八掌/十三式）的边界规则。
  3. **动词-实体联动规范**：点穴→穴道实体、传功→武功实体、赠剑→兵器实体——哪些动词出现时强制要求邻近出现哪类实体（这直接生成三元组候选）。
  4. 词表机制：消歧语法 `⟦◈伐|征伐⟧` 沿用；单字优先/复合拆分/禁嵌套照搬；词表外置 JSON 的 schema（含频率分档：高置信自动补标/多义待审/不批量——仿 04f1 三档）。
  5. 各域种子词表骨架：每域给出 15-30 个种子词（从章回版抽样归纳），标注"高置信/多义/待观察"分档。
- **输入**：`SKILL_04f_动词标注.md` + `references/SKILL_04f1-rules.md`（分档补标运营法）+ `references/SKILL_02e1_动词标注规范.md`（词表格式）；任务 1 产出（类型码）；章回版打斗段落抽样。

- **目标**：定版武侠事件类型枚举（12-15 类）、每类定义与边界、粒度判据、群体事件处理。
- **交付物**：`SKILL_04a 武侠版设计稿`。

### 任务 5｜书内相对时间轴模型（★★★）

- **目标**：为无绝对纪年的武侠世界设计完整时间体系——这是时间类四个 skill（03g/04c/04e/07a）合成的武侠新方法论。
- **交付物**：`武侠时间体系设计文档`。
- **必须回答的设计问题**：
  1. **时点键设计**：(书→卷→回→场景→相对刻度) 的键结构与粒度；可挂真实朝代时（清代系列）的挂接规则；"作品宇宙编年"的合成方式。
  2. **锚点类型学**：时令（元宵/中秋）、事件锚（大战之后）、**人物年龄锚**（武侠年龄是强锚点，shiji 相反）——各锚点的置信度排序。
  3. **叙事单调性校验**：同线时间不可倒流的检查规则；**倒叙/闪回/多线并行的时轴分叉表示法**（武侠叙事比编年体复杂——shiji 无此问题，须全新设计）。
  4. **师承代数定年法**（07a 方法 5 反向应用，金矿）：以"每代 25-30 年"从师承链推算跨书相对年代的操作规则、误差估计、与已知朝代锚的校准点。
  5. **错误模式库武侠化**：shiji 04c 的 43 种错误模式中约一半通用（单锚点塌缩/追叙≠当前/世代数≠年数/时序倒置）——逐条判定直迁/改写/报废；新增武侠特有模式（闭关 N 年出山、内力返老还童等设定内时间扭曲如何处理）。
  6. `|年龄`/`|时长` 内联消歧约定与时间实体标注格式（对接任务 1）。
  7. confidence 语义重定义：high=书内明确陈述/medium=相对推算一致/low=跨书推断。
- **输入**：`SKILL_03g_时间实体消歧.md`（五层策略骨架）；`SKILL_04c_事件年代推断.md`（43 错误模式+12 推理逻辑）；`SKILL_04e_年份消歧.md`（"只做索引不强求绝对年"经验）；`SKILL_07a_人物生卒年推断.md`（方法 4/5）；`SKILL_04d`（三步审查管线）；系列谱系考订表（14 时代段，作校准参考）。
