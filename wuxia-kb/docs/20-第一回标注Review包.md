### 2.1 三层符号体系

### 2.2 格式细则

**① 显示串与规范名（管道）**：

```text
〖TYPE显示串〗              基本格式
〖TYPE显示串|规范名〗       管道格式：本次提及指向登记表中该规范名实体
```

- 显示串**必须是原文连续字符**：不补字、不换字、不展开简称、不含外部标点。
  - ✅ `〖◆武当|武当派〗`（原文只有"武当"）；❌ 原文无"派"却写 `〖◆武当派〗`。
- 人物规范名优先可靠本名：`〖@玉罗刹|练霓裳〗`、`〖@火灵猿|朱宝椿〗`。
- 管道仅限**名称类**（指向规范名）；禁止多管道 `〖@玉罗刹|别名|练霓裳〗`。
- 管道表明"本次提及指向谁"，**不自动把称谓升级为永久别名**。

**② 时间管道（受控标签，G0 终裁）**：

- `〖%…|时点〗`：朝代年号、具体时点、时令锚（如 `〖%明万历四十三年|时点〗`、`〖%黄昏|时点〗`）。
- `〖%…|年龄〗`：年龄（如 `〖%十八九岁|年龄〗`，原文无"岁"不得补字）。
- `〖%…|时长〗`：真实时间长度。**原则**：真实时间归 `%`，功力量与招数归 `$`（`〖$十年功力〗`）。

**③ 动词触发词边界**：

- 取**最小而能表达主要动作或结果**的连续单位；"杀死、夺走、练成"等结果补语保留在内。
- 不含主语、宾语、普通程度副词和标点；❌ `⟦▣传授某剑法⟧`（吞入宾语）。
- 一个触发区间只标一个主域。
- **动词标注中的管道**用于语境消歧与完成状态注记：如 `⟦■跃过|越河脱围⟧`、`⟦⊞抢上来|劫夺未遂⟧`、
  `⟦⊡请|雇请⟧`——竖线后为注记，非第二触发词。

**④ 事件状态（动词提及 ≠ 已核实事件）**：

- 已发生/正在发生的六域动作：正常标注。
- 已实际施行的**未遂**动作：可标，必须记未遂（如管道注记）。
- 纯计划、纯条件、否定动作：实体照标，动作**默认不标**（"欲杀""若能夺得"不标）。
- 传闻、书信声称的动作：可标但不得升级为事实（须保留来源与可信状态）。

### 2.3 关键裁决（D1 / D2 / 拆标）

**D1 对话称呼裁决**：对白与叙述适用同一规则。

- 照标：本名、法号、化名、完整绰号、带姓名的关系称谓（`〖@练姐姐|练霓裳〗` ✅）。
- 不标：纯礼貌称呼（前辈、老伯、晚辈）、纯关系称呼（贤弟、师父、姐姐）、
  临时评价代称（妖女、老贼）、描述性代称（那汉子、老者、白马少年）。
- 单独职位称呼按职衔标，不转个人别名：`"〖;掌门〗，请定夺。"` ✅。

**D2 集体名号裁决**：

- 固定人物组合的稳定集体名号 → `◎`（`〖◎西川双煞〗` ✅）。
- 有独立组织延续性的共同体 → `◆`（`〖◎丐帮〗` ❌，应为 `〖◆丐帮〗`）。
- 临时职业群体不标（`〖◎众镖师〗` ❌）。
- 名号的省称若仍具稳定识别性（如"双煞"承接"西川双煞"），照 D2 精神处理。

**组织与职衔拆标**（按真实字串，一个字不重复使用）：

- `金刀寨主` → `〖◆金刀寨〗〖;主〗`；`户部侍郎` → `〖◆户部〗〖;侍郎〗`。
- 冻结绰号整体不拆（`〖@金刀寨主〗` 当其为绰号时）。

### 2.4 十五条判断原则（摘要）

| # | 原则 | 一句话要点 |
|---|------|-----------|
| 0 | 结构字符不作语义标注 | 段号、韵文块标记等结构层不标语义；文学内容不机械豁免 |
| 1 | 标具体对象 | 不标所有普通名词，只标被具体指称的对象 |
| 2 | 人物/组织/职衔可分则分 | 按制度作用区分，不混标 |
| 3 | 完整绰号、法号、化名不碎拆 | 冻结名称保持整体 |
| 4 | 本名优先 | 不凭常识猜名、不造俗名 |
| 5 | 管道解决本次所指 | 不自动扩大别名表 |
| 6 | 对白与叙述同一称名规则 | 见 D1 |
| 7 | 个人/固定群组/组织/家族分开 | 见 D2 |
| 8 | 职位与身份按制度作用区分 | 可履任的职位→`;`；职业类别/处境→`#` |
| 9 | 组织前缀拆开，完整职位词不拆碎 | 按真实字串 |
| 10 | 技术、文本与物件副本分层 | 武功内容、秘籍纸本分开标 |
| 11 | 技术名内部数字与意象不拆 | "降龙十八掌"的"十八"不标数量 |
| 12 | 年龄、时长、日期、非时间量分流 | 见 §2.2② 与 `$` |
| 13 | 边界不含非对象成分 | 最小完整单位，不含谓词、副词、标点 |
| 14 | 嵌套拍平 | 同一区间只归一个主类型，内部关系转登记层 |
| 15 | 动作、结果、可信状态分别判断 | 已攻击≠已杀死；声称≠已核实 |

### 2.5 负规则（不标清单，摘要）

1. 描述性代称不标（那汉子、老者、白马少年）。
2. 纯礼貌/关系称呼不标人物（前辈、贤弟、师父、姐姐）。
3. 通名和不定类别不标（"找一家镖局""翻过一座山"）。
4. 冻结名称内部成分不单标（十八掌的"十八"）。
5. 武功意象不拆对象（怪蟒翻身不抽蟒）。
6. 纯计划、条件、否定动作默认不标。
7. 日常微动作不泛标（转头、抬手、跃起、退半步、侧身）。
8. 普通身体与心理描写不标概念（心头一惊）。
9. 普通评价不标身份或理念（好汉子、真高明）。
10. 成语内部假指称不标（毛遂自荐不抽毛遂）。
11. 诗词意象不当事实。
12. 书信和告示不自动核实。
13. 回目预告与回末套语不抽事件。
14. 不明身份不挂确定管道（疑似某人不得挂本名）。

### 2.6 保真性硬约束（已机器验证，Reviewer 可跳过）

- 标注不得增删改原文任何字符；剥除全部标记后须与原文基线**逐字一致**（本片段已 PASS）。
- 标点留在实体边界外；三层不嵌套、不交叉、不重叠。
- 段首 `[2]`–`[12]` 为结构层段号（PN），不属于标注对象。

严重度分级：**P0** 保真错误（改动原文）/ **P1** 类型错误 / **P2** 边界或管道错误 /
**P3** 口径分歧（需项目方拍板，不算执行错误）。

### 3. 争议项裁定（§五 R1–R10）
逐项给出：裁定结论 → 依据条款 → 是否回填 few-shot（建议例句写法）。

### 4. 漏标清单
Reviewer 认为应标未标的：位置、建议标注写法、类型依据。

### 5. 过标清单
Reviewer 认为不该标的：位置、理由（对应负规则编号）。

### 6. 约束
- Review 仅输出报告，不产出改稿；不得建议改动原文任何字符。
- 裁定必须引用本包 §二 的条款（或指出规范本身的缺口，归入 P3）。
