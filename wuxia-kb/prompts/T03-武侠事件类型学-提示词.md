**任务：武侠事件类型学（产出 = SKILL_04a 武侠版设计稿）**

必须完成以下八组设计问题，每问都要给出明确答案 + 理由 + 正误对照例：

**Q1 事件类型枚举定版**（本任务的核心增量，01g/04f 均未定版）：
- 以第 3.5 节的 12 类起点为基点逐类裁决——保留/合并/拆分/删除，每处改动给理由与语义归宿；目标 12-15 类；
- 每类给出：类型名 / 一句话定义 / 典型例 / 判定信号（锚点动词域组合+参与者结构）/ 与相邻类型的边界判据（两个易混类型各给 1 组对照例）；
- **主类型归属优先级**：一个事件只标一个主类型（shiji 经验：战争优先→继位次之）。武侠版给出明确优先级序，并裁决：打斗中死人归"比武较技"还是"杀伐"？围剿中死人归"朝廷剿抚"还是"战斗"？
- **裁决"泛类型"合法性**："江湖恩怨"这类大筐是不是合法类型（shiji 03k 裁定法精神：能给出明确判定信号的才留，否则拆散进因果链）？"情爱纠葛"与 01g §9.2 情感关系（登记层状态序列）的分工——事件记"行为"（定情/悔婚/决裂），关系记"状态"，边界划在哪？
- **复合事件分层**："武林大会"（多场比武+推举盟主）、"押送被劫"（押解+劫夺+打斗）是不是独立类型，还是"容器事件+子事件"结构？给父子槽位设计（01g 最低字段已有"所属战斗或复合事件"位）。

**Q2 粒度判据**（shiji 三档的武侠化，必须给正误例）：
- 沿用三档判据：4-8 字概括/2-4 句描述/超 8 句拆分——每档给 2 个武侠正例与 1 个武侠误例；
- **"一场比武打了三页"怎么拆**：逐招铺陈（样本甲乙）是"一个事件+密集触发词"还是"多个事件"？给拆分判据（以胜负/参与者变化/场景切换为界？）——必须与 04f §6.1 连续交锋合并标注规则衔接（触发词密度规则在动词层，事件拆分规则在事件层，两层各管各的）；
- **回内多线并行**：一回常并行 2-3 条叙事线（回目对句即双线），事件锚定怎么处理；
- **跨回事件**：一场大战打了三回（追杀/围困/决战），是三个事件还是一个？给判据；
- **世系/谱系式合并的武侠对应**：shiji 把连续"X崩，子Y立"合并为"世系传承"事件——武侠版对应什么（掌门传承谱？家族兴衰概要？）给合并条件与字段；
- 粒度上下限：最小事件（"单挑一招定胜负"）与最大事件（"武林大会"）的界碑。

**Q3 群体事件处理**（武林大会/群殴/围剿/血洗满门——shiji 没有系统答案，武侠高频）：
- 参与者记录策略：参与人物几十个怎么记？给**分级记录规则**的裁决——全部记录/只记有名字者/只记主要人物/只记生死进出（建议四档：具名参与者全记 + 无名对手计数（"连败十八名强盗"）+ 无名龙套记集体 + 伤亡单列），每档给判据与正误例；
- ◎人物群组（武当七侠）/◆组织（丐帮）/临时聚集（"绿林群豪"）三种集体怎么记参与方——01g 约束：群组战绩不自动传播成员、围攻胜负可以是阵营级；
- 群体死伤字段：血洗满门死 37 口——逐人记还是计数记？与穿帮雷达"死亡一致性"检查的衔接；
- 复合群体事件的父子结构：武林大会=容器事件，其下比武=子事件，成员关系怎么标。

**Q4 事件字段体系**（以 01g §2.2.3a 最低字段为不可推翻底座，细化成字段表）：
- 给出**事件记录字段总表**：字段名/类型/必填性/来源（自 01g 迁入 vs 本文件新增）/说明——至少覆盖：event_id、事件类型、主域与子型、锚点动词（对接 04f 联动总表的谓词建议）、参与方及语义角色（施者/受者/死者/伤者/医者/授者/受艺者/物件/地点/证人……给角色词表）、相关实体（武功/器物/组织/文书）、书-回-段-字符区间定位、**书内时间槽位**（本任务只留槽位并定义字段形态：原始时间表达+锚点+偏移+精度——完整时间体系是任务 #5，不得在本文件展开设计）、发生/完成/来源/可信/叙述模式五状态、outcome（胜/负/平/未决/未知）+参照方+判定依据、死伤字段、manner 事件登记属性（情愿/不情愿/暗救；压制/险胜——01g 盘点决策点②）、所属战斗或复合事件（父事件槽位）、结果及结果依据、规范与数据版本；
- **锚点动词的对接规则**：每个事件类型的判定信号里写明"期待什么动词域组合"（如 比武较技=⊞主导+outcome、拜师学艺=⊡拜师+▣授艺/练成链、夺宝争谱=⊟夺取+{文书）；无动词入口的状态句事件（"他已是掌门"）怎么建记录——01g 允许名词谓语句无动词入口；
- **类型专用字段模板**：给 4-6 个代表性类型的字段模板（战斗/拜师学艺/夺宝/死亡/武林大会/行踪），展示总表如何按类型实例化；
- 字段缺省原则：未知不强填（01g 未知原则）——缺时间/缺地点/缺参与方时各字段的写法。

**Q5 战斗事件专项 Schema**（仿 05e，对接侠谱评分）：
- 以 01g §9.7 三层（战斗/阶段或回合/动作）为骨架，定版战斗事件 Schema：battle_id、事件名称（4-8 字）、战斗类型（单挑/围攻/混战/车轮战/比武/夜袭/守山/劫狱……给枚举与判定）、参战方（个人/◎群组/◆组织，支持多打多）、主要人物、见证人、outcome+参照方+判定依据、死伤、用武（☆招式武功列表）、兵器（•）、地点、时长、manner（压制/险胜/点到即止）、阶段列表（子事件）、锚点触发词区间、来源定位、五状态；
- **多阶段战斗**：车轮战（一人连战数敌）/三战三捷/大战三回——阶段怎么建模（子事件列表 vs 一个事件多 outcome）？给裁决与正误例；
- **总述句**："大战三百回合""斗了半日"——登记为战斗持续描述，不造触发词、不数回合（04f 已定），战斗记录的时长字段怎么写；
- **非同条件不可比**：偷袭/围攻/暗中下毒得手的胜利与堂堂之阵单挑的胜利在评分上不可直接比——战斗记录里 manner/条件字段怎么支撑这一点（评分规则本身不是本任务，但字段必须留够）；
- 战斗与杀伤的关系：同场战斗中的死亡是独立 ⊠ 事件还是战斗记录的死伤字段？给裁决（01g 主域裁决：杀死某人主域 ⊠，可关联所属战斗——事件层落实为"独立死伤记录+战斗关联"还是"仅字段"？）。

**Q6 叙述可靠性与重复叙述分层**（对接后续常识/一致性任务 #11）：
- 五状态字段落到操作细则：每种信息来源（叙述/人物发言/书信/告示/转述/回忆）× 每种可信状态（已核实/来源声称/存疑/相互冲突）的**默认处理矩阵**（可入问答？可入评分？可入编年史？只入索引？）——给 6×4 矩阵并逐格说明；
- **往事转述事件**：人物转述的旧事（样本己"听说她两年前刚出道就曾以双掌一剑连败十八名强盗"）——事件记录同时携带**叙述位置**（谁在哪回说的）与**故事时间**（两年前，槽位留待任务 #5）；口头转述 vs 书信声称 vs 叙述者直接倒叙的分层；
- **重复叙述**：同一事件在回忆/他人转述/后回呼应中再次出现——shiji 各章独立提取不去重；武侠版给分级方案（回内去重？跨回建"同一事件"关联表？首叙回为主记录、重复提及为引用记录？）给裁决与字段（如 first_narration/repeat_refs）；
- **预言/评估不是事件**："不用十年，天下第一高手就得让位给这女娃儿"——预测与评价不入事件表；声誉信息（"真名叫练霓裳""武林中谁也不知她的来历"）入实体登记不入事件——给判别信号；
- 梦境/戏中戏/假想比武：叙述模式字段的落位细则（01g：默认不标动作，事件层默认不建主故事事实记录）。

**3.4 武侠事件领域特征清单**（与史记语料的系统性差异，设计必须逐项回应）：

1. **无绝对纪年，回是天然叙事单元**：但一回常并行 2-3 条叙事线，回≠故事时间单元；事件锚定必须回内再细分（段落/字符区间）；
2. **打斗描写占比极高**：一场大战可写三页，逐招铺陈；动词密度是史传十倍——粒度判据必须先回答"比武怎么拆"；
3. **群体事件高频**：武林大会、围攻、群殴、血洗满门，参与人物几十个——shiji 的"主要人物"字段不够用；
4. **恩怨跨书生长**：灭门之仇埋 30 回后回收（伏笔-回收是武侠核心叙事结构），仇怨事件须可关联；
5. **传闻与传说层厚**：人物名声先于出场（玉罗刹未出场先有"连败十八名强盗"的传闻），往事转述密度高——叙述可靠性分层是刚需；
6. **夺宝争谱是主线引擎**：秘籍争夺链跨回跨书生长（盗谱→嫁祸→夺回→烧谱），事件链设计必须支撑；
7. **成长主轴**：拜师学艺/闭关练功/出山扬名的时间跨度大（"一十二年""闭关十年"），习得阶段（修习中/练成）必须进事件字段；
8. **朝廷线与江湖线交织**：梃击案、押送、围剿、起义——事件类型要能容纳非武林事件；
9. **委婉与夸张并存**：杀人委婉语（"结果了"）与武功夸张（"双掌一剑连败十八名强盗"）——可信状态与计数口径要处理；
10. **同一事件多回重复**：大战之后若干回，人物回忆/转述再提——重复提及的登记方式影响所有下游统计。

# SKILL 04a: 古籍历史事件识别

## 1. 任务定义

从已完成实体标注的古籍文本中，识别和提取结构化的历史事件记录。

**输入**: 已标注的Markdown文件（含@人名@、=地名=等实体标注）
**输出**: 结构化的事件索引文件（Markdown表格 + 详细记录 + 事件链）

---

## 2. 事件的定义与粒度

### 什么是一个"事件"

一个事件是一个**有完整起因-经过-结果（或至少经过-结果）的行为单元**。它通常包含：
- 一个或多个行为主体（人物）
- 一个行为或状态变化
- 可选的时间、地点、因果

### 粒度控制（最关键的判断）

| 太粗 | 适中 | 太细 |
|------|------|------|
| "黄帝一生" | "涿鹿之战" | "黄帝征师" |
| "夏朝兴衰" | "启伐有扈氏" | "启召六卿" |
| "商鞅变法" | "商鞅第一次变法" | "商鞅废井田" |

**判断标准**：
1. 能否用4-8字概括？能 → 粒度合适
2. 能否写出2-4句事件描述？不能（太简单） → 可能太细
3. 事件描述超过8句？ → 可能太粗，应拆分

### 特殊情况处理

**世系传承**: 连续的"X崩，子Y立"（无额外叙述）→ 合并为一个"世系传承"事件

```markdown
### 002-036 夏朝中期世系
- **事件类型**: 家族事件
- **事件描述**: 中康崩，子帝相立...帝扃崩，子帝廑立。
```

**重复叙述**: 同一事件在不同段落被提及（如001章和002章都提到"鲧治水"）→ 各章独立提取，不去重。去重是后处理的工作。

**太史公曰**: 评论本身不是事件，但如果评论中**首次提到**某个史实，应当提取。

## 3. 事件类型体系

共11个主要类型：

| 类型 | 说明 | 典型例子 |
|------|------|---------|
| 战争 | 战役、军事征伐、平叛 | 涿鹿之战、长平之战 |
| 继位 | 即位、崩逝、禅让、篡位、废立 | 舜践天子位、桀亡国 |
| 政治活动 | 朝会、外交、联盟、谏言、决策 | 众臣荐举虞舜 |
| 政治改革 | 变法、制度建设、任命 | 舜任命禹为司空 |
| 政治整顿 | 惩处、流放、诛杀、清洗 | 舜惩办四罪 |
| 家族事件 | 婚姻、生子、世系、家族纷争 | 黄帝娶嫘祖生子 |
| 建设 | 治水、筑城、迁都、工程 | 禹治水十三年 |
| 文化活动 | 礼乐、祭祀、著述、教育 | 尧命羲和制历 |
| 经济活动 | 商贸、赋税、盐铁、货殖 | 平准均输 |
| 自然灾害 | 洪水、地震、旱灾、天象异变 | 洪水滔天 |
| 改革 | 法律变革、官制改革 | 禹定五服制度 |

**类型归属原则**：一个事件只标注一个主类型。当多个类型可选时：
- "战争"优先级最高（凡涉及军事行动的归入战争）
- "继位"次之（凡涉及帝位变更的归入继位）
- 其余按事件核心行为判断

## 4. 不同章节类型的处理策略

### 4.1 本纪（001-012）

帝王年表式叙事，事件密度高。

- "X年，Y事" → 每条有独立意义的记录都应提取
- 注意区分同一帝王不同时期的事件
- 秦始皇本纪、高祖本纪事件量最大（可达100+）

### 4.2 表（013-022）

结构化年代表，选择性提取。

- 只提取有叙事性的重大事件
- 忽略纯年月记录（如"某年某月某日"无实质内容的）
- 关注跨国并列的重大事件

### 4.3 书（023-030）

典章制度论述，侧重制度变革节点。

- 天官书：天象异变事件
- 封禅书：历次封禅事件
- 河渠书：水利工程事件
- 平准书：经济政策变革事件

### 4.4 世家（031-060）

诸侯国通史，时间跨度长。

- 建国、迁都、灭国是关键事件
- 世系传承可合并
- 重大战役需详细记录
- 与其他世家/本纪重复的事件，各章独立提取

### 4.5 列传（061-130）

人物传记，关注生平转折点。

- 合传中不同人物分别提取
- 关键节点：出仕、建功、获罪、结局
- 类传（循吏、酷吏等）每人单独处理
- 对话/谏言中的事件也应提取

## 8. 已知难点与解决方案

### 8.1 长章节超出输出限制

问题：秦始皇本纪、高祖本纪等章节很长，事件量大，可能超出大模型单次输出限制。

方案：
- 方案A：将长章节按section拆分，分批处理后合并
- 方案B：增大max_tokens（当前16000），必要时用extended thinking

### 8.2 年表章节的处理

问题：十二诸侯年表等以表格形式存在，不是传统叙事。

方案：只提取有叙事性的重大事件（如"灭国"、"迁都"），忽略纯年月记录。

### 8.3 事件重复

问题：同一历史事件在多个章节被记述（如"武王伐纣"出现在周本纪、齐太公世家、鲁周公世家等）。

方案：各章独立提取，不在提取阶段去重。后续可构建跨章事件关联表。

### 8.4 模糊边界

## 2. 战争事件的定义

### 什么是战争事件

战争事件是指涉及**军事征伐、战役、平叛、攻城、围困**等武装冲突的历史事件。包括：

- **国家间战争**: 灭国之战、兼并战争、边境冲突
- **内部平叛**: 叛乱镇压、诸侯征伐
- **民族战争**: 华夷战争、少数民族征讨
- **军事行动**: 包围、袭击、救援、退兵

### 不属于战争事件

- **政治暗杀**: 无军事对抗的刺杀（如荆轲刺秦王）
- **武力威慑**: 陈兵示威但未发生战斗
- **军事演习**: 非实战的练兵活动
- **个人决斗**: 非军事组织的武力冲突

### 简略攻伐记录（Fact级别）

史记中大量存在极简略的攻伐记录，如：
- "攻魏"、"伐赵"（仅2-3字）
- "取某城"、"围某地"（无战争经过描述）
- 年表中的"X攻Y"条目（无详细叙述）

**处理策略**：

| 记录类型 | 建模方式 | 说明 |
|---------|---------|------|
| **有完整叙述的战争** | Event（战争事件） | 本skill（05e）处理 |
| **简略攻伐记录** | Fact（事实） | 由SKILL_05d处理 |
| **融合** | Fact关联到Event | 本skill将简略fact与战争事件关联 |

**融合规则**：

当简略fact与战争事件可能相关时，建立关联：

```markdown
### WAR-042 长平之战
- **关联Facts**:
  - FACT-043-025: %四十五年%，攻赵长平（赵世家）
  - FACT-005-087: %昭王四十五年%，伐韩野王（秦本纪）
```

这样既保留了简略记录的事实性，又将其与完整战争事件关联起来。

## 4. 战争事件提取流程

### 4.1 第一阶段：初步识别

从130章事件索引中筛选所有`事件类型 = 战争`的事件：

```bash
# 提取所有战争事件
grep "| 战争 |" kg/events/data/*_事件索引.md > kg/events/tmp/wars_raw.txt

# 统计数量
wc -l kg/events/tmp/wars_raw.txt
```

**预期结果**: 约200-300个战争事件条目（需验证）

### 4.2 第二阶段：事件归并

同一战争在不同章节可能被多次提及，需要识别并归并：

#### 自动归并规则

| 归并条件 | 示例 |
|---------|------|
| **战争名称完全相同** | "长平之战" = "长平之战" |
| **时间+地点一致** | 前260年 + =长平= → 同一战争 |
| **交战双方+时间一致** | 秦vs赵 + 前260年 → 同一战争 |

#### LLM辅助归并

对于模糊情况，使用LLM判断：

```
输入：
- 事件A: 003-015 商汤伐桀
- 事件B: 004-012 桀亡国于鸣条

问题：这两个事件是否描述同一场战争？

输出：
- 是/否
- 理由：两者都描述商汤灭夏的最终战役，时间、人物、结果一致。003章侧重商汤视角，004章侧重夏桀视角。应归并为"鸣条之战"。
```

### 4.3 第三阶段：信息融合

将同一战争的多个来源记录融合为统一条目：

#### 融合策略

| 信息类型 | 融合规则 |
|---------|---------|
| **战争名称** | 优先采用最常用名称 |
| **时间** | 取最精确的时间标注 |
| **地点** | 合并所有提及的战场 |
| **指挥官** | 合并所有提及的将领（标注来源） |
| **规模/伤亡** | 保留所有不同说法，标注来源 |
| **结果** | 若有矛盾，全部保留并标注 |
| **战争经过** | 按时间顺序整合叙述 |

#### 矛盾处理

不同章节对同一战争的记载可能矛盾，处理原则：

```markdown
### WAR-042 长平之战
- **伤亡情况**:
  - 《白起王翦列传》(073-005): 坑杀赵卒四十五万
  - 《赵世家》(043-012): 前后死者四十万
  - **矛盾说明**: 两说相差5万，可能因统计口径不同（是否含战死者）
```

### 4.4 第四阶段：细节补充

从原文中补充关键细节：

- 回到标注文本（`*.tagged.md`）查找战争描述段落
- 提取战术、转折点、名言等细节
- 补充太史公曰中的战争评价

## 5. 战争类型体系

### 5.1 按性质分类

| 类型 | 说明 | 典型例子 |
|------|------|---------|
| **国家战争** | 诸侯国间的正式战争 | 长平之战、邲之战 |
| **兼并战争** | 以灭国为目的的战争 | 秦灭六国、楚灭鲁 |
| **平叛战争** | 镇压叛乱 | 七国之乱、陈胜吴广起义 |
| **民族战争** | 华夏与周边民族 | 汉匈战争、楚伐濮 |
| **统一战争** | 改朝换代的系列战争 | 秦灭六国、汉灭项羽 |
| **内战** | 同一政权内部 | 楚国白公之乱、晋国内斗 |

### 5.2 按规模分类

| 规模 | 标准 | 典型例子 |
|------|------|---------|
| **特大** | 参战10万+或改变历史格局 | 长平之战、巨鹿之战 |
| **大型** | 参战5-10万或影响国运 | 城濮之战、马陵之战 |
| **中型** | 参战1-5万或区域性影响 | 鄢陵之战 |
| **小型** | 局部冲突 | 边境小规模战斗 |

### 5.3 按时代分类

| 时代 | 时间范围 | 战争特点 |
|------|---------|---------|
| **上古** | 前2700—前1600年 | 神话传说色彩浓厚（涿鹿之战） |
| **三代** | 前1600—前771年 | 宗法制下的征伐（武王伐纣） |
| **春秋** | 前770—前476年 | 礼仪战争、车战为主 |
| **战国** | 前475—前221年 | 兼并战争、步兵崛起 |
| **秦汉** | 前221—前87年 | 统一战争、汉匈战争 |

## 11. 已知难点与解决方案

### 11.1 战争名称不统一

**问题**: 同一战争在不同章节可能用不同名称：
- "长平之战" vs "秦赵长平之役"
- "鸿沟之约" vs "楚汉相约中分天下"

**方案**:
- 建立战争名称同义词表
- LLM辅助识别同一战争的不同称谓
- 采用最常用名称作为主名称，其他作为别名

### 11.2 系列战争的粒度

**问题**: "秦灭六国"是一个战争还是六个？

**方案**:
- **战役级**: 每场独立战役为一个事件（秦灭韩、秦灭赵...）
- **战争级**: 系列战役合并为大战争（秦统一战争）
- 两个层级都保留，建立父子关系

### 11.3 时间跨度大的战争

**问题**: 有些战争持续数年（如汉匈战争），时间标注如何处理？

**方案**:
- 使用时间范围标注：`(公元前133年—前119年)`
- 将长期战争拆分为多个阶段战役
- 建立总体战争条目 + 具体战役条目的层级结构

### 11.4 传说与史实混杂

**问题**: 上古战争（阪泉、涿鹿）史实性存疑。

**方案**:
- 在`certainty`字段标注可信度（legend/uncertain/confirmed）
- 年代标注使用 [约...] 表示不确定性
- 在描述中注明"传说"或"据《史记》记载"
