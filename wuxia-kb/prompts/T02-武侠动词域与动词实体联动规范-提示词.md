````text
**3.1 上游已定版契约：SKILL_01g 武侠版（v0.3-draft）动词层基线摘要**

> 以下为已定版结论的忠实摘要，是本任务的不可推翻基线（推翻须走附录 B 申请）。完整规范见 `wuxia-kb/skills/SKILL_01g_标注符号集合原则.md`。

**符号体系**：
- 外层括号：`⟦⟧`（U+27E6/U+27E7），与实体层 `〖〗`、修辞层 `〘〙` 三层分离，互不嵌套、不交叉、不重叠；
- 六域符号（方形动词族，与实体符号形状系列分离——史记 ◆/◈ 菱形混淆的教训）：

| 符号 | 动词域 | 说明 | Unicode |
|------|--------|------|---------|
| `⊞` | 战斗交锋 | 交战、比武、攻击、防御性对抗、战斗控制及明确战斗结果 | U+229E |
| `⊠` | 生命健康 | 出生、死亡、杀伤、致残、中毒、治疗、救活及健康状态变化 | U+22A0 |
| `⊡` | 社会关系 | 拜师、结义、婚姻、任命、继任、入派、叛离、结盟等关系建立或变更 | U+22A1 |
| `⊟` | 物件变化 | 制造、取得、赠借、买卖、夺取、返还、丢失、毁损等物件状态或归属变化 | U+229F |
| `▣` | 技术传习 | 传授、修习、偷学、悟得、练成、失去或恢复技术能力 | U+25A3 |
| `■` | 行踪迁移 | 到达、离开、迁居、押送、追踪等具有行程意义的位置变化 | U+25A0 |

**设置理由要点**（设计须继承）：
- 战斗域承担交锋，不承担全部死亡和伤病；生命健康域覆盖自然死亡、出生、治疗——避免只标杀戮漏掉生平核心；
- 物件变化域统一物件生命周期；交易、强夺、制造、毁损用子型区分；
- **不另设"救援域"**：救出被囚者→⊡（解除拘禁）、救活重伤者→⊠（治疗）、抢回宝物→⊟（物归原主）；救援的情愿/不情愿/暗救（manner）与交战的压制/险胜等修饰属**事件登记属性**，不改变动词域归属；
- 行踪迁移只标**行程级**位置变化，不标姿态调整与战斗退步。

**主域裁决基线**（12 行，已定版）：

| 动作 | 主域 | 补充登记 |
|------|------|----------|
| 杀死某人 | 生命健康 ⊠ | 可关联所属战斗 |
| 砍断宝剑 | 物件变化 ⊟ | 可关联战斗与攻击方式 |
| 擒住对手 | 战斗交锋 ⊞ | 状态为被控制；必要时另记拘押状态 |
| 把某人押往京城 | 行踪迁移 ■ | 强制性、押送者、起讫地点 |

| 被逐出门派 | 社会关系 ⊡ | 组织成员关系终止 |

**触发词边界基线**（已定版）：
- 取最小而能表达主要动作或结果的连续单位；"杀死、夺走、救活、练成"**保留结果补语**；
- 不含主语、宾语、普通程度副词和标点；否定、条件、未来标记在外，但必须进入事件状态判断；
- 一个触发区间只标一个主域；复合动作确有两个连续事实时分别标注（`⟦⊞击倒⟧对手，随后⟦⊠杀死⟧了他`）；
- 动词触发区间不吞宾语（`⟦▣传授⟧〖☆某剑法〗`，不写 `⟦▣传授某剑法⟧`）；
- **不是所有动作都标**：日常吃饭喝茶转头抬手不进六域；战斗中的侧身、跃起、退步一般不单独标；有战术结果的招架、格挡、反击可进战斗域；"双方僵持不下"登记状态不强造动词；名词谓语句允许无动词入口（"他已是掌门"照抽任职状态）。

**事件状态与 outcome 基线**（已定版）：
- 五状态字段：发生状态（已发生/正在发生/计划/条件/未发生/未知）、完成状态（完成/未遂/中断/未知）、信息来源（叙述/人物发言/书信/告示/转述/回忆）、可信状态（已核实/来源声称/存疑/相互冲突）、叙述模式（正常叙事/回忆/梦境/假想/戏中戏）；
- 默认生产策略：未发生、纯计划、纯条件动作→实体照标、动作默认不标；已实际施行的未遂动作→可标、必须记未遂；传闻和文书对已发生动作的声称→可标、不升级为事实；梦境假想→默认不标；
- outcome 五值：胜/负/平/未决/未知；必须指定参照方；双方停手≠平；后退/逃走/兵器被夺≠整场负；
- "逼退三步"只记局部结果，不判整场负。

**其他相关基线**（已定版）：
- 消歧语法沿用史记：`⟦TYPE动词|消歧说明⟧`（如 `⟦⊞走|逃走⟧`）——武侠版的具体消歧场景由本任务定版；
- 已标注实体内部不得拆出动词标注（嵌套禁令）；单字优先与复合拆分的**史记铁律已被武侠"结果补语保留"规则调整**，武侠版判别标准由本任务定版；
- 武功习得阶段论：看过/听过/记住/修习/练成是不同阶段；使用某招≠掌握整套功法（▣域的事件字段须能区分阶段）；
- 正式师承与单次传授分开（▣传授 ≠ ⊡拜师）；情感/恩义/背叛/主仆四类人物关系**不设行内符号**（§9.2 登记层离线表），动词联动不得为它们造行内标记；

**3.3 武侠动词领域特征清单**（与史记语料的系统性差异，设计必须逐项回应）：

1. **白话双音节动词主导**：打败/杀死/救活/抢走/学会/点倒——文言单字优先规则不适用，需要"核心动词+结果补语"的组合结构；
2. **招式名嵌在动作句里**：招式名常带引号、含数字（七十二手连环剑）、含意象（天外飞仙），且句式多样（"使出""一招""按照……的招数"）——实体/动词边界判定是武侠独有问题；
3. **传艺链条是主线剧情**：拜师-授艺-偷学-悟得-练成-传给下一代，跨回跨书生长——▣域要支撑武功页的完整传习链；
4. **内力机制**：运功/疗伤/闭关/渡功/传功/废武功（挑断手筋、化去内力）——史记完全没有的"技术-生命混合状态变化"；
5. **点穴与擒控**：点穴/点倒/解穴/擒拿/禁锢/挟持——旧"擒控"语义须在六域内落位；
6. **兵器流转高频**：赠剑/夺刀/铸剑/断剑/借兵刃/掷还——⊟域是神兵谱的数据源；
7. **毒药迷香**：下毒/中毒/解毒/蒙汗药——⊠与⊟、⊞的交叉裁决点；
8. **未施行动作占比远高于史记**：白话对话中的威胁/承诺/计划（"我要杀你""待我练成"）——默认生产策略的适用密度高；
9. **官府线**：追捕/缉拿/押送/劫囚/通缉——■与⊞、⊡的交叉；
10. **轻功与超常移动**：纵身/掠出/疾行/千里一夜——■的下限与设定内合理性（行踪地图真实感）。

## 技能概述

### 目标

为《史记》文本中的动词进行语义标注，将历史叙事中的核心行为动作标记为结构化实体，用于：
- **事件提取**：自动识别军事行动、刑罚事件等历史事件
- **关系挖掘**：建立主语-动词-宾语的三元组关系
- **语义检索**：按动词类型检索特定事件
- **统计分析**：量化分析军事冲突频率、刑罚执行模式等

### 核心价值

1. **事件核心要素**：动词是历史事件的核心，标注动词等于标注事件
2. **关系桥梁**：动词连接主体与客体，是关系抽取的关键
3. **语义区分**：区分动词与名词（⟦◉杀⟧ vs 〖[斩首〗），语义更精确
4. **可计算性**：结构化的动词标注便于量化分析和模式挖掘

## 标注体系

### 1. 符号系统

**外层符号**: `⟦⟧` (U+27E6/27E7 数学双方括号)

**与名词实体的区分**：
| 维度 | 名词实体 | 动词实体 |
|------|---------|---------|
| 外层符号 | `〖〗` (白色龟甲括号) | `⟦⟧` (数学双方括号) |
| TYPE符号 | 文本符号（@=;%等） | 几何符号（◈◉○◇） |
| 语义功能 | 事件参与者（主/宾语） | 事件核心（谓语） |
| 用途 | 实体识别 | 关系识别 |

### 2. 动词类型

## 标注规则

### 规则1：识别原则

✅ **应该标注**：
- 军事行动：伐/攻/击/战/破/败/灭等
- 刑罚处决：杀/诛/斩/弑/族等
- 明确的及物动词，有主语和宾语
- 可用于事件提取和关系抽取的关键动词

❌ **不应标注**：
- 日常动词：行/坐/立/言/语
- 助动词：能/可/是/为
- 趋向动词：来/去/上/下（除非军事机动）
- 一般性动作：见/闻/知/思

### 规则2：消歧原则

**何时需要消歧**：
1. 同形异义（如：走=逃亡/行走，取=攻取/获取）
2. 跨类歧义（如：亡=军事逃亡/逃避刑罚）
3. 与名词混淆（如：围=动词包围/名词包围圈）

### 规则3：标注边界

- **单字优先**：`⟦◈伐⟧` `⟦◉杀⟧`
- **复合动词拆分**（推荐）：`⟦◈击⟧⟦◈破⟧` 而非 `⟦◈击破⟧`

### 规则4：语法约束

✅ **正确**：`⟦◈伐⟧〖◆随〗` `⟦◈击|攻击⟧〖◆楚〗`

❌ **错误**：`⟦⟦◈伐⟧⟧` `⟦◈〗` `〖◈伐〗` `⟦@伐⟧`

### 规则5：禁止嵌套标注

**严禁嵌套**：动词标注符号 `⟦⟧` 内部不得包含其他标注符号（动词或名词）

❌ **错误模式**：
- `⟦◈⟦◈攻⟧击⟧` — 动词嵌套动词
- `⟦◈攻〖◆秦〗⟧` — 动词包裹名词实体
- `⟦◈击⟦◈破⟧⟧` — 复合动词嵌套

✅ **正确模式**：
- `⟦◈攻⟧⟦◈击⟧` — 复合动词分开标注
- `⟦◈攻⟧〖◆秦〗` — 动词和名词实体分开
- `⟦◈击⟧⟦◈破⟧〖◆楚〗` — 动作序列平铺标注

**特别说明**：
- 复合动词（击破、攻灭等）应拆分为独立动词：`⟦◈击⟧⟦◈破⟧`
- 动词的主语和宾语用名词实体标注，与动词标注并列：`〖◆楚〗⟦◈伐⟧〖◆随〗`
- 嵌套检测由 `scripts/lint_text_integrity.py --check-nested` 自动完成

## 常见错误及修正

### 错误1：混淆动词与名词

❌ `⟦◉斩首⟧八万`
✅ `〖[斩首〗八万`

**说明**：「斩首」是刑罚制度名词，应用 `〖[legal〗`

### 错误2：过度标注日常动词

❌ `〖@项羽〗⟦行⟧至〖=鸿门〗`
✅ `〖@项羽〗行至〖=鸿门〗`

**说明**：「行」是日常动词，不标注

### 错误3：缺少必要消歧

❌ `〖@子常〗⟦◈走⟧奔〖◆郑〗`
✅ `〖@子常〗⟦◈走|逃亡⟧奔〖◆郑〗`

**说明**：「走」有歧义（逃亡/行走），需消歧

### 错误4：错误的TYPE符号

❌ `⟦@伐⟧〖◆随〗`
✅ `⟦◈伐⟧〖◆随〗`

**说明**：军事动词用 `◈`，非人名符号 `@`

### 错误5：错误的外层符号

❌ `〖◈伐〗〖◆随〗`
✅ `⟦◈伐⟧〖◆随〗`

**说明**：动词用 `⟦⟧`，名词用 `〖〗`

**理由**：动词格式迁移容易引入隐蔽错误（如嵌套、分割不对），且全书已稳定。迁移应由专项工具有计划地推进，不得在反思任务中"顺手改"。

**扫描验证**：任何反思任务结束前必须 `grep -c '⟦[◈◉○◇]'` 前后计数一致（只增不减）。

## V.3 政治动词规律 ⟦○⟧

### V9. 政治动词核心清单（2026-04-17 扩展）

政治动词表示君主/权力机构对人/地/权位的安置与变动。

| 动词 | 含义 | 典型语境 |
|---|---|---|
| `⟦○立⟧` | 立某人为王/帝/侯 | `⟦○立⟧〖@X〗为〖;王〗` |
| `⟦○封⟧` | 分封土地/爵位 | `⟦○封⟧〖@X〗为〖;侯〗` |
| `⟦○拜⟧` | 拜任官职 | `⟦○拜⟧〖@X〗为〖;丞相〗` |
| `⟦○赐⟧` | 赏赐（爵/金/邑）| `⟦○赐⟧〖@X〗爵〖#列侯〗` |
| `⟦○益⟧` | 增益食邑/封户 | `⟦○益⟧〖○食⟧〖$X户〗` |
| `⟦○食⟧` | 享有食邑 | `⟦○食⟧〖=邑名〗〖$X户〗` |
| `⟦○谥⟧` | 赐谥号 | `⟦○谥⟧为〖@X侯〗` |
| `⟦○废⟧` | 废黜（君主/太子）| `⟦○废⟧〖#太子〗` |

| `⟦○崩⟧` | 天子/皇帝死亡 | `〖#帝〗⟦○崩⟧` |
| `⟦○薨⟧` | 诸侯/大臣死亡 | `〖;丞相〗⟦○薨⟧` |
| `⟦○卒⟧` | 士大夫死亡 | `〖@X〗⟦○卒⟧` |
| `⟦○举⟧` | 推举贤才（选拔）| `⟦○举⟧〖@贤〗` |
| `⟦○荐⟧` | 推荐某人 | `⟦○荐⟧〖@X〗` |
| `⟦○辟⟧` | 辟除（征召入幕）| `⟦○辟⟧〖@X〗为〖;掾〗` |

**君主死亡三词（崩/薨/卒）说明**（2026-04-17 新增）：
- **为什么是政治动词**：君主/诸侯/大臣的死亡是**权力更替事件**，触发嗣位、国除、谥号等一系列政治安排，是 KG 中关键的时间锚点
- **与刑罚动词"死"的区分**：
  - `⟦◉死⟧` / `⟦◉死|处死⟧` 表处决或主动赴死（刑罚结果）
  - `⟦○崩⟧` `⟦○薨⟧` `⟦○卒⟧` 表自然死亡/事件节点（政治事件）
- **与家族动词的关系**：君主死亡**同时是谱系事件**，可选双标 `⟦○崩⟧⟦♂崩⟧`，但默认使用单一 `⟦○⟧` 避免冗余
- **扫描模式**：`(?<!⟦○)崩/薨/卒(?![a-zA-Z])` — 全书候选约 2000+ 处

**选拔/推举并入政治说明**（2026-04-17）：
举/荐/辟 原考虑独立分类，最终并入 `⟦○⟧` 政治，因三者都是**君主/权臣对人才的安置行为**，语义与拜/封同类。

### V10a. `所食` 的语境分化（2026-04-17 订正，030/043/117 章）

"所食" 不能盲目标 `所⟦○食⟧`，必须按语境分化：

| 语境 | 正确 | 理由 |
|---|---|---|
| 除前**所食** (邑/地名) | `除前所⟦○食⟧` | ✓ 封邑的所食（享有食邑）|
| **无所食** / 无可食 | `无所食`（不标）| ✗ "吃"/"食物"义，非政治 |
| 尝**所食** 饿人 | `尝所食桑下`（不标）| ✗ "供食、给吃"义 |
| 民**无所食** | `民无所食`（不标）| ✗ 民众无粮可吃 |

**安全正则**：`所⟦○食⟧` 只应出现在 `除前所⟦○食⟧` 固定搭配中，**前面必须有"前"字**。

```python
# 错误：
(r'(?<!⟦)所食', r'所⟦○食⟧')
# 正确：
(r'前所食', r'前所⟦○食⟧')
```

### V10. `⟦○食⟧` 的三种用法（2026-04-17，095 章）

"食" 作政治动词有三个固定复合：

| 模式 | 标注 | 例 |
|---|---|---|
| 益/定/更/所食 | `益⟦○食⟧` `定⟦○食⟧` `更⟦○食⟧` 所⟦○食⟧` | `益⟦○食⟧〖$千户〗` |
| 食 + 地名 | `⟦○食⟧〖=地名〗` | `⟦○食⟧〖=汝阴〗` |
| 食邑 + 地名/户数 | `⟦○食邑⟧〖=地名〗` | `⟦○食邑⟧〖=涿〗〖$五千户〗` |

**排除语境**：
- 饮食（如 `饮食`、`食客`、`食肉`）→ 不标
- 粮食（如 `兵食`、`食尽`）→ 不标

### V13a. "X + 兵/卒" 军事复合的避标（2026-04-17，005 章订正）

**禁止**把 `发兵/起兵/引兵/罢兵/聚兵/收兵/徵兵` 这类**军事复合动作**标为政治动词，哪怕前字"罢"单用是政治。

### V13. 并列政治动词的单独标注（2026-04-17，095 章）

```

### V14. `⟦○国除⟧` 整词标注（2026-04-17，25 章共 430 处统一）

"国除"是**封国废除**的固定政治事件，作为**复合政治动词整体标**：

```
✅ 〖@X〗有罪，⟦○国除⟧。
✅ 无后，⟦○国除⟧。
❌ 〖#国〗除  （不拆为"国+除"）
❌ ⟦○国⟧⟦○除⟧  （不拆为两个动词）
```

**理由**：
- "国"指代特定封国（这个侯国），不是泛指
- "除"是动作（废除）
- 两字共同构成固定政治事件表述
- 年表章（017-021）高频出现，占 396 处

### E10. `〖:X〗` 旧格式迁移（2026-04-17，083 章发现 + 095 章印证）
````
