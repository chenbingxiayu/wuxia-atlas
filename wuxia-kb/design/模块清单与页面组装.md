# 江湖图志 前端模块清单与页面组装

> v1（2026-11-05）。基于 `设计文档/重构设计/` 十五份重构设计提取的前端模块清单；可视化设计画布见本目录 `design/`（design skill 画布，浏览器打开可交互查看）。
> 设计语言：沿用 `site/src/styles/tokens.css`——宣纸 `#f5efe4` / 浓墨 `#2b2b2b` / 印章红 `#a63a2b` / 黛青 `#34546e` / 泥金 `#b8860b` / 竹青 `#5e7d5a` / 幽灵 `#b9b1a2`；标题 Noto Serif SC、正文 LXGW WenKai、定位符 JetBrains Mono。

## 一、模块清单（按层级）

### L1 设计原子（全站共用，tokens 直接映射）

| 模块 | 来源文档 | 说明 |
|---|---|---|
| 色彩/字体/间距 tokens | 全站 | site tokens 直接沿用 |
| **定位符链接 LocLink** | 全站 | `书·回:行` mono 徽标，chapterHref 补零可点回目页——全站"对质"承诺的原子 |
| **置信徽章 ConfBadge** | 人物/问答/武评 | ●●/●○/○○（high/medium/low）；文字档：强证/确证/线索 |
| **分档徽章 TierBadge** | 武评/名物/门派 | 绝顶(泥金)/超一流(印)/一流(黛)/二流/三流(幽灵)；品阶：明文实底/待考虚线 |
| **实体徽章族** | 全站 | 跨书换乘(印框)/跨书/层级(统称·套·招)/类型(名门正派·世家·绿林·朝廷) |
| **状态徽章** | 全站 | 深度解析(竹青实)/建设中(金虚)/存目(幽灵虚)/考订中 |
| **Chip 族** | 全站 | 实体 chip（含 ×频次 下标）/可点/选中态；谓词 chip（传授/拥有/镇山…） |
| **EmptyState 空态族** | 全站 | 档案未载 / 记载简略（条目说明条）/ 江湖风平浪静 / 世系考订中 |

### L2 结构组件

| 模块 | 来源文档 | 说明 |
|---|---|---|
| Breadcrumb | 全站 | 用户词，无内部编号 |
| SectionHeader | 全站 | h2 + dim 说明（说明收用户词） |
| StatsBar | 全站 | `N 条 · M 书 · K 起` 构建期计算 |
| SearchBox + 联想 | 人物/武功/名物/问答/地图 | 命中规范名+**别名**+招式名；datalist |
| Tabs/PillNav | 名物(谱切换)/武评(榜域)/门派(全派导航)/宇宙(三件套) | 胶囊 tab 族 |
| FilterBar | 武评/人物 | 榜域/分档/门派/只看跨书 开关组 |
| CardGrid | 全站 | 人物卡/名物卡(剪影+品阶)/门派卡/文章卡/游戏卡/图鉴卡 |
| EvidenceList | 武功/名物/人物/问答 | 谓词+人物+定位符 行列表 |
| Timeline | 宇宙/名物/门派 | 流转时间线(verb 徽章行)/双轨编年行/世系 tenure 行(继任三档) |
| Table+Expand | 武评/问答 | 榜行内证据链展开 |
| 分层展示 | 人物/门派/游戏 | 主要人物/其余（存目）分组 + 展开控件 |

### L3 功能模块（带行为）

| 模块 | 来源文档 | 说明 |
|---|---|---|
| **CurveChart** | 专栏/人物/武评/宇宙 | 构建期 SVG 曲线族：温度曲线(双层)、主客曲线、WHR 巅峰曲线、出场曲线 |
| **MetroMap** | 首页/宇宙 | 地铁图（系列=线、书=站、状态=站形） |
| **WordCloud** | 宇宙 | 主角词云（字号∝频次、口径注、点击搜索） |
| **传承树** | 武功 | 按代分层 + 边四档（正式/记名/挂名/点拨）+ 跨书角标 |
| **MapShell 地图底座** | 地图/门派/人物 | Mercator+省界共享模块；势力层/事件层/共现层三图层 |
| **PlotMap 剧情地图** | 人物 | 锚点分色+编年编号+单条虚线+双向联动 |
| **全景势力地图** | 门派 | 实锚落点+类型着色+点击进派页 |
| **地名谱系卡** | 地图 | 坐标置信三色+沿革+关联门派 |
| **QA 组件族** | 问答 | 模板 chips/自然语言路由框/答案卡（聚合+存疑标注+口径注+复制深链） |
| **Game 组件族** | 游戏 | 谜题卡/人物测试卡/图鉴收集卡/战绩中心/今日论战卡/"小说中的今天"卡 |
| **五段式说书页** | 专栏 | 命题→图表→读图→证据链→方法（单一模板页渲染） |
| ** 武评榜** | 武评 | 主榜行/单挑榜/待考区折叠/代表作卡 |

## 二、页面组装（模块 → 15 页）

| 页面 | 组装（L1/L2/L3 模块序列） |
|---|---|
| **首页** | Hero(统计条 StatsBar) → 每日区(游戏卡+小说中的今天卡) → MetroMap → Showcase(CurveChart 缩略+武评 Top5+问答示例卡) → 主入口六卡(CardGrid) → 次级行 → 页脚 |
| **作品** | 书列表(表格) → 书页(StatsBar+CurveChart 节奏指纹+人物 chips+互文边) → 回目页(事件流=主谓宾+LocLink) |
| **人物总览** | SearchBox(别名命中) + 分层展示 + Chip 流 |
| **人物档案** | 头部 → 别名 → 人物志占位 → **关键剧情列表** → **PlotMap** → **关系区** → 师承/册立 → 门派线索 → 武功 → 神兵持物 → 战绩 → 出场 CurveChart → 关键事件 EvidenceList → 武评卡 |
| **武功详情** | 头部(层级徽章) → **一生卡** → 原著评语(L1) → **传承树** → 门派归属 → 涉及者 → 招式名表/未归套区 → 证据注记 |
| **名物详情** | 头部+**插图位** → 一生卡 → 来历 → 流转 Timeline(方向化+毁折叠) → 出场而非流转 → 终态卡 → 门派归属 → 持有人/借用 → 描写精选(L1) → 证据 |
| **门派总览** | **全景势力地图** → 分区(江湖三分+朝廷另册) → 分层 CardGrid |
| **门派详情** | 简介卡 → 驻地卡 → 镇山绝学 → 武功册 → 世系 tenure Timeline → 其余成员 → 恩怨对头 |
| **宇宙总览** | MetroMap → 三件套入口卡 → **主角词云** → 种子卡片行(生命弧) → 悬案墙 |
| **编年史** | 双视图切换：书级双轨 Timeline / 事件年谱（朝代折叠+纪年四档+冲突对照） |
| **宇宙网络** | PathFinder(AB 路径) + NetworkGraph(降级+过滤) |
| **互文图谱** | 环状 SVG + 边清单(真实 locs) |
| **行踪地图** | MapTrail 岛：滑块+播放+人物多选+图层开关(共现/势力/事件)+地名谱系卡+跨书断点 |
| **武评总榜** | FilterBar + 榜 Table(证据链展开) + 单挑榜 + 待考区 + 代表作卡 + WHR 曲线入口 |
| **游戏游乐场** | hub 卡墙 + 每日一谜 + 二十问答 + 人物测试 + 图鉴 + 战绩中心 + 小说中的今天 |
| **专栏篇页** | 五段式说书模板页 + index 卡墙 |
| **问答** | 自然语言路由框 + 模板 chips + 答案卡 + 复制深链 + 示例卡 |
| **穿帮雷达** | 总览统计 → 穿帮报告墙 → 规则覆盖墙 → 豁免清单 → 死亡一致性专区 |
| **关于/搜索** | 静态四页 + Pagefind |
