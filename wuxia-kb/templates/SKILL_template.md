# 项目 SKILL 通用模板（武侠版）

> **怎么用**：复制本文件到 `skills/<SKILL_编号>_<主题>_武侠版.md`，全文替换 `<...>` 占位符；删除本说明块。写完后跑 `python -X utf8 scripts/lint_skills.py "skills/<你的文件>.md"`，目标 **PASS（score ≥90，建议 100）**。
>
> **三条纪律**（承 docs/05 迁移总纲）：① 某一本书/某一次事件专属的内容不进 Skill；② 规范唯一来源是 SKILL 正文与 `registry/`，references 只做规律累积；③ 不确定的写成"待补/待裁"进附录 B，不写成定论。

## frontmatter 骨架（必填字段，勿改名）

```yaml
---
name: skill-<节点号>-wuxia            # 例：skill-04d-wuxia；小写、连字符
title: <中文标题（含"从…到…"式价值句，≤40 字）>
description: <一段话说清：做什么、依据哪份设计稿、产出什么、何时使用；建议 120-200 字，含触发场景关键词>
version: v0.1-draft                   # v0.1-draft → v0.1 → v1.0（冻结）
last_updated: YYYY-MM-DD
---
```

> 可选扩展：`scope:`（覆盖范围一句话）、`source:`（设计稿/迁移来源）。`name/title/description` 三项缺一即 lint FAIL（error）。

## 一、快速开始（≤150 行，必须）

> **写作要求**：给"拿到一份产物后 5-10 分钟内能跑通"的最短路径。命令一律用 `python -X utf8 scripts\...`（Windows/UTF-8），只读或写报告优先；写数据的步骤先 dry-run。**不要**把全流程塞进来（详细步骤放核心方法）。

```powershell
cd C:\Users\YANG Ruosong\Documents\workspace\Wuxiaxiaoshuo\wuxia-kb
$env:PYTHONIOENCODING='utf-8'

# Step 1 <前置检查：结构门/工具自检>
python -X utf8 scripts\<script>.py <args>

# Step 2 <主操作：解析/校验/生成，只读或出报告>

# Step 3 <读产物：哪个 JSON/报告、看哪些字段>

# Step 4 <复核：重跑/断言/门禁>
```

**判读口径**：<3-5 行说明各步看什么、什么算通过、异常先查哪里>。
