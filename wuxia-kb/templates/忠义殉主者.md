# 页型模板 · 忠义殉主者（人物档案页 · W8）

> **本文是什么**：W8 精品页的**页型模板**（page-type template），不是人物卡 Schema 的替代。人物卡（`SKILL_08a_SKU字段_武侠版.md` 五卡 schema / `registry/sku/cards.json`）提供**字段数据**；本模板规定"这类人物的页面怎么组织、哪些节必须有、哪些是加分项、哪些写法是反例"。
>
> **W8 原则**（docs/05 §2.6）：**以事实收集为主，降低分析比重**；页型反思机制照搬；史记"太史公曰"式门槛改为**作者按语门槛**（无可靠依据不写评述）。
>
> **五段式骨架**（迁移自史记 templates/忠义殉主者.md）：**适用判断 → 必有节 → 加分项 → 反面示例 → 参考页面**。同族页型（门派覆灭者/武功失传者/师门叛徒）复用同一骨架，只换"适用判断"与"必有节"。

---

## 一、适用判断（什么人物用这个页型）

### 1.1 判定条件（三条同时满足）

| # | 条件 | 判据 | 数据来源 |
|---|---|---|---|
| 1 | **殉主/殉义行为** | 为保护主公、恩主、师门、信义而主动赴死或以身相代（非战斗意外、非病故） | D03 事件（T02 生死杀伐/T11 生死救治）+ `ending.type` |
| 2 | **行为有叙事分量** | 该死亡/殉身事件在书中有独立场面或明确因果链（≥1 段叙述，非一句带过） | D03 事件 `life_events` / D05 时点键 |
| 3 | **忠义关系可溯** | 与所殉对象之间存在可证的关系边（主仆/师承/结义/恩义）或明文"为主/为义" | D06 关系边 + `faction_history`/`kinship` |

### 1.2 不适用（转其他页型或普通人物页）

- 战死沙场但无"为主/为义"关系证据 → 普通人物页（死亡事件照记）；
- 为主公而死但无独立场面、无关系边 → 普通人物页 + 事件索引（不升精品页）；
- 被主子所害（非殉主）→ 普通人物页（仇怨/杀害关系照记）；
- 同族页型：门派覆灭者（门派卡+末代成员）、武功失传者（武功卡+最后传人）、师门叛徒（师承树+隶属终止边）。

### 1.3 页型选择决策

```text
人物有"为他人/为信义而死"的可证行为？
  ├─ 是 → 有独立场面 + 关系边可溯 → 忠义殉主者（本模板）
  │        └─ 关系边缺失 → 先补关系层（D06/N5）再判
  └─ 否 → 普通人物页 / 其他页型
```

## 二、必有节（缺一不可，按顺序）

> 每节给"槽位来源"（SKILL_08a 人物卡字段 / registry 产物），页面生成器按槽位取数，人工写页按槽位核对。

### 2.1 档案头（Header）

| 槽位 | 来源 | 要求 |
|---|---|---|
| 规范名 + 展示名 | `name.canonical` / `display`（D07 双层） | 标题用 display，正文首次出现给 canonical |
| 别名/绰号组 | `aliases[{surface,type}]` | 只列有出处的别名；无则省略 |
| 身份标签 | `identity_tags`（D08 身份树叶子） | 1-3 个叶值；含"处境身份"如义仆/死士 |
| 一句话命题 | `meta.proposition`（≤100 字） | 事实性归纳，不写评价 |

### 2.2 关系与阵营（Relations）

| 槽位 | 来源 | 要求 |
|---|---|---|
| 所殉对象 | D06 关系边（主仆/师承/结义/恩义） | **必填**；给 edge_ref 与证据 loc |
| 门派/阵营履历 | `faction_history[{faction_ref,role,edge_ref,conf}]` | 含任职/隶属区间 |
| 师承/亲属/结义 | `teachers`/`kinship`/`romance` | 有则列，无则 `[]`（不虚构） |
| 同门/同伴 | D06 同门派生（derived） | 标 derived，不混人工边 |

### 2.3 殉主事件（Core Events）

| 槽位 | 来源 | 要求 |
|---|---|---|
| 事件引用 | `life_events[]`（D03 event_id） | 殉身事件 1 条 + 前因事件 1-3 条 |
| 时间锚 | D05 时点键（`tp_id`/offset） | 无锚标"时点未锚"，不猜年份 |
| 结果/结局 | `ending{type,event_ref,summary,conf}` | type=殉主/殉义/代死…；summary 只写事实 |
| 死伤关联 | D03 死亡记录（T02/T11） | 独立死亡记录，不只在战斗栏 |

### 2.4 证据与可信（Evidence）

| 槽位 | 来源 | 要求 |
|---|---|---|
| 来源定位 | `meta.sources[]`（含 `#pn-r{N}.{X}` 指针） | 只存指针与短语概括，**不引原文长句** |
| 证据类型 | D06 E1/E2/E3 | 关系类名分须 E1 明文 |
| 可信度 | `meta.confidence`（D11 A-E） | 承重字段最低值；"来源声称"最高 C |
| 版本 | `meta.data_version`/`rule_version` | 必填 |

### 2.5 未定与边界（Open Questions）

- 关系缺失、事件时点未锚、身份多值未定 → 显式列出（"未明示"≠"无"）；
- 传说/传闻层内容标"传闻"角标，不进事实节；
- 与穿帮雷达（N8）冲突项列"已知冲突"，不静默删。

## 三、加分项（有则更好，不强制）

1. **关系网小图**：以所殉对象为中心的一跳关系（D06 边 + EX-4 graph 数据），标置信分层；
2. **同族页型互链**：门派覆灭者/武功失传者/师门叛徒页互链（同书/同门派）；
3. **跨书身份**：`active_books`/`first_appearance`（D07 派生）——同名跨书时标明"本书内身份"；
4. **时间线小条**：殉身事件前后 3 个时点（D05 时点键排序）；
5. **作者按语**（有门槛）：仅在证据充分且有定版解读时写 ≤120 字按语；无依据不写（W8 原则）；
6. **引文回锚**：关键判断附 `#pn-r{N}.{X}` 指针（不贴原文）。

## 四、反面示例（写页时禁止）

| # | 反例 | 为什么错 | 正确做法 |
|---|---|---|---|
| 1 | 页面写"他为主公而死，忠义无双"但无关系边/事件引用 | 评价代替事实（W8 原则）；不可复核 | 先补 D06 边 + D03 事件，再写事实句 |
| 2 | 贴原文整段（≥10 字连续重合） | 版权红线（R1）；违反"不携带原文片段" | 概括语＋回锚指针 |
| 3 | 未知门派强填"武当" | 未知强填（K5）；设定造假 | `faction_history=[]` + "未明示" |
| 4 | 把"被主子所杀"写成"殉主" | 因果倒置；关系方向错 | 按 D06 边（杀害/仇怨）写普通人物页 |
| 5 | 把传闻（"据说他为主尽忠"）写成事实 | 传闻未降权 | 标"传闻"角标，conf≤weak，不进事实节 |
| 6 | 殉身事件无时点键却按叙述印象排序 | 时间线错序（K14） | 标"时点未锚"排后，或补 D05 时点键 |
| 7 | 把同门/同伴关系写成师承 | 名分无 E1 证据 | 按 D06 derived 同门标注 |
| 8 | 卡片 ID 写中文名/`card.*` 进关系字段 | 卡实 ID 混用（K4） | 关系/事件字段只写实体 ID |

## 五、参考页面（页面结构示意）

```text
/characters/<slug>            # slug 保持 canonical（D07/Astro 约定）
├─ 档案头（display 名 + 别名 + 身份标签 + 命题）
├─ 概览卡（所殉对象 / 阵营 / 结局 / 可信度）
├─ 关系（所殉对象、师承、同门；一跳关系图）
├─ 殉主事件（事件卡：前因 → 殉身 → 结果；时点键）
├─ 证据与来源（指针列表 + 版本）
├─ 未定与边界（未明示项、传闻角标、已知冲突）
└─ 关联页（门派/武功/同族页型）
```

> 页面数据来源：`registry/sku/cards.json`（N10 五卡）+ `registry/relations/`（D06/N5）+ `registry/time/`（D04/N4）+ `registry/gazetteer.json`（D10，若涉地点）。页面只做投影，不重算上游字段（K6）。

## 八、页型质量检查清单

- [ ] 适用判断三条同时满足（殉主/分量/关系可溯），否则转普通人物页；
- [ ] 必有节 2.1-2.5 齐全（缺一不发布）；
- [ ] 所殉对象有 D06 关系边 + 证据 loc；名分类为 E1 明文；
- [ ] 殉主事件有 D03 事件引用 + 独立死亡记录（非战斗栏藏死伤）；
- [ ] 时点键可溯或显式"时点未锚"；不猜年份；
- [ ] 无原文连续 ≥10 字片段；引用只用指针；
- [ ] 未知项显式"未明示"，不虚构；传闻有角标；
- [ ] meta 九项齐备；投影制 ID；demo 卡不进发布；
- [ ] 作者按语有门槛（无依据不写）。
