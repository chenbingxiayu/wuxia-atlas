### SY01 · 标注符号三层集合：实体〖15 类〗/动词⟦6 域⟧/修辞〘※〙
- 类别: 三大符号集合
- 现象: 脚本各写一套字符类/白名单；令牌括号混用（实体括号套动词码）。
- 判据: 01g §二 定版：实体 15 类码（@人物 ◎群组 =地点 ◆组织 &家族 ~族群 ;职衔 #身份 ☆武功 •器物 +生物 {作品文书 ^概念 %时间 $数量）；
  动词 6 域（⊞战斗 ⊠生命 ⊡社会 ⊟物件 ▣传习 ■行踪）；修辞 1 类（※固定表达）；括号 〖〗/⟦⟧/〘〙 三层独立
  （01g §3.2 策略 2）。
- 动作: 所有 lint/fix/tag 脚本 import `scripts/symbols.py`（`ENTITY_CODES/VERB_CODES/RHETORIC_CODES`）；
  禁止脚本内重写字符类（01g 设计纪律）。
- 反例: 在临时脚本里 `re.compile(r'〖[@◆]')` 自建白名单——新增类型后漂移；一律走 symbols.py。
- 来源: `SKILL_01g` §二/§3.2；`scripts/symbols.py`（SPEC_VERSION 0.3-draft）。
- 状态: 已回写

### SY02 · 标点符号集合：原文标点不改，新增标点统一
- 类别: 三大符号集合
- 现象: 标注时顺手把底本标点改全角/半角；引号退化（DEF-09）。
- 判据: 标点集合与底本保真绑定：**原文标点不改**，新增标点统一（01g §3.2 策略 1/§2.1）；围栏内禁半角标点
  （02ab §4.2 铁律 4）；引号退化属誊写缺陷（03a1:DF09）。
- 动作: 字节级注入/回填，禁止手抄；`scripts/fix_halfwidth_quotes.py`；剥标对账。
- 反例: 把底本半角引号"统一"成全角——以底本为准，不以风格偏好为准。
- 来源: `SKILL_01g` §2.1/§3.2；`SKILL_02ab` §4.2；`references/03a1_DEF错误库` DF09。
- 状态: 已验证

### SY03 · Markdown 符号集合：结构标记不进正文/统计分母
- 类别: 三大符号集合
- 现象: `#`/`|`/`~` 等 Markdown 语义与标注码位冲突；"#" 既当标题又当身份码。
- 判据: Markdown 符号集合独立（01g §2.3）；冲突 2~8 有定版处理：`#` 标题与身份码靠三层括号区分（〖#身份〗
  不会与 `#` 标题混淆）；`|` 管道只在令牌内；`{` 与属性扩展冲突用 `{文书` 令牌形态规避（01g §3.3）。
- 动作: 正文中的 Markdown 结构（标题/列表/表格）不参与标注与统计（02f1:ST13）；令牌解析先剥 Markdown。
- 反例: 把 `# 身份` 当 Markdown 标题处理——令牌在〖〗内，按 token 解析优先（symbols.TOKEN_RE）。
- 来源: `SKILL_01g` §2.3/§3.3；`scripts/symbols.py` TOKEN_RE；`references/02f1` ST13。
- 状态: 已验证

### SY04 · 管道与显示串：显示串=原文区间全文，规范名只入管道
- 类别: 三大符号集合
- 现象: 管道吞原文（DEF-02）；绰号+本名连写时显示串未覆盖全区间（DEF-12）。
- 判据: `〖@显示名|规范名〗`：管道前=原文显示串（逐字），管道后=规范名/消歧说明；显示串必须覆盖原文区间全文，
  本名只能入管道（03a1:DF02/DF11）；剥标断言 `textContent==strip(tagged)` 拦截。
- 动作: 剥标逐字对账；`scripts/fix_annotation_mechanical.py`；批处理前先跑 lint。
- 反例: 把"玉面妖狐凌霄"的"凌霄"移入管道——显示串缺字，剥标失败。
- 来源: `SKILL_01g` §2.2.1a/§2.2.3a；`references/03a1_DEF错误库` DF02/DF11。
- 状态: 已验证

## B 区 · Disjoint 与边界

### SY05 · Disjoint 原则：同形实体只属一类，判别信号可执行
- 类别: Disjoint 与边界
- 现象: 同一词汇在不同上下文标不同类型（"掌门"标 `;` 又标 `#`）；同形异类无判据。
- 判据: 01g §三 Disjoint：同形实体只属一类；判别信号须可执行（词表/句式/字段）；同形异类判定表见
  §2.2.1b（如"剑法"能力域 ^ vs 具名武功 ☆）。
- 动作: 类型歧义→查 §2.2.1b/03e1 易混卡；新增类型须过 03e1 五原则 P2 正交；标注判例入 03a1。
- 反例: 用"语境不同"解释同形异类——语境不可执行，必须有词表/句式判据。
- 来源: `SKILL_01g` §三/§2.2.1b；`references/03e1` TY02/TY11-TY13。
- 状态: 已验证

### SY06 · 符号冲突 9 类与处理定版（`$` 公式/`#` 标题/`|` 表格等）
- 类别: Disjoint 与边界

### SY08 · 修辞层边界：固定表达才标 `※`，不入实体/动词
- 类别: Disjoint 与边界

- 判据: 修辞层 `〘※固定表达〙` 仅标固定表达（01g §2.2.2）；修辞标注启用后置，不参与实体/动词统计

- 动作: 修辞层默认观察档；`scripts/tag_new_entity_types.py` 不产修辞；启用需试点。
- 反例: 把"英雄儿女"标 `#`（它是评价/修辞）——身份须可指称个体集合，评价不是身份。

### SY10 · 族群 `~` vs 家族 `&` vs 身份 `#`（B1-3 裁定）
- 类别: 类型裁决
- 现象: "罗布族/哈萨克"被标 `&`/`#`/`◆`/`◎` 混用；"X族人"人义复合词误标。
- 判据: 附录 B-1 B1-3：特定族群名本体归 **`~族群`**（〖~罗布族〗）；泛称类名（外族/异族/名门望族）维持 `#`
  原状；「X族人」人义复合词**不标**（B1-2）；`&`=以血缘/婚姻/收养/谱系构成的具名**家族**（docs/53 §一 类型定义）。
- 动作: 逐处按语境改 `~`；"X族人"剥标；机器批残留按 docs/53 §一 修正（**13 token**：&/◆/◎罗布族 10 + #罗布族人 1 +
  &哈萨克(族) 2），残留 0。
- 反例: 把"罗布族人"拆成 `~罗布族`+人——B1-2 明确不标（拆词插入语义错位）。
- 来源: `SKILL_01g` 附录 B-1 B1-2/B1-3；`docs/47` §7.4；`docs/53` §一；`references/06e1` GR12。

### SY11 · 组织 `◆` vs 家族 `&` vs 群组 `◎` 边界
- 类别: 类型裁决
- 现象: 家族（唐家/卓家）标 `◆`；军队群体（官兵/大军）标 `◆`；群组 `◎` 与组织混淆。
- 判据: `◆`=组织（门派/帮会/朝廷/军队等有行为主体性）；`&`=家族世系（血缘/婚姻/谱系）；`◎`=人物群组
  （无建制层级的群体，如官兵/大军泛称）；task-45 判例：官兵/大军 ◆→◎、鲁王→@、塔山族→~。
- 动作: 三问测试（03e1 TY11 同源：行为主体/结构可指认/边界清晰）；过三问 → ◆ 按形态挂叶；不过 → 泛称不登记。
- 反例: 把"唐家"当门派 ◆——唐家是家族世系 &（但门派志页面可交叉引用，不改变类型）。
- 来源: `SKILL_01g` §2.2.1；`docs/53` §一；`references/03e1` TY11；task-45 改判（logs/qa/s03i_close_report.md）。
- 状态: 已验证

### SY12 · 时间 `%` 三管道 vs 数量 `$`：受控子标签与量词边界
- 类别: 类型裁决
- 现象: "十年/一轮/两位"混标；`%` 管道右侧被当规范名（实际是受控子标签：时点/时长/年龄）。
- 判据: `%` 三管道（时点/时长/年龄）+ `$` 数量（数量词/量词）；`$` 与 `%` 分流按 04f §7.3；
  `%` 管道右侧是受控子标签（concordance 口径：canonical=显示串），不是规范名（01g §2.2.3a/§2.2.1a）。
- 动作: 时间词走 `%`、数量走 `$`；统计时 `%` 不入实体密度、`$` 不入时间轨（02f1:ST02；04d1:CH04）。
- 反例: "三百回合"是数量（`$`）不是时间；"一个时辰"是 `%` 时长——按语义分，不按数字形态。
- 来源: `SKILL_01g` §2.2.1a/§2.2.3a；`SKILL_04f` §7.3；`registry/concordance` spec；`references/04d1` CH04。
- 状态: 已验证
