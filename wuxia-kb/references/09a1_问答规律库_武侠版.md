## A 区 · 问题类型与检索

### AQ01 · 八类问题类型学与主检索源（Q1-Q8）
- 类别: 问题类型与检索
- 现象: 所有问题都走同一检索路径，人物关系问题用人物卡硬答；原文类问题也尝试回答。
- 判据: 09a §三 类型表：Q1 人物事实（SKU 卡 person/brief/fields）、Q2 人物关系（N5 边+05c 双树）、
  Q3 时间（N4 time_points+book_anchors）、Q4 地点（EX-7 gazetteer+09j）、Q5 统计（03l 口径+concordance）、
  Q6 设定/一致性（EX-8 consistency+07c）、Q7 跨书（03b series+07a 年代）、Q8 原文类（**拒答**）。
- 动作: 每类固定主检索源与可答条件（卡 conf≥C/边 strong·ok/时间 high·medium/地点已登记/口径声明/记录 A-E/系列身份+low）。
- 反例: 用 Q1 人物卡回答 Q2 关系（卡上不一定有关系字段）；Q8 原文类拒不拒答都是错。
- 来源: `SKILL_09a` §三；`SKILL_09_应用总览`；docs/58（N10 卡）。
- 状态: 已验证

### AQ02 · 检索顺序五步：精确定位 → 别名 → 跨书 → 上下文 → 拒答
- 类别: 问题类型与检索
- 现象: 直接全文模糊搜导致答错实体；或跳过别名/跨书直接拒答。
- 判据: 09a §3.1 固定顺序：① 精确定位（实体 ID/canonical/边/PN）→ ② 别名/同义（03b aliases）→
  ③ 跨书系列（series）→ ④ 相关上下文（同段/同回）→ ⑤ 无 → 拒答/未知。
- 动作: 问答实现按顺序短路；每步命中记 sources；最后一步不得跳过。
- 反例: 先模糊搜"吕四娘"命中"吕四娘之墓"文本就当人物事实——先精确定位实体。
- 来源: `SKILL_09a` §3.1；`SKILL_03b`（aliases）；`registry/concordance`.
- 状态: 已验证

### AQ03 · 原文类问题一律拒答（01g §9.10）
- 类别: 问题类型与检索
- 现象: 用户问"原文怎么写的"时给出连续原文片段；或绕道摘要仍含大段原文。
- 判据: Q8 原文类=**拒答**（01g §9.10 版权红线）；答案只能给概括+定位符（书·回/段/PN），不得给连续原文；
  W7 核验拦截（QA-03）。
- 动作: 拒答话术"本库不提供原文内容"；需要证据时给机锚；`refused=true` 记录。
- 反例: "只引用一句不长"仍属原文发布——任何连续片段都不行；snippet 仅内部证据不发布。
- 来源: `SKILL_09a` §三/§4.3；`SKILL_01g` §9.10；`SKILL_03d` §6.1。
- 状态: 已验证

### AQ04 · 证据等级门控：A/B 直接答、C 标注、D/E 拒答
- 类别: 问题类型与检索
- 现象: C 级推算当 A/B 直接答；D/E 弱证据也作答。
- 判据: 09a §五 门控链：证据存在？→否=拒答/未知；证据等级？→D/E 拒答、C 标注（`grade=C` +
  `confidence_note`）、A/B 直接答（回锚）；再走脱敏 R1-R5 → W7 引文核验 → 发布。
- 动作: 答案写 grade 与 convention；门控链在生成后校验（QA-04 检测 C 当 A/B）。
- 反例: 用两条 weak 边合成 strong 答案——等级取最弱证据，不取平均。
- 来源: `SKILL_09a` §5.1/§4.1；`SKILL_03d` §6；`SKILL_05a1:AQ` 相关。
- 状态: 已验证

### AQ05 · 跨书 low 结论标注（参考区间/两说并存），不得当单书事实
- 类别: 问题类型与检索
- 现象: 跨书推断（人物前后/年代）当单书事实；不同书的说法矛盾只取一说。
- 判据: 跨书 low：答案标 `grade=C`、`cross_book=true`，句式"参考区间/两说并存"；多源冲突走 `conflicts[]`
  双记（09a §4.2）；Q7 可答条件=系列身份（03b）+ low 标注。
- 动作: 跨书答案必带 series/年代依据；冲突双记不静默择一（QA-05/06）。
- 反例: "某人物在两书是同一人"若系列身份未确认，不能当事实回答；应标 low/两说。
- 来源: `SKILL_09a` §4.2/§五；`SKILL_03b`；`SKILL_跨书治理` §七。
- 状态: 已验证

## B 区 · QA schema 与句法

### AQ06 · QA 对 schema v0.1：evidence/grade/sources/convention 必填
- 类别: QA schema 与句法
- 现象: 答案只有文本，没有证据/等级/来源；下游无法审计与回锚。
- 判据: 09a §4.1 schema：`qa_id/question/answer/answer_type/grade/evidence[]/sources[]/convention/
  unknown/w7`；evidence 元素含 kind/id/subject/predicate/object/loc；grade ∈ A/B/C；unknown/refused 布尔；
  W7 核验结果入 `w7{checked,hit}`。
- 动作: 生成器按 schema 输出；校验器检查必填；下游（页面/评测）只读结构化字段。
- 反例: 把 evidence 写成自然语言描述（"据 N5"）——无法机读审计；必须带 id/loc。
- 来源: `SKILL_09a` §4.1；`logs/w_group/quote_verify.json`（w7 字段先例）。
- 状态: 已回写

### AQ07 · 句法与标注规则：六情形对应句式（A/B、C 推算、跨书、冲突、无证据、原文类）
- 类别: QA schema 与句法
- 现象: 不同证据等级用同一语气；无证据时答"大概/应该"。
- 判据: 09a §4.2 表：A/B 级=直接陈述+回锚；C 级推算="据…推算/一般认为…"+`confidence_note`；跨书 low=
  "参考区间/两说并存"+`cross_book=true`；多源冲突="一说…另一说…"+`conflicts[]`；无证据="知识库暂无可靠记载
  （可查阅原文）"+`unknown=true`；原文类="本库不提供原文内容"+`refused=true`。
- 动作: 句式与 grade 绑定校验（QA-04）；拒答话术统一中性化（QA-08）。
- 反例: 无证据但用"一般认为"——那是 C 级话术，缺证据时应 unknown；两情形不可混用。
- 来源: `SKILL_09a` §4.2；`SKILL_07e_正确性评估`.
- 状态: 已验证

### AQ08 · 禁止项四条：原文片段/未核实当真/跨书当单书/作者本意替证据
- 类别: QA schema 与句法
- 现象: 用"作者本意如此/常识如此"补证据；未核实内容写成确定事实。
- 判据: 09a §4.3 禁止项：① 原文连续片段（W7+01g §9.10）；② 未核实内容表述为确定事实（07e）；③ 跨书结论
  当单书事实（07a）；④ 用"作者本意/常识"替代证据。
- 动作: 生成后逐条自查（QA-01~08）；违规答案降级/拒答并记录。
- 反例: "梁羽生原意是歌颂…"——作者本意不是证据；只能给数据支持的事实或降级为分析。
- 来源: `SKILL_09a` §4.3；`SKILL_01g` §9.10；`SKILL_07e`/`07a`.
- 状态: 已验证

### AQ09 · 多源冲突双记（conflicts[]），禁止只取一说
- 类别: QA schema 与句法
- 现象: 两书说法矛盾时静默择一；或把冲突当"数据错误"删除一方。
- 判据: 多源冲突答案用"一说…另一说…"句式 + `conflicts[]` 双记（09a §4.2）；QA-06 检测"多源冲突只取一说"；
  冲突登记不裁决（04d1:CH18 同源纪律）。
- 动作: 冲突来源（03b/N4/N5/EX）逐条引用；答案标低等级；冲突记录进查证清单。
- 反例: 为答案简洁把两说合并成"可能"——丢失冲突信息；双记是硬要求。
- 来源: `SKILL_09a` §4.2/§七；`SKILL_04d` §8.2；`SKILL_跨书治理`.
- 状态: 已验证

## C 区 · 门控与数据边界

### AQ10 · W7 引文核验门控：不输出原文，0 叙事编造才可发布
- 类别: 门控与数据边界
- 现象: 答案/卡片引用"原文"但无法在底本定位；或报告输出引文原文（隐私/版权问题）。
- 判据: 发布前走 W7 `scripts/verify_quotes.py`：归一化子串命中；近似 ratio≥0.9/匹配块长度率≥0.9/引文≥8 字；
  省略号按段核验；**报告与 JSON 不输出引文原文**（仅长度/hash/定位符）（09a §5.1；W7 报告纪律）。
  实测：原始引号片段 2,383 → 跳过占位 1,470/短 908 → 进核验 5 → 命中 2 / 近似 0 / 未命中 3（均技术术语，
  非叙事）→ **叙事引文疑似编造 0**。
- 动作: 发布前 `verify_quotes.py --sku/--file`；未命中叙事引文=block；技术术语未命中列人工复核。
- 反例: "近似命中"直接当通过——须人工复核（W7 报告中 near=0 才无此项）；技术术语未命中也非编造。
- 来源: `SKILL_09a` §5.1；`logs/w_group/quote_verify_report.md`（5 进核验/2 命中/0 编造）；docs/59 §W7.
- 状态: 已回写

### AQ11 · 数据边界/脱敏 R1-R5：卡面正文不连续重合 ≥10 字
- 类别: 门控与数据边界
- 现象: SKU 卡/答案正文与原文连续重合过长；引文型内容无回锚。
- 判据: N10 脱敏规则（`registry/sku/cards.json` desensitization）：R1 卡面正文不得与原文连续重合 ≥10 字
  （阈值 SKILL 附录 B 待拍板，本批用 10）；R2 引文型内容"概括语+回锚"、回锚只存 ID/机锚指针不含文本；
  R3 专名可发布不算片段；R4 未过审不得 publish_state=approved、演示卡永远 blocked；R5 Procedural 源自原文
  口诀须原创归纳。
- 动作: 发布前 R1-R5 检查（N10 checks 字段）；答案侧同样适用（AQ03）；脱敏不通过=block。
- 反例: "只改几个字"仍可能连续重合 ≥10 字；必须概括化并挂机锚。
- 来源: `SKILL_09a` §5.1；`registry/sku/cards.json`（desensitization.rules/checks）；`SKILL_SKU卡片`.
- 状态: 已验证

### AQ12 · 评测指标：证据覆盖 ≥95% / 答案正确率抽样 ≥90% / 拒答正确率 100%
- 类别: 门控与数据边界
- 现象: 只测"答了多少"不测"有多少有证据"；未知类被答成确定。
- 判据: 09a §5.2 指标：证据覆盖率 ≥95%（自动校验 evidence 非空）；答案正确率抽样 ≥90%（人工抽检 10%）；
  拒答正确率=未知类 100% 不猜（构造未知集）；W7 通过率 100% 无原文片段；一致性=与数据源零矛盾（交叉核对）。
- 动作: 每次发布跑指标；未达标不发布；指标数据入报告。
- 反例: 正确率抽检只看热门问题——须按问题类型分层抽样（Q1-Q7）。
- 来源: `SKILL_09a` §5.2；`logs/w_group/quote_verify_report.md`.
- 状态: 已验证

### AQ13 · QA 错误模式库 QA-01~08（无证据/未知当确定/原文片段/等级虚高/跨书/冲突/无版本/话术泄漏）
- 类别: 门控与数据边界
- 现象: 同类问答错误反复出现（无证据作答、C 当 A/B、拒答话术泄漏结论）。
- 判据: 09a §七 错误模式库：QA-01 无证据作答→拒答；QA-02 未知当确定→改未知；QA-03 答案含原文→W7 核验；
  QA-04 C 级当 A/B→降级；QA-05 跨书当单书→标参考；QA-06 多源冲突只取一说→双记；QA-07 无版本/来源→补；
  QA-08 拒答话术泄漏未核实结论→中性化。
- 动作: 错误模式入生成后自查/评审清单；新增错误编号只增不复用；可规则化者进校验器。
- 反例: 把 QA-02 当"模型幻觉"不修——话术与门控可修（unknown 字段/拒答模板）。
- 来源: `SKILL_09a` §七；`SKILL_07e`（正确性评估）。
- 状态: 已验证

### AQ15 · 数据版本与来源声明：答案带 data_version/rule_version/契约版本
- 类别: 接口与实测
- 现象: 答案无法回溯数据版本；规则变更后旧答案仍发布。

  必填；EX 导出层 meta 版本同源（03d1:H17 版本三元组）。
- 动作: 答案/卡输出带 data_version+rule_version；重新生成时版本升级；旧版本可回溯。
- 反例: 只写"来自知识库"——无法定位数据版本；来源必须到文件/字段级。
- 来源: `SKILL_09a` §六；`registry/sku/cards.json` meta；`SKILL_03d` §6.2；docs/57/58.
- 状态: 已验证

### AQ16 · 发布前检查清单：数据层就绪 → 问题集 → 门控 → 抽检 → 版本

- 现象: 数据层未就绪就生成问答；生成后不抽检直接发布。
