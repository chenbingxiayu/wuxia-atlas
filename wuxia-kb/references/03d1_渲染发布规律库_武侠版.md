## A 区 · AST→HTML 契约（H-1~H-10 冻结）

### H01 · 每个 PN 块输出唯一 id + data-pn；id 全书唯一
- 类别: AST→HTML 契约
- 现象: 渲染器把多个段落合成一个块，或 PN 锚点重复/缺失（RND-04：围栏整体一 PN 未落到块上）。
- 判据: 每个 PN 块输出唯一 `id`（=机锚可读形式）与 `data-pn`（机锚原文）；`id` 全书唯一；
  检测方式=正则扫描 + 唯一性断言（03d H-1）。
- 动作: 转换器按 PN 切块；汇编期断言 id 唯一性；RND-04 检测项并入 CI。
- 反例: 围栏（诗/词）整体共享一个 PN 时，仍须落到唯一块上并给 id；不得因围栏合并而丢锚。
- 来源: `SKILL_03d` §5.2 H-1；§七 RND-04；docs/52（站点构建 1508 页 exit 0）。
- 状态: 已验证

### H02 · 实体节点：class 双类 + data-etype∈15 类 + data-token-id 唯一
- 类别: AST→HTML 契约
- 现象: 类名与类型码不一致（RND-03：`wx-ent-at` 但 `data-etype`=◆）；同一令牌拆成两个元素（RND-02）。
- 判据: `class="wx-ent wx-ent-<code>"`；`data-etype` 为 15 类码之一；`data-token-id` 全书唯一；
  一个令牌=单元素（03d H-2）。
- 动作: 统一映射表（类型码→类名）；类名/属性双向校验；令牌结构断言。
- 反例: 一个实体令牌跨 HTML 标签拆分（如强调标签中断）属违规，应整体包裹或调整嵌套顺序。
- 来源: `SKILL_03d` §5.2 H-2；§七 RND-02/03；`SKILL_01g` §二 15 类符号表。
- 状态: 已验证

### H03 · 动词节点：class 双类 + data-vtype∈6 域，不得复用实体类
- 类别: AST→HTML 契约
- 现象: 动词令牌用 `wx-ent-*` 类或反之；六域码写成中文/旧码。
- 判据: `class="wx-verb wx-verb-<domain>"`；`data-vtype` ∈ 6 域（⊞⊠⊡⊟▣■）；不得复用实体类（03d H-3）。
- 动作: 类名映射独立于实体；断言动词/实体类不交叉。
- 反例: 联动展示（如"交手"同时挂实体 id）应通过 data 属性关联，不得把动词节点塞实体类。
- 来源: `SKILL_03d` §5.2 H-3；`SKILL_04f` 六域表。
- 状态: 已验证

### H04 · textContent 与剥标原文逐字一致（令牌只加包裹，不改字符）
- 类别: AST→HTML 契约
- 现象: 渲染吞字/改字（RND-01：包裹时丢空格或标点）；实体管道右侧被误渲染为正文。
- 判据: 渲染后 `textContent == strip(tagged)` 逐段断言；令牌只增加包裹元素，不改字符（03d H-4）。
- 动作: 转换器逐段对账；剥标函数复用 `scripts/symbols.py`（唯一来源）；双跑 diff。
- 反例: 管道 `〖@明太祖|朱元璋〗` 中"明太祖"必须出现在正文，"朱元璋"仅入 data-canonical（H-5），
  不得把规范名替换显示串。
- 来源: `SKILL_03d` §5.2 H-4；§七 RND-01；`scripts/symbols.py` strip_markup。
- 状态: 已验证

### H05 · data-canonical 只在管道存在或登记层可唯一回溯时输出
- 类别: AST→HTML 契约
- 现象: 歧义/未登记实体也输出 data-canonical 并生成跳转（RND-05：管道规范名越权展示）。
- 判据: `data-canonical` 仅当管道存在或 registry 可唯一回溯时输出；歧义/未登记不输出（03b 口径：不猜）
  （03d H-5）。
- 动作: 与 `registry/entities.json` + `display_canonical.json` 对照；status=pending 不渲染跳转（H-9）。
- 反例: 显示串=规范名时（无管道）若 registry 命中仍可输出；仅"无法唯一回溯"时才省略。
- 来源: `SKILL_03d` §5.2 H-5；§七 RND-05；`SKILL_03b`；`registry/display_canonical.json`。
- 状态: 已验证

### H06 · 围栏块：class + data-fence=中文类型名（10 类映射）
- 类别: AST→HTML 契约
- 现象: 围栏类名拼写与 02ab 类型名不一致；回末/回末对/套语混用。
- 判据: `class="wx-fence wx-fence-<roman>"`（ci/shi/ge/duilian/huimodui/huimo/shuxin/gaoshi/koujue/shuoshu）；
  `data-fence`=中文类型名（03d H-6）。
- 动作: 类名映射表与 `SKILL_02a_02b` §4.1 围栏枚举同源；断言类型名∈10 类。
- 反例: 未识别围栏（说书/告示观察类）可降级为普通段落，但不得伪造 `data-fence`。
- 来源: `SKILL_03d` §5.2 H-6；`SKILL_02a_02b` §4.1；docs/49（40 回围栏可逆性 PASS）。
- 状态: 已验证

### H07 · 禁止输出原文之外的属性值；禁止内联事件处理器
- 类别: AST→HTML 契约
- 现象: 渲染器把注解释义/考订长文塞进 title/data-*；或内联 `onclick` 等处理器。
- 判据: 属性值只允许来自结构化字段白名单；禁 `onclick/onerror` 等内联事件（03d H-7）；安全扫描。
- 动作: 属性白名单 + 安全扫描入 CI；富文本/摘录一律走脱敏通道（见 H15）。
- 反例: 为调试方便临时加 `data-debug` 可接受于本地阅读器，但**不得**进入站点发布产物（H16）。
- 来源: `SKILL_03d` §5.2 H-7；§5.4 EX 契约；`SKILL_01g` §9.10。
- 状态: 已验证

### H08 · 输出确定性：同 AST 两次渲染字节相同
- 类别: AST→HTML 契约
- 现象: 时间戳/随机 id/UUID 进入 HTML，双跑 diff 不一致（RND-08）。
- 判据: 同 AST 两次渲染字节相同；时间戳/随机数禁止进入 HTML（03d H-8）。
- 动作: 双跑 diff 入 CI；id 用确定性派生（PN/token 序号），不用随机。
- 反例: 页面级构建时间可在**数据 meta** 记录，但不得出现在 HTML 正文/属性中。
- 来源: `SKILL_03d` §5.2 H-8；§七 RND-08。
- 状态: 已验证

### H09 · 页面级不输出未审核实体
- 类别: AST→HTML 契约
- 现象: registry status=pending/未审核实体也渲染 data-canonical/跳转。
- 判据: status=pending 不渲染 `data-canonical`/跳转，只保显示串；status 过滤断言（03d H-9 / 6.5 消费协议）。
- 动作: 导出前按 status 过滤；EX 导出器同样按 status 过滤（sects/weapons 已弃用过滤）。
- 反例: 显示串本身可以渲染（正文保真），只是不挂 canonical/链接；不能把未审核实体整体删掉造成吞字。
- 来源: `SKILL_03d` §5.2 H-9；§3.3 结构侧约束；`SKILL_06` 树 status 档位；docs/58。
- 状态: 已验证

### H10 · 本地阅读器产物不得进入 site/data 或公网静态目录
- 类别: AST→HTML 契约
- 现象: 本地 HTML 被拷入 `site/public`（RND-09：本地阅读器产物上公网）。
- 判据: 本地阅读器产物**不得**进入 `site/data` 或公网静态目录（01g §9.10、03d H-10）；路径审计。
- 动作: 发布路径审计（白名单目录）；构建脚本检查 site/public 非法产物。
- 反例: 站点自己的 Astro 页面走 `site/src` 构建——不属于"本地阅读器产物"，不受此条禁止。
- 来源: `SKILL_03d` §5.2 H-10；§6.1 发布边界；`SKILL_01g` §9.10；§七 RND-09。
- 状态: 已验证

## B 区 · EX 导出层契约

### H11 · 默认 dry-run + staging；--apply 前自动备份
- 类别: EX 导出层契约
- 现象: 导出器默认直接写 site/data；无 staging/报告/备份，误操作难回滚。
- 判据: 默认 dry-run 只写 `logs/export/staging/` + 报告；`--apply` 才写 site/data 且写前自动备份
  （docs/51 §七；`scripts/export_site_common.py`）；site/data 有阶段 0 全量快照
  `backup/site_data/phase0_20261105/`。
- 动作: 导出器统一调用 `export_site_common.finish()`；集成器 `export_site_all.py` 汇总 hard_gap。
- 反例: "小改一趟直接 apply"——docs/52 明确阶段 1 全部先 dry-run 再 apply；无例外。
- 来源: `SKILL_03d` §5.4；`docs/51` §六/§七；`docs/52` §二（阶段 1 实跑）；`scripts/export_site_common.py`。
- 状态: 已回写

### H12 · 字段不缺、类型不破（hard_gap=0）为底线，字段缺口写 meta.field_gaps
- 类别: EX 导出层契约
- 现象: 新数据没有旧站字段时静默丢弃，或类型改变（int→str）导致 Astro 页面报错。
- 判据: 新 payload 字段集合 ⊇ 基线契约（含数组元素字段）；缺失字段置 null/[] 并在 `meta.field_gaps`
  逐项说明；类型不符为硬伤（RND-07：导出伪造字段=禁止，置 null+记录）（docs/51 §五）。
- 动作: `export_site_common.diff_against_contract` 出 hard_gap 报告；硬缺口 0 才允许 apply。
- 反例: 为"好看"用旧值/推断值补字段=伪造（RND-07）；宁缺勿造，写 field_gaps。
- 来源: `docs/51` §五/§七；`docs/52` §三（阶段 1 四导出器 hard_gap=0）；`scripts/export_site_common.py`。
- 状态: 已回写

### H13 · 新增字段允许且只增不改名/不删字段
- 类别: EX 导出层契约
- 现象: 导出器借机改名（canonical→name）或删字段，站点/下游断链。
- 判据: 站点契约允许新增字段；已有字段不得改名/删除（docs/51 §五；display 层先例 docs/57：只增
  `display`/`display_name`，不改名/删字段，三表 hard_gap=0）。
- 动作: diff 报告中 extra_keys 允许、missing/type_mismatch 禁止；页面侧按可选字段处理。
- 反例: 新 schema 想统一命名——须由 W 组重建站点层时统一，导出器桥接期不改名。
- 来源: `docs/51` §五；`docs/57`（display 切换）；`docs/58`（EX-7/EX-8 hard_gap=0 并 apply）。
- 状态: 已回写

### H14 · 幂等：复跑产出确定性一致，仅时间戳字段可变
- 类别: EX 导出层契约
- 现象: 导出器复跑输出漂移（排序不稳定/dict 顺序随机/时间戳进入内容），每次 diff 噪声大。
- 判据: 同一输入复跑产出确定性一致（时间戳字段除外）；排序口径需在报告说明
  （docs/51 §七；EX-4/EX-6/EX-7 实测：同输入 staging SHA256 一致）。
- 动作: 固定排序键；`generated` 只用日期/秒级且不入内容 hash；报告记录排序口径。
- 反例: 为"最新"把生成时间嵌入每条记录——会破坏幂等与 diff，应只放 meta。
- 来源: `docs/51` §七；`docs/52`（导出层）；docs/57 EX-4；EX-6/EX-7 staging 复跑 SHA 一致（task-3/task-26 实测）。
- 状态: 已回写

## C 区 · 发布边界与安全

### H15 · 版权红线：只发布结构化数据，不发布原文/长摘录
- 类别: 发布边界与安全
- 现象: dossiers/characters 携带长段原文；evidence.snippet 越过长度上限（RND-06：页面内联原文片段）。
- 判据: 允许出口=结构化属性/关系/统计/不含正文定位/原创分析/数据与方法版本；禁止原文正文、标注正文、
  可还原正文的连续片段；`evidence.snippet ≤120 字` 且**不发布**（03d §6.1 / D07 §7.5）。
- 动作: 字段级脱敏；snippet 走版权审查通道；发布前抽检 01g §9.10 边界。
- 反例: "引用一句原文做证据"页面上仍属原文发布——只能给定位符（书·回/段），不给文本。
- 来源: `SKILL_03d` §6.1；§七 RND-06；`SKILL_01g` §9.10；`SKILL_跨书治理` §7.5。
- 状态: 已验证

### H16 · 零旧写入：导出器不写 tagged/registry/kb，不运行冻结旧脚本
- 类别: 发布边界与安全
- 现象: 导出器顺手修 registry；或调用父仓 `build_*.py` 生成数据（RND-10：旧件回流）。
- 判据: 导出器只读新管线产物与旧 kb 只读资产；不写 `tagged/`、`registry/`；不运行父仓旧脚本；
  旧脚本 mtime 保持冻结前状态（docs/51 §七 验收 5；§4.1 冻结清单）。
- 动作: 导出器 import 检查 + mtime 审计；写入仅限 `logs/export/` 与 site/data（--apply）。
- 反例: "旧 build_* 逻辑没法复用，干脆跑一下旧脚本"——冻结即禁止；旧件只作只读参考（旧考订表例外，
  属 §4.2 只读迁移输入）。
- 来源: `SKILL_03d` §5.4；`docs/51` §4.1/§4.2/§七；`docs/52` §一 冻结标记；§七 RND-10。
- 状态: 已验证

## D 区 · 版本与回滚

### H17 · 版本三元组 + 冻结窗口 + 回滚路径
- 类别: 版本与回滚
- 现象: 发布后无法判断"用的是哪版契约/色板/规则"，回滚只能拍脑袋。
- 判据: 每次发布记录 `data_version + rule_version + contract_version`；渲染契约版本
  `html_contract:v0.1`/`theme:v0.1`/`ast_schema:v0.1`；契约变更走三步治理（分级/回归≥3 书 30 回/7 天窗口）
  + 旧→新映射（03d §6.2/§6.3）；回滚=恢复站点数据快照或按契约版本回退实现（03d §6.4）。
- 动作: 数据 meta 必填 generated/version/field_gaps；变更记录与版本号落盘；回滚演练。
- 反例: 只升实现不升契约版本——下游无法感知破坏性变更；版本号必须与契约文件同源维护。
- 来源: `SKILL_03d` §6.2/§6.3/§6.4；docs/51 §八 回滚；docs/52 阶段 0 备份。
- 状态: 已回写

## E 区 · 错误模式

### H18 · RND 错误模式库（10 条）沉淀为渲染/导出断言
- 类别: 错误模式
