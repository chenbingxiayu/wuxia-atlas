## A 区 · 四类同形

### HM01 · 同名异人：不同书同名人物/同书同名不同人 → 拒绝归并 + disambig
- 类别: 四类同形
- 现象: 两书各有一个"张三丰"式同名；绰号撞名被当同一人；同书同名不同人被合并。
- 判据: 03j §三/§3.1（D07 §5.4）：同名异人=不同书同名人物或同书内同名不同人；关键属性冲突（时代/身份/亲属/
  武功体系不一致）→ 同名异人；拒绝归并、disambig 限定、各建实体。
- 动作: 拒并+拆分/限定；两实体各带 disambig（书域/身份域）；登记 reject 分类（同名异人）。
- 反例: 仅"同名"就合并——停止规则明确须 ≥1 条 L1/L2 证据（HM06）。
- 来源: `SKILL_03j` §三/§3.1；`SKILL_跨书治理` §5.4；N6 reject 分类（同名异人 8）。
- 状态: 已验证

### HM02 · 跨书同名地点/组织：拆条 + `@书` 限定符；或归并 + 分号
- 类别: 四类同形
- 现象: 两书"龙门镇"位置不同被合并；同名分号型组织拆碎。
- 判据: 03j §3.2（D10 §5.4）：同名地点先查 gazetteer `books` 书集与 `first_seen`：同书集内同名同地→归并；
  跨书同名且无互证→拆分+限定符（`龙门镇@白发魔女传`）；同名分号型组织→归并+分号（或限定符）；限定符只进
  id/disambig，不改显示串。
- 动作: 拆分→两实体各带 disambig/限定符；拆分条 aliases 不互挂；/atlas 各落各点。
- 反例: 把"同名不同书"全拆——先查书集相容性；相容（同一地点跨书）应合并 books。
- 来源: `SKILL_03j` §3.2；`SKILL_地名gazetteer` §5.4；`references/06e1`（地点树）。
- 状态: 已验证

### HM03 · 跨类同形：同一字面跨实体类 → 按类型码分建，跨类不合并（T16）
- 类别: 四类同形
- 现象: "龙门"（地名）与"龙门帮"（组织）合并；"剑"（器物）与"剑法"（武功）混。
- 判据: 03j §三：同一字面跨实体类（"龙门"=地名 vs "龙门帮"=组织；"剑"=器物 vs 剑法=武功）→ 按类型码分建实体，
  **跨类不合并**（T16）；跨类同形不触发 03j 拆分，只是类型判定问题（03a/01g）。
- 动作: 先判类型码再判同形；跨类不合并；类型误标按 03a1/01g1 处理。
- 反例: 把"天山"（=）与"天山派"（◆）当同形合并——跨类，各建。
- 来源: `SKILL_03j` §三；`SKILL_分类树五件套` T16；`references/01g1` SY05。
- 状态: 已验证

### HM04 · 通名-专名同形：通名不登记（三问裁定），专名照登
- 类别: 四类同形
- 现象: 通名/泛称（江湖/武林/山庄）当专名建实体；专名因像通名被漏。
- 判据: 03j §三：通名-专名同形——通名/泛称（"江湖""武林"）不登记（三问裁定：行为主体/结构可指认/边界清晰）；
  专名照登；"山庄"通名 vs 专名（如"xx山庄"）按语境判。
- 动作: 三问裁定通名；通名进观察池/概念层（^），不建专名实体；专名按类型码登记。
- 反例: 建"◆武林"实体——三问皆不过，属 T1 错误（03j 同源 01g §5.3）。
- 来源: `SKILL_03j` §三；`SKILL_01g` §5.3 三问；`references/01g1` SY05/SY11。
- 状态: 已验证

## B 区 · 判定规则

### HM05 · 证据优先序 L1 > L2 > L3：文内直证 > 映射/registry > 跨书推理
- 类别: 判定规则
- 现象: 用跨书推理（L3）当强证据判同/异；映射冲突不人工裁。
- 判据: 03j §4.1（引 D07/03b）：① L1 文内证据（同回/同段互证、相认段、亲属/师承句）最强，可直接判同/异；
  ② L2 映射表/registry（已核准映射、冻结映射、canonical/aliases）次强，映射冲突须人工裁；③ L3 跨书推理
  （系列谱系考订表 interchange_seeds、接力锚、师承链）作佐证、conf 封顶。
- 动作: 判定按序取最高证据；L3 只作佐证；冲突上抛人工。
- 反例: 仅凭"同系列同名"（L3）合并——L3 封顶，需 L1/L2 补证。
- 来源: `SKILL_03j` §4.1；`SKILL_03b` §8；`SKILL_跨书治理` §三/§四。
- 状态: 已验证

### HM06 · 停止规则：同名不合并/同派不合并/冲突不自动裁/引用可回链
- 类别: 判定规则
- 现象: 见同名就合并；见同派/同阵营就合并；证据冲突时自动择一。
- 判据: 03j §4.2 停止规则：单凭"同名"不得合并（须 ≥1 条 L1/L2 证据）；单凭"同书同派/同阵营"不得合并
  （共现不是证据）；证据冲突（一同一异）不自动裁决，登记冲突交人工；归并后 canonical 只保留一个，另一个降
  aliases；**归并前必须确认所有引用可回链**（关系边/事件/卡引用）。
- 动作: 停止规则前置检查；引用清单核对；冲突登记。
- 反例: 以"两人同在天山派"合并同名人物——共现非证据；须相认段/亲属句等 L1。
- 来源: `SKILL_03j` §4.2；N6 双人复核门槛（docs/57 §五）。
- 状态: 已验证

### HM07 · disambig 与限定符字段：书域/身份域限定、`@书` 后缀、旧名降 aliases
- 类别: 判定规则
- 现象: 用显示串改写做消歧；限定符进显示串；旧 canonical 直接删。
- 判据: 03j §4.3：`disambig`=同名限定词（书域/身份域）；限定符=主键后缀（跨书同名拆分 `龙门镇@白发魔女传`）；
  `aliases`=合并后旧 canonical 降别名；字段定义承 D09 共享扩展池；**不得**用显示串改写做消歧（显示串必须原文
  连续区间）。
- 动作: 限定符只进 id/disambig；旧名入 aliases；显示串保持原文。
- 反例: 把"龙门镇"改成"龙门镇@书"当显示串——显示串必须原文连续区间（HM08）。
- 来源: `SKILL_03j` §4.3；`SKILL_03b` D1 管道规则；`references/01g1` SY04。
- 状态: 已验证

### HM08 · 显示串不得改写做消歧（候选）：替代方案=disambig 字段 + 检索按书过滤
- 类别: 判定规则
- 现象: 为区分同名实体修改正文显示串；或合并后显示串统一为规范名。
- 判据: 03j §4.3：显示串必须原文连续区间，**不得**用显示串改写做消歧；替代=disambig 字段/限定符（id 层）+
  检索按书过滤。该替代方案在多书同名检索中的呈现口径待试点验证（候选）。
- 动作: 显示串保原文；disambig/限定符承载消歧；检索层按 books 过滤。
- 反例: 合并后把正文"韦小宝"改成"韦小宝（鹿鼎）"——显示串改写，剥标断言失败。
- 来源: `SKILL_03j` §4.3；`references/01g1` SY04；`SKILL_03b` D1。
- 状态: 候选

## C 区 · 动作与冲突

### HM09 · 四类动作：拆分/限定符/别名归并/拒绝归并（各留痕）
- 类别: 动作与冲突
- 现象: 拆分/归并无记录；拒绝归并缺分类。
- 判据: 03j §5.1 四动作：拆分（同名异人/证据不足归并→两实体各带 disambig，留拆分原因+依据）；
  限定符（跨书同名共存→id `@书` 后缀、显示串不变，留规则记录）；别名归并（证据充分判同一→主 canonical+别名，
  引用重指，留合并前后映射+受影响引用清单）；拒绝归并（同名异人/证据不足→保持分立，留 reject 分类）。
- 动作: 四动作均留痕（台账）；归并前引用清单核对。
- 反例: "先合了再说"——归并前未确认引用可回链（HM06），回滚困难。
- 来源: `SKILL_03j` §5.1；N6 review_queue 状态机。
- 状态: 已回写

### HM10 · 冲突登记（不可裁决）：{实体A/B, 同形面, 证据A/B, 冲突类型, 建议, conf}
- 类别: 动作与冲突
- 现象: 证据冲突时静默择一；或把冲突当错误删除一方。
- 判据: 03j §5.2：条目结构 `{实体A, 实体B, 同形面, 证据A, 证据B, 冲突类型, 建议, conf}`；冲突类型对齐 D07
  （同名异人/跨书矛盾/时代错置/身份混淆）；**只登记不裁决**，裁决走人工/考订流程。
- 动作: 冲突登记进查证清单；双记；不自动改 registry。
- 反例: 两书矛盾直接信"正文优先"并删另一说——冲突信息丢失（07e1:AU08 同源）。
- 来源: `SKILL_03j` §5.2；`SKILL_跨书治理` §三；`references/07e1` AU08。
- 状态: 已验证

### HM11 · 归并前引用可回链：关系边/事件/卡引用逐项核对
- 类别: 动作与冲突
- 现象: 归并后旧 canonical 的关系边/事件/卡片断链；回滚无映射。
- 判据: 03j §4.2：归并后 canonical 只保留一个，另一个降 aliases；**归并前必须确认所有引用可回链**
  （关系边/事件/卡引用）；留合并前后映射（可回退）。
- 动作: 归并前扫描引用（registry/relations、events、sku/cards、acceptance）；映射表留档；回滚脚本就绪。
- 反例: 直接改 registry canonical 不更新 references——下游 404/断链；须引用清单+重指。
- 来源: `SKILL_03j` §4.2/§5.1；N6 回写顺序/ID 封存（review_queue）。
- 状态: 已验证

### HM12 · 与 N6 分工：N6 产候选（140/actionable 17/reject 123），03j 消费 reject 做登记层落地
- 类别: 动作与冲突
- 现象: 03j 与 N6 重复跑归并候选；或 N6 reject 清单无人消费。
- 判据: 03j §5.3：N6 `merge_crossover.py` 产出候选 140（E3 13/E4 127）、actionable 17、reject 123
  （已归并 113/组织关联 6/同名异人 8）；03j 消费 N6 的 reject 清单与 review_queue，负责"同名异人 8 条"的
  登记层落地（disambig/拆分）；N6 E3 双人复核/E4 候选池仍待人工。
- 动作: 分工固定：N6 跨书归并候选+队列，03j 登记层消歧动作；不重复跑。
- 反例: 03j 自建归并候选与 N6 结果冲突——以 N6 队列为准，03j 只做消歧落地。
- 来源: `SKILL_03j` §5.3；`registry/crossover/merge_candidates.json`；`logs/crossover/summary_20261105_175054.json`.

### HM13 · 实测：registry canonical↔alias 撞名 33 条（34→33，无新增）
- 类别: 撞名实测
- 现象: 别名与其它条目 canonical 撞名（同一字面多主）；或新增撞名。
- 判据: 实测（docs/56 §二 / registry_calib_batch2_report）：registry canonical↔alias 跨条目撞名 **34→33**
  （无新增）；03j 现状口径=撞名 33 条（无新增），逐条裁定（合并/限定/保留）——待登记层校准批。
- 动作: 撞名清单逐条裁定；新增别名前查唯一性（别名不属多主）；校准批留台账。
- 反例: 给某实体加别名时撞上他人 canonical——须先裁定（合并/限定/保留），不静默加。
- 来源: `docs/56` §二；`logs/qa/registry_calib_batch2_report.md`（34→33）；`SKILL_03j` §1.2/§七。

### HM15 · 同名异人 8 条处置口径：disambig/拆分/保留（待人工）

### HM16 · gazetteer 跨书同名地点：书集维度消歧（D10 §5.4）+ `@书` 限定符
- 类别: 撞名实测
- 现象: 地名同名在不同书被合并/拆分无据；限定符不进 id。
- 判据: 03j §3.2 + gazetteer §5.4：同名地点默认共享（同一地点跨书共用一条，books 聚合）；冲突拆分=主条目保留原 id、
  拆出条目 id 加 `@书` 限定符；aliases 不互挂；/atlas 各落各点；拆分同步 #7 台账。
- 动作: 书集维度判同/异；拆分条 `@书`；渲染按当前书集过滤。
