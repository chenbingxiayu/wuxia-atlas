## A 区 · 七步解析链

### RT01 · 七步解析链总表（N4 实现分解）
- 类别: 七步解析链
- 现象: 解析跳步（直接年号换算）；失败不标原因。
- 判据: 04e §三 七步：① 令牌读取（`%` 令牌+管道→display/type/chapter/pn；管道非法→04c A 径）；② 粒度判定
  （年/季/月/日/时段五级）；③ 锚点识别（朝代/事件/年龄/时令/时长锚）；④ 基准绑定（锚点+回序→t0；基准不明→low）；
  ⑤ 相对量加减（t=t0±Δ）；⑥ 排轨（主轨/对白隔离/fork；冲突→W 类）；⑦ 单调性（E1/E2/E4）；每步失败有处置。
- 动作: N4 实现按七步分函数；每步记 failure_reason；报告分步统计。
- 反例: 跳到⑤硬算——基准 t0 未绑定，结果不可审计（RP-01）。
- 来源: `SKILL_04e` §三；`scripts/time_resolver_wuxia.py` S1-S6。
- 状态: 已验证

### RT02 · 令牌读取与管道：`%` 三管道（时点/时长/年龄），管道右侧是受控子标签
- 类别: 七步解析链
- 现象: 把 `%` 管道右侧当规范名；时点/时长/年龄混标。
- 判据: 04e §三 Step1：`%` 令牌+管道 → (display,type,chapter,pn)；管道右侧=受控子标签（时点/时长/年龄），
  非规范名（01g §2.2.1a；concordance 口径 canonical=显示串）；管道非法→04c A 径。
- 动作: 解析器按 type 分派；非法管道记录；显示串取左侧。
- 反例: 把"十年|时长"当规范名"时长"——canonical 是显示串"十年"，type=时长。
- 来源: `SKILL_04e` §三；`SKILL_01g` §2.2.1a；`registry/concordance` spec。
- 状态: 已验证

### RT03 · 粒度判定五级：年/季/月/日/时段；无法判→unknown/low
- 类别: 七步解析链
- 现象: 粒度虚高（年→日）；无法判时猜一个粒度。
- 判据: 04e §三 Step2：显示串→粒度五级（纪元级/年级/季月级/日级/日内级；D05 §二 五级）；无法判→unknown/low；
  RP-08 粒度虚高检测（年→日）。
- 动作: 粒度取最低可保证级；约略表达标精度=约略；未判留 unknown。
- 反例: "次年春天"给到"日"粒度——只能到季/年级，粒度虚高。
- 来源: `SKILL_04e` §三；`SKILL_时间体系` §二 五级。
- 状态: 已验证

### RT04 · 锚点识别四类：朝代/事件/年龄/时令（+时长非锚点）
- 类别: 七步解析链
- 现象: 时令/事件弱锚当强锚；把时长当锚点。
- 判据: 04e §三 Step3/§4：锚点四类（朝代/事件/年龄/时令）；时长/年龄不产生时点（N4 口径：时长与年龄不产生
  时点，只解析数值）；锚点置信排序见 D05 §3.2（朝代 > 事件强 > 年龄 > 事件弱 > 时令）。
- 动作: 按类识别并分级；非锚点归时长/年龄字段；事件锚需 04a 事件落库互证（RT07/RT09）。
- 反例: "十年"（时长）当时间锚定位年份——时长不产生时点。
- 来源: `SKILL_04e` §三/§4；`SKILL_时间体系` §3.2；N4 汇总 §二 锚点分布。
- 状态: 已验证

## B 区 · 相对表达与基准

### RT05 · 相对表达规则表：11 型表达→基准/运算/置信
- 类别: 相对表达与基准
- 现象: 同一表达式（"五年前/三年后"）不同批解析不同基准。
- 判据: 04e §四 规则表 11 型：绝对纪年（朝代/年号锚→区间映射 high 区间级）、干支纪年（朝代锚+干支循环→就近
  匹配 ±60 年唯一 medium）、明确日期（八月十五→年份基准→定日 medium）、时令（中秋/元宵/黄昏→邻近时点/年份基准
  →medium/low）、相对点（五年前/第二日/次日→前文最近时点（同线）→±时长 medium）、相对量（三年后/十年→前文基准
  →+Δ low）、连年/多年（区间拉长 low）、年龄（十八岁/五十余岁→人物出生/年龄锚→medium，约数降 low）、同时
  （与此同时/同一日→当前时点→相等 medium）、追叙（三年前回忆句→fork 基准→独立刻度 low）、对白（人物说"明天"
  →对白语境隔离→不进主线）。
- 动作: 按表达型查表；置信按表定档；未匹配表→unknown。
- 反例: "三年后"按精确日算——相对量 Δ 可能约量，置信低。
- 来源: `SKILL_04e` §四；N4 `CHECK_RULES`.
- 状态: 已回写

### RT06 · 基准选择顺序五级：最近前文→回内年份时令→年龄锚→事件锚→未解析（禁默认年）
- 类别: 相对表达与基准
- 现象: 无基准硬算绝对年；用出版年/作者年当书内年。
- 判据: 04e §4.1 基准选择顺序：① 同线最近前文时点（默认）；② 回内明确年份/时令锚；③ 人物年龄锚
  （"十八岁那年"）；④ 事件锚（"泰山大会之后"——需 04a 事件落库互证，未落库降 low）；⑤ 无基准→未解析/low
  （**禁止**默认用出版年/作者年）；RP-02 禁用出版年/作者年。
- 动作: 基准按序取；无基准留未解析；报告基准来源统计。
- 反例: 无任何锚点时按"书出版年 1957"推算——RP-02 明禁。
- 来源: `SKILL_04e` §4.1；D05 §2.6/§8.4；N4 未解析 187。
- 状态: 已验证

### RT07 · 年号/干支换算口径：年号→区间，不承诺精确公历日；干支 60 年窗口唯一才 high
- 类别: 相对表达与基准
- 现象: 年号映射到精确公历日；干支乱配。
- 判据: 04e §4.2（与 03b §8.3 分工）：年号+年/年间/元年→`%`（03b 已定）；本文负责把年号映射为**区间**
  （年号元年+年数），不承诺精确公历日；干支：以朝代锚限定 60 年窗口内**唯一**匹配才 high，否则 medium/low；
  朝代区间锚（如"东汉 25-220"）N4 实测 low（区间级），仅作约束不作事实；RP-06 检测年份→精确日。
- 动作: 年号输出区间+依据；干支按窗口唯一性定档；跨书换算只作显示辅助。
- 反例: "万历四十三年"给精确公历日 1615-xx-xx——只到年/区间（high 区间级）。
- 来源: `SKILL_04e` §4.2；`SKILL_03b` §8.3；D05 §2.5；docs/55。
- 状态: 已验证

### RT08 · 年龄锚规则：年龄是强锚（N4 实测 244 处）；约数降一档
- 类别: 相对表达与基准
- 现象: 约数年龄当精确（"十八九岁"算 18）；年龄锚与出生年不联动。
- 判据: 04e §4.3：年龄是武侠强锚点（**N4 实测 244 处**）；"十八岁那年"→与前文出生/年龄锚联动；
  约数（"十八九岁""五十余岁"）→区间，置信降一档（RP-05）。
- 动作: 年龄锚建档（人物出生/年龄）；约数→区间；跨书年龄冲突登记（04d1 CH18）。
- 反例: "五十余岁"当 50 岁——约数降档且区间化。
- 来源: `SKILL_04e` §4.3；N4 汇总 §二（人物年龄锚 244）；`references/04d1` CH09。
- 状态: 已验证

### RT09 · 时令与同时表达：时令定位季/时段，同时=当前时点相等
- 类别: 相对表达与基准
- 现象: 时令（中秋/元宵/黄昏）硬给具体日；"与此同时"未对齐。
- 判据: 04e §四：时令→定位季节/时段（medium/low）；同时（与此同时/同一日）→当前时点相等（medium）；
  连续/同日需与相邻时点对齐（D05 §4.5）；事件锚未互证降 low（RP-09）。
- 动作: 时令只到季/时段；同时对齐当前时点；事件锚需事件层互证。
- 反例: "中秋"给八月十五精确日——除非正文明写日期，否则只到季/时段。
- 来源: `SKILL_04e` §四；`SKILL_时间体系` §4.5；N4 时点定位率 74.0%。
- 状态: 已验证

## C 区 · 隔离与分叉

### RT10 · 对白隔离：人物说"明天"不进主线
- 类别: 隔离与分叉
- 现象: 对白中时间词推进主轨；引号内"三年前"拉回主轨。
- 判据: 04e §5.1：对白内时间**不进主线**（对白语境隔离）；N4 实测对白隔离 **573** 条；D05 §4.3/§4.4；
  RP-03 检测。
- 动作: 解析器判 in_dialogue→隔离；对白内时间标但不用来推进主轨。
- 反例: 人物说"二十年前我见过他"直接把主轨往回拉——对白隔离。
- 来源: `SKILL_04e` §5.1；`SKILL_时间体系` §4.3；N4 汇总（对白隔离 573）。
- 状态: 已验证

### RT11 · 追叙/闪回 fork：独立刻度、隔离主轨；未登记分叉=潜在 E1 误报
- 类别: 隔离与分叉
- 现象: 追叙不建 fork 直接进主轨，导致 E1 假阳性；或所有"那年"都建 fork 碎片化。
- 判据: 04e §5.2：追叙（N年前/当年）建 **fork** 并隔离（独立刻度）；N4 实测 **171** 闪回候选；fork 逐条确认；
  未登记分叉=潜在 E1 误报（04d1 CH07）。
- 动作: 追叙信号→fork；fork 逐条确认；不确认者保留待核。
- 反例: 所有"那年"都建 fork——须有明确追叙信号（回头看/忆起/旁白交代）。
- 来源: `SKILL_04e` §5.2；`SKILL_时间体系` §4.2；`references/04d1` CH07。
- 状态: 已验证

### RT12 · 多线并行：分轨标记，不回退（RP-07）
- 类别: 隔离与分叉
- 现象: 多线（主线/支线/回忆线）共用一条 t 轴，单调性误报。
- 判据: 04e §5.3：多线并行须分轨标记（线 id）；各线独立单调；RP-07 多线未分轨检测；D05 §4.2 时轴分叉。
- 动作: 分轨（line_id）；各线独立排轨；跨线同时用 simultaneous 对齐。
- 反例: 把支线事件插进主线 t 轴——E1 假阳性。
- 来源: `SKILL_04e` §5.3；`SKILL_时间体系` §4.2；N4 fork/轨道字段。
- 状态: 已验证

### RT13 · 产物 schema：time_points 必填字段与未解析记录
- 类别: 隔离与分叉
- 现象: 解析结果无 tp_id/无 loc；未解析项无原因。
- 判据: 04e §六/§6.1：产物 schema `wuxia-time-resolve-v1`：每 time_point 含 tp_id/段锚（`{work}#pn-r{回}.{段}`）/
  display/type/粒度/锚点/基准/偏移/t_days/conf/fork/line_id 等；未解析记录必须带 `unknown_reason`（无锚/歧义/跳变）；
  RP-10 检测缺 tp_id。
- 动作: N4 输出按 schema；`registry/time/<书>.json` 校验；未解析清单进报告。
- 反例: 解析结果只有 t 数值无 tp_id——下游无法回链（RP-10）。
- 来源: `SKILL_04e` §六；`registry/time/*.json`（wuxia-time-resolve-v1）；`references/04d1` CH01。
- 状态: 已验证

### RT14 · RP-01~10 错误模式：无基准硬算/出版年/对白进主线/追叙倒流/约数年龄/年号精确日/多线/粒度虚高/事件锚未互证/无 tp_id
- 类别: 产物与实测
- 现象: 同类时间解析错误反复（无基准硬算、对白进主线、年号给日）。
- 判据: 04e §八 RP-01~10：RP-01 无基准硬算绝对年→降 low/未解析；RP-02 出版年/作者年→禁止；RP-03 对白时间进主线
  →排除；RP-04 追叙当主线倒流→建 fork；RP-05 约数年龄当精确→降一档；RP-06 年号→精确公历日→只到区间；
  RP-07 多线未分轨→分轨；RP-08 粒度虚高（年→日）→降粒度；RP-09 事件锚未互证→降 low；RP-10 无 tp_id→补。
- 动作: 解析后逐条自查；错误编号只增；可规则化者进 N4 校验器（`--selftest`）。
- 反例: RP-03 常见：对白内"今晚"推进主轨——必须隔离。
- 来源: `SKILL_04e` §八；`scripts/time_resolver_wuxia.py`。
- 状态: 已验证

### RT15 · N4 实测：3,413 令牌/90.4% 解析/74.0% 定位；主轨 607/对白 573/分叉 171/未解析 187/E1E2=0
- 类别: 产物与实测
- 现象: 只看解析率不看定位率/隔离比例；或 E1/E2=0 就认为时间轴完美。
- 判据: N4 5 书汇总实测（logs/time/time_resolve_summary.md）：时间令牌 **3,413**；解析率 **90.4%**；时点定位率
  **74.0%**；主轨 607/对白隔离 573/分叉（闪回候选）171/未解析 187；**E1 0/E2 0**；错误码 T05×5/T15×4/T11×1/T07×2；
  朝代锚 48；置信 high/medium/low 逐书分布（江湖 515/152/628 等）。定位率 74% 说明 26% 时点仍无书内刻度（合法：
  时长/年龄不产生时点+无锚未解析）。
- 动作: 报告分列解析率/定位率/隔离比例/错误码；E1/E2=0 需结合 26% 未解析理解。
- 反例: 把"解析率 90.4%"当"时间轴可信"——定位率仅 74%，且 187 未解析、171 分叉待确认。
- 来源: `logs/time/time_resolve_summary.md` §一/§二；`SKILL_04e`；docs/56 §五。
- 状态: 已回写

### RT16 · 未解析与降档：显式 unknown_reason（无锚/歧义/跳变）、不补默认年、审查不写回 N4 产物
- 类别: 产物与实测
- 现象: 未解析项默认填年；或审查直接改 registry/time。
