## EV01 · 13 类定版（T01-T13），一事件一主类型

- 类别: D 事件与动词
- 现象: 一事件填两主类型，或自造类型码。
- 判据: 13 类定版（T01 比武/T02 杀伐/T03 夺宝/T04 传艺/T05 练功/T06 盟约/T07 门派/T08 朝廷/T09 战争/T10 婚恋/T11 生死/T12 行踪/T13 大会容器）；**一事件一主类型**，交叉事实用关联字段（所属战斗/子事件/事件链）承载。
- 动作: 主类型唯一性校验；容器型（T13）另立容器标记。
- 反例: "夺谱引发血战"拆成 T03+T02 两条事件，不把两条主类型塞进一条。
- 来源: `SKILL_04a` §3.4；EX-5 `event-v1` type/type_label。
- 状态: 已验证

## EV02 · 类型归属优先级：P1 战争级 ＞ P2 朝廷主体 ＞ P3 生死 ＞ P4 器物目的 ＞ P5 其他

- 类别: D 事件与动词
- 现象: 朝廷围剿记成杀伐、灭派过程记成门派兴替。
- 判据: 优先级 P1-P5（04a §3.3）；一事件只按最高优先级取主类型，次优先事实另记（子事件/关联）。
- 动作: 类型判定按优先级顺序过；冲突时高优先胜。
- 反例: 官兵围剿+山寨死伤 → T08 朝廷剿抚（P2），死伤另立；山寨主处决 → T02（P2 不命中）。
- 来源: `SKILL_04a` §3.3；EX-5 类型分布实测（T08 280/T02 781）。
- 状态: 已回写

## EV03 · 事件 ID 格式 `{书ID}#{回号}-{序号}`，序号发布后不变

- 类别: D 事件与动词
- 现象: 事件 ID 嵌 PN、重排旧序号、跨回改号。
- 判据: 书ID 同源；回号 2 位、序号 3 位按回内阅读顺序；**序号发布不变**，补录用追加序号；事件 ID 不嵌 pn（PN 是文本锚，一对多）。
- 动作: 事件 ID 生成器按格式；定位字段（回/段/字符区间）对接 PN。
- 反例: 结构重生成后重排事件序号——破坏引用。
- 来源: `SKILL_04a` §8.1；EX-5 `event_id`（如 `000.003.01`）。
- 状态: 已验证

## EV04 · 36 字段分层必填（★/◐/可选/⚙），最低字段不可减

- 类别: D 事件与动词
- 现象: 事件只填类型/参与方，时间/五状态/定位缺省。
- 判据: 36 字段必填性分层（04a §5.1）；01g §2.2.3a 最低字段全部迁入、无一减损；★必填缺失=事件不合格。
- 动作: 生成器按字段表填充；缺省按"未知"显式声明（字段 34 降级待审）。
- 反例: 缺 event_id/主域/时间槽位的事件不入库。
- 来源: `SKILL_04a` §5.1；EX-5 `event-v1` 字段集（event_id/type/verb_domain/participants/outcome/tp_id…）。
- 状态: 已验证

## EV05 · 五状态五组：发生/完成/来源/可信/叙述模式（值域定版）

- 类别: D 事件与动词
- 现象: 五状态只填一两个，或自造值。
- 判据: 发生状态六值（已发生/正在发生/计划/条件/未发生/未知）、完成状态四值（完成/未遂/中断/未知）、信息来源六值、可信状态四值、叙述模式五值。
- 动作: 字段 17-21 全填；自造值即违例。
- 反例: 把"计划"填进完成状态——发生/完成两组不混。
- 来源: `SKILL_04a` §5.1 字段 17-21；`SKILL_02e`（叙述模式）。
- 状态: 已验证

## EV06 · 五状态消费矩阵决定问答/评分/编年/索引许可

- 类别: D 事件与动词
- 现象: 任何事件都进问答/评分。
- 判据: 6 来源×4 可信矩阵；问答/评分只取「已核实」格；编年分流传闻轨/存疑轨；索引全收标层级（详见 `02e1_叙事模式规律库_武侠版.md`）。
- 动作: 消费端按矩阵过滤；事件字段 19/20 校验。
- 反例: 来源声称的战斗进评分——评分只取已核实。
- 来源: `SKILL_04a` §7.1；`02e1` N01/N06。
- 状态: 已回写

## EV07 · 粒度三档与拆分三判：谓词不同/时间不同/参与方不同即拆

- 类别: D 事件与动词
- 现象: 复合叙述塞一条事件，或把一事件拆碎。
- 判据: 粒度三档（回内单元/事件/子事件）；拆分三判（谓词不同/时间不同/参与方不同）；"一场比武打了三页"按三判拆。
- 动作: 拆分后共享 loc、各自独立可核；子事件挂父容器。
- 反例: "夺剑刺死"拆 2 事件（转移+杀害）——两谓词两原子。
- 来源: `SKILL_04a` §2.2/§2.3；`SKILL_05d_事实发现_武侠版.md`（原子性同构）。
- 状态: 已验证

## EV08 · 跨回大战：一记录多区间或事件链，不重复建记录

- 类别: D 事件与动词
- 现象: 跨三回的大战建三个独立事件，战绩断裂。
- 判据: 同一战斗跨回 → 一个记录多区间定位；不同战斗 → 事件链（prev/next）或母容器。
- 动作: 定位字段多区间；事件链槽位（字段 31）。
- 反例: "大战三回"拆成三个互不关联记录 → 整场战绩断裂（04a §6.5 反例同构）。
- 来源: `SKILL_04a` §2.5/§8.3；EX-5 事件链字段。
- 状态: 已验证

## EV09 · 容器型 T13：多场子事件＋统一名目；EX-5 实测 0 命中（聚合阈值待定）

- 类别: D 事件与动词
- 现象: 单场比武+宴席被立为"武林大会"容器。
- 判据: T13 容器门槛=多场子事件+统一场面名目+多方齐聚；不足门槛→并列事件不立容器。
- 动作: 容器记录+子事件列表双向关联；EX-5 当前 T13=0（聚合阈值未定，待升级）。
- 反例: "只有一场比武加一顿宴席"→ 不够容器门槛（04a §3.4 T13 边界）。
- 来源: `SKILL_04a` §3.4 T13/§4.4；EX-5 实测（docs/59 §一：T13 0 命中）。
- 状态: 候选

## EV10 · 群体事件四档参与者＋群体死伤字段

- 类别: D 事件与动词

## EV11 · 战斗记录=事件模板实例，battle_id=event_id（不设平行编号）

## EV12 · 独立死亡记录＋战斗关联：死伤不藏在战斗栏

- 现象: 只在战斗记录死伤栏写"卫士×2"，不建死亡记录。

## EV13 · outcome 五值＋参照方＋可引原文判定依据（对抗类必填）

- 类别: D 事件与动词

- 状态: 已验证

## EV14 · 锚点动词对接：触发词区间；无动词入口用"状态句入口"

## EV20 · EX-5 22,978 事件 vs 旧人工约 1/3 量级：逐动词候选粒度，不直接相减

- 类别: D 事件与动词
- 现象: 用 22,978 与旧站 484 场/旧人工事件表直接比较，误判质量。
- 判据: EX-5 为**逐动词候选粒度**（一个动词入口一条事件），旧人工事件表约其 1/3 量级；matches 215 场是"主宾俱全+outcome∈{胜,负,平}"的子集；数量不可直接相减。
- 动作: 质量评估按类型/置信/主宾完备率分层；不按总量比。
- 反例: 以事件总量判"新优于旧"或"新漏旧"——口径不同。
- 来源: EX-5 实测（docs/59 §一/§1.2）；`logs/events/_summary.md`；`logs/export/reports/matches_report.md`。
- 状态: 候选
