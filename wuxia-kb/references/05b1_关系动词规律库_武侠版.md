## A 区 · 联动候选

### RL01 · 04f 联动 27 行表结构：触发动词/子型→联动实体→强度→谓词建议
- 类别: 联动候选
- 现象: 从共现直接编关系边；联动表版本与 D06 不一致。
- 判据: 05b §3.1（引 04f §四）：联动表 27 行结构=触发动词/子型 → 联动实体 → 强度（强制/建议）→
  三元组候选（谓词建议）→ 缺失处理；联动是**候选生成器**不是定论。
- 动作: N5 落库前核对联动表版本与 D06 55 谓词白名单；候选进核验队列。
- 反例: 见"打"就建交手边——先确认战斗对手实体与结果域（04f2:VB02）。
- 来源: `SKILL_05b` §3.1；`SKILL_04f` §四；`references/04f2` VB10。
- 状态: 已验证

### RL02 · 候选生成规则：触发词 × 同段实体对 → (S,?,O)，多谓词歧义进候选池
- 类别: 联动候选
- 现象: 跨段远距离配对；一行动作挂到上下文最近的实体（强制缺失时硬挂）。
- 判据: 05b §3.2：候选 = 04f 触发词 × 同段实体对；触发词边界见 04f §3.1；强制档缺失→降级待审
  （04f §4.2 铁律 2）；多谓词歧义→候选池不硬选（判定顺序④）。
- 动作: 同段窗口候选；缺失强制实体→待审；歧义→候选池；放弃记原因（RL10）。
- 反例: "⟦▣练成⟧"句无武功名→待审，不能挂到上一句的剑法上（04f §4.3 反例）。
- 来源: `SKILL_05b` §3.2；`SKILL_04f` §3.1/§4.2；`references/04f2` VB11。
- 状态: 已验证

### RL03 · 谓词判定顺序五步：语式直证→域+对象类型→上下文唯一性→候选池→放弃
- 类别: 联动候选
- 现象: 跳过语式直证先猜谓词；或无法判定时硬选一个。
- 判据: 05b §4.1 判定顺序：① 语式直证（"A 拜 B 为师"→师承，方向 B→A）；② 动词域+对象类型（⊟ 赠 + •→赠予）；
  ③ 上下文唯一性（同段仅两实体、动作链清晰）；④ 多谓词歧义→候选池（不硬选）；⑤ 无匹配→放弃（记原因）。
- 动作: 按序短路；每步记 rule 依据；候选池不落库正式边。
- 反例: 无语式直证却按"可能"给 strong——顺序①未过应走④/⑤。
- 来源: `SKILL_05b` §4.1；`SKILL_关系体系` §8.4 语式表。
- 状态: 已验证

## B 区 · 谓词判定与验证

### RL04 · 实体关系子类与谓词示例：地点/制度/事物/异名/武功层级
- 类别: 谓词判定与验证
- 现象: 人物-地点关系用人物谓词；异名关系重复建边；武功层级边越层。
- 判据: 05b §4.2：地点关系（人物-地点：位于/属于/发生于，地点用 gazetteer id）、制度关系（人物-组织/职衔：
  隶属/统属/任职）、事物关系（人物-器物/文书：持有/赠予/夺取/失落，与神兵表 chain 对齐）、异名关系
  （绰号↔本名：直接落 03b 别名映射，不重复建边）、武功层级（招式∈武功∈心法：层级归 D08 树，边只记**直接**关系）。
- 动作: 先判子类再选谓词；异名走别名系统；武功层级不越层建边。
- 反例: 给"绰号↔本名"建 relation 异名边——应落 registry aliases（SPO-10）。
- 来源: `SKILL_05b` §4.2；`SKILL_关系体系` §三/§七；`references/05a1` RP04。
- 状态: 已验证

### RL05 · 谓词白名单 55 条：超表即 SPO-02（改谓词/报 D06）
- 类别: 谓词判定与验证
- 现象: 自造谓词（"打斗/认识/喜欢"）入库；谓词名与 55 总表不一致。
- 判据: 05b §八 SPO-02：谓词超 55 总表即违规——改谓词或报 D06 讨论（新谓词须过 §7.4 命名一致性检查），
  不得静默入库。
- 动作: N5 按 55 白名单校验；自造谓词→映射已有/上报；新谓词走 D06 治理。
- 反例: "打斗"自造谓词——白名单用"交手"（#53）；语义相同即改。
- 来源: `SKILL_05b` §八；`SKILL_关系体系` §7.2/§7.4；`references/05a1` RP02。
- 状态: 已验证

### RL06 · 方向与对称：师承不对称、结义/婚约对称、交手对等、方向反=RE-03 拆边
- 类别: 谓词判定与验证
- 现象: 师承方向颠倒（徒→师）；对称谓词只记单边；交手记成有向支配。
- 判据: 05b §4.3（D06 §八）：师承=师→徒（不对称）；结义/婚约=对称（双边记录或对称标记）；赠予=施→受；
  交手=对等（双向可记一次或对称标记）；杀害=施→受；**方向反了=RE-03，必须拆边重记**。
- 动作: 边落库前核方向；对称谓词补反向或 symmetric 标记；方向错误拆边。
- 反例: "冯琳拜师晦明"标成 晦明→冯琳 的徒→师——方向反；应师→徒（晦明→冯琳）。
- 来源: `SKILL_05b` §4.3；`SKILL_关系体系` §7.2 方向列；`references/05a1` RP07。
- 状态: 已验证

### RL07 · 五项验证属性：方向性/对称性/可传递性/互斥性/时序约束（不过降 weak 不删边）
- 类别: 谓词判定与验证
- 现象: 验证不过直接删边；或五项全过却只给 weak。
- 判据: 05b §五：① 方向性（动词语义 vs 主宾位置）→拆边；② 对称性（对称表）→补反向；③ 可传递性→不推导；
  ④ 互斥性（婚约 vs 仇怨可并存；师承 vs 叛门记时序）；⑤ 时序约束（门派存续/生死/职任期间，记 loc+N4 时间锚）。
  **五属性不过 ≠ 删边**：可降 weak 并记"验证未过"原因；strong 边五项全过。
- 动作: 落库时逐项打勾；不过降档记录；strong 门槛五项全过。
- 反例: 时序缺失就删师承边——应保留边+记 `time_anchor:null` 降 weak。
- 来源: `SKILL_05b` §五；`SKILL_关系体系` §八；`references/05c1` QY06。
- 状态: 已验证

## C 区 · 落库与放弃

### RL08 · edge schema（relations-v0.1）必填字段：subject/type/predicate/object/置信/loc/证据/params
- 类别: 落库与放弃
- 现象: 落库边缺 loc/证据；params 方向/对称字段缺失，下游无法核验。
- 判据: 05b §6.1 schema：subject/subject_type/predicate/object/object_type/confidence/loc（PN）/
  evidence{level,rule,snippet_short}/params{direction,symmetric,transitive}；必须可回链（RL11）。
- 动作: N5 产物按 schema 校验；缺 loc→补 PN（SPO-08）；params 缺失→补。
- 反例: 只存 subject/predicate/object 三字段——下游无法定位证据（SPO-08）。
- 来源: `SKILL_05b` §6.1；`registry/relations/*.json`（relations-v0.1）；`references/03d1` H12。
- 状态: 已回写

### RL09 · 落库流程（N5）：候选→五项验证→置信分档→落库/候选池/放弃
- 类别: 落库与放弃
- 现象: 候选直接落库；放弃无记录无法审计。
- 判据: 05b §6.2 落库流程：候选 → 五项验证 → 置信分档（strong/ok/weak）→ 落库（或候选池/放弃）；
  落库与 04f/实体/归属同批（检查清单落库前）。
- 动作: N5 批量落库；报告分列落库/放弃；放弃原因分类（RL10）。
- 反例: 为提升边数跳过验证——弱信号冒充 strong（SPO-09）。
- 来源: `SKILL_05b` §6.2；`logs/relations/_summary.md`.
- 状态: 已验证

### RL10 · 放弃原因分类六类：无事件层/证据不足/谓词不匹配/同名异人/语境排除/群体动作
- 类别: 落库与放弃
- 现象: 放弃的候选无原因；同类放弃反复出现无法归因。
- 判据: 05b §七 六类：无事件层（仇怨/毁损需事件锚→04a 后重跑）、证据不足（弱语式/孤立共现→weak 候选池）、
  谓词不匹配（超 55→D06 讨论）、同名异人（03b 消歧后重试）、语境排除（计划/否定/围栏）、群组/群体动作
  （不可归个人→群体层，01g §9.8 红线）。
- 动作: 放弃必须记原因+走向；报告分类统计（N5 放弃 1,145）。
- 反例: 放弃原因写"不合适"——无法审计/复跑；必须落六类之一。
- 来源: `SKILL_05b` §七；`logs/relations/_summary.md`.
- 状态: 已验证

### RL11 · 派生同门：由师承派生 +16，不逐条人工标（derived 标记）
- 类别: 落库与放弃
- 现象: 同门当人工边逐条登记；或派生边不带标记无法区分。
- 判据: 05b §1.4/§六：同门=同师派生（N5 实测 +16 边），不逐条人工标；派生边带 derived 标记；EX-4 投影可带
  derived（docs/57 §三）。
- 动作: 先落师承边，再由规则派生同门；derived 标记；不反向用同门补师承。
- 反例: 师承未知时凭"同门"补师承——派生方向只能是师承→同门。
- 来源: `SKILL_05b` §1.4；`SKILL_关系体系` §4.6；`references/05a1` RP11。
- 状态: 已验证

### RL12 · SPO-01~10 错误模式：见动词编边/谓词超55/方向颠倒/对称单边/计划否定/群组归个人/多谓词并存/loc 不可解析/weak当strong/异名重复

### RL14 · 置信梯度与发布：strong 105 全五项过/ok 711/weak 94 不发布

- 反例: weak 边（如仅同名共现）进 graph.json——SPO-09 违规。
