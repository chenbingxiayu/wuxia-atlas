## A 区 · 五原则评估

### TY01 · P1 频次：新增 ≥30 处跨 ≥3 书；合并 ≥90% 实例归并后无歧义
- 类别: 五原则评估
- 现象: 凭一两个例子提新类型；新类型全年只有个位数实例（类型空转）。
- 判据: P1 频次：新增类型须 ≥30 处跨 ≥3 书；合并须 ≥90% 实例归并后无歧义（03e §四 P1）；证据必须带
  语料 loc 与统计数字（提案卡）。
- 动作: 提案附频次统计（跨书/逐书）；不足 30 或仅 1 书 → 关闭或改词表条目（TRE-03）。
- 反例: 单书高频但跨书零实例的半文半白类型——先作为该书词表条目，不新增全局类型。
- 来源: `SKILL_03e` §四 P1/§4.1；`SKILL_分类树五件套` §7.1；TRE-01/TRE-03。
- 状态: 已验证

### TY02 · P2 正交：同词汇任何上下文只属一个类型（01g §三 Disjoint）
- 类别: 五原则评估
- 现象: 两类型无判别信号，标注员每次靠猜；边界案例沿管线放大。
- 判据: P2 正交：同一词汇在任何上下文是否只属一个类型（01g §三 Disjoint）；两类型须有可执行判别信号
  （词表/句式/字段）；P2 <4 禁止新增（03e §4.2）。
- 动作: 提案写 Disjoint 声明与判别信号；P2 <4 → 合并方案或降为属性（TRE-02）。
- 反例: "掌门"同时标 `;` 与 `#` 两类型——无判别信号即 P2 不通过；应按建制/身份拆分判据（03a D1）。
- 来源: `SKILL_03e` §四 P2/§4.2；`SKILL_01g` §三；TRE-02。
- 状态: 已验证

### TY03 · P3 边界可判：≥5 正例 + ≥5 负例 + 1 条冲突兜底
- 类别: 五原则评估
- 现象: 类型定义只有抽象描述，标注员遇边界就自由心证。
- 判据: P3 边界可判：能给出 ≥5 条正例 + ≥5 条负例 + 1 条冲突兜底（03e §四 P3）；边界不可判的类型禁止新增
  （03e §4.2：新增须 P2/P3 均 ≥4）。
- 动作: 提案附正/负例与兜底规则；P3 <4 → 关闭或合并；边界错误走 S-03f（TRE-08）。
- 反例: 用"语境判断"代替判据——不可自动/半自动，成本失控；必须落成词表/句式/字段。
- 来源: `SKILL_03e` §四 P3/§4.2；`SKILL_03f`（边界错误反思）。
- 状态: 已验证

### TY04 · P4 下游增益：至少 1 个具体下游（页面字段/统计口径/SKU 字段）（待裁）
- 类别: 五原则评估
- 现象: 为分类而分类；新类型没有页面/字段/统计消费，知识库不增值。
- 判据: P4 下游增益：至少 1 个具体下游（页面字段/统计口径/SKU 字段）（03e §四 P4）；"下游增益"的认定
  口径（是否必须是已实现页面，还是设计稿字段亦可）待裁（03e 附录 B 同类开放项）。
- 动作: 提案点名下游与读出字段；无下游 → 挂 watch 不新增；认定争议上抛 Lead。
- 反例: 以"N10/SKU 卡以后可能会用"当下游——设计稿字段可作为候选，但不能与已实现字段同权。
- 来源: `SKILL_03e` §四 P4；`SKILL_SKU卡片`；references/templates §W8.
- 状态: 待裁

### TY05 · P5 成本可回收：变更影响 ≤1 波次、可脚本化迁移、有回滚
- 类别: 五原则评估
- 现象: 一次类型改动拖垮整批标注（迁移/重标/词表/脚本全翻工）。
- 判据: P5 成本可回收：影响 ≤1 波次、可脚本化迁移、有回滚（03e §四 P5）；四类动作方案必须写迁移脚本与
  回滚点（03e §7 试点与 diff 规范）。
- 动作: 提案附迁移脚本/回滚点/回归口径（5 书 accept 不退化）；成本超波次 → 拆分或推迟。
- 反例: 全库重标型改名——旧编号/旧引用全失效；应保留旧名映射 + 增量迁移。
- 来源: `SKILL_03e` §四 P5/§七；`SKILL_03a` §2.5 纪律。
- 状态: 已验证

### TY06 · 评分卡与决策阈值：≥18 试点 / 12-17 watch / <12 关闭
- 类别: 五原则评估
- 现象: 提案不走评分卡；或总分够但 P2/P3 低也放行。
- 判据: 03e §4.1 评分卡：P1-P5 各 5 分，总分 ≥18 进入试点、12-17 挂 watch、<12 关闭；**新增**须总分 ≥18
  且 P2/P3 均 ≥4；**合并**后实例覆盖率 ≥95% 且不丢下游字段；**废弃**须零实例且无下游消费 ≥2 批。
- 动作: 提案文件（v0.1 约定）必填评分卡；决策规则机检；不达阈值不得进试点。
- 反例: "总分 18 但 P3=2"仍试点——新增类型边界不可判，会制造更大混乱；规则明确禁止。
- 来源: `SKILL_03e` §4.1/§4.2；§8.1 提案文件。
- 状态: 已验证

## B 区 · 四类动作流程

### TY07 · 新增类型五步法：侦察→设计→试点→批量→文档
- 类别: 四类动作流程
- 现象: 直接全量标注新类型；无试点 diff；文档滞后。
- 判据: 03e §5.1（照 META-08 类型新增五步法）：① 侦察（S1-S7 信号+跨书频次+同形实例）→ ② 设计（定义/
  判别信号/正负例/Disjoint 声明，≤2 页）→ ③ 试点（≥3 书 30 回 apply 候选词表/规则 → diff 新增/误报/漏报）→
  ④ 批量（全量词表+5 书回归+accept 复跑）→ ⑤ 文档（回写 01g 附录 B-1+词表规划 WL+README/索引）。
- 动作: 每步产出留档（候选卡/设计稿/试点 diff/回归报告/裁决记录）；缺一即未完成。
- 反例: 跳过试点直接批量——误报无法回收；试点 diff 是新增类型的必经闸。
- 来源: `SKILL_03e` §5.1；`META-08`（类型新增五步法）；`SKILL_01g` 附录 B.
- 状态: 已回写

### TY08 · 合并类型流程：≥90% 不可分 → 保留下游字段更全者 → 脚本迁移+剥标断言
- 类别: 四类动作流程
- 现象: 两类型并存但 90% 语境不可分；合并后下游字段丢失。
- 判据: 03e §5.2：① 候选（A/B 两类型在 ≥90% 语境不可分）→ ② 方案（保留 B，A 降为子类/属性）→
  ③ 迁移（旧标 A 的令牌重标 B，脚本化+剥标断言，无法自动的进人工清单）→ ④ 验证（合并前后准确率抽检、
  accept 不退化）→ ⑤ 回写（01g §八 类型表+子类表+错误模式库补"旧 A 标法"反例）。
- 动作: 迁移脚本必须可重跑；人工清单逐条裁决；合并后旧编号不删（保留指针）。
- 反例: 合并后直接删旧类型定义——历史标注/引用断链；旧类型标"停用"保留符号（TY09 同源）。
- 来源: `SKILL_03e` §5.2；`SKILL_01g` §八；`SKILL_03a` 剥标断言。
- 状态: 已验证

### TY09 · 废弃类型：零实例 ≥2 批 + 无下游消费 + 有替代；符号保留标停用
- 类别: 四类动作流程
- 现象: 因"不常用"就废弃；或废弃后历史语料被重标（TRE-05）。
- 判据: 03e §5.3：触发=零实例 ≥2 批 + 无下游消费 + 有替代类型；**废弃不等于删符号**（符号保留但标"停用"）；
  已废弃类型的历史语料**不重标**（TRE-05 检测 tagged diff）。
- 动作: 废弃决定写入 01g 类型表并标停用；下游移入替代类型；历史归档。
- 反例: 为"整洁"重标历史语料——破坏可追溯性；TRE-05 直接判失败并回滚。
- 来源: `SKILL_03e` §5.3；TRE-05；`SKILL_01g` §八。
- 状态: 已验证

### TY10 · 改名：仅语义漂移且旧名歧义；旧→新映射表+迁移脚本，禁止静默重命名
- 类别: 四类动作流程
- 现象: 类型改名无映射；旧引用/旧标注指向已不存在的名字（TRE-04）。
- 判据: 03e §5.4：改名仅当语义漂移且旧名有歧义；必须给旧名→新名映射表与迁移脚本（禁止静默重命名）；
  改名后旧名在文档/引用中保留映射（03e §8.2 回写点）。
- 动作: 映射表入 01g/词表；迁移脚本可重跑；下游（references/页面）同步；改名前后 diff 报告。
- 反例: "顺手把 kind 改叫 subtype"——无映射即断链；改名不是优化命名的自由。
- 来源: `SKILL_03e` §5.4；TRE-04；`SKILL_分类树五件套` §7.3。
- 状态: 已验证

### TY11 · 易混卡 1：门派 ↔ 帮会 ↔ 世家（`◆` 内部三叶）
- 类别: 易混卡
- 现象: 同一组织在不同书/批次里一会儿"武学门派"一会儿"帮会"；家族组织（世家）与门派混。
- 判据: 03e §6.1（docs/05 §2.3 指定）：武学门派=师徒传承/开山收徒；帮会=地缘/行业结社（帮规/香堂/分舵）；
  武林世家=家族传承/同姓数代/庄堡为基；`&` 家族世系与 `◆` 组织分型（03a 类型表）。
- 动作: 按 06e1:GR10 多源实例与 06e1 应届挂叶；三叶判别信号表维护在 06e1/01g；边界案例走 03f。
- 反例: 唐家既是家族（`&`）又在门派志出现（旧站 sects 含唐家）——按登记对象分型，不强行单选。
- 来源: `SKILL_03e` §6.1；`SKILL_分类树五件套` §5.4；`SKILL_03a` 类型表；task-45 塔山族/鲁王合并判例。

## D 区 · 错误模式与实测闭环

### TY14 · TRE 错误模式库（8 条）：凭感觉新增/不可分/单书特设/改名无映射/重标历史/样本偏斜/回写不全/掩盖边界
- 类别: 错误模式与实测闭环
- 现象: 类型反思被误用为"改类型掩盖边界错误"；或只改文档不改词表。
- 判据: 03e §九 TRE-01~08：TRE-01 凭感觉新增（无频次证据）→补 ≥30 实例跨 3 书；TRE-02 与既有类型不可分
  →合并/降属性；TRE-03 单书特设→关闭/词表；TRE-04 改名无映射→补映射+迁移；TRE-05 废弃后重标历史→回滚；
  TRE-06 试点只抽密集章→重抽；TRE-07 回写只改 01g 未同步词表/下游→补 §8.2；TRE-08 用类型反思替代边界修复
  （证据=吞词/粘字）→转 S-03f。
- 动作: 提案前自查 TRE 清单；新增错误编号只增不复用；可规则化者进校验器。
- 反例: 把"边界切错"（吞词/粘字）当类型问题改类型——TRE-08 明确转 S-03f 边界修复。
- 来源: `SKILL_03e` §九；`SKILL_03f`（边界错误反思）；`SKILL_03a` 缺陷库。
- 状态: 已验证
