## V0 · 纪律

### V0-1 · 反思/复核中只增不改：不顺手改动词格式、不迁移符号、计数只增不减
- 类别: D 事件与动词
- 现象: 反思轮里顺手改动词格式/符号，或删除既有令牌导致计数下降。
- 判据: 只增不改；迁移走专项映射；计数只增不减（04f §八 V0-1）。
- 动作: 改动走补丁（`scripts/apply_annotation_patches.py`）+ 剥标断言；迁移单独任务。
- 反例: 以"统一格式"为由批量重写动词括号——破坏可逆性与验收基线。
- 来源: `SKILL_04f` §八 V0-1；04f1 纪律（04f §八 引）。
- 状态: 已验证

### V0-2 · 计划/意图/条件/否定/假想语境中"未发生"的动词不标
- 类别: D 事件与动词
- 现象: "想下山""若要动手""待他回来""没来迟""欲进招"等未发生动作被标 ⟦域⟧。
- 判据: 04f §3.6 + 03a v1.8：计划/意图/条件/否定/命令内容不标；已发生（既成事实/正在实施）才标。
- 动作: 摘标（删令牌）；accept_batch judgment 计划否定项按此裁决；同段多 token 精确到 offset。
- 反例: "动手"在打斗已进行语境=已发生，保留（docs/45 #9 先例）；"捉"已捕获问原因=已发生（#70）。
- 来源: `SKILL_04f` §3.6；docs/45 §三（⑧ 35 条：33 删/2 留）；docs/48 §九（plan_negation 99：76 删/23 留）。
- 状态: 已回写

## V1 · ⊞ 战斗交锋

### V1-1 · 逐招标注连招动作会密度爆炸：起止+关键结果合并标注
- 类别: D 事件与动词
- 现象: 一套连招每一式都标 ⟦⊞⟧。
- 判据: §6.1 合并标注（起止+关键结果）；主/近景交锋逐式标但"招式名称☆每现必标、姿态微动作不标、远景/群战只标主干"（R-013 三分）。
- 动作: 合并/删减；招式名归 ☆。
- 反例: 车轮战/三战三捷按阶段记，不拆到每招（04a §6.5）。
- 来源: `SKILL_04f` §八 V1-1、§6.1；SKILL_03a v1.8 R-013。
- 状态: 已验证

### V1-2 · 姿态动词（跃起/掠出/疾退）不入 ⊞ 或 ■：有战术结果才算
- 类别: D 事件与动词
- 现象: 姿态微动作被标 ⟦⊞⟧ 或 ⟦■⟧。
- 判据: 姿态不标；有独立战术结果（闪避成功/脱离）才算；战斗闪避标 ⊞、日常微动作不标（03a 对照例）。
- 动作: 摘标；战斗语境闪避保留 ⊞。
- 反例: "身形⟦⊞一闪⟧"（战斗闪避）标；"点头/勒马/侧身"不标。
- 来源: `SKILL_04f` §八 V1-2、§2.1；`SKILL_03a` §二对照例。
- 状态: 已验证

### V1-3 · 约战/挑战书当已发生的 ⊞ = 错
- 类别: D 事件与动词
- 现象: "三日后与你比武"被标 ⟦⊞比武⟧。
- 判据: 未发生不标（V0-2 同源）；计划语境不标。
- 动作: 摘标。
- 反例: "两人当即交手"已发生，标。
- 来源: `SKILL_04f` §八 V1-3、§2.1 排除项。
- 状态: 已验证

### V1-4 · 状态句不强造触发词（"僵持不下"）
- 类别: D 事件与动词
- 现象: 给"僵持不下/难分胜负"造 ⟦⊞⟧。
- 判据: 状态登记，不造动词（04f §2.1 排除项）。
- 动作: 摘标；战斗记录 outcome 记"未决/未知"（04a §6.4）。
- 反例: "斗了半日，不分胜负"→ 战斗记录 outcome=平（04a 先例）。
- 来源: `SKILL_04f` §八 V1-4、§2.1；`SKILL_04a` §6.4。
- 状态: 已验证

## V2 · ⊠ 生命健康

### V2-1 · 受伤阈值="改变后续行动能力"：中剑后继续缠斗不标 ⊠
- 类别: D 事件与动词
- 现象: "中了一剑"每次都标 ⟦⊠⟧。
- 判据: 退出战团/倒地/需疗伤/伤重难支 → ⊠；继续缠斗 → 只作 ⊞ 局部结果；关节命中 ⊠ 优先于点穴 ⊞；单纯酸麻痛不构成阈值。
- 动作: 按阈值改域/摘标；`--wordlist-strict` 恢复 error 时同口径。
- 反例: "被扫一鞭继续缠斗"不标 ⊠；"刺中关节透骨"标 ⊠（docs/45 #43/#47）。
- 来源: `SKILL_04f` §八 V2-1、§2.2；docs/45 §三 #32/#43/#47；docs/29 v1.4。
- 状态: 已回写

### V2-2 · 威胁、险些、委婉反讽不入事实
- 类别: D 事件与动词
- 现象: "险些丧命""再不住手便取你性命"标 ⟦⊠⟧。
- 判据: 按状态字段策略（§3.6）；未发生/假设不标。
- 动作: 摘标；确属疑似诊断按 `|疑似，未确证` 注记（v2.1）。
- 反例: "似是中毒"→标事件+疑似注记（不摘，保推断状态）。
- 来源: `SKILL_04f` §八 V2-2、§3.6；03a v2.1 疑似诊断裁决。
- 状态: 已验证

### V2-3 · 自然死亡漏标（病逝/自尽/气绝同属 ⊠）
- 类别: D 事件与动词
- 现象: 只标他杀，病逝/自尽/气绝漏标。
- 判据: ⊠ 含出生/死亡/杀伤/致残/中毒/治疗；自然死亡同属 ⊠。
- 动作: 补标；与 T11 生死救治事件衔接。

### V2-4 · 攻击动作误标 ⊠（"刺出"未中）：攻击 ⊞，致害结果才 ⊠
- 类别: D 事件与动词

- 反例: 自伤伪装（轻微）属生命健康 ⊠（docs/45 #34 保留）。
- 来源: `SKILL_04f` §八 V2-4、§2.0/§2.2；docs/45 §三 #32。
- 状态: 已验证

## V4 · ⊟ 物件变化

### V4-1 · 借/还方向不记录 = 错：方向字段强制，未知记未知
- 类别: D 事件与动词
- 现象: "借/还"只标 ⊟ 不记方向。
- 判据: §四 #13 方向字段强制；未知则记未知，不猜。

- 来源: `SKILL_04f` §八 V4-1、§四 #13。
- 状态: 已验证

### V4-2 · 兵器名内拆动词（断门刀"断"）：名称整体是实体，事件在名称外
- 类别: D 事件与动词
- 现象: "断门刀"中的"断"被标 ⟦⊟⟧。
- 判据: 兵器名整体是实体（`•`）；事件动词在名称外（DEF-06 同源）。

- 反例: "一刀砍断门板"中的"断"是事件动词，标。
- 来源: `SKILL_04f` §八 V4-2；DEF-06。

### V4-3 · 夺人性命误标 ⊟：生命归 ⊠
- 类别: D 事件与动词
- 现象: "夺命/结果了他"标 ⟦⊟⟧。
- 判据: 杀归 ⊠（生命健康）；⊟ 只给物件变化。
- 动作: 改域 ⊟→⊠。
- 反例: "夺剑"（夺物）标 ⊟，mode=夺。
- 来源: `SKILL_04f` §八 V4-3、§2.0。
- 状态: 已验证

### V4-4 · 逐出/驱逐的域归属按"组织除名 vs 强制迁移"分流（待裁边界）
- 类别: D 事件与动词
- 现象: "逐出宫/逐出师门"与"逐出回疆/驱逐出境"同标 ■ 或同标 ⊡。

- 反例: "逐出回疆"不是组织除名（docs/45 #50/#53 保留 ■）；"逐出宫"是组织/宫廷除名（#56 改 ⊡）。
- 来源: docs/45 §三 #50/#51/#53/#56/#58；`SKILL_04f` §2.0/§2.6。
- 状态: 待裁

## W · 武侠特有（跨域/离线/联动）

### W-3 · 招式名→☆、相邻动作→⊞、同一字符一种标注
- 类别: D 事件与动词
- 现象: 招式名被标为动词；动词吞招式名；同字符双标。

- 来源: `SKILL_04f` §八 W-3、§2.1；`SKILL_04a` T05 边界。
