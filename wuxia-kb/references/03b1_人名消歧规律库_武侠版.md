## X01 · 两层 canonical 不混：书内 canonical=本名优先，系列 display=认知最高频

- 类别: B 跨书与管道
- 现象: 书内层与系列层混用（把系列 display 当书内 canonical，或反之）。
- 判据: 书内 canonical 取本名/书内规范名；系列 display 取认知最高频形式（D07 双层规则）；两层各司其职，不混层。
- 动作: registry 记 canonical；`display_canonical.json` 记 display；页面显示 display、内部 key 保持 canonical。
- 反例: 用"飞红巾"当书内 canonical（本名哈玛雅）——书内层未统一（X19）。
- 来源: `SKILL_03b` §7.1；`SKILL_跨书治理_武侠版.md` §四；docs/57 §三。
- 状态: 已验证

## X02 · 帝王四类指称：本名 canonical；年号/庙号入别名；通称禁作别名

- 类别: B 跨书与管道
- 现象: 帝王 canonical 用年号（康熙/崇祯），或把"皇上"写成别名。
- 判据: 本名（朱由检/玄烨/福临/胤禛）=canonical；年号（崇祯/康熙/顺治/雍正）与庙号（思宗/圣祖）入 aliases；通称（皇上/陛下/圣上/今上/先帝/万岁）**禁止作 alias**。
- 动作: registry 改 canonical + aliases；年号指人时标 @ 挂管道，纪年时归 `%`。
- 反例: `E5062` canonical=康熙（年号）→ 改 canonical=玄烨（docs/55 §1.3 已执行）。
- 来源: `SKILL_03b` §8.1；docs/55 §1.3；`SKILL_03a` G-20。
- 状态: 已验证

## X03 · 通称禁入 aliases/contextual；旁白回级可定才挂管道

- 类别: B 跨书与管道
- 现象: 把「皇上/皇帝→本名」写进全局映射/别名 → 其他回全部假冲突。
- 判据: 通称/歧义 surface 禁入 aliases/contextual（loader 摊平单值）；旁白叙述指称 + 本回时代可定 → 才挂管道；对白当面尊称不标。
- 动作: 摘管道保留显示串；回级映射快照承载；registry 删除通称独立实体（`E83494 皇上`）。
- 反例: 江湖 82 条中 26 条通称（皇上×8/皇帝×13/皇上×5）→ 摘管道而非写映射（docs/55 §1.2）。
- 来源: `SKILL_03b` §7.2/§7.3；docs/55 §1.2；docs/47-语义 §四。
- 状态: 已回写

## X04 · 对白当面尊称不标；旁白叙述指称才标

- 类别: B 跨书与管道

- 判据: 对白当面尊称一律不标（D1）；旁白叙述指称可标 @，管道按回级证据挂。

- 反例: 叙述句"皇上在乾清宫召见"→ 旁白指称，可标挂管道（回级可定）。

- 状态: 已验证

## X05 · 年号≠时间词：纪年→`%`、指人→`@`、年号+年+帝称先分词

- 类别: B 跨书与管道
- 现象: "崇祯三年"标 @、"崇祯自缢"标 %。
- 判据: 纪年形态（崇祯三年/康熙十二年/雍正年间）→ `%` 时点；指人（崇祯自缢/康熙即位）→ `@` 挂本名；"X皇帝"→ @ + 称号外置；"X朝"视上下文，不挂人名管道。
- 动作: 分词后按形态判定；称号外置（03a L135）。
- 反例: `〖@崇祯|朱由检〗皇帝` 正确；`〖%崇祯〗` 指人是错。
- 来源: `SKILL_03b` §8.3；`SKILL_03a` §二；docs/45 §三 #69（%老 摘除同源）。
- 状态: 已验证

## X06 · 避讳/异体：改写形入别名，canonical 用定版本名；禁 surface→年号反向管道

- 反例: docs/49 §2.5 已摘 2 处 `允禛|雍正`。
- 来源: `SKILL_03b` §8.4；docs/49 §2.5。
- 状态: 已验证

## X07 · 歧义 surface 禁入单值映射：loader 摊平会放大假冲突

- 类别: B 跨书与管道
- 现象: 把歧义通称写进映射快照，qa `pipe_issues` 从 136 涨到 321。

- 反例: 第一版「皇上/皇帝→本名」写入快照 → 118+ 条他回假冲突（docs/55 §1.2 关键工程判断）。
- 来源: `SKILL_03b` §7.2；docs/55 §1.2；docs/59 §四。
- 状态: 已回写
