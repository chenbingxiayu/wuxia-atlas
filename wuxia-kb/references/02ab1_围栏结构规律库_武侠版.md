## A 区 · 围栏枚举与铁律

### FN01 · 围栏枚举定版：正式 7 + 观察 3（`::: 类型` / `:::` 闭合）
- 类别: 围栏枚举与铁律
- 现象: 围栏类型名不统一（"诗词/诗/词牌"混用）；观察类当正式类批量使用。
- 判据: 02ab §4.1 枚举：正式类 7（词/诗/歌/对联/回末对/回末/书信）+ 观察类 3（告示/口诀/说书）；语法沿用
  Pandoc Fenced Div：`::: 类型` 开、`:::` 独立行收；标签渲染为 tooltip 而非标题；围栏类型→块类型/文本模式/
  标注豁免边界一一对应。
- 动作: 结构标注器/检测器只输出 10 类枚举；新增类型须过试点（附录 B），观察类遇真实案例才启用并逐例登记。
- 反例: 给"有诗为证"引语新设类型——实测 0 次（水浒型说书套语在梁书缺位），不设类型。
- 来源: `SKILL_02ab` §4.1；`scripts/generate_pn_wuxia.py`；docs/49（40 回围栏可逆性 PASS）。
- 状态: 已回写

### FN02 · 围栏五铁律：成对不跨回/不嵌套/整体一 PN/禁半角标点/可逆
- 类别: 围栏枚举与铁律
- 现象: 围栏跨回或嵌套（信中附诗开内层围栏）；围栏拆多 PN；剥标后无法还原底本。
- 判据: 02ab §4.2 五铁律：① 成对闭合且不跨回（一回一文件；启用 `##` 层时须在标题前关闭）；② 不嵌套（信中附诗/
  词前小序并入宿主围栏）；③ 围栏整体一 PN（§3.3）；④ 围栏内禁半角标点；⑤ 可逆性——剥除 PN 与围栏行后
  逐字符还原锁定底本（疑似讹字"欲如"一律保留原样）。
- 动作: `--verify` 逐回验证可逆性；lint_fence_format 检查成对/嵌套；围栏行不进正文分母。
- 反例: 为保留"词前小序"另开 `::: 诗` 内层——违反不嵌套；小序并入 `::: 词` 宿主。
- 来源: `SKILL_02ab` §4.2/§3.3；`scripts/lint_fence_format.py`；docs/49。
- 状态: 已验证

### FN03 · 行内引语 vs 成段围栏：分流三判据（成段/完整/自称文体）
- 类别: 围栏枚举与铁律
- 现象: 书信/对联嵌在叙述句内也被整体围栏，导致正文被切成围栏（分母失真）。
- 判据: 02ab §4.3 三判据（全部满足才围栏）：① 成段（独立成段、前后有空行）；② 完整（书信有称谓+落款；
  对联/诗是完整两联/篇章，非截引）；③ 自称文体（去除引文后叙述句仍自足成立）。
- 动作: 行内引语保持行内（可标实体，不围栏）；成段且完整才围栏；误围栏回退。
- 反例: "拆开信一看，信的前半段说：……"后续引文虽成段但前后叙述句不自足——不围栏（样本乙错误例）。
- 来源: `SKILL_02ab` §4.3；docs/49。
- 状态: 已验证

### FN04 · 围栏内标注边界：实体限实指、动词不标、回末全不标
- 类别: 围栏枚举与铁律
- 现象: 围栏内修辞泛指实体被标；诗词内动词被标；回末套语被标。
- 判据: 02ab §4.4：词/诗/歌/对联/回末对 → 实体限实指、动词不标；回末 → 全不标；书信/告示 → 实体可标、
  事件不核实；口诀 → 技术名可标、动词不标；说书 → 可标、不抽事件。
- 动作: 围栏内逐 token 复核；实指保留（记录理由）、泛指摘除；围栏内动词全部剥除；复跑 lint/剥标断言。
- 反例: 回末"天山"实指地名可保留（属于回末对而非回末全不标区）；须按围栏类型对号。
- 来源: `SKILL_02ab` §4.4；`references/03a1` DF16；`references/06e1`（类型侧）。
- 状态: 已验证

### FN05 · 观察类围栏：不批量预围栏、暂不计入正式统计
- 类别: 围栏枚举与铁律
- 现象: 告示/口诀/说书被批量预围栏；观察类内容混入正式 E14 阈值。
- 判据: 02ab §4.1 观察类语义：枚举保留、试点期遇真实案例才启用并逐例登记；观察类内容**暂不计入**正式统计口径，
  晋升评审通过后回溯；禁止批量预围栏。
- 动作: 观察类单列统计；晋升走试点数据（附录 B）；E14 判定仅正式类。
- 反例: 因"口诀全文罕见"就全库扫口诀词预围栏——误围率高于收益；按案例逐例启用。
- 来源: `SKILL_02ab` §4.1；`SKILL_02f` §2.1/§2.4；`references/02f1` ST04。
- 状态: 已验证

- 类别: 韵文检测树

### FN07 · 支路 A 四言/五七言：verse_score 阈值与整组投票
- 类别: 韵文检测树
- 现象: 单行像诗就判诗；引出词/章首词漏检。
- 判据: 支路 A：韵文阈值/引出词降权阈值 **0.6/0.8（≥3 行）**；整组投票门槛 **≥2 行且 ≥6 句**（02ab §5.2/§5.6）；
  章首开卷诗/回中成段诗归 `诗`；五七言整齐韵文。
- 动作: 按阈值实现；引出词（"诗曰/有诗为证"）降权；整组投票防单行误判。
- 反例: 一句五言就围栏——整组投票门槛未过；应进存疑灰区人工裁决。
- 来源: `SKILL_02ab` §5.2/§5.6；`scripts/detect_verse_wuxia.py`。
- 状态: 已验证

### FN08 · 支路 B 长短句词牌：句式/阕对称 + 词牌署名行
- 类别: 韵文检测树
- 现象: 词被当诗；章首词因"容缺"漏检；词牌署名行被当正文。
- 判据: 支路 B：长短句词牌（章首词/回中填词），可带词牌署名行；阈值 **0.6**、阕对称相似度 **0.7**（02ab §5.3/§5.6）；
  章首词为高频正式（容缺设计，§2.3）。
- 动作: 词牌署名行单独识别（渲染为 tooltip/落款）；阕间空行保留；词牌名不标实体。
- 反例: 无词牌署名的长短句也可能是词——看句式与阕对称，不能只认署名。
- 来源: `SKILL_02ab` §5.3/§2.3/§5.6；docs/49（塞外 002 词）。

### FN09 · 支路 C 对联与归派：回末对/回中即兴/回末套语分块（候选）
- 类别: 韵文检测树

- 判据: 支路 C 阈值 0.6；归派规则（§5.5）：回末"正是："+对仗两联且回末位置 → `回末对`；回中独立成段对句

- 动作: 回末区域先判"对句 vs 套语"再围栏；灰区人工标注；阈值校准后回写。
- 反例: 把"正是：……"整段当回末套语——对句部分应 `回末对`（实体限实指），后面套语才 `回末`。
- 来源: `SKILL_02ab` §5.4/§5.5/§5.6/§6.2；docs/54 §二（回末对新增）。

## C 区 · PN 与回目

### FN10 · PN 语法：`[N]` / `[N.M]` 两级、父子/连续/不可变
- 类别: PN 与回目
- 现象: 出现三级 PN；回目行被编成正文段号；PN 重排后下游锚点失效。
- 判据: 02ab §3.1/§3.2：`[N]` 顶级段 / `[N.M]` 子级（回目固定 `[0]`）；只用两级（symbols.PN_MAX_LEVEL=2）；
  PN 父子、连续、不可变；回目行 `# [0] 标题` 是标题层不算正文段（02f1 分母排除）。
- 动作: `generate_pn_wuxia.py` 统一生成；回灌/重排前备份；下游锚点扫描（docs/55 §二 七剑 030）。
- 反例: 为"更细"引入 `[N.M.K]` 三级——symbols 明确禁三级；细粒度用行内定位。
- 来源: `SKILL_02ab` §3.1/§3.2；`scripts/symbols.py`（PN_TITLE/PN_MAX_LEVEL）；docs/55 §二。
- 状态: 已验证

### FN11 · 围栏整体一 PN；回目/回末对/套语分块

### FN13 · 章首词容缺/回末套语容缺：结构模板的容缺设计

## D 区 · 漂移治理与实测

### FN14 · 围栏漂移治理：检测树缺口 → 重生成 → 回灌 → 五门 lint → accept
- 类别: 漂移治理与实测
- 现象: 围栏数前后漂移（旧 struct 与当前检测器输出不一致）不追溯；直接手改 struct。
- 判据: 治理流程（docs/49 §五/§八、docs/54 §二）：① 定位检测树缺口（章首歌/短句诗组/词牌署名/续书预告回末/
  末段回末）→ ② 修检测树（`generate_pn_wuxia.py`/`detect_verse_wuxia.py`）→ ③ 重生成 struct（`--all --verify`）→
  ④ `_oneshot/rebuild_tagged_from_struct.py` 回灌（剥标==struct、内容行序列不变断言）→ ⑤ 按围栏豁免剥令牌 →
  ⑥ 五门 lint → ⑦ accept_batch 复跑 → ⑧ 报告前后围栏/PN/令牌 delta。
- 动作: 备份先行（tagged 目录）；回灌脚本验证；新增围栏内 token 剥除清单。
- 反例: 手工往 struct 加围栏行——不可逆且 tagged 未同步；必须走检测树重生成+回灌。
- 来源: `docs/49` §五/§八；`docs/54` §二；`docs/53` §二；`scripts/generate_pn_wuxia.py`/`_oneshot/rebuild_tagged_from_struct.py`。
- 状态: 已回写

### FN15 · 实测：塞外 1→6 / 冰魄 0→2 围栏修复（检测树缺口）
- 类别: 漂移治理与实测
- 现象: 塞外应有 6 处围栏（001 歌/002 词/004 歌/007 歌/028 词+回末）仅识别 1 处；冰魄应有 2 处
  （001 章首七言诗、012 全书末段续书预告回末）为 0。
- 判据: docs/53 §二/docs/49 实测：修检测树后塞外 **1→6**（类型分布 歌3/词2/回末1；与旧稿金标准 **5/6 逐行一致**，
  028 词栏含宿主引出段属既有 SIG 回溯行为未改）；冰魄 **0→2**；40 回结构可逆性 PASS、accept 塞外 28/28、冰魄 12/12、
