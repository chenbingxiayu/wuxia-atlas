## A 区 · 六域与主域裁决

### VB01 · 六域码位封闭：⊞⊠⊡⊟▣■ 与主域语义
- 类别: 六域与主域裁决
- 现象: 新增第七个动词域；或在域内混用旧/新码位。
- 判据: 04f §二 定版 6 域：⊞战斗交锋/⊠生命健康/⊡社会关系/⊟物件变化/▣技术传习/■行踪迁移；码位封闭
  （`scripts/symbols.py` VERB_CODES）；旧"擒控救援"语义拆入 ⊞/⊡/⊠（§2.7）。
- 动作: 所有脚本 import symbols.VERBS；新语义先试映射旧 6 域，确需新域走 03e1 治理；禁自造动词码。
- 反例: 给"谋划"新设"谋略域"——04f 已有 ⊡ 社会关系/◈ 事件外表达；新域须证明旧域无法表达。
- 来源: `SKILL_04f` §二/§2.7；`scripts/symbols.py` VERBS；`references/01g1` SY01。
- 状态: 已回写

### VB02 · 结果决定主域：同一动作按结果补语归域
- 类别: 六域与主域裁决
- 现象: "刺中"一律 ⊞ 或一律 ⊠；"打"无补语时域选择随意。
- 判据: 04f §3.1/§2.0 主域裁决总表：**结果决定主域**——"一剑刺中（未致命）"→⊞；"一剑刺死"→⊠；
  "打死/打伤"→⊠；"打成一片/打招呼"→不标；"打酒/打造"→⊟ 或制造义。
- 动作: 先看结果补语/状态词再定域；无结果补语按动作本体域；主域裁决总表逐行查。
- 反例: 把"刺中手臂"标 ⊠——未达伤情阈值（§2.2 三线定义），主域仍是 ⊞。
- 来源: `SKILL_04f` §3.1/§2.0/§2.2；`references/04f1` V2 系列。
- 状态: 已验证

### VB03 · 生命健康 ⊠ 伤情阈值三线：酸麻痛≠阈值、关节命中优先、点穴分语境
- 类别: 六域与主域裁决
- 现象: 轻微酸麻痛标 ⊠；膝关节命中漏标 ⊠；战斗点穴标 ⊠。
- 判据: 04f §2.2：伤情阈值三线（酸麻痛≠阈值；关节命中 ⊠ **优先于**点穴攻击 ⊞；单纯酸麻痛不转 ⊠）；
  点穴：战斗语境→⊞（战斗控制）、非战斗制服→⊡（拘禁子型）、解穴→⊠（恢复）。
- 动作: 逐条按阈值判；被点名穴道另标 ^ 并联动三元组；状态字段记录"被控制"。
- 反例: "被点了穴"（非战斗制服）标 ⊞——应 ⊡ 拘禁子型；点穴定身与解穴主域不同。
- 来源: `SKILL_04f` §2.2/§2.0；docs/29 外部评审（2026-11-04 裁定）；`references/04f1`。
- 状态: 已验证

### VB04 · 物件变化 ⊟：借/还方向字段、毁损、夺财 vs 劫人分流
- 类别: 六域与主域裁决
- 现象: 借/还不记方向；"夺"泛用一律 ⊟；劫人当劫财。
- 判据: 04f §2.4/§2.0：赠/借/还方向字段强制（给/取；未知记未知）；毁损/折断/烧毁 → ⊟；劫夺：劫人→■
  （强制迁移）、劫财→⊟（夺取），按宾语分流；对尸体/遗体的操作→⊟（死因归 ⊠）。
- 动作: 方向字段必填；宾语分流；器物/文书实体联动（§4.1 #11-15）。
- 反例: "夺路而逃"标 ⊟——"路"是通道义，⊞/不标；非器物。
- 来源: `SKILL_04f` §2.4/§2.0/§4.1；`references/04f1` V4 系列。
- 状态: 已验证

### VB05 · 旧"擒控救援"语义落位表（v2 回收）：分拆到 ⊞/⊡/⊠（待裁）
- 类别: 六域与主域裁决
- 现象: 旧版本"擒控救援"域语义被整块搬进 ⊞，救援/解除拘禁类错域。
- 判据: 04f §2.7 旧"擒控救援"语义落位表：擒住→⊞（战斗控制）；救出被囚者→⊡（解除拘禁）；救活重伤者→⊠
  （治疗）；拘押→⊡；劫囚→⊡（打斗 ⊞、带离 ■ 分标）。"旧语义落位表"的最终口径（是否保留"救援"作为 ⊡ 子型标签）
  待裁（04f 附录/FAQ 开放项）。
- 动作: 按落位表分标；分标而非合并（§2.7 例句）；争议上抛 Lead。
- 反例: "救出被囚者"标 ⊠——是解除拘禁（⊡）非治疗；除非同时治疗伤者才另标 ⊠。
- 来源: `SKILL_04f` §2.7；`references/04f1`；`SKILL_关系体系` §7.2（解救/拘押谓词）。
- 状态: 待裁

## B 区 · 边界与消歧

### VB06 · 招式名 vs 出招动作：决策表与实体联动
- 类别: 边界与消歧
- 现象: 招式名（☆）当动词标；动词吞招式名；同字符双标。
- 判据: 04f §3.4 判定决策表：引号内招式名 → ☆ 实体；"使出/施展 + 招式" → 动作动词（⊞ 或 ▣ 语境）+ ☆ 实体；
  名称整体是实体，事件在名称外（V4-2 "断门刀"的"断"不标）。
- 动作: 先判"是否招式名"；招式名标 ☆ 并挂父式；动作词标六域；同一字符一种标注（V0 纪律）。
- 反例: "白鹤亮翅"里的"亮"标 ⊞——招式名整体 ☆，不拆字；V4-2 同源。
- 来源: `SKILL_04f` §3.4/§2.0；`references/04f1` V4-2/W-3。
- 状态: 已验证

### VB07 · 否定/条件/未发生不标；计划与建议不生成事件
- 类别: 边界与消歧
- 现象: "欲杀/若能夺得/打算去"标成已发生事件；条件句造事实。
- 判据: 04f §3.6：否定、条件、未发生的操作不标（不生成事件）；计划/建议语境按 04a 事件识别降级为"计划"；
  触发词边界以"是否已发生/进行中"为准（docs/45 judgment 分类 plan_negation_verb）。
- 动作: judgment 复核时对 plan_negation_verb 类逐条判"已发生/纯意图"（docs/45 §三）；纯意图摘标。
- 反例: "我必杀你"（誓言）标 T02 杀伐事件——纯意图，不生成事件；仅留关系/情绪。
- 来源: `SKILL_04f` §3.6；`SKILL_04a` §5（事件五状态）；docs/45 §三；`references/04f1` V1-3/V2-2。
- 状态: 已验证

### VB08 · 嵌套禁令与复合动词整词清单
- 类别: 边界与消歧
- 现象: 动词令牌嵌套（⟦⊞打⟧⟦⊠死⟧）；复合词逐字拆（自废/纵马）。
- 判据: 04f §3.5 嵌套禁令：动词令牌不得嵌套、不重叠；复合动词按整词清单（§3.2）："自废/纵马/迈步"整体判断，
  边界错切会吞字（03a1:DF03）。
- 动作: 嵌套 lint；整词清单维护在词表；错切修复走 `fix_annotation_mechanical.py`。
- 反例: "纵马过来"拆 "纵"+"马"+"过来"——整词"纵马"作行踪触发词；拆字丢"纵马"。
- 来源: `SKILL_04f` §3.5/§3.2；`references/03a1` DF03；`references/04f1`。
- 状态: 已验证

### VB09 · 多义词消歧：管道说明 + 分型卡 senses（打/夺/教/走/退/断/放）
- 类别: 边界与消歧
- 现象: 高频多义词（打/夺/教/走/退/断/放）按单一义项标注；管道消歧说明缺失。
- 判据: 04f §3.3 消歧语法（管道=消歧说明，非规范名）；§5.3 七张高频多义动词分型卡（打/夺/教/走/退/断/放），
  每卡给语境→标注→模板→安全条件；单义项确认后仍按卡对照。
- 动作: 逐卡查语境；管道写消歧说明（如 ⟦⊟夺|夺物⟧）；多义未决进候选/待审。
- 反例: "夺"一律 ⊟——"夺人性命"是 ⊠、"夺路而逃"是 ⊞/不标；分型卡逐语境决定。
- 来源: `SKILL_04f` §5.3/§3.3；`wordlists/verbs.json`；`references/04f1`。
- 状态: 已验证

## C 区 · 联动规范

### VB10 · 联动总表 27 行：强制/建议两档强度
- 类别: 联动规范
- 现象: 联动全设强制导致大量待审；或全设建议导致三元组乱挂。
- 判据: 04f §4.1 联动总表 27 行：**强制**（缺邻近实体则标注存疑、事件不入确定性问答）与**建议**（共现记候选、
  允许缺席）两档定版；v2 第三档"可选"已否决。
- 动作: 联动时查总表定强度；强制缺失→待审标记（§4.2 铁律 2）；建议缺失→不生成三元组。
- 反例: "使用阵法"设强制——阵名常无名（"布下阵势"），总表定建议；强制会误伤大量合法标注。
- 来源: `SKILL_04f` §4.1/§4.2；`SKILL_关系体系` §8.2。
- 状态: 已验证

### VB11 · 联动三铁律：候选非定论/强制缺失降级/四类关系不进联动
- 类别: 联动规范
- 现象: 共现即生成三元组；缺失强制实体仍入确定性问答；情感类造行内触发词。
- 判据: 04f §4.2 三铁律：① 联动生成候选不生成定论（方向须核验，被动句施受反转要解析）；② 强制档缺失即降级
  （事件打"待审"，不进 KG 确定性问答/评分统计）；③ 情感/恩义/背叛/主仆四类人物关系不进联动（01g §9.2，
  走离线表，不设触发词/不造行内符号）。
- 动作: 候选→核验→入表；待审标记；离线关系只作候选素材。
- 反例: 从"师父与他同桌吃饭"推师承——防共现误推（§4.3）；共现不生成任何三元组。
- 来源: `SKILL_04f` §4.2/§4.3；`SKILL_01g` §9.2；`references/05a1` RP02/RP14。
- 状态: 已验证

### VB12 · 联动方向与被动句：施受反转必须解析
- 类别: 联动规范
- 现象: "他被点了穴"方向颠倒（把受者当施者）；被动句/使役句不解析。
- 判据: 04f §4.1 联动总表方向（#5 点穴、#8 杀害、#9 治愈等均需施受）；被动句施受反转必须解析（§4.2 铁律 1）；
  "被 X 点"→施者=X，受者=主语。
- 动作: 方向核验（主语/宾语/被字句/把字句）；方向字段必填（借/还）；未知记未知。
- 反例: "他被冯琳点倒"标成 冯琳受者——方向反；应 施者=冯琳、受者=他。
- 来源: `SKILL_04f` §4.1/§4.2；`SKILL_关系体系` §7.2 #54 点穴；`references/04f1`。
- 状态: 已验证

### VB13 · 连续交锋合并标注（密度规则）：起止+关键结果，不逐招轰炸
- 类别: 联动规范
- 现象: 逐招标注连招动作，密度爆炸（V1-1）；密度统计被撑爆。
- 判据: 04f §6.1 连续交锋合并标注：起止+关键结果；每段触发词 1-6 处正常，>10 回头查逐招误标
  （02f1:ST02 密度口径）；"回合数"不数触发词。
- 动作: 合并标注；密度自检按 02f 口径；异常回查。
- 反例: 三百回合逐招标——"三百回合"是数量（$），连续交锋合并为一段。
- 来源: `SKILL_04f` §6.1；`references/04f1` V1-1；`references/02f1` ST02。
- 状态: 已回写

### VB14 · 七张多义分型卡：打/夺/教/走/退/断/放
- 类别: 多义卡与实测
- 现象: 高频多义动词无统一判据，跨批标注不一致。
- 判据: 04f §5.3 七张分型卡（打/夺/教/走/退/断/放）：每卡给"语境→标注→模板→安全条件"；卡 1 打=战斗⊞/打死⊠/

- 动作: 标注时逐卡核对；新增高频多义词→补卡（编号只增）；卡进词表/提示词。
- 反例: "教"一律 ▣——"教他做人"是 ⊡/不标；卡 3 教：传授武功 ▣、教导/训斥 ⊡、宗教义理不标。
- 来源: `SKILL_04f` §5.3；`wordlists/verbs.json`；`references/04f1`。
