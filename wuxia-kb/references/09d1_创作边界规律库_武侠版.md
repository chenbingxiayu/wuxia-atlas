## A 区 · 创作边界

### CR01 · 零原文：不得复制/改写原文连续片段（01g §9.10）
- 类别: 创作边界
- 现象: 故事/文献稿件含原文连续片段；或"改写"后仍可还原原文。
- 判据: 09d §1.4 关键约束：**零原文**——不得复制/改写原文连续片段；人物对话若必要，用"概括式转述"并回锚；
  01g §9.10 版权红线；W7 核验阻断（CR13）；ST-01 检测"复制/改写原文"。
- 动作: 概括式转述+定位符；W7 核验；必要引文走版权审查通道（责任在作者/权利审核）。
- 反例: "只删改几个词"仍属改写原文——概括转述才算原创叙述。
- 来源: `SKILL_09d` §1.4；`SKILL_01g` §9.10；ST-01；W7。
- 状态: 已回写

### CR02 · 事实可核：实体/关系/事件必须能在知识库找到来源
- 类别: 创作边界
- 现象: 故事把无来源的设定当事实；人物关系/事件无回锚。
- 判据: 09d §1.4：事实可核——故事中的实体/关系/事件必须能在知识库找到来源；ST-03 检测"无来源编造情节"→
  补来源或删；可用素材=SKU/N5/EX-5/N4/07c（CR05）。
- 动作: 情节骨架从可用素材取；无法回锚的情节删改；来源写进 works 元数据 sources。
- 反例: "某人在某年练成某功"若 N5/N4/EX-5 无记录——不得写入事实段落，只能进"推演"并标注。
- 来源: `SKILL_09d` §1.4/§三；ST-03；`registry/sku`/`relations`/`events`/`time`。
- 状态: 已验证

### CR03 · 原创声明：derivative_type=原创派生 + 数据版本 + rule_version
- 类别: 创作边界
- 现象: 作品不标派生来源；或标"原著"；版本缺失无法追溯。
- 判据: 09d §1.4/§6.1：每篇标 `derivative_type=原创派生`、`data_version`、`rule_version`；`license_note`
  =非原著正文、不冒充作者佚文；元数据含 story_id/template/title/sources/consistency/w7/publish_state。
- 动作: 元数据必填；发布前 schema 校验（ST-09）。
- 反例: 不写 derivative_type 发"梁羽生佚文"——ST-02 冒充原著。
- 来源: `SKILL_09d` §1.4/§6.1；ST-02/ST-09。
- 状态: 已验证

### CR04 · 不得冒充原著：不称"作者佚文/未刊稿"
- 类别: 创作边界
- 现象: 标题/正文暗示"原著/佚文/未刊稿"；把推演当官方设定。
- 判据: 09d §1.4：**不得冒充原著**——不得声称"作者佚文/未刊稿"；ST-02 检测声明→改"原创派生"；09k 不越级：
  demo 卡/推演/低置信事件不得写成考订结论（LW-06）。
- 动作: 声明检查；推演内容标 simulate/demo；发布文案中性化。
- 反例: 用"梁羽生未刊稿"标题吸引点击——冒充原著，一票否决。
- 来源: `SKILL_09d` §1.4；ST-02；`SKILL_09k` §六（不越级）；LW-06。
- 状态: 已验证

## B 区 · 素材分层与模板

### CR05 · 可用素材六类：N10 SKU/N5/EX-5/N4/07c/01g
- 类别: 素材分层与模板
- 现象: 创作不用结构化素材，凭印象写；或素材来源不可回链。
- 判据: 09d §3.1：可用素材——人物卡字段（N10 SKU person brief/identity_tags/arts/teachers/ending）；门派卡
  （SKU faction lineage/members/history）；事件（EX-5 类型/参与方/outcome/时间）；关系边（N5 师承/结义/情缘/仇怨）；
  时间轴（N4 相对刻度/锚点，参考）；设定（07c 34 规则/01g 类型）。
- 动作: 从可用素材取骨架；sources 字段回链；不引入素材外"事实"。
- 反例: 凭记忆写人物结局——应从 SKU ending 字段取并回链。
- 来源: `SKILL_09d` §3.1；`registry/sku/cards.json`/`relations`/`events`/`time`。
- 状态: 已验证

### CR06 · 慎用素材四类：性格推断/多源冲突/跨书年代/统计口径
- 类别: 素材分层与模板
- 现象: 性格推断写"他一定会…"；多源冲突只取一说；跨书年代写具体年数；统计数字无口径。
- 判据: 09d §3.2：慎用素材——人物性格推断（OOC 风险，只作弱信号，不写"他一定会…"式断言）；多源冲突（07c，
  双记/注明"一说"）；跨书年代（07a low，只作"参考"不写具体年数）；统计（03l，附口径声明或避免具体数字）。
- 动作: 慎用素材降级表述；"推演"标注；冲突双记；统计带口径。
- 反例: "据推算他生于 1615 年"（跨书 low 写具体年）——应写"约在明末"。
- 来源: `SKILL_09d` §3.2；ST-05/ST-06/ST-07；`references/07e1` AU05。
- 状态: 已验证

### CR07 · 禁用素材四类：原文/未核实/读者推断/可还原片段
- 类别: 素材分层与模板
- 现象: 原文片段、未核实设定、E4 读者推断、可逐步还原的片段数据进入创作。
- 判据: 09d §3.3：禁用素材——原文正文/连续片段（01g §9.10）；未核实却当事实的设定（07e D/E）；读者推断（E4）；
  从原文可逐步还原的片段数据；ST-08 敏感/未脱敏内容拦截。
- 动作: 禁用素材零容忍；发布前 R1-R5 脱敏检查；E4 不进正文。
- 反例: "据读者推测"写成正文事实——E4 禁用。
- 来源: `SKILL_09d` §3.3；`SKILL_01g` §9.10；`references/07e1` AU01。
- 状态: 已验证

### CR08 · 四类创作模板：说书人专栏/人物小传/门派史话/事件演义
- 类别: 素材分层与模板
- 现象: 创作无模板导致结构散/超边界；模板与素材错配。
- 判据: 09d §四：① 说书人专栏（推荐首发，短篇评书体）；② 人物小传（依 SKU person）；③ 门派史话（依 SKU
  faction lineage）；④ 事件演义（依 EX-5 事件+outcome）；各模板对应的素材与结构见 09d §4。
- 动作: 按模板取素材；模板版本入元数据（template 字段）。
- 反例: 用事件演义模板写人物传记——素材类型错配，易生无源情节。
- 来源: `SKILL_09d` §四；`SKILL_SKU卡片`；`references/04a2`。
- 状态: 已验证

## C 区 · 一致性门控与元数据

### CR09 · 设定门控（07c）：无硬矛盾才可发布，冲突双记
- 类别: 一致性门控与元数据
- 现象: 创作与设定冲突时"为剧情硬改"（ST-04）。
- 判据: 09d §5.1/§6.2：设定门控（07c）——无硬矛盾（双记可）；ST-04 检测"设定冲突为剧情硬改"→双记/改情节；
  07c 34 条规则与 01g 类型为世界规则一致性底座。
- 动作: 创作前跑 07c 检查；冲突双记或改情节；N8 已登记冲突可作"已知名目"。
- 反例: 为剧情让"已死人物"复活且不标双记——ST-04。
- 来源: `SKILL_09d` §5.1/§6.2；ST-04；`references/07e1` AU08。
- 状态: 已验证

### CR10 · 人物一致性（OOC 边界）：性格推断只作弱信号、标"推演"
- 类别: 一致性门控与元数据
- 现象: 把读者对人物性格的推断写成官方设定；OOC 当官方。
- 判据: 09d §5.2：人物一致性（OOC 边界）——性格推断只作弱信号、不写"他一定会…"式断言；ST-05 检测"人物
  OOC 当官方"→标"推演"；元数据 consistency.ooc=weak-signal-only。
- 动作: OOC 内容标推演；人物行为从 SKU 字段取据；发布门控记录。
- 反例: "练霓裳一定会原谅他"（性格断言）——弱信号，进推演小节。
- 来源: `SKILL_09d` §5.2/§6.1；ST-05；`references/09a1` AQ07。
- 状态: 已验证

### CR11 · 跨书门控（07a/07d）：low 不写具体年数，跨书结论标参考
- 类别: 一致性门控与元数据
- 现象: 跨书推算写具体年；跨书结论当单书事实。
- 判据: 09d §5.3：跨书门控（07a/07d）——跨书 low 只作参考不写具体年数（ST-06）；跨书结论标"参考"；
  07d 溯源推理提供出处链。
- 动作: 跨书内容降级表述；标 data_version；07a/07d 检查。
- 反例: 把两书年代推算写成"确凿 1650 年"——low 不写具体年。
- 来源: `SKILL_09d` §5.3；ST-06；`SKILL_07a`/`07d`；`references/04d1`。
- 状态: 已验证

### CR12 · 故事稿件元数据 schema：story_id/derivative_type/template/sources/版本/consistency/w7/publish_state
- 类别: 一致性门控与元数据
- 现象: 稿件无元数据/无版本/无核验记录，无法审核与回溯。
- 判据: 09d §6.1 schema：`{story_id, derivative_type, template, title, sources[], data_version, rule_version,
  consistency{07c,ooc}, w7{checked,hit}, publish_state(in-review|approved|blocked), license_note}`；
  发布门控（§6.2）五项：原文片段 W7 通过/事实来源可回锚/设定一致/评级不以 D·E 作情节/脱敏版权。
- 动作: 元数据必填；发布前门控五项逐项勾；blocked 不得发布。
- 反例: 无 data_version 的稿件发布后无法复现（ST-09）。
- 来源: `SKILL_09d` §6.1/§6.2；ST-09；`references/03d1` H17。
- 状态: 已验证

### CR13 · 发布门控：W7 0 未命中 + 事实可回锚 + 设定一致 + 不越级 + R1-R5
- 类别: 一致性门控与元数据
- 现象: 未过 W7 直接发布；或发布含 D/E 内容当情节事实。
- 判据: 09d §6.2 发布门控：① 原文片段：W7 通过（0 未命中）；② 事实来源：实体/关系/事件可回锚；③ 设定一致性：
  07c 无硬矛盾（双记可）；④ 评级：不以 D/E 内容作情节事实；⑤ 脱敏/版权：R1-R5、01g §9.10。
- 动作: 五项全过才发布；不过则 blocked；报告归档。
- 反例: W7 未跑就发布——ST-01/LW-08 风险。
- 来源: `SKILL_09d` §6.2；`SKILL_03d` §6.1；`registry/sku/cards.json`（R1-R5）。
- 状态: 已回写

## D 区 · 证据、W7 与错误模式

### CR14 · 证据三级（09k）：E1 一手数据/E2 原文定位/E3 二手研究；禁用错配
- 类别: 证据、W7 与错误模式
- 现象: 用 E3 冒充 E1（"研究表明"无出处）；用 E1 支撑价值判断；用 E2 单条定位支撑统计结论。
- 判据: 09k §4.1 证据三级：E1 一手数据（知识库导出字段/统计，附 data_version）；E2 原文定位（loc_r/PN/ID，
  不引原文）；E3 二手研究（已发表研究/评述，必须完整出处，不得冒充 E1/E2）；禁用=错配。
- 动作: 论断-证据表（§4.2）写作前必建：claims[{id,claim,evidence[{level,ref,version}],counter,status}]；
  status∈{supported,partial,待证,rejected}；待证不得写成陈述句。
- 反例: "研究表明 T01 最多"无出处——E3 冒充 E1。
- 来源: `SKILL_09k` §4.1/§4.2；`references/07e1` AU01。
- 状态: 已验证

### CR15 · 写作边界七不：不代笔/不伪造/不以论代证/不越版权/不越级/不隐口径/不引全文
- 类别: 证据、W7 与错误模式
- 现象: 文献写作越线（代笔/伪造/越版权/越级/口径缺失）。
- 判据: 09k §六：不代笔（不生成"可署名论文"）；不伪造（引文/定位/统计/二次文献全真实，一票否决）；不以论代证
  （价值判断标"主观"，排序需方法）；不越版权（原文引用责任在作者/权利审核，本库只给定位）；不越级（demo 卡/
  推演/低置信不得写考订）；不隐口径（统计四问齐全）；不引全文（不提供整章/整回原文）。
- 动作: 写作前逐条对照；越线即改；交付前检查清单。
- 反例: 综述输出"可署名论文"——不代笔红线。
- 来源: `SKILL_09k` §六；§1.4 硬规则；LW-01~08。
- 状态: 已验证

### CR16 · ST-01~09 / LW-01~08 错误模式 + W7 实测：2,383 原始→5 进核验→0 叙事编造
- 类别: 证据、W7 与错误模式
- 现象: 同类创作/文献错误反复（复制原文/伪造引文/无定位/口径漂移）；W7 未落地。
- 判据: 09d §八 ST-01~09：复制原文/冒充原著/无来源/设定硬改/OOC 当官方/跨书具体年/统计无口径/未脱敏/无版本；
  09k §九 LW-01~08：伪造引文/无定位引用/以论代证/口径漂移/越界原文/越级考订/综述变百科/未过 W7 即交付。
  W7 实测（`logs/w_group/quote_verify_report.md`）：原始引号片段 **2,383** → 跳过占位 1,470/短 908 → 进核验
  **5** → 命中 **2**/近似 0/未命中 **3**（均技术术语非叙事）→ **叙事引文疑似编造 0**；阈值=精确子串/近似 ratio≥0.9/
  块长度率≥0.9/引文≥8 字；报告不输出原文。
- 动作: 创作/文献交付前跑 W7 `--strict`（miss 不得交付）；ST/LW 逐条自查；报告随稿归档。
- 反例: W7 跳过占位/短引文就当通过——作者须自行确认这些不是伪造引文（09k §5.2 第 5 条）。
- 来源: `SKILL_09d` §八；`SKILL_09k` §五/§九；`logs/w_group/quote_verify_report.md`（5 进核验/2 命中/0 编造）。
