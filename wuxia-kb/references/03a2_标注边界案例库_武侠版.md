## A 区 · C20 八模式

### BC01 · P1 实体跨动词吞入：`〖@卓一航提剑〗` → 拆
- 类别: C20 八模式
- 现象: 实体令牌把后面的动作动词一起吞入（"卓一航提剑""练霓裳说道"）。
- 判据: P1 定义：实体跨动词吞入；正确=实体只覆盖人名，"提剑/说道"留在令牌外（03f §三；03a DEF-03 同源）；
  吞动词触发词表：说道/喝道/问道/答道/笑道/走了/来了/飞起/跃起/看到/听见 等（§3.1）。
- 动作: 收缩令牌边界；触发词表随批增补（记 03a DEF 库/03f 附录 C）；修完跑剥标断言。
- 反例: "〖@卓一航〗提剑" ✅ vs "〖@卓一航提剑〗" ❌；但"金刀寨主"整体为称谓（03b §八），不按 P1 拆。
- 来源: `SKILL_03f` §三/§3.1；`scripts/detect_entity_boundary_errors.py` P1；kb/白发魔女传/边界案例库.md。
- 状态: 已验证

### BC02 · P2 实体后粘语气/动词："玉罗刹道" → 拆
- 类别: C20 八模式
- 现象: 实体后粘"道/说/喝/问/了/着"（"〖@玉罗刹道〗""〖@卓一航着〗"）。
- 判据: P2 定义：实体后粘语气/动词；粘字尾表：道/说/喝/问/了/着（03f §3.1）；正确=实体到人名止，
  语气/动词留外面。
- 动作: 收缩边界；批量用 `fix_annotation_mechanical.py`；复跑 C20 检测。
- 反例: "玉罗刹"是固定绰号（含"罗刹"），不因"刹"字拆；判据以"后粘词是否独立动作/语气"为准。
- 来源: `SKILL_03f` §三/§3.1；`scripts/detect_entity_boundary_errors.py` P2。
- 状态: 已验证

### BC03 · P3 介词误入："山上"拆为 `〖=山〗上`
- 类别: C20 八模式
- 现象: 介词被裹进实体（"〖=山上〗"）；或实体吞介词（"〖@他于〗"）。
- 判据: P3 定义：介词误入；介词尾表：于/在/向/从/往/到/自（含"于上/于中/在上/向上/从中"等固定式豁免，
  03f §3.1）；正确=`〖=山〗上`、`他于`。
- 动作: 拆介词到令牌外；固定式按白名单豁免（WUXIA_WN）；记反例防过度拆。
- 反例: "于上"是固定式（"于上写道"）时豁免；不能机械拆"于"。
- 来源: `SKILL_03f` §三/§3.1；`scripts/detect_entity_boundary_errors.py` P3。
- 状态: 已验证

### BC04 · P4 官职/身份拆分错误：`〖;掌门〗` vs `〖@掌门〗`
- 类别: C20 八模式
- 现象: 职衔当人名（"〖@掌门〗"）；或人名字段拆出职衔（"〖@卓掌门〗"）。
- 判据: P4 定义：官职/身份拆分错误；判据=03a D1：`;`=可任命/册封建制职衔，`#`=职业/身份类别，纯衔不挂人物管道；
  "掌门/帮主/寨主"为 `;` 不为人名（03a1:DF05）。
- 动作: 按 D1 改类型；纯衔不挂人物管道；人物+职衔用"显示串/管道"处理（03b §四）。
- 反例: "掌门"在某句确为人物代称（"掌门走了进来"）——仍是 `;` 职衔指代，不建 @ 实体。
- 来源: `SKILL_03f` §三；`SKILL_03a` §二/D1；`references/03a1` DF05。
- 状态: 已验证

### BC05 · P5 单字实体边界：`〖@李〗` 不收
- 类别: C20 八模式
- 现象: 单字人名/地名入令牌（"〖@李〗""〖=山〗"）。
- 判据: P5 定义：单字实体边界；判据=单字不收（歧义过大），留人工（03b）；应为全名或裸文。
- 动作: 单字令牌进人工清单（03b）；不入 auto 批量；`infer_single_char_names.py` 仅候选。
- 反例: 单字姓"李"在"李氏"复合称谓中可作部分；但令牌必须覆盖完整指称（≥2 字）或裸文。
- 来源: `SKILL_03f` §三；`SKILL_03b`；`scripts/infer_single_char_names.py`。
- 状态: 已验证

### BC06 · P6 括号内标点：`〖@张三，〗` → 标点外置
- 类别: C20 八模式
- 现象: 令牌内包含中文标点（"〖@张三，〗""〖=京城。〗"）。
- 判据: P6 定义：括号内标点；正确=标点外置（`fix_annotation_mechanical --punct-outside`）；令牌显示串为原文
  连续字区间，不含句读（01g §2.2）。
- 动作: 机械外置标点；复跑 lint_symbol_conflicts/剥标断言。
- 反例: 书名号/破折号若属专名本体（如《XX》）另行处理；句末逗号句号一律外置。
- 来源: `SKILL_03f` §三；`scripts/fix_annotation_mechanical.py`（--punct-outside）。
- 状态: 已验证

### BC07 · P7 实体覆盖人名+称谓："魏公公魏忠贤" → 称号外置/管道
- 类别: C20 八模式
- 现象: 实体令牌覆盖"称号+姓名"（"〖@魏公公魏忠贤〗""〖@练姐姐练霓裳〗"）。
- 判据: P7 定义：实体覆盖人名+称谓；正确=称号外置或入管道（03a L135；03b §四）；"魏公公"是称谓、
  "魏忠贤"是本名。
- 动作: 显示串=原文区间全文若连写（DEF-12）；本名入管道；或称号外置 + 本名令牌。
- 反例: "玉面妖狐凌霄"全形连写——显示串须覆盖全区间、本名入管道（DEF-12），不是简单外置。
- 来源: `SKILL_03f` §三；`SKILL_03a` L135/DEF-12；`SKILL_03b` §四；`references/03a1` DF11。
- 状态: 已验证

### BC08 · P8 回末套语误标：回末段出现实体/动词
- 类别: C20 八模式
- 现象: 回末段（套语）出现 `〖@张华昭〗`/`⟦⊞杀出⟧` 等令牌。
- 判据: P8 定义：回末套语误标；判据=回末围栏**全不标**（02ab §4.4）；回末套语词族见 02ab §6.2 强信号；
  归因 F（结构）。
- 动作: 摘除回末内全部令牌；修 02ab 结构检测；复跑围栏 lint/剥标断言。
- 反例: 回末对（"正是："对句）≠回末——回末对实体限实指可保留（02ab1:FN04）。
- 来源: `SKILL_03f` §三；`SKILL_02ab` §4.4/§6.2；`references/02ab1` FN04/FN16。
- 状态: 已验证

## B 区 · 方法与搜索

### BC09 · 修饰词整体标注原则：语义单位整体标，方式/介词/助词留外
- 类别: 方法与搜索
- 现象: 把"玉面妖狐凌霄"拆成绰号+本名两个令牌；或把方式修饰吞入实体。
- 判据: 03f §4.1：修饰语与中心语构成一个语义单位时**整体标注**（"玉面妖狐凌霄"整体显示串、本名入管道，
  DEF-12；"金刀寨主"按 03b §八）；**但**方式修饰/介词/动态助词留在外面（"纵马⟦■过来⟧""迈步⟦■入内⟧"）。
  判据：拆开后①任一片段不是独立语义单位 或 ②拆开破坏原文连续区间 → 整体标；反之拆。
- 动作: 按两条判据决定整体/拆分；显示串保原文连续区间；动词边界按 04f。
- 反例: `⟦⊠害死⟧` ✅ vs `⟦⊠害⟧死` ❌（固化动宾整体，03a P3-4）。
- 来源: `SKILL_03f` §4.1；`SKILL_03a` DEF-12/P3-4；`references/01g1` SY04。
- 状态: 已回写

### BC10 · 主动搜索 PR-01~08：只清 C20 报告 = BND-01（候选，probe 清单动态增补）
- 类别: 方法与搜索
- 现象: 反思只清检测器报告条目，不主动构造搜索；同型错误在检测盲区复发。
- 判据: 03f §4.2：C20 八模式是有限探针；每批至少跑 8 类 probe——PR-01 实体内外 1-2 字动词/语气/介词；
  PR-02 `;`/`#` 接人名/`@` 含职衔；PR-03 单字实体；PR-04 显示串含标点；PR-05 围栏/回末令牌；PR-06 管道
  回锚；PR-07 称谓白名单差集；PR-08 机械修复 diff。**主动搜索发现的条目必须给 probe 编号**，否则不进回归。
- 动作: 每批跑 PR-01~08；条目带 probe 编号归因；probe 清单随新书动态增补（候选维护）。
- 反例: 报告 0 条就宣布"无边界问题"——BND-01；必须主动搜索佐证。
- 来源: `SKILL_03f` §4.2/§七 BND-01；`scripts/detect_entity_boundary_errors.py`。
- 状态: 候选

## C 区 · 归因与修复

### BC11 · 归因四源 R/W/S/F：同错跨模型→R/S；特定词→W；特定结构→F
- 类别: 归因与修复
- 现象: 不区分错误来源，统一改 tagged（下批复发）。
- 判据: 03f §五：R 规则（改 03a/04f/03b 条款+补正反例→03a DEF/04f 错误库）；W 词表（补 wordlists 源→编译）；
  S 示例/种子（修 few-shot→重跑 build_03a_fewshot.py）；F 结构/围栏（修 02ab 检测树→回灌）。
  判据：同错在不同模型/批次重复→R/S；只在特定词→W；只在特定结构块→F。
- 动作: 逐条标归因源；按源修对应资产；不直接批量改 tagged。
- 反例: 同一 P2 错误在 3 书均现却只改本批 tagged——BND-05；应改规则/种子。
- 来源: `SKILL_03f` §五；`SKILL_03a` §2.5 纪律。
- 状态: 已验证

### BC12 · 三阶段修复法与记录 schema（batch/item_id/pattern/loc/attribution/fix/regression/status）
- 类别: 归因与修复
- 现象: 修复无台账；修复后不回归（BND-11）。
- 判据: 03f §4.3/§6.1 记录 schema：`{batch,item_id,pattern,book,chapter,loc,display,context_short,attribution,
  severity,fix{type,target,change},regression{accept_hard,c20_after,strip_equal},status}`；修复三阶段（采样→
  主动搜索→归因→修复→回归）；case=1-2 处，system=≥3 处同模式必须规则化（BND-04）。
- 动作: 每条修复按 schema 记录；回归字段填 accept/c20/剥标；system 级进规则回写。
- 反例: 修复记录只写"已改"——无 pattern/loc/regression，无法审计。
- 来源: `SKILL_03f` §4.3/§6.1；`references/03a1` DF13（自报须程序化）。
- 状态: 已验证

### BC13 · BND-01~12 错误模式：只清报告/凭记忆自报/单字 find/个案当系统/只改本批/顺手改正文/span 顺序/围栏丢字/管道当边界/白名单扩张/不回归/只写文档
- 类别: 归因与修复
- 现象: 边界修复过程本身引入新错误（正文被改、编辑错位、白名单掩盖）。
- 判据: 03f §七 BND-01~12：核心几条——BND-02 凭记忆写定位→程序化生成；BND-06 修边界顺手改正文→只动令牌+

- 动作: 修复流程逐条对照；可机械化项进 C20/lint（BND-12）。
- 反例: BND-07 常见：同段多处编辑顺序错导致后一处覆盖前一处——必须按 span 逆序应用。
- 来源: `SKILL_03f` §七；docs/48 §九（span 逆序）；`references/03a1`。
- 状态: 已回写

### BC14 · 与 03a DEF 库映射：边界反思发现 → DEF 编号 / BND 编号
