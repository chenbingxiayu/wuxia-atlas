## A 区 · A-E 分级与分层

### AU01 · A-E 五级定义与发布口径
- 类别: A-E 分级与分层
- 现象: 用"可信/不可信"两档；C 级内容当断言发布；D 级派生资料当事实。
- 判据: 07e §三（引 D11 §6.1）：A=正文明确陈述+无矛盾+无转述（可作事实/答案）；B=正文多处互证/正文+修订一致
  （可作事实，附来源）；C=单一正文线索/推算（N4/N5）/序跋（L3）/叙述声称（可展示，**不作断言性答案**）；
  D=派生资料（影视/评论）/读者推断（不发布，仅争议区/附注）；E=与设定明确矛盾（穿帮候选）或不可考（记录/雷达）。
- 动作: 每条事实/关系/事件评级；C 以下不作断言；E 进 N8 雷达/争议区。
- 反例: "据序跋说"给 B——序跋是 L3 单一来源，上限 C；多处正文互证才可 B。
- 来源: `SKILL_07e` §三；`SKILL_常识与设定一致性` §六（D11 §6.1）。
- 状态: 已验证

### AU02 · 三层分层评估：主线设定/情节经过/细节对话
- 类别: A-E 分级与分层
- 现象: 卡片只给一个总级，不区分"人物身份 A、台词细节 C"。
- 判据: 07e §3.1（D11 §6.2 照搬）：主线设定（人物身份/门派归属/核心关系/生死）要求 A/B 才可断言、C 需展示保留；
  情节经过（事件/因果/胜负）A/B 为主、推算 C 可展示；细节对话（台词细节/称谓/器物外貌）C 可接受、D 不入库；
  同一卡片可三层不同级；SKU 聚合取加权最低层或分字段标注。
- 动作: 分层评级；SKU 聚合标"加权最低层"；D 级细节不入库。
- 反例: 人物身份（主线设定）给 C 却直接写"某某是某派掌门"——主线需 A/B 才可断言。
- 来源: `SKILL_07e` §3.1；`SKILL_SKU卡片` §6.3；`references/09a1` AQ04。
- 状态: 已验证

### AU03 · 评级对象与证据取法：事实/关系/事件/卡片四类
- 类别: A-E 分级与分层
- 现象: 评级对象不清（评实体还是评某条陈述）；证据来源混用。
- 判据: 07e §二 Step1：对象=事实/关系/事件/卡片；取来源（正文/序跋/转述/推断）+ N4/N5/N8 证据；
  `target_id` 指向 evt/rel/card-id；证据 kind ∈ authorial/quoted/derived。
- 动作: 评级前先定 target/证据类型；推算链（N4 tp/N5 derived）标 basis=推算；引文/声称标 quoted。
- 反例: 用"关系边存在"直接给 A——N5 derived 边止于 C（AU07）。
- 来源: `SKILL_07e` §二/§7.1；`registry/relations`、`registry/events` 接口。
- 状态: 已验证

### AU04 · E 级不是"不可考"：不可考标未知，E 仅给明确矛盾/可证伪
- 类别: A-E 分级与分层
- 现象: 原文没写（不可考）判 E（穿帮）；或把"未知"当 E 记录。
- 判据: 07e §4.2：证据缺失/不可考 → 标"未知"，**不降级**、不判 E；E 只给"与设定明确矛盾"（07c 三分流判定为破绽）
  或"可证伪"；不可考（原文未写）与矛盾（原文写了不一致）两码事。
- 动作: 未知入 unknown 字段；E 需 07c 三分流+人工确认（N8 引擎不产 E）。
- 反例: 某人物生卒年原文未交代 → 未知，不判 E；两书同一事件年代冲突→可能是 E 候选（矛盾）。
- 来源: `SKILL_07e` §4.2；`SKILL_07c_设定一致性`；`logs/consistency/summary.md` §三（E 需人工确认）。
- 状态: 已验证

## B 区 · 评级规则

### AU05 · 来源声称上限 C：转述/传闻/人物声称即使斩钉截铁也不得 A/B
- 类别: 评级规则
- 现象: "据说他早已死了"按正文事实给 A/B；人物对白中的断言当作者叙述。
- 判据: 07e §4.1：转述/传闻/人物声称（04a 叙述模式 quoted/claim）→ **上限 C**；例："据说他早已死了"→C；
  正文直接叙述死亡→A/B；传闻被后文证实/证伪→重评（证实升、证伪转 E 并记翻案）。
- 动作: 评级前查叙述模式（04a §七）；quoted/claim 标 C；多源互证可升 B（AU12）；翻案记录重评。
- 反例: "某某亲口说自己是掌门"给 A——声称上限 C，除非另有正文直证。
- 来源: `SKILL_07e` §4.1/§六；`SKILL_04a` §七；`references/04a1`（叙述模式）。
- 状态: 已回写

### AU06 · 未知 ≠ N8 穿帮：A-E 与 N8 error/warning/info 的映射口径
- 类别: 评级规则
- 现象: N8 命中按 error/warning/info 直接当 A-E；或把 info（B 级备案）当穿帮。
- 判据: N8 口径（`logs/consistency/summary.md` §三）：error→**D 疑似穿帮候选**（待人工复核，E 需人工确认）；
  warning→**C 存疑**；info→**B 备案/资产**；叙述模式豁免（04a 回忆/梦境/假想/戏中戏）不入 violations；
  传言/转述归来源声称层（J8）。本批 error(D)=0：C1/C5 等弱信号按 SKILL 证据强度止于 C。
- 动作: N8 命中按映射定级；升 D/E 须人工复核+事件层/档案层补证；豁免项记录。
- 反例: 把 N8 warning 一律当 D 穿帮发布——warning 只是 C 存疑，未确认。
- 来源: `logs/consistency/summary.md` §三；`SKILL_07e`；`references/06e1`（N8 接口）。
- 状态: 已验证

### AU07 · 推算链止于 C：N4/N5 推导证据不得给 A/B
- 类别: 评级规则
- 现象: 由 N4 时间推算或 N5 关系推导得出的结论给 A/B；跨书推理当直证。
- 判据: 07e §4.1/§1.4 实测："证据来自 N4 推算 / N5 推导 → **止于 C**"——推算链无法给 A/B；升级条件=事件层
  （04a/D03/EX-5）与死亡/习得登记补证后可升（07e §1.4）。
- 动作: basis 标"推算"；C 级展示保留；事件层补证后按 AU09 升级。
- 反例: 由年龄锚推出"某年 25 岁"给 A——N4 推算，最多 C（时间轴自洽性证据）。
- 来源: `SKILL_07e` §1.4/§4.1；docs/57 §五；`registry/time`、`registry/relations`。
- 状态: 已验证

### AU08 · 多源冲突双记：按 D07 权威层级取高层，低层进 conflicts；不可判双记+降级
- 类别: 评级规则
- 现象: 两源冲突硬裁一方；或只保留高权威来源丢失低层记录。
- 判据: 07e §4.3：两源冲突（正文 vs 序跋/修订/派生）→ 按 D07 §三 权威层级取高层级评级，低层进记录层
  （conflicts）；无法判别 → **双记 + 降一级 + 争议区**（禁止硬裁，D07 R6）。
- 动作: conflicts[] 双记；争议区；翻案/重评记录（AU09）；下游答案走"两说并存"（09a1:AQ09）。
- 反例: 正文与序跋矛盾时直接信正文并删除序跋说法——低层记录丢失，无法追溯。
- 来源: `SKILL_07e` §4.3；`SKILL_跨书治理` §三（D07 R6）；`references/09a1` AQ09。
- 状态: 已验证

### AU09 · 升级/降级/重评三动作与留痕（证据+日期+复核人）
- 类别: 评级规则
- 现象: 评级改来改去无记录；规则版本变更后旧评级不复评。
- 判据: 07e §4.4：升级=新增互证/事件层补证/翻案确认（记录证据+日期+复核人）；降级=发现反证/来源被证伪
  （反证+理由）；重评=规则版本变更（新旧级+规则版本）；`rule_version`/`reviewed_by`/`date` 字段必填。
- 动作: 评级变更写记录；翻案走 RV-09 检测；下游（SKU/N8/问答）按新级重算。
- 反例: 不写 rule_version 就批量升级——无法判断评级依据哪版规则；重评无从触发。
- 来源: `SKILL_07e` §4.4/§7.1；`references/03d1` H17（版本三元组）。
- 状态: 已回写

## C 区 · 七法与叙述接口

### AU10 · 七法转写：版本对勘/年代/职官/地理/名物/门规/分层（门规 ★★★★★ 可机器化）
- 类别: 七法与叙述接口
- 现象: 照搬史记七法；或忽略武侠最高价值可机器化项"门规鉴定"。
- 判据: 07e §五（D11 §6 映射）：版本对勘→锁定底本 vs 修订版对照（部分）；年代鉴定→N4（部分）；职官制度→门派
  职衔/建制（部分）；地理→gazetteer real/fiction（部分）；名物→器物/武功/秘籍体系（部分）；**法律/门规鉴定→
  门规/帮规/江湖规矩核验（★★★★★ 可机器化）**；分层评估（人工）。
- 动作: 门规核验优先机器化（01g `:` 礼仪规约 + D11 江湖常识区）；其余部分可机器化项挂 N4/N7/词表。
- 反例: 只做"版本对勘"不做门规核验——武侠版最高价值可机器化项被漏。
- 来源: `SKILL_07e` §五；`SKILL_01g` §九（`:` 礼仪规约）；`SKILL_常识与设定一致性`（D11 §6.1）。
- 状态: 已验证

### AU11 · 叙述可靠性接口：6×4 矩阵 → 评级上限
- 类别: 七法与叙述接口
- 现象: 梦境/幻觉被当事实；不可靠叙述者的话给 A。
- 判据: 07e §六（04a §七 6×4 矩阵）：叙述者直接叙述（可靠）→A/B；人物对白/声称→C；传闻/据说→C（多源可 B）；
  回忆→C（核对回忆对象与时间）；梦境/幻觉/想象→**E（不入事实）**；不可靠叙述者（有意欺骗）→C/D（记录欺骗语境）。
- 动作: 评级前标 narrative_mode；梦境/幻觉直接 E 不入库；声称/回忆按上限；不可靠叙述者记录语境。
- 反例: 梦境中"某人死亡"给 A——梦境 E（不入事实）。
- 来源: `SKILL_07e` §六；`SKILL_04a` §7.1-§7.5；`references/04a1`。
- 状态: 已验证

### AU12 · 记录 schema v0.1：target/layer/grade/basis/sources/conflicts/rule_version
- 类别: 七法与叙述接口
- 现象: 评级只有"grade"字段；无来源/版本/复核人，无法审计。
- 判据: 07e §7.1 schema：`{"target_id":"evt/rel/card-id","layer":"主线设定|情节经过|细节对话","grade":"A|B|C|D|E",
  "basis":"正文直证/互证/推算/声称/派生/矛盾","sources":[{"loc","kind":"authorial|quoted|derived"}],"conflicts":[],
  "rule_version":"07e@v0.1","reviewed_by":"","date":""}`。
- 动作: 评级产物按 schema 输出；`rule_version` 必填；conflicts 双记；下游按 target_id 关联。
- 反例: 用自由文本"可信/不可信"记录——无法机审计/聚合。
- 来源: `SKILL_07e` §7.1；`references/03d1` H17。
- 状态: 已验证

### AU13 · 转述声称多源升级：证实升/证伪转 E 并记翻案
- 类别: 七法与叙述接口
- 现象: 传闻被后文证实后仍按 C；或被证伪后仍保留 C 不重评。
- 判据: 07e §4.1：传闻被后文证实/证伪 → 重评（证实升、证伪转 E 并记翻案）；07e §4.4 升级条件=新增互证/
  事件层补证/翻案确认；翻案未重评由 RV-09 检测。
- 动作: 翻案记录（原级/新级/证据）；下游重新发布；N8 对已登记冲突降级"已知名目"。
- 反例: 传闻人物已死，后文出现其人——不重评还按 C 当"可能已死"。
- 来源: `SKILL_07e` §4.1/§4.4；RV-09；`SKILL_常识与设定一致性` §四（死亡再现检查）。
- 状态: 已验证

## D 区 · 错误模式与实测

### AU14 · RV-01~10 错误模式库：声称当 A/未知当 E/推算给 A/派生当事实/冲突硬裁/不分层/无版本/C 级断言/翻案未重评/与 N8 不一致
- 类别: 错误模式与实测
- 现象: 同类评级错误反复出现（C 级作断言答、评级与 N8 by_grade 对不上）。
- 判据: 07e §八 RV-01~10：RV-01 来源声称当 A/B→上限 C；RV-02 未知当 E→改未知；RV-03 推算链给 A/B→止于 C；
  RV-04 派生资料当事实→D/不发布；RV-05 多源冲突硬裁→双记+降级；RV-06 只给总级不分层→补分层；
  RV-07 评级无证据/版本→补；RV-08 C 级作断言性答案→拒答/标注；RV-09 翻案未重评→重评；
  RV-10 评级与 N8 by_grade 不一致→对账统一。
- 动作: 评级后逐条自查；错误编号只增；可规则化者入校验器（schema/叙述模式/证据类型检查）。
- 反例: 把 RV-02 当"数据缺失"忽略——未知与 E 不同（AU04），必须显式记 unknown。
- 来源: `SKILL_07e` §八；`references/04a1`；`logs/consistency/summary.md`.
- 状态: 已验证

### AU15 · N8 实测：44 命中（0 D/28 C/16 B）+ 39/39 规则覆盖 + 0 error
- 类别: 错误模式与实测
