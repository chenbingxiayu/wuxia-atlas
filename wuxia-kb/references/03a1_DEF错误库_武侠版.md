## A 区 · 类型误标

### DF01 · 标记收括号误写：`⟧` 写成 `〗` / 缺半角括号
- 类别: A 类型误标
- 现象: 003 回约 30 处收括号误写（`⟧`→`〗`、半角括号残留）；解析器把动词令牌当实体/文本处理，剥标即错位。
- 判据: 令牌只允许 〖…〗（实体）/ ⟦…⟧（动词）/ 〘…〙（修辞）三种括号；收括号与开括号必须同种、成对；
  `⟧` 后缀出现 `〗` 即语法破损（DEF-01）。
- 动作: 括号归一化（限已识别标记）；重跑五门 lint＋剥标断言；原始/修复数分列入报告；批处理走
  `scripts/fix_nested_annotations.py`/`scripts/fix_annotation_mechanical.py`。
- 反例: 原文引号内正常出现的「〗」不是令牌括号，剥标后仍应保留；不得因归一化误删原文括号字符。
- 来源: `SKILL_03a` §2.4 DEF-01（003 回约 30 处）；docs/21 第一回修订说明。
- 状态: 已验证

### DF02 · 管道吞原文：原文字符从显示串搬入管道
- 类别: A 类型误标
- 现象: `⟦⊠遭|横死⟧`、`〖@明太祖|朱元璋〗`——"遭/明太祖"等原文字符被搬进管道右侧，剥标后原文缺字。
- 判据: 管道右侧只放**规范名/消歧说明**，不得承载原文正文；显示串必须逐字等于原文区间（03a 输出契约 4）；
  `textContent == strip(tagged)` 逐段断言失败即命中。
- 动作: 修正式 `⟦⊠遭横死⟧`、`明太祖〖@朱元璋〗`；跑剥标逐字对账；同类批量用
  `scripts/fix_annotation_mechanical.py` 修复并复跑 lint。
- 反例: `〖@玉罗刹|练霓裳〗` 中"玉罗刹"在原文且为显示串，合法；判断依据是"被移入管道的字是否原文字符"。
- 来源: `SKILL_03a` §2.4 DEF-02；`SKILL_01g` 管道语义；docs/20 §4.2。
- 状态: 已回写

### DF03 · 触发词分词错误：吞方式/漏字/错切复合词
- 类别: A 类型误标
- 现象: "迈步入内"误标成"步｜入内"；`⟦■纵马过来⟧` 丢"纵马"；"自废武功"拆成"自+废"。
- 判据: 触发词区间应覆盖完整动作语块（方式+动作）；纯边界过长由语义验收把关，**文字丢失只能由剥标断言暴露**；
  复合词（自废/纵马）不得按单字拆（04f §边界错切警觉）。
- 动作: 剥标逐字断言（仅当文字丢失时暴露）；语义验收抽查触发词边界；04f1 的 W-3 同源反例互证。
- 反例: "迈步入内"若原文是"迈步入内"则显示串必须完整；不得为凑动词域把"迈步"移入管道。
- 来源: `SKILL_03a` §2.4 DEF-03；`SKILL_04f` §边界错切警觉/W-3；docs/47 补标处置。
- 状态: 已验证

### DF04 · 亲属词标 `;`（旧规残留）
- 类别: A 类型误标
- 现象: "儿子/孙儿/兄/弟/妻"等纯亲属关系词标成职衔 `;`（A1 v0 旧规），与 03a v2 裁定冲突。
- 判据: 纯关系词=关系描述，**不标**（关系归关系层/登记层）；承担身份指称的亲属复合词整体标 `#`；
  禁嵌套拆分（03a §二、DEF-04、03b D1）。
- 动作: 摘标纯关系词；复合词整体标 `#`；关系数据交 N5/`SKILL_关系体系_武侠版.md`；词表侧对应
  `wordlists/kinship.json`（62 条，watch 档）。
- 反例: "义父子"按语境判（义父/义子为身份或亲属）；"父子二人同来"群像叙述不标。
- 来源: `SKILL_03a` §2.4 DEF-04；`SKILL_03b` D1；`wordlists/kinship.json`；docs/34 G-25。
- 状态: 已回写

### DF05 · 职业与建制职混标
- 类别: A 类型误标
- 现象: 镖头/镖师/道士等职业称谓标 `;`；掌门/帮主等可任命职位标 `#`；同 surface 混用。
- 判据: `#`=职业类别/社会身份/法定/处境身份；`;`=可任命/册封的建制职衔；纯关系词不标（DEF-04）；
  见 03a §二 `#`/`;` 行与 D1 规则。
- 动作: 按语境改 `;↔#`；同步 `wordlists/identity.json`（现行 `;`82/`#`130 条）与 03a D1 判据；
  批处理走 `scripts/apply_annotation_patches.py`。
- 反例: "以 X 为掌门"是任命语境，掌门仍为 `;`；"大侠/高手"是身份 `#` 不是职衔。
- 来源: `SKILL_03a` §2.4 DEF-05；`SKILL_03b` D1；`wordlists/identity.json`；docs/34 G-25。
- 状态: 已回写

### DF06 · 技艺转喻标器物
- 类别: A 类型误标
- 现象: "阁下真好弹弓"中"弹弓"被标 `•` 器物——实际是转喻评价（技艺/本领），不是具体器物。
- 判据: 转喻/评价语境不标实体；只有指称具体器物（可被持有/使用）时才标 `•`（03a v2 裁定）。
- 动作: 摘标；同类"好剑法/好掌法"归 ☆ 或 ^ 能力域（01g B1-1），不标 `•`。
- 反例: "他的弹弓"=具体器物，仍标 `•`；判断依据是"是否可指认具体对象"。
- 来源: `SKILL_03a` §2.4 DEF-06；`SKILL_01g` B1-1 能力域。
- 状态: 已验证

### DF07 · 空间夹处标战斗控制
- 类别: A 类型误标
- 现象: `⟦⊞夹⟧` 把"夹"（空间夹处/夹击位置）标成战斗控制动作。
- 判据: 夹处≠控制；战斗控制（⊞）须有"一方对另一方施加限制/制服"的语义；空间位置描述不标（03a v2 裁定）。
- 动作: 撤标；若实际是"夹击"战法，按 04f ⊞ 合并标注（起止+关键结果），不逐招标。
- 反例: "左右夹攻"是战术描述，若正文只写阵形无动作则不标；"夹住手腕"确有控制结果才标 ⊞。
- 来源: `SKILL_03a` §2.4 DEF-07；`SKILL_04f` §6.1 合并标注。
- 状态: 已验证

## B 区 · 边界与管道

### DF08 · 礼仪动作/临时许可标关系建立
- 类别: B 边界与管道
- 现象: "下拜""允了"等礼仪动作或临时许可标成关系建立（⊡），误生成师承/结义边。
- 判据: 只标师承/结义/任命等**实质变更**；礼仪动作、口头许可不构成关系建立（03a v2 裁定 + 04f V3-1）。
- 动作: 摘标 ⊡；关系建立以拜师/结拜/任命事件为准；单次指点不建关系（04f V3-2）。
- 反例: 正式拜师仪式（三跪九叩/敬茶）可标 ⊡；"下拜"若确为拜师礼的一部分则与拜师事件合并，不单独标。
- 来源: `SKILL_03a` §2.4 DEF-08；`SKILL_04f` V3-1/V3-2；docs/29 外部评审。
- 状态: 已验证

### DF09 · 誊写引号退化（弯引号→半角）
- 类别: B 边界与管道
- 现象: 转录/标注过程中中文弯引号“”退化为半角 "，标点层与原文不一致。
- 判据: 文本保真以底本字节为准；引号退化属誊写缺陷，剥标对账可检出（docs/20 §4.2）。
- 动作: 字节级注入/回填，禁止手抄产物；用 `scripts/fix_halfwidth_quotes.py` 修复并复跑 lint_markdown。
- 反例: 底本原本就是半角引号的段落不得"修"成弯引号（以底本为准，不以风格偏好为准）。
- 来源: `SKILL_03a` §2.4 DEF-09；docs/20 §4.2；`scripts/fix_halfwidth_quotes.py`。
- 状态: 已回写

### DF10 · 规则文本与种子漂移
- 类别: B 边界与管道
- 现象: v1.0 规则写"囚禁→■/模糊时间不标"，种子已演进为 ⊡/宽口径——规则文本与 few-shot 种子不同步。
- 判据: 规则永远从种子/裁定重新编译；构建器加版本锁定 + 构建断言；文-码两张皮即漂移（DEF-10）。
- 动作: 版本锁定 `prompt_version` + §五.2 构建断言；`scripts/build_03a_fewshot.py` 自动回填版本号。
- 反例: 为兼容旧种子保留旧规则文本——会继续漂移；应改种子并重编译，规则文本不手改。
- 来源: `SKILL_03a` §2.4 DEF-10；`scripts/build_03a_fewshot.py` v3；docs/24。
- 状态: 已验证

### DF11 · 显示串未覆盖全区间（绰号+本名连写）
- 类别: B 边界与管道
- 现象: "玉面妖狐凌霄"全形出现时显示串未覆盖全区间，本名"凌霄"被推入管道（004 回 8 处）。
- 判据: 显示串=原文区间全文；本名只能入管道；`textContent == strip(tagged)` 断言拦截；
  全形连写显示串规则见 DEF-12。
- 动作: 修正显示串覆盖全区间、本名入管道；批量复跑剥标断言；断言拦截新增同类。
- 反例: 原文只出现"凌霄"（本名单独出现）时显示串可只含"凌霄"；不能把未出现的绰号补进显示串。
- 来源: `SKILL_03a` §2.4 DEF-12（合并入本条）；docs/29 外审；`scripts/build_03a_fewshot.py` 断言。
- 状态: 已验证

## C 区 · 剥标与工具

### DF12 · 工具误报：相邻同 TYPE 位字符跨标签误配对
- 类别: C 剥标与工具
- 现象: `lint_symbol_conflicts` 旧式 @X@ 检测在未剥令牌原文上运行，004 报 170 处假阳性（003 同被掩盖）。
- 判据: 检测前必须剥除有效令牌；门绿灯必须看完整输出，不能只看"0 处"（DEF-11）。
- 动作: 检测前先剥有效令牌（2026-11-03 已修复）；CI/五门 lint 必须看完整输出与样本。
- 反例: 修复后仍报的"疑似冲突"需人工抽样确认，不得一律当假阳性忽略。
- 来源: `SKILL_03a` §2.4 DEF-11；docs/29 实现审计；`scripts/lint_symbol_conflicts.py`。
- 状态: 已验证

### DF13 · 自报疑点与成品不符（凭记忆写自报）
- 类别: C 剥标与工具
- 现象: 评审发现自报"窝藏已标"实际漏标、自报"羊皮书标•"实际标 {（2 处）。
- 判据: 自报疑点清单必须**程序化从成品生成**，禁止凭记忆撰写（DEF-13）。
- 动作: 用 `scripts/qa_annotation_report.py`/accept 报告自动生成疑点清单；自报只引用生成结果。
- 反例: 人工抽查补充的疑点可写，但须注明"人工发现+loc"，不得写"已全标"式结论。
- 来源: `SKILL_03a` §2.4 DEF-13；docs/29 外部评审。
- 状态: 已回写

### DF14 · 草稿占位符泄漏进产出
- 类别: C 剥标与工具
- 现象: 用 `〦`/`?`/`___FSn___` 等占位标记"此处不标"，剥除正则连原文字符一起删；006 回 v1 草稿批量损坏
  （原文字符丢失、贪婪 `[^〗]*` 跨段吞噬、JSON 转义吞 `\1`）。
- 判据: 标注文本必须一次写成最终形态；中间态只放独立草稿文件，禁止进产出脚本（DEF-14）；
  剥标逐字对账兜底。
- 动作: 清理占位符泄漏；剥标断言；草稿隔离到 `_oneshot/` 或 `logs/` 草稿目录，不参与产出。
- 反例: 调试用的临时占位符在最终文件里即使"后面会删"也不可接受——产出必须一次成型。
- 来源: `SKILL_03a` §2.4 DEF-14；docs/27 §八；docs/29 实现审计。
- 状态: 已验证

### DF15 · judgment 机械处置的单条裁定未入账（待裁）
- 类别: C 剥标与工具
- 现象: judgment 项按规则分类可机械处置（quantity_boundary 裸数词→应摘；plan_negation_verb 纯意图/否定→应摘；

- 动作: 用 `scripts/finalize_judgment.py`（--dry-run 默认）生成分类与高置信清单；落盘前备份 tagged、
  剥标断言、复跑 accept；台账入 `logs/qa/judgment_signoff_*`。
- 反例: "为省事把 judgment 全标应摘"——doc/45 已裁定宽口径时间边界应保留，误摘会损伤时间锚。
- 来源: `SKILL_03a` §2.4（DEF-13 同源流程纪律）；docs/45 §三；docs/54 §一；`scripts/finalize_judgment.py`。
- 状态: 待裁

## D 区 · 围栏与流程

### DF16 · 围栏内实指实体被机械摘除 / 修辞泛指被保留
- 类别: D 围栏与流程
- 现象: 02ab 围栏（诗/词/歌/回末对等）内实体策略 real_only：实指保留、修辞泛指应摘；此前 fence 漂移修复后
  新增围栏内的实指 token（如"金环""天山"）被误摘或泛指被保留。
- 判据: 围栏类型→实体策略表（02ab §4.4）：词/诗/歌/对联/回末对 → 实体限实指；回末 → 全不标；
  书信/告示 → 可标；口诀 → 技术名可标。判断"实指"以正文语境为准。
- 动作: 围栏内逐 token 复核；实指保留（记录人工理由），修辞泛指摘除；复跑 lint_fence_format/剥标断言。
- 反例: 回末"天山"确指地名（实指）应保留；"金环"若是人名（实指）保留，若只是比喻"金环似的月"则摘。
- 来源: `SKILL_02a_02b` §4.4；docs/54 §二（围栏 64→67/29→54 漂移治理）；docs/59 §二（8 条残留项终签）。
- 状态: 已验证

### DF17 · pipe_unsourced：管道右值无来源
