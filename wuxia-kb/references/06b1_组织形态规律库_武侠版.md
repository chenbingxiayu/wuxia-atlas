## A 区 · 势力树结构与判定法

### ORG01 · 势力树结构：3 分支 11 叶（武学传承型/结社据点型/庙堂武力型）
- 类别: 势力树结构与判定法
- 现象: 给组织新设"其他"叶/按正邪分树；分支归属随心。
- 判据: D08 §5.4：势力树 3 分支 11 叶——武学传承型（武学门派/武林世家/海外门派）、结社据点型（宗教教门/帮会/
  盟会联盟/绿林山寨/黑店赌坊/镖局）、庙堂武力型（宫廷势力/义军组织）；分支取舍见附录 B9（可拍平 11 叶，待拍板）。
- 动作: 组织按形态挂叶；不设兜底叶（06e1:GR04）；正邪入属性（ORG12）。
- 反例: 新设"邪派"叶——正邪是属性不是形态（§5.1 裁决）。
- 来源: `SKILL_分类树五件套` §5.2/§5.4；`references/06e1` GR01/GR06。
- 状态: 已验证

### ORG02 · 三问裁定法：行为主体/结构可指认/边界清晰（不过=泛称不登记）
- 类别: 势力树结构与判定法
- 现象: 泛称（武林/江湖/绿林道）建组织；或把国家/部族/地理大区当 ◆。
- 判据: D08 §5.3 三问测试：① 文本中该词是否独立发出组织行为（下旨/传艺/劫镖/会盟/开山收徒）？② 能否指出
  首领、层级、成员范围？③ 能否说出"谁在其中、谁不在"？三问皆过→合法实例按形态挂叶；部分过→拆解到语境中
  具体实体；皆不过→**泛称，不登记**。
- 动作: 先过三问再建实体；不过者降级（^ 概念/◎ 群组）或删除；留裁定理由。
- 反例: "◆武林"（T1 错误）——三问皆不过；"◆官兵"泛称→◎ 群组（task-45 判例）。
- 来源: `SKILL_分类树五件套` §5.3；`references/03e1` TY11；task-45 改判。
- 状态: 已验证

### ORG03 · 正邪/存续/出现书目/地域是属性字段，不入树
- 类别: 势力树结构与判定法
- 现象: 门派页按"正派/邪派"分树；隐世/被灭设叶；跨书出现设"跨书传承门派"叶。
- 判据: D08 §5.1 正邪裁决：立场=属性（正/邪/中立/未定，支持按书/阶段分段），不入身份树也不入势力树；§5.2：
  隐世→存续状态属性；跨书→出现书目字段（派生统计）；地域→属性。
- 动作: 邪正/存续/书目/地域写属性字段；树只按形态。
- 反例: 把"魔教"当叶——教门+邪正=邪；"隐世门派"→形态叶+存续=隐世。
- 来源: `SKILL_分类树五件套` §5.1/§5.2；`references/06a1`（本体规律）。 
- 状态: 已验证

## B 区 · 11 叶逐叶判定

### ORG04 · 武学门派：师徒传承、开山收徒的武术门派
- 类别: 11 叶逐叶判定
- 现象: 把家族（&）当门派；把门派驻地当地点条；把只出现一次的门派泛名当门派。
- 判据: D08 §5.4：武学门派=师徒传承、开山收徒的武术门派；信号=开山/师承/辈分字谱；武功以派名冠（X派剑法）；
  门规；正例=武当/少林/峨眉/天山派；易误判=门派类型≠成员个体身份（§5.5）。
- 动作: 按信号挂叶；与 & 家族分建；与 = 地点（山门/驻地）分建（hq_of 关联）。
- 反例: "唐家"是家族世系 &（但门派志可交叉引用），不改类型；"天山派驻地"是地点不是组织。
- 来源: `SKILL_分类树五件套` §5.4/§5.5；S-03i 落叶实测（武学门派 14）。
- 状态: 已验证

### ORG05 · 武林世家：家族传承武学的门第庄堡
- 类别: 11 叶逐叶判定
- 现象: 单代父传子称世家；把普通家族当门派。
- 判据: D08 §5.4：武林世家=家族传承武学的门第庄堡；信号=同姓数代习武/家传绝艺/庄堡为基；易误判=单代父传子
  不成世家，挂武学门派观察。
- 动作: 同姓数代+家传绝艺才挂世家；不足者观察；& 家族与 ◆ 世家的判定（家族本体在 &，组织形态在 ◆）。
- 反例: 某家仅一代为武——仍按武学门派观察，不升世家。
- 来源: `SKILL_分类树五件套` §5.4；S-03i（武林世家 0 实例，稀疏预警叶）。
- 状态: 已验证

### ORG06 · 海外门派：域外/海岛武学组织
- 类别: 11 叶逐叶判定
- 现象: 把内陆边域门派当海外；或域外门派挂普通门派。
- 判据: D08 §5.4：海外门派=域外/海岛武学组织；信号=跨海异域语汇/武学体系异源；稀疏预警叶（附录 B8），
  地域另记属性；S-03i 实测 0 实例（当前语料无触发）。
- 动作: 遇跨海域外门派才挂；地域属性另记；稀疏叶备案（06e1:GR07）。
- 反例: 西藏天龙派（域内高原）→武学门派，不按"异域"挂海外。
- 来源: `SKILL_分类树五件套` §5.4；S-03i（海外门派 0）；`references/06e1` GR07。
- 状态: 已验证

### ORG07 · 宗教教门：神祇崇拜的秘密宗教结社
- 类别: 11 叶逐叶判定
- 现象: 把寺院/门派当教门；把"魔教"泛称当叶。
- 判据: D08 §5.4：宗教教门=神祇崇拜的秘密宗教结社；信号=教主—教众层级/教义神祇信奉/传教收众；"魔教"不是叶
  ——教门+邪正=邪；S-03i 实测 0 实例（语料无登记）。
- 动作: 教门与寺观（地点）、武学门派（僧道武学）分开；邪正属性。
- 反例: 少林派（武学门派，非秘密宗教结社）；红教/白教等宗教组织才可能挂教门。
- 来源: `SKILL_分类树五件套` §5.4；S-03i（宗教教门 0）。
- 状态: 已验证

### ORG08 · 帮会：地缘/行业结社
- 类别: 11 叶逐叶判定
- 现象: 泛称"帮派"建实体；帮会与结义/盟会混。
- 判据: D08 §5.4：帮会=地缘/行业结社；信号=帮规/香堂/漕运盐业地盘/帮众层级；正例=丐帮/漕帮式；易误判=
  泛称"帮派"不登记；S-03i 落叶 8（龙门帮/五龙帮/天地会/铁扇帮/青阳帮/马帮/大地会/洪门）。
- 动作: 按地缘/行业挂帮会；结义/盟会走各自叶；泛称不登记。
- 反例: 天地会/洪门=秘密会社（帮会），不是"盟会联盟"（无多组织会盟）。
- 来源: `SKILL_分类树五件套` §5.4；S-03i（帮会 8）；task-40 判定表。
- 状态: 已验证

### ORG09 · 盟会联盟：跨组织会盟结成的联盟
- 类别: 11 叶逐叶判定
- 现象: 临时会盟未设常设机构就建盟会；把帮会当盟会。
- 判据: D08 §5.4：盟会联盟=跨组织会盟结成的联盟；信号=多方会盟/推举盟主/盟约文书/联盟旗号；易误判=临时
  会盟未设常设机构→事件不登记（§5.3）；S-03i 落叶 1（东林党，政治结社）。
- 动作: 有常设机构/盟约才挂；临时会盟归事件；域名/秘书属性。
- 反例: "武林大会"是事件（T13 容器），不是盟会联盟；会盟后设盟主府才建实例。
- 来源: `SKILL_分类树五件套` §5.3/§5.4；S-03i（盟会联盟 1）。
- 状态: 已验证

### ORG10 · 绿林山寨 / 黑店赌坊 / 镖局：据点型三叶
- 类别: 11 叶逐叶判定
- 现象: 山寨当帮会；镖局当普通商号；黑店赌坊与帮会混。
- 判据: D08 §5.4：绿林山寨=占山据水的绿林组织（山寨/水寨据点/啸聚/分金排座次；与地点树山寨水寨双登记联动）；
  黑店赌坊=以灰色营生为业的据点（黑店/赌坊/销赃语汇；稀疏预警→并帮会）；镖局=保镖营业组织（字号/总号分号/
  走镖护镖/雇镖师；与地点树镖局车店、职衔树镖行职衔联动）。
- 动作: 三叶按据点/营业形态分；S-03i 实测：绿林山寨 1（眉山寨）、镖局 3（武威镖局/镖局/镖行）、黑店赌坊 0。
- 反例: 武威镖局是镖局（营业组织），其据点（镖局车店）归地点树，不重复。
- 来源: `SKILL_分类树五件套` §5.4；S-03i（绿林1/镖局3/黑店0）。

### ORG11 · 宫廷势力 / 义军组织：庙堂武力型两叶

## C 区 · 属性字段与双身份

### ORG12 · 邪正立场属性：正/邪/中立/未定，支持分段，不入树
- 类别: 属性字段与双身份
- 现象: 因个别弟子作恶把门派改"邪"；组织被诬陷/平反无法留痕。
- 判据: D08 §5.1 裁决：邪正立场=属性字段（正/邪/中立/未定，支持按书目/阶段分段）；理由=上游契约（01g 邪正=
  属性）、立场随剧情变迁、组合爆炸、可筛性不成立；检索路径="名门正派"=武学门派+邪正=正+公认地位。
- 动作: 邪正写属性；分段留痕；成员个体立场不入组织字段（§5.5）。
- 反例: "魔教"=教门+邪正=邪，不是"邪教叶"。
- 来源: `SKILL_分类树五件套` §5.1/§5.2/§5.5。
- 状态: 已回写

### ORG13 · 存续状态与 hq_of 双身份：隐世/活跃/分裂/被灭/复兴；驻地不设叶
- 类别: 属性字段与双身份
- 现象: 隐世/被灭设叶；门派驻地当组织叶；驻地与地点重复。
- 判据: D08 §5.2/§5.3：存续状态属性（活跃/隐世/分裂/被灭/复兴）；**不设"门派驻地"叶**——驻地是组织-地点关系，
  由 hq_of 承载（地点条目 hq_of=["天山派"]；组织页读 gazetteer；一派多驻地/迁驻建两条地点）；组织本身不入
  gazetteer（"武当山"才是地点）。
- 动作: 存续写属性；驻地双登记联动（地点树+组织属性）；迁驻分段。
- 反例: "天山派驻地"建 ◆ 组织——错；应 = 地点+kind 秘境洞府+hq_of 双身份。
- 来源: `SKILL_分类树五件套` §5.2/§5.3；`SKILL_地名gazetteer` §5.3；`references/06e1` GR10。
- 状态: 已验证

### ORG14 · 组织形态与分类树其他维度的正交：≠ 成员身份、≠ 地点、≠ 家族
- 类别: 属性字段与双身份
- 现象: 门派树类型当成员身份（"武当派门徒都标门派叶"）；组织与家族/地点混建。
- 判据: D08 §5.5：门派树的类型与邪正是**组织级**字段；成员个体身份与立场在人物侧登记（身份树+人物卡）；
  个体正邪永不写回门派树。类型维度：◆ 组织 / & 家族世系 / = 地点 / ◎ 群组正交（ORG01/ORG03）。
- 动作: 组织字段只写组织；个体身份走 #；家族走 &；地点走 =（hq_of 关联）。
- 反例: 因某弟子作恶把武当派邪正改"邪"——组织立场被个体绑架（§5.5 明禁）。
- 来源: `SKILL_分类树五件套` §5.5；`references/06a1`；`references/03e1` TY11。
- 状态: 已验证
