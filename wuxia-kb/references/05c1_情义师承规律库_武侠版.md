## A 区 · 双树与辈分

### QY01 · 双树同构：师承树 ↔ 血缘树，传递/无环/辈分复用同一套算法
- 类别: 双树与辈分
- 现象: 两套辈分算法给出冲突辈分；或把师承与血缘混在一棵树。
- 判据: 05c §1.4/§3（D06 §五）：双树**同构**——传递推理/无环检测/辈分推导复用同一套算法；节点=人，
  边=师承或血缘；树根/层级/辈分口径一致。
- 动作: 辈分推导只实现一处（双树共用）；输出标签写人物卡/关系报告，不写回树。
- 反例: 血缘用"代距"、师承用"入门年"两套算法——出现同日不同辈冲突。
- 来源: `SKILL_05c` §1.4/§3；`SKILL_关系体系` §5.1/§5.2；`references/05a1` RP12。
- 状态: 已验证

### QY02 · 血缘树（家族世系）：`&` 14 条家族 + 亲属关系
- 类别: 双树与辈分
- 现象: 家族（&）与组织（◆）混用建树；亲属关系缺方向。
- 判据: 05c §3.1：血缘树=家族世系（registry `&` 14 条：铁家/卓家/孟家/石家/纳兰相府/鄂王府/方家/唐家/桂家/
  洪家/陆家/冒门/马家/爱新觉罗氏）+ 亲属关系（亲属谓词按类型方向：亲长→幼辈；同辈对称）。
- 动作: 血缘树只取 & 与亲属边；组织（◆）不进血缘树；亲属边方向按 D06 §7.2 #43。
- 反例: 把"唐家"（&）与"唐门"（◆）并树——类型不同，各建各树/各挂叶。
- 来源: `SKILL_05c` §3.1；`SKILL_关系体系` §7.2 #43；`registry/entities.json`（&14）。
- 状态: 已验证

### QY03 · 师承树（武侠核心）：师承边 39、方向师→徒、5 子型
- 类别: 双树与辈分
- 现象: 师承方向反；传授边当师承；师承树出现环。
- 判据: 05c §3.2：师承树=N5 师承边（39 边）；方向师→徒；子型=正式拜师/逐出/叛门/自立门户；传授（师→徒武功）
  不自动建师承；循环师承=数据错误（QX-02）。
- 动作: 师承边落库→建树→无环检测→层级；逐出/叛门记状态不改边；循环回溯 03b/错标。
- 反例: "指点一招"建师承——04f V3-2 明确不自动建；单次指点不成师承。
- 来源: `SKILL_05c` §3.2；`SKILL_关系体系` §4.2/§7.2 #35-36；`references/04f2` VB11。
- 状态: 已验证

### QY04 · 辈分推导规则：师祖/师叔/同门/侄辈；N5 实测 26 全 weak
- 类别: 双树与辈分
- 现象: 辈分手工填写；或跨书辈分直接抬升为 ok/strong。
- 判据: 05c §3.3 辈分推导表：师祖/师伯/师叔=师承树代距 1-2→ok；同门/师兄/师弟=同师+入门先后（若可判）→ok
  （先后不可判→weak）；侄辈/孙辈=血缘/师承代距→ok/weak；跨书辈分=系列身份+双树+07a 年代→low。
  N5 实测辈分标签 **26 条全 weak**——师承树浅（冰魄/塞外树浅）与入门先后不可判，v0.1 不强行升档。
- 动作: 辈分由树推导（QX-08 禁手填）；树浅/先后不可判→weak；跨书→low。
- 反例: 跨书"师叔"直接标 ok——跨书辈分 low（需系列身份+年代证据）。
- 来源: `SKILL_05c` §3.3；`logs/relations/_summary.md`（辈分 26 weak）；`references/05a1` RP13。
- 状态: 已验证

## B 区 · 五类人物关系与验证

### QY05 · 五类人物关系验证属性：方向/对称/互斥/时序
- 类别: 五类人物关系与验证
- 现象: 师徒+结义兄弟并存未记冲突；婚约/仇怨互斥误判。
- 判据: 05c §四（D06 §四/§八）：五类人物关系（师承/结义/敌对/婚约/亲属等）逐类验证方向/对称/互斥/时序；
  婚约 vs 仇怨可并存；师承 vs 叛门需时序；对称缺失补反向或标 symmetric:pending。
- 动作: 建树前逐类核验证属性；冲突双记+人工裁定；时序缺失记 `time_anchor:null` 降 weak。
- 反例: "师徒+结义兄弟"并存当错误删一条——人物关系可多类并存（互斥表只列真互斥项）。
- 来源: `SKILL_05c` §四；`SKILL_关系体系` §4.8；`references/05b1` RL07。
- 状态: 已验证

### QY06 · 验证失败处置：补反向/双记裁定/降 weak/循环回溯
- 类别: 五类人物关系与验证
- 现象: 验证不过直接删边/静默改。
- 判据: 05c §4.1：对称缺失→补反向边或标 `symmetric:pending`；互斥冲突→双记+人工裁定；时序缺失→
  `time_anchor:null` 降 weak；循环师承→判数据错误，回溯 03b 归并或错标。
- 动作: 按四类处置记录；不删边；循环回溯。
- 反例: 循环师承直接删一条边——可能是归并错误，应回溯 03b/错标。
- 来源: `SKILL_05c` §4.1；`references/05b1` RL07。
- 状态: 已验证

### QY07 · 循环师承检测（QX-02）：无环断言 + 回溯
- 类别: 五类人物关系与验证
- 现象: A 师 B、B 师 A（或长链闭环）入库。
- 判据: 05c §七 QX-02：师承循环=数据错误（无环检测）；回溯错误边/03b 归并错误；双树建树前无环断言。
- 动作: 建树前跑无环检测；命中→回溯并记录；修复后重建。
- 反例: 环由同名异人造成（两个"张三丰"）——先 03j1 消歧再建树，不是简单删边。
- 来源: `SKILL_05c` §七；`SKILL_关系体系` §5.3；`references/03j1` HM01。
- 状态: 已验证

### QY08 · 多师/叛门时序：师承链存在，状态变叛/逐出
- 类别: 五类人物关系与验证
- 现象: 叛门后删师承边（QX-07）；多师无时段限定。
- 判据: 05c §七 QX-07/QX-09：叛门后**保留师承边**+状态（状态事件不改链存在，但需时序）；多师须按时段限定，
  无时序→降 weak；正式拜师优先、义父/养父次之（交叉裁决）。
- 动作: 师承边保留；叛门/逐出记状态+时间锚；多师按时段分段。
- 反例: "叛出师门"后删边——历史师承仍在；只改状态。
- 来源: `SKILL_05c` §七；`SKILL_关系体系` §5.4/§4.2；`references/05a1` RP13。
- 状态: 已验证

## C 区 · 情义离线表

### QY09 · 情义层为什么离线：不进内联标注、不进 lint、不设行内符号
- 类别: 情义离线表
- 现象: 给"恩/仇/爱/恨"造行内动词或实体符号；情义进 tagged 标注。
- 判据: 05c §5.1（doc 02 决策 + 01g §9.2 铁律）：救/叛/赠/辱/爱/恨只进**离线表**；不进内联标注、不进 lint、
  不设行内触发词；`报 X 之仇`类只作离线抽取候选素材。
- 动作: 情义候选走离线表；内联标注零符号（QX-04 检测）；lint 不扫情义。
- 反例: 给"恩断义绝"标 ⟦⊡⟧——QX-04 违规；离线表记 type=叛/恨。
- 来源: `SKILL_05c` §5.1；`SKILL_01g` §9.2；`references/04f2` VB11。
- 状态: 已回写

### QY10 · 情义离线表 schema：八类 type + status + event_ref + 置信
- 类别: 情义离线表
- 现象: 情义记录无受控类型/无状态/无事件关联，无法聚合。
- 判据: 05c §5.2 schema：`{"edge_id","book","chapter","type":"救|叛|赠|辱|爱|恨|恩|义","subject","object",
  "direction","status":"active|ended|uncertain","evidence":{loc,snippet_short,event_ref},"confidence",
  "note"}`；八类受控；status=恩义是否已报/情缘是否结束；event_ref 可选关联 04a 事件 id。
- 动作: 离线表按 schema 输出；type/status 枚举校验；event_ref 后补。
- 反例: type 自由填"感激"——八类受控（救/叛/赠/辱/爱/恨/恩/义），映射到"恩"。
- 来源: `SKILL_05c` §5.2；`SKILL_关系体系` §6.2/§6.3。
- 状态: 已验证

### QY11 · 人工 TSV 裁定流程：候选→TSV→人工裁定→离线表落库
- 类别: 情义离线表
- 现象: 情义候选直接落库无人工裁定；裁定无台账。
- 判据: 05c §5.3：① 候选生成（04f 动词救/叛/赠/辱 + 实体对 → 候选 TSV）；② 人工裁定（考订 TSV 稳定键）；
  ③ 落离线表（带 evidence/reviewer/date）；裁定不可自动（情感/恩义自动推导度低，01g §9.2）。
- 动作: 候选 TSV 留档；人工裁定后落表；台账可回溯。
- 反例: 用正则直接生成情义表——推导度低，必须人工裁定（01g §9.2）。
- 来源: `SKILL_05c` §5.3；`SKILL_01g` §9.2；`references/04f2` VB11。
- 状态: 已验证

### QY12 · 情义与 SPO 边界：赠可双记不重复计、叛不改师承、爱/恨不推导对等
- 类别: 情义离线表
- 现象: 赠类同时记 SPO 与情义被重复计数；爱/恨强行双向。
- 判据: 05c §5.4："赠"类可同时有 SPO 边（赠予）与情义层（恩），**不重复计**；"叛"必须有时序（拜师后），
  不与师承边互斥（师承仍在，状态变叛）；"爱/恨"不推导对等（单恋/单恨合法）。
- 动作: 双记但统计分离；叛记状态+时序；爱恨保留单向。
- 反例: "赠剑"既计转移边又计恩义当两条关系——统计分开、不重复。
- 来源: `SKILL_05c` §5.4；`SKILL_关系体系` §6.4；`references/05a1` RP06。
- 状态: 已回写

### QY13 · 情义置信与发布：strong 明写/ok 情节推断/weak 读者推断不发布
- 类别: 情义离线表
- 现象: weak 情义（读者推断）进入发布数据；或明写恩义只给 ok。
- 判据: 05c §5.2：confidence=strong（明写）/ok（情节推断）/weak（读者推断，**不发布**）；QX-10 检测 weak
  情义发布；发布侧只消费 strong/ok。
- 动作: 置信分档；weak 留候选；发布侧过滤。
- 反例: "疑似爱慕"（读者推断）当 ok 发布——weak 不发布。
- 来源: `SKILL_05c` §5.2/§七 QX-10；`SKILL_关系体系` §6.4。
- 状态: 已验证

### QY14 · QX-01~10 错误模式：混树/循环/派生当人工/情义内联/无证据/单恋当双向/叛后删边/辈分手填/多师无时序/weak 发布

  QX-04 情义进内联→撤销（禁止）；QX-05 情义无证据/裁定→补或删；QX-06 单恋当双向→改单向；QX-07 叛门后删师承边

### QY15 · N4/N5/07c 接口：时间锚/师承边/一致性消费
