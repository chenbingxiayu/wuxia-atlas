# SKILL 09i 武侠版：学术工具 — 让研究可引用、可复现、可核验

> **上游声明**：本件属本批 C1 应用组新划定 09i，对应 docs/03 §3.10 原 09k 文献写作（✅ 照搬：形式学与工具链通用）与检索类应用（09d 语义搜索）。**无专属设计稿**：由 01g §9.10、W7 引文核验、07e A-E、03l 统计口径、08d 正确性、09h 数据开放、D07 证据四级综合而成（v0.1 框架）。
> **接口**：`registry/intertext/intertext_loc.json`（loc_r 锚点）、`registry/sku/cards.json`（sources/supported_by）、N5 `registry/relations`（evidence/loc）、EX-5 `registry/events`（loc_r）、EX-7 `gazetteer`、EX-8 `audit`、`logs/w_group/quote_verify.json`（W7）、03l/08b 统计口径。
> **核心原则**：**没有定位符的引用不是引用；没有版本的结论不可复现。** 学术工具的价值在于让每条结论都能被第三方按同一数据/规则版本重跑。

## 一、定位与边界

### 1.1 工序位置

```text
知识库（锚点/证据/版本）→ 09i 学术工具（检索/引用/导出/核验）
        ↓
研究者产出（论文/报告/数据集）→ 引用规范 + 诚信检查 + 可复现声明
```

### 1.2 本文做什么

1. **引用规范**：定位符（loc_r/PN/ID）、数据版本/规则版本、引用格式模板；
2. **检索工作台**：实体/关系/事件/主题/跨书检索与结果导出；
3. **研究导出**：CSV/JSON 数据集 + 口径声明；
4. **学术诚信**：引文核验（W7）、未核实不表述（07e）、不得伪造；
5. **可复现声明**：数据版本/规则版本/查询命令/环境。

### 1.3 本文不做什么

| 不做 | 归属 |
|---|---|
| 改知识库 | 只读 |
| 原文提供 | 禁（01g §9.10） |
| 论文写作代笔 | 超范围 |
| 版权/许可决策 | 权利审核 |

### 1.4 关键约束

- **可定位**：任何引用必须带 loc（人类定位符）+ loc_r（机锚）之一；
- **可版本**：结论附 data_version + rule_version；
- **可核验**：引文/片段过 W7；未核实标"存疑/推算"（07e）；
- **不伪造**：不得虚构引文/定位/数据（W7 只给定位/长度/hash，不给原文）；
- **原文不出**：论文引用原文片段的责任在作者/权利审核；本库工具只给定位与核验结果。

## 三、引用规范（v0.1）

### 3.1 定位符体系

| 类型 | 格式 | 来源 | 用途 |
|---|---|---|---|
| 机锚 | `{作品ID}#pn-r{N}.{X}` | 02ab/N11 | 段落级引用（最推荐） |
| 人类定位 | `书·回:段`（回:段） | D07 §7.4 | 与机锚并列（人类可读） |
| 实体 ID | `E%04d` / SKU `card.*` | registry/SKU | 实体级引用 |
| 边 ID | relations edge id | N5 | 关系级引用 |
| 事件 ID | event id/loc_r | EX-5 | 事件级引用 |
| 数据集版本 | `data_version`/`rule_version` | meta | 复现 |

### 3.2 引用格式模板

```text
[1] 梁羽生《江湖三女侠》第12回（机锚 jianghu#pn-r12.3；数据版本 2026-11-05.01；
    规则版本 rel-verbs@v1）——关系边「吕四娘→师承→独臂神尼」（confidence ok）。
[2] 知识库 SKU 卡 card.person.xxx（registry/sku/cards.json，data_version 2026-11-05.01）。
```

- 引文/原文片段：**本库不提供**；作者若引原文，需自行取得授权并过 W7 核验（工具只回传"命中/未命中/定位"，不回传原文）。

### 3.3 引用纪律

- 不得只给"某书某人"而无 loc；
- 不得引用未核实（D/E 级）内容作确定结论；
- 不得跨版本混引（数据/规则版本不一致需说明）；
- 同一结论多源→按 D07 权威层级列主次。

## 四、检索工作台

### 4.1 检索维度

| 维度 | 入口数据 | 输出 |
|---|---|---|
| 实体 | SKU/concordance/registry | 卡字段/别名/出处 |
| 关系 | N5 relations | 边（谓词/方向/证据/loc） |
| 事件 | EX-5 events | 类型/参与方/outcome/时间 |
| 主题 | 关键词→实体/事件/设定 | 主题包（跨数据源） |
| 跨书 | D07 intertext/series | 跨书引用/谱系/传播 |
| 一致性 | EX-8 consistency | 穿帮/异常记录（A-E） |

### 4.2 检索输出 schema（v0.1 约定）

```json
{"query":"吕四娘 师承","hits":[{"kind":"relation_edge","id":"…","loc":"jianghu#pn-r12.3",
 "loc_r":"jianghu#pn-r12.3","predicate":"师承","confidence":"ok","data_version":"2026-11-05.01"}],
 "meta":{"rule_version":"rel-verbs@v1","took_ms":12}}
```

### 4.3 主题包

- 输入主题词（如"天山派传承"）→ 输出：实体集+关系子图+事件链+跨书引用+数据版本；
- 允许导出研究数据集（CSV/JSON）+ 口径声明（统计类）。

## 十、FAQ（首批 5 问）

**Q1 怎么引用一条关系？**
给边 ID + loc/loc_r + confidence + data_version/rule_version（§3.2 模板）；只给"某书某人"不合格。

**Q2 能直接引用原文句子吗？**
本库不提供原文；作者自行取得授权，且可用 W7 核验其引文（工具只回传命中/定位/长度/hash，不回传原文）。

**Q3 跨书年代能作为论文结论吗？**
只能作"参考/区间"（07a low），并注明方法；不得表述为确定事实。

**Q4 统计数字怎么引用？**
附口径（L1/L2/L3、分母、范围、版本）；否则不可引用（03l）。

**Q5 数据开放与学术工具什么关系？**
09h 定开放边界与 API；09i 是研究消费方（检索/引用/导出），两者共享脱敏与版本纪律。

## 结语

学术工具的意义不在"给研究者一个搜索框"，而在**让每条结论都有定位、有版本、有核验、可复现**。数据可以开放，原文必须守住；引用可以丰富，伪造不能容忍。
