# SKILL 04d 武侠版：年代审查

> **上游声明**：本文是 D05 时间体系（`SKILL_时间体系_武侠版.md`，v0.3-draft）的**审查执行件**，不重定义时间方法论。时点键双层结构（§二）、四类锚点与置信排序（§三）、单调性/分叉/隔离（§四）、定年方法 M1-M7（§五）、43 条错误模式三分裁决与 W1-W6（§六）、`%` 三管道（§七）、confidence 三档与未知原则（§八）全部由 D05 定版；本文只负责"把 N4 的解析结果逐条复核、裁决、累积成可消费的年代证据"。
> **移植依据**：`docs/05-管线技能与脚本逐项改造分析.md`（04d 年代审查：**三步循环 + 知识累积管线照搬**，ground truth 换书内一致性校验，confidence 三档重定义）；`docs/17` §2.5（S-04d ←D05）；`docs/56-loader回级与N4N5实现记录-2026-11-05.md` §四（N4 首版接口与 5 书实跑）。
> **核心原则**：**N4 是解析器，本文是裁决者**。解析器负责"尽量解析"，审查者负责"哪些可信、哪些冲突、哪些必须留未知"；**不得为凑单调/凑编年而硬造时间**。

## 一、技能定位与边界

### 1.1 工序位置

```text
SKILL_04a 事件识别 ──故事时间槽位（字段 14）──┐
SKILL_时间体系（D05）──规则源（§二-§八）──────┤
                                              ↓
N4 time_resolver_wuxia ──registry/time/<书>.json（tp 全量 + errors + forks）──┐
                                              ↓                              │
S-04d 年代审查（本文）──逐条复核 + 裁决 + 冲突登记 + 审查记录 ←──────────────┘
                                              ↓
下游：事件编年 / 人物生平线 / 跨书宇宙编年 / 穿帮雷达（年龄矛盾、死亡一致性）/ E5 事件页
```

- **前置**：tagged 语料（`%` 令牌已标）、PN 段锚（02ab）、N4 可运行（`--selftest` 30/30 PASS）。
- **后继**：事件层编年、N8 穿帮雷达、W 组时间轴页面、跨书系列谱系考订。
- **现行事实（2026-11-05）**：N4 v0.1 已 5 书实跑——3,413 时间令牌、解析率 90.4%、时点定位率 74.0%、E1/E2=0/0、闪回/分叉候选 171、未解析 187；产物 `registry/time/`（5 书）+ `logs/time/`。

### 1.2 本文做什么（六件事）

1. **复核**：按四类锚点、单调性、分叉、定年方法逐条核对 N4 结果；
2. **裁决**：锚点冲突/倒流/换算冲突按 D05 §三.3、§四.1、§二.5 规则 5 裁决；
3. **补登**：未解析项给出原因分类（原文未给/多解/分叉内/跨书矛盾）与可补证据；
4. **累积**：把裁决结果沉淀为"知识累积"（锚点表、换算登记表、师承代数链），供后续回目与跨书复用；
5. **登记冲突**：跨书年龄冲突、两书同事件年代分歧，按 D05 §4.6 接口只登记不裁决；
6. **出审查记录**：每条审查有结论、依据、置信度、回链 tp_id。

### 1.3 本文不做什么（边界，越界即错）

- **不改语料**：审查只读 tagged，不改 `%` 令牌；需要改标注的走 `apply_annotation_patches.py` 补丁流程（另案）；
- **不重算 N4 的解析算法**：审查结论与 N4 产物冲突时，登记"审查覆盖"条目，不直接手改 JSON；
- **不建公历编年表**：换算只作显示辅助与跨书排序，不覆盖书内相对排序（D05 §2.5 规则 2）；
- **不裁决设定内扭曲**：闭关/驻颜/假死/传功续命按 W1-W4 照记＋设定依据，解释归设定层。

## 二、快速开始（五步操作序）

> 目标：拿到一本书的 N4 产物，跑完"复核→裁决→登记→记录"闭环。命令全部只读或只出报告。

```powershell
cd C:\Users\YANG Ruosong\Documents\workspace\Wuxiaxiaoshuo\wuxia-kb
$env:PYTHONIOENCODING='utf-8'

# Step 1 解析器自检（先确认工具可用，再看数据）
python -X utf8 scripts\time_resolver_wuxia.py --selftest

# Step 2 单书/全书解析（只读 tagged；--strict 时 E1>0 或 fatal>0 exit 2）
python -X utf8 scripts\time_resolver_wuxia.py --book 白发魔女传
python -X utf8 scripts\time_resolver_wuxia.py --all

# Step 3 读产物：stats / errors / forks / monotonicity / error_mode_coverage
#   registry/time/白发魔女传.json；报告 logs/time/白发魔女传.md
python -X utf8 -c "import json;d=json.load(open('registry/time/白发魔女传.json',encoding='utf-8'));print(d['stats']);print(len(d['errors']),'errors')"

# Step 4 按 §四-§八 逐项审查，填 §附录 A 审查记录（logs/qa/time_review_<书>.md）

# Step 5 复验：审查结论回填后重跑 N4（解析器不读审查记录时，用审查记录做人工对照）
python -X utf8 scripts\time_resolver_wuxia.py --book 白发魔女传 --strict
```

**判读口径**：Step 3 的 `stats.by_confidence` 中 high 应占多数；`errors` 按 code 分级（E1/E2 为单调性，T 系列为错误模式）；`forks` 是闪回/追叙候选，**必须逐条确认**（未登记分叉=潜在 E1 误报）。

## 三、审查输入与产物

### 3.1 输入：`registry/time/<书>.json`（schema `wuxia-time-resolve-v1`）

| 顶层字段 | 审查用途 |
|---|---|
| `book/work_id/generated_at/tool/spec` | 版本与规则源核对（spec.sections 应含 §二-§八） |
| `inputs` | 输入语料范围（回号清单）与 tagged 目录 |
| `book_anchors` | 书级锚点（朝代/时代段） |
| `time_points[]` | 全量时点条目（逐条审查对象，字段见 §3.2） |
| `forks[]` | 分叉条目（叉型/基点/偏移/回插点） |
| `discipleship_estimates[]` | 师承代数定年估计（M6） |
| `monotonicity` | 单调性检查结果（E1/E2/E3/E4 计数） |
| `errors[]` | 错误清单（code/level/chapter/message/tp_ids/cite） |
| `error_index` / `error_mode_coverage` | 错误码索引与 43+W 模式覆盖 |
| `stats` | 计数（tokens/by_type/by_pipe/by_granularity/by_anchor_type/by_confidence） |

### 3.2 单条 tp 的审查字段（`time_points[]` 条目）

`tp_id / anchor（段锚+行号+span）/ time_raw / display / pipe / time_type / granularity / anchor_type / anchor_ref / offset / t_days / year_ce / year_range / age / duration_days / precision / confidence / calendar / narrative_line / narrative_mode / fork_id / simultaneous_to / status / precision_basis / unknown_reason / flags / context`。

审查时**重点看**：`anchor_type` 是否选对、`anchor_ref` 是否悬空、`offset` 单位与正负、`t_days/year_ce` 是否与依据一致、`precision` 是否缺省、`status`（resolved/unresolved）与 `unknown_reason` 是否自洽。

### 3.3 产物

1. **审查记录**：`logs/qa/time_review_<书>.md`（模板见附录 A），逐条给结论（通过/改判/留未知/冲突登记）；
2. **审查覆盖条目**：与 N4 冲突但不改 JSON 的，记录 `{tp_id, N4 值, 审查值, 依据, conf}`，供下一版 N4 或人工消费层使用；
3. **冲突登记**：跨书年龄冲突/同事件年代分歧，按 D05 §4.6 结构登记（只登记不裁决）；
4. **知识累积**：锚点表、换算登记表、师承代数链，累积到书级考订附件（供跨书编年）。

## 四、四类锚点审查

### 4.1 锚点定版表（引 D05 §3.1，审查用）

| 锚点 | 识别信号 | 置信档 | 失效条件（审查重点） |
|---|---|---|---|
| 朝代锚 | 真实朝代/年号/日期 | high | 作者错置（与史历冲突）→ 照记＋登记冲突，入设定期 |
| 事件锚·强 | 明确偏移（三日后/翌日）或死亡/历史大事件 | medium→可升 high | 回指对象未排轨（悬空回指）→ 先排轨被指事件 |
| 事件锚·弱 | 模糊回指（"大战之后"） | medium | 只给先后不给量 |
| 人物年龄锚 | "时年二十""年过六旬" | medium（本人当下强，跨场景降） | 驻颜/返老还童/年龄外传（W2）→ 转设定登记 |
| 时令锚 | 元宵/中秋/凉秋九月/开春 | low～medium（年内区间） | 修辞化用（写景套语）→ 词表屏蔽 |

**置信总排序**：朝代锚 ＞ 事件锚·强 ＞ 人物年龄锚 ＞ 事件锚·弱 ＞ 时令锚（D05 §3.2）。

### 4.2 审查动作（逐条）

1. **锚点类型复核**：N4 判的 `anchor_type` 是否与识别信号一致；时令锚是否被误升为事件锚；年龄锚是否被当作绝对时间。
2. **锚点引用复核**：`anchor_ref` 必须指向真实 tp_id/event_id/朝代锚；悬空引用 → 退回"未解析"并记原因。
3. **锚点归属复核**：偏移的锚点归属是否正确（D05 例："常洵出京后只一年"锚是出京事件，不是开篇直录时点——锚点选错差一年）。
4. **冲突裁决**：同段两锚矛盾 → 按总排序取高者为主锚，低者照记不删＋冲突登记；年龄锚与事件锚矛盾 → 先查分叉未登记，再双值并存；朝代锚与相对链矛盾 → 朝代锚为主＋登记换算冲突（D05 §2.5 规则 5）。

## 五、单调性、分叉与隔离审查

### 5.1 报告级别（D05 §4.1）

| 级别 | 定义 | 审查动作 |
|---|---|---|
| E1（error） | 同线、两时点均无分叉标记、精度均非未知、t 硬倒流 | 必须处置：查是否漏登分叉/锚点归属错/叙述模式误判 |
| E2（warning） | 一方精度=约略的疑似倒流 | 核对约略精度是否合理，必要时降精度而非改序 |
| E3（warning） | "与此同时"类信号未登记线间同时 | 补 `simultaneous_to` 登记 |
| E4（info） | 分叉内倒流（合法） | 仅确认 fork 条目存在 |

### 5.2 分叉审查（fork 条目）

- 叉型七值：追叙/倒叙/闪回 ＋ 回忆/梦境/假想/戏中戏（D05 §4.2）；**04a 五状态不扩**，闪回走叉型字段。
- 隔离规则：回忆/梦境/假想/戏中戏内时点**不进主轨、不参与单调性、不得作排轨锚**；追叙/倒叙/闪回内时点参与发生时间重建但不改叙述推进刻度。
- 审查动作：①每个 fork 的基点/偏移/发生时点/回插点四要素齐全；②未登记倒叙是否被 E1/E2 捕获；③嵌套分叉只记一层（深嵌套按嵌套链累加偏移，阈值待试点校准）；④回指型事件的时间是否指向首叙时点（不新建 tp）。

### 5.3 叙述顺序 ≠ 发生顺序（审查判据，D05 §4.4）

| 判据 | 审查动作 |
|---|---|
| 前向偏移词（三日后/翌日） | 发生时点=叙述位置＋偏移，核对正负与单位 |
| 追叙信号词（当年/早在/想当年/N 年前） | 必须有 fork 条目；方向不得反解（"十六年前"不是"故事开始于十六年后"） |
| 叙述模式≠正常叙事 | 隔离于主轨；回忆里的年龄锚仍作年龄证据 |
| 多线并行（且说/却说） | 各线独立单调；线间同时用 simultaneous_to |

## 六、定年方法与师承代数审查

### 6.1 M1-M7 复核（D05 §5.1）

| 方法 | 置信 | 审查重点 |
|---|---|---|
| M1 直录法 | high | 书内明确陈述是否被降标；明确纪年不得被推算覆盖（错误 7/模式 7） |
| M2 锚点＋偏移顺推 | medium | 链断裂即停，不得跨链补；偏移累计核查 |
| M3 年龄锚定年 | medium | 出生点本身多为 low，合并后取低档 |
| M4 朝代区间约束 | low～medium | 不得越过考订表 era 段（模式 30） |
| M5 接力锚 | 依 conf | strong/ok 可入编年；回指＋编年互证=ok；仅师承/组织延续=todo |
| M6 师承代数定年 | low（封顶） | 见 §6.2；多源交叉不自然升档，升档须走 §6.3 收敛条件 |
| M7 跳变登记 | — | 闭关跳变保单调不填事件 |

### 6.2 师承代数复核（D05 §5.2/§5.3）

- 一条传承边=一对师徒（拜师即立边）；代当量：早中年授艺=1 代（25-30 年）、晚年授艺=2 代（50-60 年）；
- 推算区间=[25E−10, 30E+10] 年，半宽≈2.5E+10；E=4 时约 ±20 年 → **一律 low，只作排序佐证**；
- 只数边不数人头（同辈结义/夫妻不算边）；起算锚优先级：朝代锚人物 ＞ 书内明确纪年人物 ＞ 考订表 era 段代表人物；
- 审查动作：①边是否真实（拜师/传功有文本依据，不得虚构中间师承）；②当量判定是否有授艺年龄描述支撑；③多链交叉交集宽度 ≤15 年才可升 medium，交集为空 → 登记跨书冲突。

### 6.3 校准演示复核（D05 §5.4）

白发 001 回"明万历四十三年"=1615 → 岳鸣珂（晦明禅师）晚年收凌未风 → 七剑起于康熙十三年=1674，跨度 59 年 ÷ 当量 2 = 29.5 ∈ [25,30] ✓ 自洽。审查要点：**当量判定必须有"晚年授艺"证据**；若误按 1 代推算会与康熙十三年矛盾（这正是"世代数≠年数"错误 8 的教材）。

## 七、错误模式与设定扭曲审查

### 7.1 43 条错误模式（D05 §6.1 三分裁决）

D05 对史记 04c 的 43 条（错误 1-8 + 模式 1-35）逐条裁决：**直迁 10 / 改写 33 / 报废 0**。审查时按"直迁"与"改写"两栏分别执行：

- **直迁类**（如错误 7 确定性标注不足、模式 7 原文精确纪年被覆盖、模式 18 锚点引用错误、模式 21 明确沉寂期、模式 23 登记行位置、模式 26 裸年份精度、模式 28/33/34 去重、模式 35 指令残留）：按原文规则硬查，命中即改判；
- **改写类**（如错误 1 单锚点塌缩、错误 5 追叙误用、错误 8 世代数≠年数、模式 27 时序倒置）：按武侠判据查（见 D05 §6.2 四例）。
- **单锚点塌缩报警**：同回 ≥3 事件共享同一**推算**刻度即报警（K 初值 3，待试点校准）；正确做法是只有朝代锚定年、其余保序＋精度约略、无序留未知。

### 7.2 W1-W6 设定内扭曲（D05 §6.3）

| 码 | 模式 | 审查动作 |
|---|---|---|
| W1 | 闭关/学艺跳变 | 跳变登记 t+=ΔN＋依据；期间不补事件；精度=原文陈述精度 |
| W2 | 内力驻颜/返老还童 | 年龄照记；外貌描述不作年龄证据；脱钩登记设定依据 |
| W3 | 假死 | 假死期间生平线连续；死亡事件降"存疑"至复现；复活补"假死揭示"事件 |
| W4 | 传功续命 | 长寿不设常人上限；豁免穿帮雷达须设定依据非空 |
| W5 | 周期性时长 | 周期登记＋频次字段；总量须有陈述支撑，无次数留未知 |
| W6 | 谚语/虚指时间 | 不入时间轨；数量走 `$` 层 |

> **反向保护**：无设定依据的超常现象（凭空活两百岁、无传功而还童）不豁免，照常入年龄矛盾审计。

### 7.3 N4 错误码处理（T 系列）

N4 的 `errors[]` 按 `code` 分级（如 T15 朝代锚×相对链冲突、T05 追叙/时序类、T11、T07 等；完整码义以脚本注释与 D05 §六为准）。审查动作：

1. 按 `level` 分流：error 必处置；warning 逐条判"改判/留未知/登记冲突"；
2. 按 `cite` 回查 D05 条款，确认裁决方向（如 T15 → §2.5 规则 5：朝代锚为主＋登记换算冲突）；
3. `tp_ids` 定位到具体时点，回读 `context` 原文；
4. 结论写入审查记录，不直接改 `registry/time/*.json`（下一版 N4 或消费层读取审查覆盖）。

## 八、换算、跨书与冲突登记

### 8.1 朝代锚换算登记（D05 §2.5）

- 书内出现真实朝代/年号/日期 → 照标并登记朝代锚；建立每书换算登记表 `{tp_id ↔ 公历值, 依据, 置信度}`；
- 换算只作显示辅助与跨书排序，**不覆盖书内相对排序、不改写时点键**；
- 只能沿"已锚定时点＋明确偏移"传播；超误差上限只保留区间（上限待试点校准）；
- 多朝代锚互证 → 换算置信升级并记双证；冲突 → 朝代锚为主＋登记"换算冲突"。

### 8.2 跨书年龄冲突登记（D05 §4.6）

冲突条目：`{人物, 书A tp/年龄值, 书B tp/年龄值, 推算路径A, 推算路径B, 差值, conf}`。**只登记不裁决**——改值须走考订流程；穿帮雷达对已登记冲突降级为"已知名目"不再重复报警。两书对同一事件年代说法不一致走同一接口。

### 8.3 无朝代锚书的纯相对纪律（D05 §2.6）

不猜朝代、不借同名历史人物挂年份、不造锚；时代区间只能来自系列谱系考订表 `era` 字段与跨书接力锚且降档；`era=todo` 的书在时代段未定前不参与跨书排序，页面显式标"年代待考"。

## 十二、成功标准（Success Criteria）

1. **覆盖率**：N4 未解析项 100% 给出原因分类；错误码 100% 分流处置。
2. **一致性**：E1=0；登记分叉后不再出现假倒流；换算冲突全部登记。
3. **可信度分布**：high 档占已解析项 ≥70%（5 书 N4 当前 high 422/medium 102 量级为参照，按书复核）；时令锚不得出现 high。
4. **可追溯**：每条审查结论可回链 tp_id + 原文 `context` + D05 条款。
5. **知识累积**：锚点表/换算表/师承链可被下一书或跨书编年复用，且带版本。
6. **零臆造**：无依据的年份/朝代/锚点补造 = 0；无设定依据的 W 类豁免 = 0。
