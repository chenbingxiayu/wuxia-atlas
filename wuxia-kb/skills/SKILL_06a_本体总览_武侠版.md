# SKILL 06a 武侠版：本体总览

> **上游声明**：本文是 D08 分类树五件套（`SKILL_分类树五件套_武侠版.md`，v0.3-draft）的**本体总览索引件**：五树 64 叶、四条全局裁决、正交属性与待拍板清单由 D08 定版；本文只做"一页式本体地图 + 查询路径 + 一致性核对"，不重定义树与叶。符号与 15 类顶层类型由 `SKILL_01g_标注符号集合原则.md`（D01）定版；树结构方法见 `SKILL_03h_实体子类_武侠版.md`，登记见 `SKILL_03i_分类登记_武侠版.md`，颗粒度见 `SKILL_06e_颗粒度审查_武侠版.md`。

## 一、技能定位与边界

### 1.1 三层本体结构

```text
第 1 层 标注层（01g）：15 类实体符号 〖@ ◎ = ◆ & ~ ; # ☆ • + { ^ % $〗
        ↓
第 2 层 分类层（D08 五树）：地点16 / 职衔12 / 身份18 / 势力11 / 武功7 ＝ 64 叶
        ↓
第 3 层 属性层（正交字段）：真实性 / 邪正 / 品类 / 存续 / 江湖活跃状态 / 性别 …
        ↓
登记层实例（每实体 = 1 个类型码 + 1 个叶值 + N 个属性 + 关系边/事件）
```

- **前置**：01g 15 类定版、D08 五树定稿、N9 可运行。
- **后继**：S-03i 登记、S-06e 颗粒度审查、页面/关系图/词表消费。
- **现行事实（2026-11-05）**：五树 64 叶与规范一致（N9 结构 PASS、文-码漂移 64/64 PASS）；**error 0 / warning 70（◆ 未挂叶）/ info 35**；本体未发生类型/属性漂移。

### 1.2 本文做什么（四件事）

1. **一页式地图**：五树 + 属性 + 铁律 + 多书约定的总览（§三）；
2. **查询路径**：给定一个词/实体，怎么判断它属哪类、哪棵树、哪个属性（§四）；
3. **一致性核对**：本体与 01g/D08/N9 的一致性检查口径（§六）；
4. **缺口索引**：本体层当前缺口（未挂叶 70、待拍板 9 项）与下游（§五）。

### 1.3 本文不做什么（边界，越界即错）

- **不重定义树/叶**：叶的定义与判定信号以 D08 为准；
- **不做登记**：逐实体挂叶/属性赋值是 S-03i；
- **不做颗粒度裁决**：≥10/树深/挂叶审查是 S-06e；
- **不新增类型/符号**：类型扩展走 S-03k 三问 + 01g 审批。


## 三、本体地图（一页式）

### 3.1 五树总览（合计 64 叶）

| 树 | 类型码 | 分支（叶数） | 叶数 | 树深 | 正交属性（不进树） | 下游 |
|---|---|---|---|---:|---|---|
| 地点树 | `=` | 自然地貌 3 / 人居建筑 8 / 组织驻地 3 / 秘境遗址 2 | 16 | 3 | 真实性四值、兼值 | gazetteer/行踪地图 |
| 职衔树 | `;` | 朝廷轨 7 / 江湖轨 5 | 12 | 3 | 任职机构、任职区间 | 人物页/关系图 |
| 身份树 | `#` | 武林身份 5 / 权位身份 4 / 江湖职业 4 / 处境身份 5 | 18 | 3 | 性别、江湖活跃状态、邪正 | 人物页/着色 |
| 势力树 | `◆` | 武学传承型 3 / 结社据点型 6 / 庙堂武力型 2 | 11 | 3 | 邪正、存续状态、出现书目 | 门派页/着色 |
| 武功谱系树 | `☆` | 心法层 2 / 武功层 1 / 招式层 3 / 阵法层 1 | 7 | 3 | 品类（剑/掌/内功/轻功…）、派生根基 | 武功页/谱系 |

> **结构单叶豁免**（D08 §7.2）：武功树"武功层/阵法层"单叶是层级四分的结构必然，不适用"同层 3–12"软标准。

### 3.2 四类正交属性（永不入树）

| 属性 | 适用树 | 取值 | 默认 |
|---|---|---|---|
| 真实性 | 地点 | 真实/虚构/真实原型改造/未定 | **未定** |
| 邪正 | 身份/势力 | 正/邪/中立/未定 | **未定** |
| 品类 | 武功 | 剑/掌/内功/轻功/身法/…（必填主品类） | 必填 |
| 存续状态 | 势力 | 存续/隐世/已灭/未定 | 未定 |
| 江湖活跃状态 | 人物（身份登记时） | 活跃/隐退/死亡/未定 | 未定 |
| 性别 | 人物（身份登记时） | 男/女/未定 | 未定 |

> **默认值文化**：宁未定，勿错定；"确认无所属"（散修）与"信息缺失"（未明门派）是两种缺省态，分开登记。

### 3.3 三条铁律（D08 §1.1）

1. **铁律一（登记层）**：树节点 = 登记表字段值，不是 〖〗 内的类型码；不新增任何行内标注符号。
2. **铁律二（颗粒度）**：子类预计实例 ≥10 才单列为叶；树深 ≤4；实例只挂叶。
3. **铁律三（可操作）**：每个子类给判定信号（触发词/共现/结构信号），不给名词解释。

### 3.4 多书共享宇宙约定

- 树值跨 34 书统一（"武当"在所有书中同挂"武学门派"叶）；
- 实例按书登记（`出现书目` 字段记录）；跨书差异（改名/灭派/传承）用属性分段或关系边表达；
- **不为单书特例增设树节点**；跨书 canonical 由 D07 双层规则定（系列层/书内层不混）。

## 九、成功标准（Success Criteria）

1. **三层清晰**：任何登记条目可唯一回答"类型/树/叶/属性"四问。
2. **结构稳定**：五树 64 叶、树深 ≤4、无兜底叶、无属性入树。
3. **挂叶完整**：登记范围内实体 100% 有叶值（或"未定"入查证清单）。
4. **多书一致**：树值跨书统一，跨书差异用属性/关系表达。
5. **可核对**：N9 可复跑；本体地图与 D08 规范无漂移。
