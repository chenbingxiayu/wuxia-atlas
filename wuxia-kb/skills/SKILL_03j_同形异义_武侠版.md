# SKILL 03j 武侠版：同形异义

> **上游声明**：本文是 D08 分类树五件套（`SKILL_分类树五件套_武侠版.md`）的**同形异义专项执行件**，处理"登记层与分类层的同名/同形"问题，不重定义人名消歧与跨书同一性方法论。人名消歧三层判定（L1 文内证据/L2 映射表/L3 跨书推理）由 `SKILL_03b_人名消歧_武侠版.md` 定版；跨书双层 canonical、权威四层、同名异人冲突类型学由 `SKILL_跨书治理_武侠版.md`（D07）定版；树结构由 `SKILL_03h_实体子类_武侠版.md` 与 `SKILL_06a_本体总览_武侠版.md` 定版。
> **移植依据**：`docs/05-管线技能与脚本逐项改造分析.md`（分类树五件套配套消歧）；`docs/17` §2.5（S-03j ←D08）；`docs/56-loader回级与N4N5实现记录-2026-11-05.md` §二（registry canonical↔alias 撞名 33 条）；`docs/57` §五（N6 同名异人 8 条 reject）。
> **核心原则**：**同形不是同一；证据不足不合并；拆有据、并留痕、限定符可逆**。同形异义的处置目标是"可检索、可区分、可回退"，而不是"消灭同名"。

## 三、四类同形类型学

| 类 | 定义 | 典型 | 处置方向 |
|---|---|---|---|
| **同名异人** | 不同书中同名人物，或同书内同名不同人 | 两书各有"张三丰"式同名；绰号撞名 | 拒绝归并；disambig 限定；各建实体 |
| **跨书同名地点/组织** | 同名地点/门派在不同书指向不同实体或同名分号 | "龙门镇"在两书不同位置；分号型组织 | 拆分 + 限定符（`龙门镇@白发魔女传`）；或归并 + 分号 |
| **跨类同形** | 同一字面跨实体类 | "龙门"=地名 vs "龙门帮"=组织；"剑"=器物 vs 剑法=武功 | 按类型码分建实体；跨类不合并（T16） |
| **通名-专名同形** | 通名/泛称与专名同形 | "江湖""武林"（泛称）vs 组织名；"山庄"通名 vs 专名 | 通名不登记（三问裁定）；专名照登 |

### 3.1 同名异人的判定信号（D07 §5.4）

- 两书 canonical 相同但**关键属性冲突**（时代/身份/亲属/武功体系不一致）→ 同名异人；
- 两书 canonical 相同且**文内互证**（跨书接力锚/系列谱系考订表 interchange_seeds）→ 同一人（归并）；
- 仅"同名"无任何互证 → 默认**不合并**（宁可分开，合并留痕可回退）；
- 归并拒绝原因必须分类：已归并 / 组织关联 / 同名异人 / 证据不足（N6 口径）。

### 3.2 跨书同名地点的判定（D10 §5.4）

- 同名地点先查 gazetteer `books` 书集与 `first_seen`：同书集内同名同地 → 归并；跨书同名且无互证 → 拆分 + 限定符；
- 限定符格式：`<规范名>@<书>`（如 `龙门镇@白发魔女传`）；限定符只进 id/disambig，**不改显示串**；
- 拆分后两实体各自保留 aliases，检索时按书过滤。

## 四、判定规则（证据优先 + 停止规则）

### 4.1 证据优先序（引 D07/03b，不重抄全表）

| 序 | 证据 | 用途 |
|---|---|---|
| 1 | L1 文内证据（同回/同段互证、相认段、亲属/师承句） | 最强，可直接判同/异 |
| 2 | L2 映射表/registry（《已核准映射表》、冻结映射、登记层 canonical/aliases） | 次强；映射冲突须人工裁 |
| 3 | L3 跨书推理（系列谱系考订表 interchange_seeds、接力锚、师承链） | 佐证；conf 封顶 |

### 4.2 停止规则（防过度消歧）

- 单凭"同名"不得合并（必须 ≥1 条 L1/L2 证据）；
- 单凭"同书同派/同阵营"不得合并（共现不是证据）；
- 证据冲突（两源一同一异）→ 不自动裁决，登记冲突交人工；
- 归并后 canonical 只保留一个，另一个降 aliases；**归并前必须确认所有引用可回链**（关系边/事件/卡引用）。

### 4.3 disambig 与限定符字段

| 字段 | 用法 | 例 |
|---|---|---|
| `disambig` | 同名限定词（书域/身份域） | `"甲书"` |
| 限定符 | 主键后缀（跨书同名拆分） | `龙门镇@白发魔女传` |
| `aliases` | 合并后旧 canonical 降为别名 | 旧名入 aliases(type=旧名) |

> 字段定义承 D09 统一 Schema（`disambig` 为共享扩展池字段）；**不得**用显示串改写做消歧（显示串必须原文连续区间）。

## 五、动作与冲突登记

### 5.1 四类动作

| 动作 | 触发 | 产出 | 留痕 |
|---|---|---|---|
| **拆分** | 同名异人/跨书同名且证据不足归并 | 两个实体（各带 disambig/限定符） | 拆分原因 + 依据 |
| **限定符** | 跨书同名需共存 | id 加 `@书` 后缀；显示串不变 | 限定符规则记录 |
| **别名归并** | 证据充分判同一 | 主实体 canonical + 别名；引用重指 | 合并前后映射 + 受影响引用清单 |
| **拒绝归并** | 同名异人/证据不足 | 保持分立；记 reject 原因 | reject 分类（同名异人/组织关联/证据不足） |

### 5.2 冲突登记（不可裁决）

条目结构：`{实体A, 实体B, 同形面, 证据A, 证据B, 冲突类型, 建议, conf}`；冲突类型对齐 D07：同名异人/跨书矛盾/时代错置/身份混淆。**只登记不裁决**；裁决走人工/考订流程。

### 5.3 与 N6 跨书归并的分工

- N6 `merge_crossover.py` 产出候选 140（E3 13/E4 127）、actionable 17、reject 123（已归并 113/组织关联 6/同名异人 8）；
- 本文消费 N6 的 reject 清单与 review_queue，负责"同名异人 8 条"的登记层落地（disambig/拆分）；
- N6 的 E3 双人复核/E4 候选池仍待人工（见 `registry/crossover/review_queue.md`）。

## 十、成功标准（Success Criteria）

1. **零误并**：同名异人误并 = 0；合并均有 ≥1 L1/L2 证据。
2. **零静默**：所有合并/拆分/拒绝有留痕；冲突登记率 100%。
3. **可检索**：同名实体可通过限定符/书过滤区分检索。
4. **可回退**：任一合并可依留痕回退，引用可重指。
5. **一致性**：registry 唯一性 PASS；N9 无新增 error；N6 reject 清单全部落地。
