# W8 精品页（武侠版）—— 五段式：把卡变成"可读的档案页"

> **本文是什么**：W8 是 Butler 最重的一类页：把 SKU 卡（结构化事实）+ registry/tagged 证据，写成**五段式精品页**——档案头、关系与阵营、核心事件与结局、证据与来源、未定与边界，并过 quality gate（W3 featured 标准）。
> **上游依赖**：`templates/忠义殉主者.md`（五段式模板）；`SKILL_08a_SKU字段_武侠版.md`（卡字段/w8_w9_interface/脱敏）；`skills/W3_质量四档_武侠版.md`（featured/断言分级）；`scripts/verify_quotes.py`（W7）。
> **一句话**：**精品页 = 事实（卡+registry+PN）+ 克制的分析 + 完整的来源链；不是文学创作。**
> **只读纪律**：上游只读；页产物落 `content/`；当前全部页 `demo:true`，不进入发布库（R4/K3）。

## 二、五段式页型（必有节，缺一不可）

### 2.1 页面骨架（引 templates/忠义殉主者.md）

| 节 | 内容 | 数据来源 |
|---|---|---|
| **一、档案头** | 规范名/展示名/别名/身份标签/首见/行经/结局 | SKU 卡 name/aliases/identity_tags/active_books/first_appearance/ending |
| **二、关系与阵营** | 师承/同门/结义/门派隶属/家族 | N5 relations + 05c 双树 + 卡 flags |
| **三、核心事件与结局** | 关键事件链/时点锚/结局 | EX-5 events + N4 time + 卡 life_events/ending |
| **四、证据与来源** | evidence 表（registry ID/PN/卡/统计） | 卡 evidence + 页面 evidence[] |
| **五、未定与边界** | 缺失字段/冲突双记/待考 | 卡 unfillable_fields + W3 缺项 |

### 2.2 模板的 8 个组成部分（模板层，非页面层）

1. 适用判断（什么对象用此页型）；2. 必有节；3. 加分项；4. 反面示例；5. 参考页面；6. Markdown 模板（复制即用）；7. 填充示例（demo，非发布）；8. 页型质量检查清单。

### 2.3 页面写作纪律

- **以事实收集为主、降低分析比重**（shiji W8 原典）：分析句 ≤150 字/段且必须有 ①② 证据支撑（W3）；
- **缺失写「未明示」/[]/null**，不虚构、不脑补；
- **「作者按语/旁白按语」节**：仅当原文有作者/旁白明文时写入（≤120 字），不脑补；
- **引文块**：text + cited_pn 独立字段，≤60 字/段，全部过 W7；
- **跨书互见**：同一实体跨书视角并置（D07 series 成员）。

## 三、SKU 卡槽位映射（五类卡 → 页面节）

### 3.1 通用槽位（五类共用）

| 槽位 | 卡字段 | 页面节 |
|---|---|---|
| title | name.canonical（+display） | 档案头 |
| summary | brief（200-500 字，R1/R2 脱敏） | 档案头摘要 |
| core_facts | 类型化数组（见 §3.2） | 档案头/三节 |
| sources | meta.sources + supported_by | 证据与来源 |
| confidence | meta.confidence + publish_state | 档案头状态/质量门 |

### 3.2 类型化槽位（w8_w9_interface / docs/61 §四）

| 卡类型 | 类型化槽位 | 页面节 |
|---|---|---|
| **person** | identity_tags/teachers/disciples/kinship/arts/age_anchor/life_events/ending/active_books/first_appearance | 档案头/关系/事件 |
| **faction** | faction_type/lineage/signature_arts/strongholds/timeline/status/branch_alliance/member_stat | 档案头/关系与阵营/沿革 |
| **art** | level（心法/武功/招式）/parent_art/sect/creator/transmission/practitioners/children | 档案头/谱系/修习者 |
| **artifact** | kind/grade/grade_basis/chain/holders/borrowers/makers/end_state | 档案头/流转链/结局 |
| **manual** | content_arts/藏处/争夺事件链/传人 | 档案头/内容与争夺 |

### 3.3 槽位填充纪律

- 填充率记录（docs/61 §四实测：faction 57%/art 47%/artifact 81%/manual 68%）；
- 空槽位→「未明示」占位，不写推测；
- 冲突字段（如两书结局不同）→ 双记 + 出处。

## 四、质量门（featured 标准）

### 4.1 W3 featured 判据（W8 对齐）

| 判据 | 要求 | 检查 |
|---|---|---|
| PN 引文 | ≥3 个引文块，每块 ≤60 字，**全部过 W7** | `verify_quotes.py` |
| 多角度评价 | ≥3 人（对手/盟友/作者按语） | 内容审核 |
| 作者按语节 | 仅当原文有明文 | 内容审核 |
| 跨书互见 | ≥1 处（series 成员视角并置） | D07/series |
| 相关页互联 | 事件/门派/武功/名物互链 | 链接检查 |
| 断言有源 | 每条断言 ①② 级源（W3） | W3 质量门 |
| 版权 L0 | ≤60 字/段、R1/R2、不输出原文 | copyright gate/规则 |

### 4.2 发布状态机

```text
demo:true（生成器产出，永不发布）
  → 人工审核（内容/引文/证据）
  → publish_state=in-review（候选）
  → W3/W4 质量门 + W7 → approved（可发布）
  → 发布库（W 组/EX 消费；当前 demo 页不进）
```

## 五、生成器接口（scripts/generate_w8_pages.py）

### 5.1 生成契约（frontmatter）

```yaml
page_type: 人物档案页            # 页型
page_schema: w8-five-section-v0.1
template_ref: templates/忠义殉主者.md
template_page_type: 忠义殉主者
template_sha256_12: bab8c364689e   # 模板版本锁
card_ref: card.person.e0001
entity_ref: E0001
canonical: 卓仲廉
display: 卓仲廉
slug: 卓仲廉                    # URL 保持 canonical（display 切换在 Astro 层）
confidence: C
publish_state: draft
demo: true
demo_note: demo 数据，不进入发布库（R4/K3）
data_version / rule_version / generated_by / generated_at
sections: [一、档案, 二、关系与阵营, 三、核心事件与结局, 四、证据与来源, 五、未定与边界]
evidence: [{kind, ref}]          # source/entity/pn/edge/event
quotes: []                       # 待填 text+cited_pn → W7
used_cards: [card.person.e0001]
```

### 5.2 生成器行为（docs/61 §四实测）

- 输入：`registry/sku/cards.json` + registry/relations/events/time + 模板；
- 输出：`content/<card_type>/card.<id>.md` + `_index.json`；
- 五类卡扩展：faction 60/art 852/artifact 226/manual 21 = 1,159 页（+person 367 = 1,526）；
- 幂等：`--apply` 备份 + sha256 + 回读 + 重跑幂等；`--selftest` PASS；
- 当前所有卡类型共用 `templates/忠义殉主者.md` 单模板（分型模板待 W9 沉淀）。

### 5.3 只读上游

生成器只读 SKU/registry/tagged，不写 registry；页面产物落 content/（demo）。

## 十一、FAQ（首批 6 问）

**Q1 精品页和普通页的区别？**
精品页=五段式+featured 质量门（≥3 PN 引文/多角度/跨书互见/相关页互联）；普通页（stub/basic）只需最小可用+3 事实。

**Q2 现在 1,526 页都是精品页吗？**
不是。它们都是**五段式页型骨架（demo）**，quotes 待填、publish_state=draft/in-review；当前无 featured 页。

**Q3 为什么全部页引用同一个模板？**
v0.1 单模板兜底（忠义殉主者）；五类卡已有槽位差异，但分型模板待 W9 沉淀（附录 B）。

**Q4 引文怎么填、怎么核？**
`quotes: [{text, cited_pn}]` 独立字段；`verify_quotes.py --file <page>` 核验；miss 拒绝。

**Q5 demo 页会发布吗？**
不会。demo:true 永不发布；审核后 publish_state=approved 才可进发布库（当前无）。

**Q6 W8 与 09d 故事创作的区别？**
W8=事实页（卡+registry+PN，克制分析）；09d=原创派生故事（明确标注、不得冒充原著）。两者共用 W7/07e 门控。
