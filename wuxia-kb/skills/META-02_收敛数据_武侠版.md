# META-02 收敛数据（武侠版）

---

## 快速开始

1. **取数**：从 `registry/acceptance/<书>_<章范围>.json` 取 accepted/hard/judgment/E/V/chars；从 `logs/qa/` 取管道与五门数据；从批次日志取成本。
2. **核口径**：按 §一 定义确认分子分母（E/V 是令牌计数还是去重实体数？chars 含不含标点？judgment 是否含已裁条目？）。
3. **对账**：新数据必须与"上一次落盘值 + 本轮 delta"能对上（§三 轨迹法），不允许直接覆盖旧值。
4. **写表**：总表一行一书；收敛轨迹按轮次追加；成本分"首次/返工/合计"。
5. **引用**：对外引用必须带数据源路径与统计时点（`docs/` 或 `registry/acceptance/`）。

> 成功标准：任一新书批次能在 1 小时内产出与 5 书同口径的总表行；引用数据 100% 可溯源到 JSON 字段。

## 一、口径定义（引用数据前必读）

| 指标 | 定义 | 分母/边界 | 数据源 |
|---|---|---|---|
| `accepted` | 通过验收门的章回数 | 批次内回数 | `registry/acceptance/*.json` 的 `summary.accepted/total` |
| `hard` | 阻塞级错误数（accepted 不成立） | 全批 | 同上 `summary.hard` |
| `warn` | 风格/统计告警数 | 全批 | 同上 `summary.warn` |
| `judgment` | 需人工裁决但**不阻塞** accepted 的条目数（plan_negation/quantity/time/domain/fence/wordlist/称谓等分类之和） | 全批 | 同上 `summary.judgment`；分类明细在 `judgments` |
| `unsourced` | 管道无来源条目数（`pipe_unsourced`） | 全批 | qa 报告 + accept summary |
| `E` | 实体令牌数（`〖@…〗〖#…〗〖$…〗〖%…〗` 等实指类） | 令牌计数，非去重实体 | accept 统计 |
| `V` | 动词令牌数（`⟦■…⟧` 等） | 令牌计数 | accept 统计 |
| `chars` | 正文字符数（底本正文，含标点；不含结构层围栏标记） | 全书/批内 | accept 统计 |
| `E/百字` | `E ÷ chars × 100` | 本表统一用全字符分母 | 计算值 |
| `coverage` | 标注跨度字符覆盖率（被实体/动词跨度覆盖的正文字符占比） | 批内正文 | registry 汇总 |
| `token delta` | 本轮令牌数与基线的差值（正=新增，负=删除） | 逐文件 | `logs/qa/` delta 报告 |
| 成本 | 实际 API 计费（美元），按批次日志；"返工"单列 | 单书/单批 | 批次日志（docs/45/47/48/54 记录） |
| 吞吐 | 墙钟时间（含并行）与单位耗时 | 单批 | 批次日志 |

> **口径纪律**：docs/47-020、docs/48 的密度表以"剔除围栏/韵文后的正文字数"为分母，故数值略低于本表全字符口径（如白发 6.55 vs 本表 6.79）。**两种口径不可混用**，引用时必须写明分母。

**换书预估公式**（首次口径，不含返工）：

```
预估成本(USD) ≈ 新书 chars ÷ 10,000 × 0.024
预估墙钟(min) ≈ 回数 × 1.1（4 worker 并行）
返工上界 ≈ 首次成本 × 0.5（历史 5 书返工占比约 20%~40%）
```

> 注：白发 $/回 偏高是 pilot 特性（首回调试、few-shot 迭代）；稳定批次取 0.023~0.030 $/回。成本为 API 账单口径，未含人工裁决工时。

## 八、检查清单（每次更新总表）

- [ ] 分子分母已按 §一 核对（E/V 是令牌数不是去重数）；
- [ ] chars 分母口径已注明（全字符 vs 剔围栏）；
- [ ] judgment 是否含已裁条目已注明；
- [ ] 新值 = 旧值 + 本轮 delta（对不上必须解释）；
- [ ] 成本分首次/返工，单位 $/回 与 $/万字符 都已算；
- [ ] 墙钟与并行度已记（否则吞吐不可比）；
- [ ] 数据源路径已写；
- [ ] 口径版本变更已标注（如覆盖率定义调整）。

## 九、成功标准

1. 总表任一行可在 `registry/acceptance/*.json` 中逐字段对上；
2. 收敛轨迹保留全部中间值（不允许只留首末）；
3. 换书预估误差 ≤ 30%（成本）/ ≤ 50%（墙钟）；
4. 每批新书更新总表 + 轨迹 + 成本三处，缺一不算完成；
5. 对外引用 100% 带口径与数据源。
