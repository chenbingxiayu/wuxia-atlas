### 1.2 本文做什么

1. **跨书设定溯源**：同一设定/武功/神兵/门派在系列内的出现顺序、演化、呼应/翻案；

## 三、跨书设定传播链（对象与方法）

### 3.1 溯源对象

| 对象 | 例 | 链的证据 |
|---|---|---|
| 武功/招式 | 天山剑法跨书传承 | 师承/秘籍/招式名+互文 |
| 神兵/器物 | 游龙剑四书流转 | 神兵表 chain + 互文 |
| 门派/组织 | 武当在 14 书出现 | D07 §4.6（关联为主，非归并） |
| 世界规则/设定 | 内功体系/门派规矩 | 正文一致/冲突 |
| 人物称号/绰号 | 白发魔女跨书称名 | 03b 别名+互文 |

### 3.2 证据分级（引 D07 §二）

| 级 | 含义 | 溯源用途 |
|---|---|---|
| E1 | 正文明示（"事见拙著《…》""这套剑法源自…"） | 直证传播/呼应 |
| E2 | 序跋/再版说明/作品元数据 | 作者意志级证据 |
| E3 | 情节暗示（传承/伏笔/武学体系） | 候选传播链 |
| E4 | 读者推断/常识 | 不落盘 |

### 3.3 传播链的形态

```text
线性传承：A 书（创派/首创）→ B 书（传人）→ C 书（再传/失传）
呼应：后书明文接续前书（资产，记 relations）
翻案：后书明文推翻（资产+裁决，D07 R4）
修订：再版改笔（消解，记修订信号）
断裂：中间书无记载（沉默证据差集：应有而未出现→削弱）
```

### 3.4 互文证据的用法（D07 §七）

- **authorial 98 条**：E1 直证；"authorial 只证明有互文，不自动等于可归并"——probe 指向需解析（人物/事件/神兵/书名指引）；
- **quoted 31 条**：E3 辅证；与 E1/E2 互证成链才有效；
- **bare 1,775 条**：走 B0-B8 分流（B1 绰号撞书名等 → 候选池/群组层），不得整表丢弃。

## 四、书内信息传播链（谣言链）

### 4.1 传播链结构

```text
信源：知情者（亲历/参与者）· 旁观者 · 转述者 · 编造者
  ↓
传播节点：谁在什么场合对谁说了什么（事件/对白/叙述）
  ↓
受众：江湖大众/门派/官府/特定人物
  ↓
可信状态：事实 / 部分失真 / 夸大 / 谣言 / 未知
```

### 4.2 与 04a 叙述可靠性矩阵（6×4）的接口

| 叙述模式 | 可信倾向 | 溯源处理 |
|---|---|---|
| 叙述者直接叙述 | 高 | 事实层候选 |
| 人物对白/声称 | 中 | 记来源，不升事实 |
| 传闻/据说 | 低 | 谣言链节点 |
| 回忆 | 中 | 核对回忆对象/时间 |
| 梦境/幻觉 | 极低 | 不入事实链 |
| 不可靠叙述者（有意欺骗） | 低 | 标欺骗语境 |

### 4.3 公开性 × 细节度矩阵（保留自 07d 原版）

| 公开性＼细节度 | 细节具体 | 细节模糊 |
|---|---|---|
| **公开**（江湖皆知） | 易夸大/传奇化（如"某大侠一战歼百人"） | 口号/传闻（可信度最低） |
| **半公开**（门派/圈子） | 较可信但可能派系化 | 模糊但要害（需互证） |
| **秘密**（少数人） | 可信但可能被封锁/篡改 | 最易失真（以讹传讹） |

> 用途：判断一条消息"为何失真/为何可信"；不是给它直接定真值——真值仍需 07e 评级。

### 4.4 谣言链的分析输出（示例）

```json
{"rumor_id":"RM-001","book":"江湖三女侠","claim":"某人已死",
 "origin":{"type":"旁观者|转述|编造","entity":"…","loc":"…"},
 "propagation":[{"to":"江湖大众","medium":"客栈议论","loc":"…"}],
 "publicity":"公开","detail":"模糊","plausibility":"存疑",
 "status":"rumor|partially_true|false|unknown",
 "evidence":[{"level":"E3","ref":"04a 叙述模式=传闻"}]}
```

## 十、FAQ（首批 6 问）

**Q1 溯源是不是找"最早出现的书"？**
不全是。跨书链要还原"出现序+演化+呼应/翻案"；最早出处只是链的起点，不能解释后续接受。

**Q2 authorial 互文能直接归并身份吗？**
不能。D07 §7.1 明确"authorial 只证明有互文，不自动等于可归并"；probe 指向需解析。

**Q3 bare 1,775 条怎么办？**
按 B0-B8 分流：B1 绰号撞书名→候选池；B2 分词陷阱→噪声；B3/B4 韵文/事件→噪声；B6 对象名→转层。

**Q4 谣言链的意义是什么？**
情节结构分析：谁掌握信息、谁相信、如何失真——这是武侠叙事的核心结构之一，也是 07e 可信评级的输入。

**Q5 公开性×细节度矩阵怎么用？**
判断失真模式：公开+细节具体易传奇化；秘密+细节模糊最易以讹传讹；不直接定真值。

**Q6 与 07c 的边界？**
07d 还原传播结构与证据；07c 判"是不是矛盾/资产"；两者串联（先溯源后分流）。

## 结语

溯源推理的价值在于把"从前有座山"讲成"这座山是怎么被一传再传的"：跨书看设定如何被接续与改写，书内看消息如何从知情者流向江湖。两条链都只给证据与结构，真值交给评级，裁决交给分流。
