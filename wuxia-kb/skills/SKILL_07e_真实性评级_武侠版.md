# SKILL 07e 武侠版：真实性评级 — 给每条知识一个可信标签

> **上游声明**：本文从 shiji-kb `SKILL_07e_真实性推理` 移植重造（🔴 重度 45:55），移植依据见 `docs/05-管线技能与脚本逐项改造分析.md` §2.4（**认识论转写：唯一真值→作者设定一致性**；七法模板逐一映射（法律鉴定→门规鉴定仍可机器化）；分层评估原则照搬）与 `docs/17-技能脚本改造实现图与拓扑排序.md`（S-07e 属 18 个"设计已备"节点，←D11）。
> **设计源（权威）**：`SKILL_常识与设定一致性_武侠版.md`（D11）§6.1 A-E 五级（07e 认识论转写：从"记载真伪"到"与系列设定的一致程度"）、§6.2 分层评估（照搬 07e，武侠化三层）、§6.3 与上游字段映射、§7 反常三分流。
> **现有产物接口**：N8 `registry/consistency/<书>.json` 的 `summary.by_grade`（实测 B 3 / C 5，**无 D**：证据来自 N4 推算/N5 推导 → 止于 C）；04a §七 叙述可靠性（6×4 矩阵）；03b 登记层 status（approved/proposed/pending）；SKU 卡可信聚合（D12 §6.3）。

## 一、定位与边界

### 1.1 工序位置

```text
04a 叙述模式 · 07c 三分流 · N8 一致性 · 03b 登记 status · N4/N5 证据
        ↓
07e 真实性评级（本文：A-E + 分层评估）
        ↓
SKU 卡可信聚合 · 问答门控 · 发布审核 · 穿帮雷达争议区
```

### 1.2 本文做什么

1. **A-E 五级定义**：与系列设定的一致程度（不是"史实真伪"）；
2. **分层评估**：主线设定 / 情节经过 / 细节对话三层，各自评级；
3. **评级规则**：来源声称上限 C、未知≠穿帮、多源冲突双记、置信与证据映射；
4. **七法模板转写**：把 shiji 七法映射到武侠可执行判据；
5. **下游接口**：N8 grade/SKU 可信聚合/问答门控/发布审核。

### 1.3 本文不做什么

| 不做 | 归属 |
|---|---|
| 一致性规则引擎 | N8（本文消费 grade） |
| 叙述模式分类本身 | 04a §七（本文消费） |
| 反常三分流判定 | 07c（本文按分流结果评级） |
| 事实抽取/事件识别 | 04a |
| 发布/版权决策 | 01g §9.10 + 项目权利审核 |

### 1.4 实测基线（docs/57 §五）

- N8 5 书 44 条命中：A 0 / B 3 / C 5（无 D/E 出现于违规集）；
- 判定说明："证据来自 N4 推算 / N5 推导 → 止于 C"——推算链无法给 A/B；
- 升级条件：事件层（04a/D03/E5）与死亡/习得登记补证后可升。

## 三、A-E 五级（引 D11 §6.1，认识论转写）

| 级 | 与原义对照 | 武侠版定义（一致程度） | 发布口径 |
|---|---|---|---|
| **A** | 史料原文直证 | 正文（L1）明确陈述 + 无矛盾 + 无转述 | 可作事实/答案 |
| **B** | 多源互证 | 正文多处互证/正文+修订一致 | 可作事实（附来源） |
| **C** | 单一来源/存疑 | 单一正文线索、推算（N4/N5）、序跋（L3）、叙述声称 | 可展示，**不作断言性答案** |
| **D** | 后出/低可信 | 派生资料（影视/评论 L4）、读者推断 | 不发布（仅争议区/附注） |
| **E** | 证伪/不可考 | 与设定明确矛盾（穿帮候选）、或不可考 | 记录/雷达，不作事实 |

### 3.1 分层评估（D11 §6.2，照搬三层）

| 层 | 内容 | 评级倾向 |
|---|---|---|
| 主线设定 | 人物身份/门派归属/核心关系/生死 | 要求 A/B 才可断言；C 需展示保留 |
| 情节经过 | 事件发生/因果/胜负 | A/B 为主；推算 C 可展示 |
| 细节对话 | 台词细节/称谓/器物外貌 | C 可接受；D 不入库 |

> 同一卡片可三层不同级（如人物身份 A、某句台词 C）；SKU 聚合取**加权最低层**或分字段标注（D12 §6.3）。

## 四、评级规则（操作化）

### 4.1 来源声称上限 C

- 转述/传闻/人物声称（04a 叙述模式：quoted/claim）→ **上限 C**，即使说得斩钉截铁；
- 例："据说他早已死了" → C；正文直接叙述死亡 → A/B；
- 传闻被后文证实/证伪 → 重评（证实升、证伪转 E 并记翻案）。

### 4.2 未知 ≠ 穿帮

- 证据缺失/不可考 → 标"未知"，**不降级**、不判 E；
- E 只给"与设定明确矛盾"（07c 三分流判定为破绽）或"可证伪"；
- 不可考（原文未写）与矛盾（原文写了不一致）是两码事。

### 4.3 多源冲突双记

- 两源冲突（正文 vs 序跋/修订/派生）→ 按 D07 §三 权威层级取高层级评级，低层进记录层（conflicts）；
- 无法判别 → 双记 + 降一级 + 争议区（禁止硬裁，D07 R6）。

### 4.4 升级与降级

| 动作 | 条件 | 记录 |
|---|---|---|
| 升级 | 新增互证/事件层补证/翻案确认 | 证据+日期+复核人 |
| 降级 | 发现反证/来源被证伪 | 反证+理由 |
| 重评 | 规则版本变更 | 新旧级+规则版本 |

## 十一、FAQ（首批 7 问）

**Q1 虚构小说里谈"真实性"有什么意义？**
不是史实真伪，而是"与系列设定的一致程度+证据强度"。评级决定这条知识能不能发布/能不能当答案。

**Q2 为什么来源声称最高只能 C？**
声称≠事实；需正文互证或后文证实才能升；这与 04a"声称不入问答"一致。

**Q3 没有证据是不是就是 E？**
不是。未知≠穿帮；E 只给明确矛盾或可证伪。未知标"未知"。

**Q4 为什么现在没有 D 级？**
D=派生资料（影视/评论）；当前知识库只收正文与考订表，未收派生资料。未来接入影视对照才用 D。

**Q5 一条卡片三层不同级怎么办？**
分字段标注或取加权最低；不得用一个总级掩盖细节层的不确定性（D12 §6.3）。

**Q6 推算的年龄/年代能给 A 吗？**
不能。推算链上限 C；事件层补证后可升 B（需正文互证）。

**Q7 评级会不会随规则变化？**
会。规则版本化（rule_version），重评记录新旧级；评级可回退。

## 结语

武侠知识库的真实性评级，本质是**给"我们知道多少、凭什么知道"贴标签**：A/B 才敢当事实，C 只能展示，D 不发布，E 进雷达；未知就是未知。评级不是学术装饰，它是发布与问答的安全阀。
