## 一、定位与边界

### 1.1 工序位置

```text
03a 标注 → 03b 消歧/登记 → 结构（02ab PN/围栏） → accept（质量门）
         ↓
03l 出现统计（本文）──→ registry/concordance/<书>.json（实体×出现×位置）
                    ├──→ 统计报告（分书/跨书）
                    ├──→ 跨书聚合（active_books/first_appearance 等派生字段）
                    └──→ 下游：人物卡/门派页（01g §9.8）、SKU 卡（D12）、榜单/问答（需口径声明）
```

### 1.2 本文做什么

1. **三层口径定义**：L1 令牌计数、L2 实体去重计数、L3 跨书聚合派生；
2. **分母纪律**：正文分母（02ab §9.2）与"数触发词不数回合"（04f）在实体统计中的对应执行；
3. **跨书聚合**：按 D07 §4.6 类型强度决定哪些类型可跨书相加、哪些只做书内统计；
4. **产物 schema**：concordance/统计报告/跨书聚合 JSON 的字段与消费协议；
5. **发布纪律**：任何"最多/排名/密度"必须声明口径、样本量与版本（01g §9.9）。

### 1.3 本文不做什么

| 不做 | 归属 |
|---|---|
| 文本规模/密度/可读性统计（字数、句长、韵文占比） | SKILL_02f 文本统计 |
| 实体归并/同名消歧 | SKILL_03b 人名消歧 |
| 跨书系列身份最终归并 | D07 `series_identities`（本文只做统计聚合） |
| SKU 卡字段内容生成 | SKILL_SKU卡片_武侠版 |
| 榜单/评分权威性 | 应用层（本文只给口径与置信说明） |

### 1.4 与其他统计的边界（必读）

| 统计对象 | 归属 | 分母/口径 |
|---|---|---|
| 实体令牌次数 | **本文 L1/L2** | 全文令牌 vs 正文本体（围栏/回目/套语不计） |
| 动词触发词密度 | 04f / 02f | 触发词数 ÷ 正文分母（02ab §9.2） |
| 韵文占比/句长 | 02f | 韵文块/总块 |
| 字数/章节规模 | 02f | 汉字数（含/不含标点声明） |
| 页面访问/搜索热度 | 站点应用层 | 非本文 |

## 三、三层口径（核心）

### 3.1 定义与适用

| 层 | 定义 | 单位 | 适用 | 禁用场景 |
|---|---|---|---|---|
| **L1 令牌出现次数** | 原文中该实体令牌（`〖@…〗`）出现次数（mentions） | 次 | 分书统计、密度、抽检 | 跨书直接相加（同实体会重复计） |
| **L2 实体去重计数** | 按 `(type, canonical)` 归并后的实体数/组数 | 个（组） | 登记覆盖、去重实体、页面数 | 回答"出现多少次" |
| **L3 跨书聚合** | 同一系列身份跨书成员与派生字段 | 书数/总次数 | 人物卡/系列页/SKU | 未归并类型强行相加 |

### 3.2 关键指标定义（每个都带口径）

| 指标 | 定义 | 分母 | 备注 |
|---|---|---|---|
| 出现次数 | L1 mentions（可注明"含/不含围栏"） | — | 必须声明是否含管道/别名 |
| 去重实体数 | L2 组数 | — | 报告"多少实体"用 |
| 回覆盖率 | 该实体出现的回数 ÷ 全书回数 | 全书回数 | 反映分布广度 |
| 章密度 | 该实体 mentions ÷ 全书正文字数（万字） | 正文分母（02ab §9.2） | 与 02f 字数口径一致 |
| 首现 | 最早出现的 (书, 回, 段, PN) | — | 编年序 vs 出版序须声明（D07 first_appearance 用编年） |
| 共现/联动 | 同段/同回与指定实体共现次数 | — | 不等于关系（03b/关系体系） |
| 跨书书数 | 该系列身份 active_books 数 | — | L3 派生，非 L1 相加 |

### 3.3 口径声明模板（对外数字强制）

```text
【统计口径】L1 令牌出现次数 | 范围：江湖三女侠 001-048 共 48 回 | 分母：正文本体 602,043 字
| 是否含围栏/回目/套语：不含 | 数据版本：tagged@2026-11-05 + concordance@同批 | 规则版本：symbols v1.0
| 实体键：(type, canonical) registry 454 条 | 生成命令：build_entity_concordance.py --book 江湖三女侠
```

> 01g §9.9 红线："出现最多"不说明"提及 vs 去重实体"即违规；"打斗密度"不说明"动作/回合/战斗"即违规。本文把这条扩为所有统计的发布前置。

## 四、分母纪律（引 02f/02ab）

1. **正文分母** := 块类型=正文段的 PN 数/字数；排除回目 `[0]`、全部围栏（词/诗/歌/对联/回末对/回末/书信/告示/口诀/说书）；
2. **韵文提及不计入密度**（02ab §9.2：诗块整块不计；宿主引出句在正文但动词非触发词）；
3. **套语段不进分母**（回末"欲知后事如何"类）；
4. **实体统计的分母用法**：密度类指标一律用正文分母；"出现次数"可给全文字符口径（须声明）；两者不可混在同一条结论里；
5. **字数口径**：02f §二 的汉字数（含/不含标点）必须与密度分母一致。

> 出入账总表（02f §2.3）是本文口径对账依据：任何统计数字必须能在该表找到对应分母定义。

## 五、跨书聚合（本文的武侠增量）

### 5.1 归并强度约束（引 D07 §4.6）

| 类型 | 治理强度 | 跨书统计动作 |
|---|---|---|
| `@` 人物 | 强 | ✅ 主战场：按 series 身份聚合 members；L1 次数**不直接相加**，先归并后按成员分别统计再汇总（成员间可能重复指代） |
| `◎` 人物群组 | 中 | ✅ 组成员各自归并；组称号单独建系列身份 |
| `◆` 组织 | 关联为主 | ⚠️ 仅改名时归并；"武当"跨 14 书=同一组织关联，统计按"出现书数/时代切面"，不把出现次数当兴衰 |
| `•` 器物 | 强（神兵） | ✅ chain 归并；跨书次数=持有链语境统计 |
| `☆` 武功技艺 | 中 | ✅ 传承链归并；跨书次数区分"同一武功"与"同名异功" |
| `&` 家族 | 中 | ✅ 谱系延续 |
| `{` 文书 | 特殊 | ✅ 秘籍/剑谱归并（注意纸本 vs 技术） |
| `=` 地点 | 接口 | ❌ 不并；走 gazetteer（本文只引 id） |
| `+` 生物 / `;` 职衔 / `#` 身份 / `~` 族群 / `^` 概念 / `%` 时间 / `$` 数量 | 不归并 | ❌ 不做跨书相加（可做书内统计） |

### 5.2 跨书聚合产物（v0.1 约定）

```json
{
  "entity_key": {"type": "@", "canonical": "练霓裳"},
  "series_id": "E-P-0007",
  "members": [
    {"book": "白发魔女传", "canonical": "练霓裳", "mentions": 1234, "chapters": 32},
    {"book": "塞外奇侠传", "canonical": "练霓裳", "mentions": 12, "chapters": 3}
  ],
  "active_books": ["白发魔女传", "塞外奇侠传"],
  "first_appearance": {"book": "白发魔女传", "loc_r": "…", "order": "编年"},
  "aggregate": {"books": 2, "mentions_sum": 1246, "merge_conf": "strong"},
  "convention": "L3 | 成员归并来自 series_identities（v1.0）/ registry aliases（v0.1）| 次数为成员 L1 之和（免重复口径见注）"
}
```

- **派生字段纪律**（D07 §4.3）：`active_books`/`first_appearance` 由 members 聚合重算，**人工只维护 members**；两表未落地前（v0.1），用 registry aliases + 跨书同名/别名匹配做**临时聚合**，并在产物注明 `merge_source=temp`；
- **重复计数防护**：同一实体在同一书内多 canonical（书内层差异，如晦明/岳鸣珂）→ 先按书内 canonical 汇总，再挂系列身份，禁止全库直接 group by canonical 相加；
- **未归并实体**：跨书聚合只输出 `conf=strong/ok` 的成员；`todo` 成员单列"候选"不计入 aggregate。

### 5.3 页面/SKU 消费口径

| 下游 | 字段 | 必须携带 |
|---|---|---|
| 人物卡/门派卡（D12） | 出现次数、活跃书集、首现 | `mentions_convention`、`merge_source` |
| 页面排序（01g §9.8） | "出现最多"榜 | 口径声明 + 样本量 + 数据版本 |
| 问答 | 统计类回答 | 口径模板（§3.3）+ 禁止未核实推断 |
| 穿帮雷达/质量 | 分布异常（某书某类骤增） | 分母与分书对比 |

## 六、产物 schema 与消费

### 6.1 concordance（已有实现）

- 产物：`registry/concordance/<书>.json` + `.md`；
- 记录：实体组（type/canonical/[registration.id]/books/第一出现/mentions/aliases/章节分布）；
- 实测口径（5 书批次）：白发 32,716 次→若干组（docs/44 §二 C24）；江湖 3,804 组/36,300 次、registered 68/alias 9/unregistered 323（docs/55 §四）——**unregistered 不是缺失，是待登记队列**，统计消费时必须分列。

### 6.2 统计报告

- `generate_entity_stats_report.py`：分书/全库实体统计（type 分布、canonical 排名、回覆盖）；
- 输出：stdout/JSON（`--json`）——页面/看板消费 JSON，不消费 Markdown 表。

### 6.3 与 SKU/页面的接口

- 人物卡 `appearance_total` = L1 mentions（声明口径）；`active_books` = L3；`first_appearance` = 编年最早；
- 门派卡不把"出现次数"当兴衰（01g §9.8 红线）；武功卡区分同名异功（D07 §4.6）。

## 七、错误模式库（ST 系列，首批 10 条）

| # | 错误 | 检测 | 修正 |
|---|---|---|---|
| ST-01 | 把 L1 次数当去重实体数 | 报告字段歧义 | 两列分列并声明 |
| ST-02 | 跨书直接相加 mentions | aggregate 未归并 | 先归并成员再汇总 |
| ST-03 | 分母混用（正文/全文/字数） | 密度不可复算 | 统一 02ab §9.2 |
| ST-04 | 围栏/回目令牌计入 | 与 02f 口径不符 | 排除并声明 |
| ST-05 | 把 unregistered 计入"零出现" | 分布失真 | 分列待登记 |
| ST-06 | 同名异人合并计数 | 跨书数字虚高 | 03b 限定词/同名组 |
| ST-07 | 派生字段手填 | active_books 与 members 不一致 | 重算 |
| ST-08 | 榜单不做样本量/显著性提示 | 小样本排名误导 | 附样本量/置信说明 |
| ST-09 | 出现次数当兴衰/强度 | 01g §9.8 红线 | 改用时代切面/事件链 |
| ST-10 | 统计结果无版本 | 不可复现 | 数据+规则双版本 |

## 十、FAQ（首批 7 问）

**Q1 "出现次数"到底算令牌还是算实体？**
都行，但必须声明：L1=令牌出现次数，L2=去重实体数。页面/卡片默认 L1，登记覆盖用 L2。

**Q2 跨书能不能说"某人物出现 5000 次"？**
必须先归并（series 成员）再汇总，并声明"成员次数之和"；未归并/同名异人不得相加。

**Q3 围栏里的实体算不算？**
默认不计入密度分母；"出现次数"若含围栏须显式声明。韵文意象类本就不标（02ab §4.4）。

**Q4 unregistered 算不算"没出现"？**
不算。它是"已出现但未登记"，统计报告须分列（如江湖 323 条）。

**Q5 首现按什么序？**
按编年（书内叙事时间）最早；无时间轴依据时按出版序并声明（D07 first_appearance 用编年）。

**Q6 门派出现次数能说明门派兴衰吗？**
不能（01g §9.8 红线）：出现次数≠组织兴衰；兴衰要看事件链/时代切面。

**Q7 统计结果多久更新？**
每批 accepted 后重跑并记录版本；对外引用必须绑定数据/规则版本。

## 结语

统计不是"数一数"，而是**在正确口径下可复算地回答一个问题**。三层口径把"次数/实体/跨书"分开，分母纪律把"密度"钉在正文上，归并约束把"跨书相加"限制在可归并类型内——这样统计才能既好看又站得住。
