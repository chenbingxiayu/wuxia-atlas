> **核心理念**：标点是文本理解的第一道工序。但武侠底本（现代排印本）**已带标点**——本文的工作不是从零断句，而是**守护底本标点不被标注过程悄悄改动**，并把"标点确实错了"的判断移交校勘工序、另建映射。

## 一、定位与适用场景

### 1.1 工序位置

```text
G0 底本锁定（含底本标点验收）
        ↓
S-01f 句读标点（本文）：底本标点守护 + 疑误登记 + 半角修复
        ↓                       ↘ 疑似底本句读错误 → S-01b 互校裁决
02ab 结构层（围栏内标点由 E16 把关）
        ↓
S-01a 完整性维护：剥标后标点必须与底本逐字相同（最终验收）
```

### 1.2 何时使用本文

- **场景 1**：标注/修复中发现引号方向颠倒、成对失衡、半角混入等标点问题；
- **场景 2**：多版本对照时发现标点差异（句读位置、引号样式），需要裁决流程；
- **场景 3**：围栏（词/诗/书信/对联/回末对）内标点合规检查（E16）；
- **场景 4**：理解 lint 对账时标点差异的处置规则（默认严格、--norm 待重审）。

### 1.3 本文不做的事

- ❌ 无标点文本的 AI 自动断句（gj.cool API、本地模型断句等整节**删除**——武侠底本已标点）；
- ❌ 直接修改锁定底本的标点（那是 S-01b 勘误流程的事，且须重算指纹）；
- ❌ 在标注层"顺手"统一标点样式（01g §2.1 明令禁止）。

## 二、标点符号规范

### 2.1 标点三原则（照搬，加一条总前提）

**总前提：原文优先**——底本既有标点是原文的一部分，一字不动（01g §2.1）。三原则只管辖**校勘层裁决**与**新写文本**（规范文档、报告、登记表）：

1. **全角优先**：校勘映射的替换目标、新写说明一律全角标点；
2. **语义优先**：裁决句读分歧时标点服从语义，不拘泥现代语法；
3. **从俗从简**：常用标点优先，避免生僻符号。

### 2.2 弯引号与直角引号的处理差异（武侠化核心节）

史记版规定"直角引号 ❌ 禁止"——那是**新写文本**的规则。武侠版按 01g §2.1 重新划界：

| 层 | 规则 |
|---|---|
| **底本既有标点** | 用什么保留什么。底本是直角引号 `「」『』`，标注层就是直角引号，**不得**替换为弯引号 |
| **标注过程** | 不批量转换半角↔全角、直角↔弯；不删除所谓"多余标点"后沿用旧定位 |
| **校勘工序** | 若确需统一（如直角→弯），**另建校勘映射文件**并声明，不与标注混在一次变换中；映射落地前底本原样 |
| **新写文本** | 规范文档、报告、登记说明统一用弯引号体系 |

**正误对照**（01g §2.1 原例精神）：

```text
✅ 底本为 「玉罗刹来了。」，标注为 「〖@玉罗刹|练霓裳〗来了。」
❌ 标注时改为 “〖@玉罗刹|练霓裳〗来了。”，却未声明建立了校勘版本
```

**理由**：标点统一属于校勘工序，原文无损属于标注工序，两者不能混在一次变换中——混了，剥标还原（S-01a 铁律）立刻破功。

### 2.3 标点符号对照表（新写文本口径）

底本既有标点**优先于**本表；本表约束校勘映射目标与新写文本：

| 类型 | 符号 | Unicode | 禁止使用 |
|-----|------|---------|---------|
| 句号/逗号/顿号 | 。 ， 、 | U+3002 / U+FF0C / U+3001 | 半角 `. ,` |
| 分号/冒号 | ； ： | U+FF1B / U+FF1A | 半角 `; :` |
| 问号/叹号 | ？ ！ | U+FF1F / U+FF01 | 半角 `? !` |
| 弯双引号 | “ ” | U+201C / U+201D | 半角 `"` |
| 弯单引号 | ‘ ’ | U+2018 / U+2019 | 半角 `'` |
| 书名号 | 《 》 | U+300A / U+300B | 半角 `< >` |
| 破折号/省略号 | —— …… | U+2014×2 / U+2026×2 | `--` / `...` |

（直角引号 `「」『』` 的 Unicode 见 01g §2.1 表；在武侠库它们是**合法的底本标点**，仅新写文本不用。）

### 2.4 引号三层嵌套规则（照搬）

嵌套顺序从外到内：

```text
第一层：“ ” （弯双引号）
第二层：‘ ’ （弯单引号）
第三层：“ ” （重复第一层）
```

示例（规则演示，非作品原文）：

```text
老掌门说道：“祖师遗训有云‘剑不轻出，出必饮血’，你们都忘了。”
         └─第1层───┘└──第2层──────┘└─收束─┘
```

常见错误：

- ❌ 使用半角引号（标注作业手误的头号来源，见 4.1 修复流程）；
- ❌ 全部用同一种引号、不分层次；
- ❌ 引号跨境配对（在 02ab 场景即"信中附诗另开内层围栏"式错误——附诗并入宿主围栏，不另开）；
- ⚠️ 底本若本身是直角引号体系，嵌套按**底本的体系**判断（「」外、『』内），不强套弯引号三层。

### 2.5 已标点版本的引号方向反思（保留并武侠化）

史记版"场景 B"整体保留——这是本文仅存的"反思"场景。电子录入底本的常见病：

| 病灶 | 表现 | 检查手段 |
|---|---|---|
| **方向颠倒** | `”他说“……’` 前后引互换 | 行级配对扫描（奇偶计数） |
| **成对失衡** | 只有一只引号、行内不闭合 | 行级左右引号平衡检查 |
| **半角混入** | 录入时输入法切换残留 `"` `'` | `lint_symbol_conflicts.py` + `fix_halfwidth_quotes.py` |
| **体系混用** | 同书弯引号与直角引号并存 | 分书统计引号样式分布，异常书登记存疑 |

**反思流程**：

1. 提取该书现有标点模式（引号样式分布、句读密度）；
2. 对照参校版本的同段落标点（版本清单见 S-01b，待 G0 回填）；
3. 对可疑位置（长对话、嵌套引语、书信引文）逐处人工裁决；
4. **裁决结果先落校勘记录，不动底本**；确认为底本录入错误的，走 S-01b 勘误流程合并回底本并重算指纹。

### 2.6 韵文标点格式（照搬 + 围栏化）

基本原则（史记版三条全保）：

1. **每句一行**：每个韵脚结束后换行；
2. **句内不断**：句子内部不加句号（允许逗号）；
3. **保持对仗**：对仗句式保持格式一致。

武侠版差异：韵文一律处于围栏内（`::: 词` / `::: 诗` / `::: 对联` / `::: 回末对`），标点格式检查由 E16 与 02ab §5 判定共同覆盖；围栏内**不标实体/动词**（02ab §4.4 分层豁免），所以韵文标点是"纯底本字符"，任何改动都必须有校勘记录。

```text
::: 对联
联文上句，
联文下句。
:::
```

## 三、围栏内标点规则（武侠新增）

02ab §4.2 围栏通用铁律第 4 条：**围栏内禁半角标点**。落地为 `lint_purple_numbers.py` 的 **E16（error 级）**：

- 检查字符集为保守集（`,.;:!?()"\'<>` 等），待试点校准后扩容；
- E16 报错的处置分两步：
  1. **先判归属**：围栏内字符是底本字符——若底本该处就是半角（电子录入残留），这是**底本疑误**，转 S-01b 登记，不在标注层改；
  2. 若底本是全角而标注文件被改成了半角，属标注手误，立即恢复并重跑；
- ⚠️ "疑误讹字一律保留原样"（02ab §4.2 铁律 5）同样适用于标点：`欲如`类疑似讹字、疑似错位引号，未走勘误流程前一个字符都不许动。

## 四、标点与标注的关系

**核心原则（照搬）**：标点符号在标注符号**外部**；标点标记语义边界，标注符号标记实体/结构。01g §2.1 配套负规则：不把引号、书名号、句末标点包入实体边界。

```text
✅ 〖@练霓裳〗冷笑道：“〖=天山〗的雪，比人心干净。”
✅ 〖@卓一航〗、〖@岳鸣珂〗先后上山。
✅ 他使出〖☆怪蟒翻身〗，剑势一收。
❌ 〖@练霓裳冷笑道：〗——标点被包入实体边界
❌ 〖@卓一航〗、〖@岳鸣珂〗，先后上山。——顿号改逗号（改了底本标点）
```

第三例最隐蔽：**改一个顿号也是改底本**，S-01a 对账会报实质差异。句读确有疑误时，登记存疑，交校勘裁决。

## 五、工具链

### 5.1 修复工具

- `fix_halfwidth_quotes.py` — 半角引号 → 弯引号（C5 直接移植，码点状态机）：

```bash
# 批量处理全库（缺省扫 config.DIR_TAGGED）
python scripts/fix_halfwidth_quotes.py

# 只处理指定书
python scripts/fix_halfwidth_quotes.py --book 白发魔女传

# 指定单回或部分文件名（多书时配 --book）
python scripts/fix_halfwidth_quotes.py 001
python scripts/fix_halfwidth_quotes.py 白发魔女传/001
```

  智能特性（照搬史记版）：按上下文判断左/右引号（右引号后随字符优先判定）；只处理半角引号 `"`→`“”`、`'`→`‘’`，**不碰全角引号、弯引号、直角引号**——直角引号是合法底本标点，绝不被此脚本"修复"。

### 5.2 检查工具

- `lint_symbol_conflicts.py` — 六项检查照搬（半角标点、直角引号、标点在标注内、Markdown 在标注内、嵌套标注、标注跨标点）+ 旧符号检测（史记体系残留令牌即 error）；文件位置参数可缺省（缺省扫全库），`--book` 单书；
- `lint_purple_numbers.py` — E16 围栏内半角标点（error），随 E1-E17 结构检查一起跑；
- `lint_text_integrity.py` — 终审：默认字符级严格模式下，**任何标点差异都计为差异**（`--norm` 规范化豁免待底本重审，启用前不存在"可忽略标点差"）。

### 5.3 标准修复流水

```bash
# 第一步：检测
python scripts/lint_symbol_conflicts.py --book 白发魔女传
# 第二步：修复半角引号
python scripts/fix_halfwidth_quotes.py --book 白发魔女传
# 第三步：复检 + 结构检查 + 对账
python scripts/lint_symbol_conflicts.py --book 白发魔女传
python scripts/lint_purple_numbers.py --book 白发魔女传
python scripts/lint_text_integrity.py --book 白发魔女传
```

⚠️ 若底本本身含半角标点（录入残留），第一步会反复报错——此时**停止**批量修复，把相关回目转 S-01b 登记底本疑误；批量修复只处理"标注文件引入"的半角符号。

## 六、完整性检查中的标点处理（对账语义）

衔接 S-01a，标点在对账中的命运：

1. 底本自带标点（武侠常态）→ 标注文件剥除 PN/围栏行/标注令牌后，**标点原样保留**，与底本逐字比对；
2. 默认严格模式（`--norm` 关）→ 全角↔半角、弯↔直角差异一律计为差异，**修复方向以底本为准**；
3. `--norm` 启用后（待底本重审）→ 规范化映射表中的标点等价项才可能被豁免；引号删除条目对武侠底本不成立（底本自带引号），重审时必须移除或改写。

## 八、FAQ

**Q1：为什么删除无标点断句场景？**
武侠底本是现代排印标点本，从零断句（gj.cool API、本地模型、validate_punctuation 等）整条工序不复存在。底本句读质量的问题转化为 S-01b 的版本对照与勘误流程。

**Q2：底本用的是直角引号，怎么处理？**
保留原样。直角引号在 01g §2.1 是合法标点符号；不得在标注过程中替换为弯引号。若项目层面决定统一（如阅读器渲染需求），走校勘映射：另建映射文件、声明、可逆，底本不动。是否建立全局直角引号映射表见附录 B。

**Q3：半角标点什么时候可以改？**
只有一种情况可以批量改：**标注文件**引入的半角引号（手误），用 `fix_halfwidth_quotes.py`。底本自带的半角标点是疑误，登记不改；围栏内的半角标点先按第三章两步定性再动手。

**Q4：改标点和改句读是一回事吗？**
不是。引号方向、半角混入是**机械修复**（本文管）；句读位置（这里该逗号还是句号）的改动是**校勘裁决**（S-01b 管），且无论裁决结果如何，落地前底本字符不动。
