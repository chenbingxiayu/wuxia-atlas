# W3 质量四档（武侠版）—— 每条断言都要有源

> **本文是什么**：Butler 的"质量标准"。W2 管动作，W3 管**做到什么程度算合格**：页面分四档（stub→basic→premium→featured），页面上每条断言必须挂证据（PN 引文 > registry 边/事件 ID > 统计数字 > 分析句），并有质量快照与回归机制防降档。
> **上游依赖**：`skills/W2_动作库_武侠版.md`（动作）；`skills/W4_评估_武侠版.md`（评估）；`logs/qa/w_group_design_brief.md`（W3 设计）；`scripts/verify_quotes.py`（W7 引文合格线）。
> **一句话**：**在武侠 KB 里，"写得好"不等于"写得多"，而是"每条断言都能指回证据"。**
> **只读纪律**：质量检查只读页面与上游；质量门输出只落 `logs/w_group/quality/`；不改页面内容（发现缺项交 W2/W4）。

## 快速开始

````text
1. 取页     content/<类型>/<page>.md + frontmatter（含引文独立字段）
2. 断言清点 把页面拆成"断言列表"（事实句/关系句/统计句/分析句）
3. 逐条挂源 ①PN 引文 ②registry 边/事件 ID ③统计（口径+脚本+版本）④分析句（≤150 字且段有①②）
4. 定档     stub/basic/premium/featured（§三）
5. 出质量门 JSON（quality + 缺项清单）→ W4/W10u；快照/差异/回归（§五）
````

## 一、定位与边界

### 1.1 在 W 组中的位置

```text
W2 动作产出页面 → W3 质量标准（本文）→ quality JSON → W4 评估 / W10 健康度 / W8 精品升级
        ↓
W6 离线质检（批量抽查）· W7 引文核验（引文硬门）
```

### 1.2 本文做什么

1. **四档标准**：stub/basic/premium/featured 的客观判据；
2. **断言分级**：四类证据的优先级与"分析句"的约束；
3. **质量门 JSON**：每页 quality + 缺项清单；
4. **快照/差异/回归**：质量状态快照、轮间 diff、降档拦截；
5. **版权/脱敏 L0 档**：短引文、R1/R2、不输出原文。

### 1.3 本文不做什么

| 不做 | 归属 |
|---|---|
| 执行动作/写页面 | W2（本文只判定） |
| 评估 accept/fail/rollback | W4 |
| 批量离屏扫描 | W6 |
| 引文核验算法 | W7 `verify_quotes.py` |
| 精品页图式 | W8/W9 |

## 二、断言分级（核心规则）

### 2.1 四级证据（优先级从高到低）

| 级 | 证据 | 示例 | 可发布 |
|---|---|---|---|
| ① PN 引文 | 原文引文块（带机锚 `book#pn-r{回}.{段}`，≤60 字/段） | "……"（jianghu#pn-r12.3） | ✅（必须 W7 过） |
| ② registry ID | 关系边 ID/事件 ID/SKU 卡字段 | `关系边 J-xxx`、`card.person.e0001` | ✅（可回溯） |
| ③ 统计数字 | 须写口径+生成脚本+数据版本 | "出现 1,234 次（L1 令牌，2026-11-05.01）" | ✅（附口径） |
| ④ 分析句 | 原创分析，**≤150 字/段**，且每段至少 1 条 ①/② 支撑 | "由此可见…" | ✅（有支撑）/❌ 无支撑 |

### 2.2 硬规则

1. **每条断言必须有源**：无源断言=不合格，禁止进入 basic 及以上；
2. **④ 分析句不能独立成段**：必须依附 ①② 证据；
3. **统计数字不得裸奔**：必须带口径（03l/02f：L1/L2/L3、分母、范围、版本）；
4. **引文不得混在散文中**：content 层引文必须是**独立字段**（frontmatter `quotes[]`），便于 W7 稳定抽取与核验；
5. **demo/未过审内容**不得作为断言来源（W0/W1 纪律）。

## 三、质量四档（判据）

| 档 | 判据（全部满足） | 典型 |
|---|---|---|
| **stub** | 只有 canonical + 来源映射；corpus 证据 0；无断言 | 最小可用页 |
| **basic** | ≥3 条 registry 结构化事实（关系/事件/卡字段）+ ≥1 个 PN 引文块（过 W7） | 大多数人物页目标 |
| **premium** | ≥8 条结构化事实 + ≥3 个 PN 引文块 + 跨书/跨章互见 ≥1 | 重要人物/门派 |
| **featured** | W8 标准全满足（多角度评价≥3/独立按语节/相关页互联/跨书互见/引文≥3 且全过 W7） | 精品页 |

### 3.1 档位判定顺序

```text
断言清点 → 无源断言=0？
  否 → stub（并记缺项，交 W2 动作 2/7/10 补）
  是 → registry 事实数 ≥3 且 PN 引文 ≥1？
        是 → basic；否则 stub+
  是 → 事实 ≥8、PN ≥3、跨书 ≥1？
        是 → premium；否则 basic+
  是 → W8 全标准？
        是 → featured；否则 premium
```

### 3.2 质量门 JSON（v0.1 约定）

```json
{"page":"content/person/card.person.e0001.md","quality":"basic",
 "assertions":[{"text":"卓一航是武当派弟子","evidence":[{"type":"relation_edge","id":"…"}]},
                {"text":"原文引文块","evidence":[{"type":"pn_quote","loc":"baimo#pn-r12.3","w7":"hit"}]}],
 "missing":["PN 引文仅 1 处（premium 需 ≥3）","跨书互见缺"],
 "checks":{"no_source_assertions":0,"stats_without_convention":0,"quotes_not_independent":0},
 "convention":{"data_version":"2026-11-05.01","rule_version":"w3@v0.1","w7":"verify_quotes.py"}}
```

## 四、版权与脱敏（L0 档）

| 规则 | 内容 |
|---|---|
| 引文长度 | ≤60 字/段；连续片段不超 R2（SKU 脱敏规则） |
| 原文输出 | content 页面不得输出原文连续大段；引文块只作证据 |
| R1/R2 | 卡面正文不得与原文连续重合 ≥10 字；引文型内容=概括语+回锚 |
| demo 隔离 | demo/未过审卡页不发布 |
| W7 | 所有引文块过 `verify_quotes.py`（hit/near 可，miss 拒绝） |

> 说明：W7 的作用是**核验**，不是**提供原文**；其输出只含长度/hash/定位，不含原文。

## 五、快照、差异与回归

### 5.1 质量快照

- 每次 W 轮后生成 `logs/w_group/quality/<date>_round<N>.json`：全部页面 quality 分布 + 缺项统计 + 数据/规则版本；
- 快照不可变（追加式），用于跨轮对比。

### 5.2 轮间差异

| 差异类 | 含义 | 处置 |
|---|---|---|
| 升级 | 档位上升 | 记录（W4 accepted） |
| 降档 | 档位下降 | **拦截**：必须 W4 复核+理由，否则回滚 |
| 新增页 | 新 stub/basic | 正常（W2 动作 1） |
| 删除/合并 | 页面消失 | 核对 W10 内务动作 |
| 断言源变化 | 证据 ID/引文失效 | 重核 W7/registry |

### 5.3 回归纪律

1. **不得无授权降档**：降档必须记录原因（内容删减/证据失效/脱敏要求）；
2. **引文回归**：W7 miss 任何引文块 → 页面 quality 降级并进 W6 队列；
3. **无源断言回归**：新增无源断言 → 立即回退到上一快照版本；
4. **快照复跑**：同输入/同规则版本 → 分布一致（可复算）；
5. **回归门**：轮末 `quality_regression` 报告缺失即视为评估不完整（W4 拒收）。

### 5.4 健康度六指标（W4/W10 共享口径）

| 指标 | 定义 | 目标 |
|---|---|---|
| K 知识量 | 内容页总字符数 | 持续增长 |
| link_density | 有站内 wikilink 页面占比 | >80% |
| stub_ratio | stub 页占比 | <10% |
| source_coverage | 有 PN 引注页面占比 | >60% |
| citation_error_rate | W7/W6 open 引文问题/总引文 | <2% |
| disambiguation_coverage | 多义/同名实体有消歧页占比 | >90% |

## 十、FAQ（首批 6 问）

**Q1 为什么卡面引文很少却不算质量问题？**
SKU 卡按 R1/R2 脱敏（引文=概括语+回锚），W7 对卡面预期"零引文"；引文主战场在 content 页面（独立字段）。

**Q2 分析句能不能多写？**
可以，但每段 ≤150 字且必须有 ①② 支撑；纯分析段不合格。

**Q3 降档一定回滚吗？**
不。有正当理由（内容删减/证据失效/脱敏）可降，但必须 W4 复核+记录；无理由降档=回滚。

**Q4 统计口径写哪？**
断言旁注（L1/L2/L3、分母、范围、版本）；或引用 03l 口径声明。

**Q5 快照有什么用？**
跨轮对比（升级/降档/新增）、回归证据、健康度基线；不可变追加。

**Q6 W3 和 W4 区别？**
W3 判"页面达到什么质量档"（静态标准）；W4 判"这个动作收不收/回不回滚"（动态评估）。

## 结语

质量四档的本质是**把"好不好"变成"够不够"**：每条断言有源、每页有档、每轮有快照、每次降档有理由。标准一旦客观，Butler 的动作与评估才能形成闭环。
