# SKILL 09e 武侠版：有声书 — 让标注语料"可朗读"

> **上游声明**：本件属本批 C1 应用组新划定 09e，对应 docs/03 §3.10 原 09f 音频 / 09m 电子书（中度 60-65：形式学与工具链通用，换选题即用）。**无专属设计稿**：由 02ab §四 围栏语义、03d AST/HTML 契约、01g §9.10 发布边界综合而成；**v0.1 为骨架（TTS/音频管线未接）**。
> **接口**：`tagged/<书>/NNN.tagged.md`（只读）+ `struct`（PN/围栏）+ 03d AST 节点模型（chapter/fence/para/entity/verb/text）+ 01g §9.10 发布边界。
> **核心原则**：**朗读文本 = 剥标正文 + 围栏文体化处理；音频映射必须可回锚 PN。** 有声书不是"把标注符号念出来"，也不是"公开发布原文"。

---

## 一、定位与边界

### 1.1 工序位置

```text
tagged/struct（只读）→ 09e 朗读脚本（文本清洗/围栏处理/朗读标注）→ 音频管线（TTS/人工录音）
        ↓
音频产物 + 时间轴映射（PN ↔ 时间戳）→ 本地播放器/公开音频（版权分层）
```

### 1.2 本文做什么

1. **朗读文本清洗**：令牌剥除（保留显示串）、括号/管道处理、标点朗读化；
2. **围栏文体处理**：词/诗/歌（吟诵节奏）、回末（套语收束）、书信（书信语气）、口诀（技术断句）；
3. **朗读标注**：PN→时间戳映射、停顿/重音、角色音、多音字/生僻字注音（仅本地笔记，不入发布）；
4. **音频产物契约**：SSML/脚本 JSON、章节切分、时间轴索引；
5. **版权/发布分层**：本地收听 vs 公开音频的边界。

### 1.3 本文不做什么

| 不做 | 归属 |
|---|---|
| TTS/录音管线实现 | 工具选型（未接，附录 B） |
| 改 tagged/struct | 只读 |
| 原文公开发布 | 禁止（01g §9.10） |
| 音频版权定性 | 项目权利审核 |

### 1.4 关键约束（v0.1）

- **只读输入**：任何朗读脚本生成不得写 tagged/registry；
- **剥标不丢字**：朗读文本的显示串序列与剥标正文逐字一致（03a 铁律延伸）；
- **围栏不念符号**：`::: 词` 等围栏标签不朗读，只影响文体；
- **发布分层**：本地收听可用完整原文朗读；公开音频需版权审核且不得"以音频形式公开原文全文"（01g §9.10 精神，待法务确认）。

## 三、朗读文本清洗规则

### 3.1 令牌与结构处理

| 输入 | 处理 | 例 |
|---|---|---|
| `〖@显示串|规范名〗` | 保留显示串，弃管道 | 朗读"卓一航" |
| `⟦◈显示串|注记⟧` | 保留显示串（动词照读） | 朗读"刺" |
| `〘※…〙` | 保留显示串（修辞照读） | — |
| PN `[N]` / `[N.M]` | 不朗读，作切段锚 | 段界 |
| 围栏行 `::: 类型` | 不朗读，作文体标记 | 见 §3.2 |
| 回目 `# [0] 第N回 …` | 朗读为章节标题（可选） | 标题音 |
| `## ` 可选层 | 不朗读/作小节 | — |

### 3.2 围栏文体处理（引 02ab §4.1）

| 围栏 | 朗读处理 |
|---|---|
| 词 | 吟诵节奏；上下阕间明显停顿；词牌署名可读作"调寄××" |
| 诗 | 吟诵；每句一顿 |
| 歌 | 唱/吟均可；口语化处理 |
| 对联/回末对 | 上下联拆读 |
| 回末 | 弱化收束（"欲知后事如何，且听下回分解"） |
| 书信 | 书信语气；称谓/落款自然断句 |
| 口诀/告示/说书 | 说明性语气；技术名清晰 |

### 3.3 标点与语气

- 引号内对话：角色语气（角色音标注）；
- 破折号/省略号：停顿处理；
- 数字/量词：按语义朗读（"十八掌" vs "十八般"）。

## 四、朗读标注 schema（v0.1 约定）

```json
{"book":"江湖三女侠","chapter":12,"pn":"jianghu#pn-r12.3",
 "text":"吕四娘提剑上山，直奔白云观。",
 "style":{"fence":null,"role":"旁白","pace":"normal"},
 "marks":[{"pos":4,"type":"pause","ms":200},{"pos":12,"type":"stress"}],
 "pron":{"多音字":"…"}, "audio":{"start_ms":null,"end_ms":null},
 "anchor":"jianghu#pn-r12.3"}
```

| 字段 | 说明 |
|---|---|
| `text` | 剥标后朗读文本（与底本逐字一致） |
| `style.fence` | 围栏类型（null=正文） |
| `style.role` | 旁白/角色/说书人 |
| `marks` | 停顿/重音/语调 |
| `pron` | 多音字/生僻字注音（本地，不进发布） |
| `audio.start_ms/end_ms` | 音频时间戳（TTS 后回填） |
| `anchor` | PN 回锚 |

## 五、音频产物契约

### 5.1 章节切分

- 按回切分（`NNN`）；回目行作标题音；
- 回内按 PN 段切分（可选），保持回锚；
- 音频文件命名：`<书>_<回>_<段或全回>.mp3`（本地约定）。

### 5.2 时间轴索引

```json
{"book":"江湖三女侠","chapter":12,"audio_file":"jianghu_012.mp3",
 "segments":[{"pn":"jianghu#pn-r12.1","start_ms":0,"end_ms":8500},
             {"pn":"jianghu#pn-r12.2","start_ms":8500,"end_ms":21000}]}
```

- 用途：阅读器"听读同步"（03d 阅读器 + 音频）；
- 校验：segments 覆盖全部朗读段、时间单调、回锚存在。

### 5.3 发布分层

| 形态 | 边界 |
|---|---|
| 本地收听完整朗读 | 可（个人使用） |
| 公开音频（完整原文朗读） | 需版权审核；原则上不整本公开原文（01g §9.10 精神） |
| 摘要/导读音频（原创概述） | 相对安全，但仍需声明非原著 |

## 九、FAQ（首批 5 问）

**Q1 有声书会不会构成公开原文？**
本地收听不构成；公开音频需版权审核，且原则上不整本公开原文（01g §9.10 精神）。本技能只给工程边界。

**Q2 诗词要不要念？**
要，但按围栏文体（吟诵/停顿），不逐句念 PN，也不当正文语气。

**Q3 多音字怎么处理？**
建多音字表+人工审校（本地注音记录）；注音不进发布数据。

**Q4 听读同步怎么做？**
按 PN 段切分音频并回填时间戳索引（§5.2）；阅读器据 PN 联动。

**Q5 v0.1 能直接出音频吗？**
不能。TTS/录音管线未接；本文先定文本清洗、朗读标注与音频契约（骨架）。
