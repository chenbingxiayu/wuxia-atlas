## 一、定位与边界

### 1.1 工序位置

```text
03a/03b 实体+规范名 · 04a 事件 · 04f 动词 · 05b SPO 边
        ↓
05c 情义师承（本文）──┬─→ 血缘树（家族/亲属，& 类）
                      ├─→ 师承树（拜师/传艺/逐出，@+▣）
                      └─→ 情义层离线表（救/叛/赠/辱/爱恨，人工裁定）
        ↓
N5 落库 → 辈分标签/同门派生 → 07c 称谓辈分检查 + 关系页 + 问答
```

### 1.2 本文做什么

1. **双树构建**：血缘树（`&` 家族/亲属）+ 师承树（拜师/传艺/逐出/叛门）同构；
2. **辈分推导**：师祖/师叔/同门/侄辈；推导规则与置信；
3. **情义层**：离线表 schema + 人工 TSV 裁定（不进内联标注）；
4. **验证属性**：对称性（结义/情缘）、互斥性（情敌/师徒）、时序一致（叛门在拜师后）；
5. **下游接口**：N5 落库/辈分标签、07c 辈分检查、关系页展示。

### 1.3 本文不做什么

| 不做 | 归属 |
|---|---|
| 一般 SPO 边（交手/到达/赠予） | 05b/05a |
| 事件关系 | 04a |
| 情义层内联标注（禁止） | 本文明令不进标注层 |
| 家族/族群类型判定 | 01g §八/03b |
| 辈分错乱的穿帮裁决 | 07c/N8 |

### 1.4 关键口径（D06 定版）

- 双树**同构**：传递推理/无环检测/辈分推导复用同一套算法（D06 §五）；
- **情义层不进内联、不进 lint**（doc 02 决策）：救/叛/赠/辱/爱/恨只进离线表；
- 师承边方向=师→徒；逐出/叛门=状态事件，不改师承链存在，但需时序；
- 同门=同师**派生**（N5 实测 +16 边），不逐条人工标。

## 三、双树设计（D06 §五）

### 3.1 血缘树（家族世系）

| 项 | 内容 |
|---|---|
| 边来源 | `&` 家族实体 + 亲属关系（父/子/兄弟/夫妻等；当前 27 行联动无亲属触发→未产出） |
| 推导 | 父子/兄弟传递；夫妻不传递；辈分=代距 |
| 约束 | 无环；同一人只能有一个父/母（多源冲突→双记） |
| 状态 | **当前未产出**（N5 实测无亲属触发边）；属 v0.1 缺口 |

### 3.2 师承树（武侠核心）

| 项 | 内容 |
|---|---|
| 边来源 | 拜师/收徒/传艺/教授（▣ 技术传习 + 语式）；N5 实测 39 边/56 节点 |
| 方向 | 师→徒 |
| 状态事件 | 逐出/叛门/自立门户（不改边存在，附加状态与时序） |
| 推导 | 师祖=师的师；师叔=师的师弟；同门=同师派生；辈分=代距 |
| 约束 | 无环（不可 A 师 B 且 B 师 A）；一人可多师（需时序/门派限定） |

### 3.3 辈分推导规则

| 关系 | 推导 | 置信 |
|---|---|---|
| 师祖/师伯/师叔 | 师承树代距 1-2 | ok |
| 同门/师兄/师弟 | 同师 + 入门先后（若可判） | ok（先后不可判→weak） |
| 侄辈/孙辈 | 血缘/师承代距 | ok/weak |
| 跨书辈分 | 系列身份 + 双树 + 07a 年代 | low |

> N5 实测辈分标签 26 条全 weak——因师承树浅（冰魄/塞外树浅）与入门先后不可判；v0.1 不强行升档。

## 四、五类人物关系与验证属性（D06 §四/§八）

| 类 | 方向/对称 | 互斥/约束 | 时序 |
|---|---|---|---|
| 师承 | 师→徒（不对称） | 不可循环；可多师需限定 | 叛门/逐出在拜师后 |
| 结义 | 对称 | 与"仇怨"可并存（反目需时序） | 八拜之后 |
| 情缘 | 对称（夫妻/恋人；单恋不对称） | 情敌互斥（同一对象） | 分手/丧偶状态 |
| 仇怨 | 施→受（可双向） | 须关联因果事件（灭门/夺爱/夺秘籍） | 恩怨开始/解除时间 |
| 同门 | 对称（派生） | 同师且未叛门 | 入门先后 |

### 4.1 验证失败处置

- 对称缺失 → 补反向边或标 `symmetric:pending`；
- 互斥冲突（如同时"师徒"且"结义兄弟"） → 双记 + 人工裁定；
- 时序缺失 → 记 `time_anchor:null`，降 weak；
- 循环师承 → 判数据错误，回溯 03b 归并或错标。

## 五、情义层离线表（D06 §六，武侠增补核心）

### 5.1 为什么离线

- 情感/恩义/背叛没有稳定 SPO 结构（"救了"—何时/是否持续/双方如何表述都不稳定）；
- 内联标注会污染实体/动词层，lint 也难判（doc 02 决策：不进内联不进 lint）；
- 离线表由人工/T SV 裁定，附证据与置信，供页面/问答/关系图参考。

### 5.2 离线表 schema（v0.1 约定）

```json
{"edge_id":"QY-20261105-001","book":"江湖三女侠","chapter":12,
 "type":"救|叛|赠|辱|爱|恨|恩|义",
 "subject":"吕四娘","object":"冯瑛","direction":"subject→object",
 "status":"active|ended|uncertain",
 "evidence":{"loc":"jianghu#pn-r12.3","snippet_short":"…","event_ref":null},
 "confidence":"strong|ok|weak","note":"救命之恩，后文未报"}
```

| 字段 | 说明 |
|---|---|
| type | 八类受控（救/叛/赠/辱/爱/恨/恩/义） |
| status | active/ended/uncertain（恩义是否已报、情缘是否结束） |
| event_ref | 可选关联 04a 事件 id（有事件层后补） |
| confidence | strong（明写）/ok（情节推断）/weak（读者推断，不发布） |

### 5.3 人工 TSV 裁定流程

```text
① 候选生成：04f 动词（救/叛/赠/辱）+ 实体对 → 候选 TSV
② 人工裁定：逐条填 type/方向/status/证据（双人复核高价值条目）
③ 落库：registry/relations 或独立情义表（v0.1 约定：registry/relations/<书>.json 内 `affection_edges`）
④ 发布：strong/ok 可上关系页；weak 仅候选
```

### 5.4 与 SPO 的边界

- "赠"类可同时有 SPO 边（赠予）与情义层（恩）；不重复计；
- "叛"必须有时序（拜师后）；不与师承边互斥（师承仍在，状态变叛）；
- "爱/恨"不推导对等（单恋/单恨合法）。

## 十、FAQ（首批 6 问）

**Q1 为什么情义不能内联标注？**
无稳定结构、易污染动词/实体层、lint 难判；doc 02 已决策离线表+人工裁定。

**Q2 师承树和血缘树能合成一张图吗？**
不能。边的证据语义/传递规则/采集方式不同；D06 §五 定双树同构，分开建。

**Q3 同门边要人工标吗？**
不用，由同师派生（N5 +16）；人工只补入门先后（若原文可判）。

**Q4 辈分标签为什么全 weak？**
师承树浅 + 入门先后不可判；v0.1 不强行升档，等上游标注/树深度改善。

**Q5 叛门后师承边还在吗？**
在。叛门是状态事件（时序），不改"曾拜师"的事实；关系页显示"叛门"状态。

**Q6 血缘树什么时候能建？**
需亲属关系触发词/标注支持（当前 27 行联动无亲属），属 v0.1 缺口，随 05b/N5 扩展。

## 结语

情义师承是武侠关系层最"武侠"的部分：师承树给辈分骨架，血缘树给世系骨架，情义层给恩怨血肉。骨架必须可推导、无环、有时序；血肉必须离线、可核、不冒充事实。
