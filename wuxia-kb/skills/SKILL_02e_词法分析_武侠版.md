## 二、方法论（武侠版三法）

### 3.1 jieba 分词分析（核心方法，替代史记字级字表）

白话章回以多字词为主，用 jieba（0.42.1）分词 + 词性标注：

| 分类 | 方法 | 说明 |
| ---- | ---- | ---- |
| 虚词/功能词 | 白话虚词表（的了呢吧吗啊呀么便只就都被把让向往从在是与和或但然而于是因为所以虽然如果即使……） | 封闭表，不标 |
| 动词 | jieba 词性 v 开销 + 04f 六域触发词表交叉 | 词类活用按 04f 口径 |
| 数词/量词 | jieba m/q 词性 + $ 类既有标注 | 优先复用已有标注 |
| 候选实体 | jieba nr/ns/nt + 排除集 | 需二次判断 |

**两遍分析**：
- **第一遍：剥标分词** — `symbols.strip_markup` 剥标后 jieba 分词，词性分布统计
- **第二遍：夹心 lint** — 检测标签边界异常：`X〖☆Y〗`（裸前缀+标签）、`〖@A|B〗B`（标签后紧跟本名）等模式

### 3.2 排除集与候选发现

已有实体资产 × 未标注文字 → 交叉匹配 → 遗漏候选：
- 排除集 = `registry/entities.json`（surfaces/aliases/canonical）+ `wordlists/*.json` 词目 + wordlist 编译表 auto 部分
- 高频候选（>10 次）人工审核 → 走 03a 补标或词表登记

### 3.3 交叉匹配法（别名扫描）

`scripts/scan_untagged_aliases.py`（已正式化）：registry 别名 × 裸文本 → C18 报告（docs/54-0611 三书批次即此链路）。
