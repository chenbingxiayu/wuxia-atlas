## 一、技能定位

### 1.1 结构层是什么

结构层不管实体、不管动词，管的是**文本模式与骨架**：1,378 回如何切分与编号、诗词/书信/口诀如何围栏、回目页/阅读器/定位符能用什么结构层、事件统计的"正文模式分母"如何计算。

两处硬接口决定了本文的定版权限：

- **对 01g（实体层）**：01g 结构层最低字段中"块类型/文本模式"两个枚举由本文定版；01g 的"围栏内不标注"由本文按其原则零细化为"分层豁免"（§4.4）；
- **对 04f（动词/事件层）**：04f 的"韵文提及默认不计入正文事件密度"依赖本文第五章的韵文判定；"回末套语/回目预告不抽事件"依赖本文第六章的套语分级。

📌 编号一旦分配不可更改。结构层的设计错误会固化到全部 34 部书，因此本文宁可保守（容缺、存疑清单、观察类），不可激进（宁漏围栏勿错围栏——漏围可后补且不动 PN，错围修正需变更治理）。

### 1.4 实测基线与修正声明

本文以《白发魔女传》32 回 grep 实测 + 抽样观察为基准数据，凡实测与任务清单起点假设冲突处，**以实测为准**，逐条显式修正如下（正文对应章节不再重复论证）：

1. **"有诗为证"型套语实测 0 次**（同批 0 次的还有"花开两朵各表一枝""不在话下"）——水浒型说书套语在梁书缺位。修正：不设"有诗为证引语"围栏类型、词表不收录；改为"缺位监视项"登记（§6.2），试点期其他 33 部书若出现即回填。
2. **"只见"实测 190 次，绝大多数是叙事动词**（"但见"39 次同类）——最强伪信号。修正：只见/但见 定为伪信号级，禁止其单独触发任何围栏或分节动作（§6.2）；并新增 lint 误围栏告警（§9.1 E15）。
3. **部分回无章首词**（七剑下天山第一回：回目后直接叙事）——章首词约定必须容缺。修正：`[1]` 定义为"回目后第一个文本块"而非"章首词"，无章首词时 `[1]` 归正文首段（§2.3）。
4. **"欲如后事如何"与"欲知后事如何"变体并存**（样本丙）——回末套语按词族收录而非字面收录（§6.3）。
5. **"调寄"词牌署名实测仅 1 次**——词牌署名只作加分信号，不可依赖（§5.3）。
6. **武功口诀全文罕见**（多为"传了口诀"式叙述提及）、**书信多为行内引语**（样本乙）——口诀围栏设为观察类（§2.5），行内引语与成段围栏分流（§4.3）。

## 二、章回单元与回目约定

### 2.1 回内标准结构模板

每一回的标注文件遵循以下骨架（示例统一取自《白发魔女传》第一回，即样本甲/丙与本书正文首段；编号规则见第三章）：

```markdown
# [0] 第一回　铁矢神弓　少年扶巨宦　金鞍宝马　大盗震虚声

::: 词
[1] 一剑西来，千岩拱列，魔影纵横；问明镜非台，菩提非树，境由心起，
可得分明？是魔非魔？非魔是魔？要待江湖后世评！且收拾，话英雄儿女，先叙闲情。

风雷意气峥嵘。轻拂了寒霜妩媚生。叹佳人绝代，白头未老；百年一诺，不负心盟。
短锄栽花，长诗佐酒，诗剑年年总忆卿。天山上，看龙蛇笔走，墨泼南溟。

——调寄沁园春
:::

[2] 〖%凉秋九月〗，北地草衰，有一行人马正沿着绵亘〖=川陕〗两省边界的大巴山脉，放马西行。（正文首段）

[3] （正文段……）

::: 回末对
[41] 正是：笑语温言施毒手，路旁吓煞锦城侯。
:::

::: 回末
[42] 欲如后事如何？请听下回分解。
:::
```

要点：回目行 `# [0]` 不围栏；章首词整体一个 PN、围栏含署名行；上阕/下阕间空行保留在围栏内；回末对与回末套语是**两个块、两个 PN、两种围栏**；围栏块消耗一个顶级编号，正文编号跨围栏连续递增。

### 2.2 回目行约定

**定版**：回目行 = `# [0] 第N回　回目对句`，与 shiji 篇名 `[0]` 同构。回目对句**不切 PN、不围栏、不标实体符号**。

理由：

1. 回目行身份是**标题优先**——它参与目录、检索、回目页导航，史记经验（标题存储时清理实体标记、标题不含段号）直接适用；
2. 回目对句虽是韵文（对句体），但其文学性由**回目元数据**承接：以全角空格为界拆分句，前半归上联、后半归下联（实测格式 `第一回　铁矢神弓　少年扶巨宦　金鞍宝马　大盗震虚声` 拆为 2+2 四分句）。拆分结果存回目元数据供回目页对句展示，不写进标注文件；
3. 回目预告不抽事件（01g 负规则十三），标注收益仅剩专名识别——而回目中的人名多为绰号式预告（"少年""大盗"），实指密度低，收益不抵对导航数据的污染。

⚠️ 分句数为 2 或 4 视为常态；出现 3/5 分句（个别书目回目变格）不判错，进存疑清单（待试点校准）。

**正误对照**（改编样本甲）：

```markdown
❌ 错误（对句切 PN、围栏、标实体）：
# [0] 第一回　铁矢神弓　少年扶巨宦　金鞍宝马　大盗震虚声
[1] 〖@少年〗扶巨宦　[2] 大盗震虚声
::: 对联
[3] 铁矢神弓，金鞍宝马
:::

✅ 正确：
# [0] 第一回　铁矢神弓　少年扶巨宦　金鞍宝马　大盗震虚声
（回目元数据：上联=铁矢神弓/少年扶巨宦，下联=金鞍宝马/大盗震虚声；行内零标注）
```

### 2.3 章首词约定（容缺设计）

**定版**：

- `[1]` 恒定义为**回目后第一个文本块**，无论其是章首词还是正文首段；
- 该块若判定为韵文（支路 A/B，见第五章）→ 加 `::: 词`（长短句）或 `::: 诗`（五七言/四言整齐）围栏，**整体一个 PN**，词牌署名行（"——调寄沁园春"）入围栏末行、不单独编号；若章首即**民歌/口语化短句韵文**且有"歌/唱/吟"引出信号或旧稿先例，可加 `::: 歌`（§4.1 `歌` 型；允许≠强制，信号不成立一律不围）；
- **E13 章首围栏类型**（2026-11-05 设计补正）：由 `{词,诗}` 扩为 `{词,诗,歌}`——先例《塞外奇侠传》001 回"玫瑰花开像云霞……"民歌五句，旧稿即 `::: 歌`；本次起 `lint_purple_numbers.E13_HEAD_FENCES` 同步放行 `歌`。其余类型仍不得出现在章首 `[1]`；
- 该块若为散文叙事 → 不围栏，`[1]` 就是正文首段。**无章首词不补写、不占位**（样本丁为常态而非异常）；
- 词内**不逐句编号**：上阕/下阕以空行分隔（围栏内允许且仅允许这类结构性空行），阕间空行不得切断围栏。

**正误对照**（样本丁，无章首词）：

```markdown
❌ 错误（把首段叙事误围为词，或给无词回留空占位）：
# [0] 第一回　一女独寻仇　十六年间经几劫　群雄齐出手　五台山上震三军
::: 词
[1] 山西五台山是著名的佛教圣地，其上的清凉寺，据说是东汉时所建……
:::
[1] （空占位）

✅ 正确：
# [0] 第一回　一女独寻仇　十六年间经几劫　群雄齐出手　五台山上震三军

[1] 山西五台山是著名的佛教圣地，其上的清凉寺，据说是东汉时所建……
```

### 2.4 回末约定：对句与套语分块

**定版**：回末结构=两个独立块（样本丙裁决）：

1. **回末对**：行首"正是："引出的对仗两联 → `::: 回末对` 围栏 + 独立 PN。块类型=对联，文本模式=诗词；渲染居中；实体按 §4.4 韵文规则；**不抽事件**；
2. **回末套语**："欲知/欲如后事如何？请听下回分解。"式段落 → `::: 回末` 围栏 + 独立 PN。块类型=回末套语，文本模式=套语（新增枚举值，见 §4.1 说明）；渲染弱化（灰斜体右对齐）；**不抽事件、不计正文分母**。

**为什么不是一个块**：对句是韵文（进韵文统计与"说书人专栏"引用池），套语是纯结构公式（负规则十三过滤对象）——二者下游消费完全不同，合并会使韵文统计混入公式文本、分母过滤误伤对句。

**为什么套语也要围栏**：不围栏则套语落在"正文段"，04f 的"回末不抽事件"就只能靠词表逐条排查；围栏把负规则十三的执行机制化。

**正误对照**（样本丙）：

```markdown
❌ 错误一（合并一块）：
::: 回末
[41] 正是：笑语温言施毒手，路旁吓煞锦城侯。
欲如后事如何？请听下回分解。
:::

❌ 错误二（变体改字）：
::: 回末
[41] 欲知后事如何？请听下回分解。
:::
（原文是"欲如"，检测词表漏了它，标注时"顺手改对"——违反可逆性）

✅ 正确：
::: 回末对
[41] 正是：笑语温言施毒手，路旁吓煞锦城侯。
:::

::: 回末
[42] 欲如后事如何？请听下回分解。
:::
```

⚠️ 容缺：个别回无回末对（直接套语收尾）或无回末套语（散文收尾）均为合法变体；lint 对套语缺失给 warning 而非 error（实测 27/32 回有套语）。

### 2.5 回中即兴诗词与武功口诀

- **回中即兴诗**（人物即席吟唱完整四句/两句）：正式类。五七言整齐 → `::: 诗`；口语化、句长不齐、有"歌曰/唱道/吟道"引出 → `::: 歌`。整体一 PN；
- **回中对句**（回中"正是："评点引出、厅堂楹联、门上对联独立成段）：`::: 对联`，正式类；位置判据见 §5.5；
- **武功口诀全文**：`::: 口诀` 设为**观察类**——实测"传了口诀"式叙述提及为主、全文极罕见，正式启用前先在试点期登记每一次出现，校准触发特征与频级后再决定是否晋升正式类（晋升标准进附录 B）；
- **叙述提及不围栏**："他传了口诀""将剑法精要说了"是正文叙事，禁止见"口诀"二字就围栏。

**正误对照**：

```markdown
❌ 错误：她传了掌法口诀，又拆解了三十六路变化。
   ::: 口诀
   [17] 她传了掌法口诀……
   :::
   （叙述提及被围栏——围栏的是"口诀全文"，不是"提到口诀"）

✅ 正确：她传了掌法口诀，又拆解了三十六路变化。   （纯正文段）

✅ 正确（确有全文时）：
::: 口诀
[17] 气沉丹田，意守玄关；手随身动，步随身换……
:::
```

### 2.6 多书编号体系

- **每部书独立回号**：回号从 1 起、本书内连续；"把全宇宙的第三回当成一个唯一回目"是错误（01g 定位规则），一切定位必须作品 ID + 回号联合（§3.5 锚点）；
- 34 部书各自成目录 `{作品ID}/`，回文件 `r001.md … rNNN.md`；书目间共享宇宙（人物跨书）不产生结构层耦合，跨书关系由实体层处理；
- 部书内回数不等（几十回至百馀回），回号一律三位零补（`r007`），保证文件系统排序。

## 三、Purple Numbers 武侠版

### 3.1 编号语法

**定版**：沿用史记层级点分格式，**武侠版只用两级**（`[N]`、`[N.M]`），**禁用三级**。

```
[0]      回目行（固定，每回文件恰一个）
[N]      顶级块（正文段或围栏块，回内从 [1] 连续递增）
[N.M]    子段（仅对话拆分时产生，见 §3.4）
```

理由：史记三级编号服务于八书十表的结构性章节；武侠一回是均质叙事流，结构层次已由**围栏类型**（词/诗/书信…）承担，再开三级只会制造无消费方的深度。史记 026 历书"三级转二级"的返工教训（参考件三）不应重演。

**格式要求**（继承）：方括号包裹、纯数字点分、行首紧跟一空格；❌ `[1.a]` ❌ `[一]` ❌ `[1-2]`。

### 3.2 父子、连续、不可变

- **父子关系**：有子必有父。对话拆分产生的子段，父编号独立一行（可空内容）：
  ✅ `[3]`（空父）+ `- [3.1] …` + `- [3.2] …`；❌ 无 `[3]` 直接 `[3.1]`；
- **同层连续**：`[1]→[2]→[3]` 不跳号；`[3.1]→[3.2]` 不跳号；
- **不可变性**：PN 一旦分配永不更改（史记教训第一条）。后续插段用子编号，不改已有编号：

```markdown
[5] 原有段落
[5.1] 后续插入的段落（新增）
[6] 原有段落（编号不变）
```

- **回内重置**：PN 在回文件内从 `[0]` 重新计数——跨回唯一性由锚点的回号层保证（§3.5），不采用全书连续编号（那样每插一段即引发后续全回重编，与不可变性正面冲突）。

### 3.3 围栏块与 PN

**定版**：每个围栏块**恰有一个 PN**，位于围栏内容首行行首；围栏内不得出现任何其他 PN；围栏块消耗一个顶级编号，正文编号跨围栏连续递增（§2.1 模板中回末对 [41]、回末 [42]）。

类推 shiji 赞规则（太史公赞韵文整体一编号、不按行拆分）的理由：围栏内容不进正文事件分母，段落级引用需求低；韵文逐句编号反而诱导下游把诗行当叙事段消费。

⚠️ 长信多段同理：**整信一 PN**，信内分段只用空行，不编子号。这是有意取舍——牺牲信内段落级锚点，换取"围栏=一个不可分语义块"的全局简单性；信内定位需求由锚点+信内关键词检索承接。

### 3.4 对话拆分裁决（白话长段）

史记规则"多人对话每句独立编号"在白话武侠中**收紧适用**：

- **默认不拆**。梁书对话与动作高度交织（"王照希一怔，道：……"），"X曰："式的干净拆分边界基本不存在，机械拆分会切碎"说—动—说"结构；
- **仅当**：纯对话段（无动作插入）∧ 不同说话人 ≥3 轮 ∧ ≥500 字，才拆为列表项子编号（拆分时保持原文引号层级，单引号不得升双引号——继承史记嵌套引号铁律）；
- 阈值（3 轮/500 字）**待试点校准**；拆错方向是"漏拆"，漏拆不违规（拆分本就是可选优化），错拆才违规。

**正误对照**：

```markdown
❌ 错误（对话与动作交织仍硬拆）：
[7]
- [7.1] 〖@玉罗刹〗冷笑一声，道："好一个名门正派！"
- [7.2] 〖@王照希〗按住剑柄，说道："姑娘此言差矣。"
- [7.3] 两人在崖边对峙，山风猎猎。   ← 叙事句混入对话列表

✅ 正确：整段保持 [7] 一个 PN 不拆（叙事句与对话共段，非纯对话段）。

✅ 正确（确属纯对话长段时才拆）：
[9]
- [9.1] 〖@岳鸣珂〗道："师兄以为如何？"
- [9.2] 〖@卓一航〗道："师兄以为，此事还需从长计议。"
```

### 3.5 跨书 PN 锚点

**定版**：机器锚点 = `{作品ID}#pn-r{回号}.{X}[.{Y}]`。回号以 `r{N}` 作为锚点最外层——因为 PN 回内重置，无回号的 `#pn-3.1` 在 1,378 回里歧义无穷；`#pn-` 前缀保持与史记同一套 ID 体系（全系统只允许这一套）。

| 定位对象 | 机器锚点 | 人类定位符 |
|---|---|---|
| 回目 | `baimofanzhuan#pn-r1.0` | 白发魔女传 1:0 |
| 回内顶级段 | `baimofanzhuan#pn-r1.41` | 白发魔女传 1:41 |
| 对话子段 | `baimofanzhuan#pn-r1.9.2` | 白发魔女传 1:9.2 |
| 段区间（同回） | `baimofanzhuan#pn-r2.23~25` | 白发魔女传 2:23-25 |

- **书名 vs 作品 ID**：锚点主体用**作品 ID**（slug，唯一、稳定、URL 安全）；中文书名（"白发魔女传 2:23"）是人类展示层，站点层做别名映射（映射责任在站点，见附录 B）；
- **与 01g 定位符字段换算**：01g 的（书,回,段,区间）四元组 ↔ 锚点逐位对应：书=作品 ID、回=`r{N}`、段=`{X}.{Y}`、区间=`~` 连接；
- **与 01g §9.8 页面消费对接**：人物档案/问答证据引锚点；回目页取 `#pn-r{N}.0` + 回目元数据；阅读器渲染按块类型；节奏指纹按正文分母（§9.2）逐 `r{N}.{X}` 聚合；
- **示例**：问答答案写作"依据 `baimofanzhuan#pn-r1.41`（第一回回末对）"。

## 四、围栏类型体系

### 4.1 枚举定版表

语法沿用 Pandoc Fenced Div：`::: 类型` 开、`:::` 独立行收；标签渲染为 tooltip 而非标题（继承史记设计决策）。**正式类 7 种 + 观察类 3 种**：

| 围栏类型 | 块类型 | 文本模式 | 触发特征 | 渲染语义 | 标注豁免边界（细则 §4.4） | 实测频级 |
|---|---|---|---|---|---|---|
| `词` | 词 | 诗词 | 长短句韵文（章首词/回中填词），可带词牌署名行 | 居中、硬换行、阕间空行保留 | 实体限实指；动词不标 | 高频正式（章首词容缺） |
| `诗` | 诗 | 诗词 | 五七言/四言整齐韵文（章首开卷诗/回中成段诗） | 居中、硬换行 | 同上 | 低频正式 |
| `歌` | 歌 | 歌词 | "歌曰/唱道/吟道"引出、句长口语化不齐 | 居中、硬换行 | 同上 | 低频正式 |
| `对联` | 对联 | 诗词 | 回中独立成段对句：楹联/门联/"正是："回中评点对 | 居中对联样式 | 同上 | 低频正式 |
| `回末对` | 对联 | 诗词 | 行首"正是："+对仗两联，且回末位置 | 居中 | 同上 | 高频正式 |
| `回末` | 回末套语 | 套语 | 回末套语词族（§6.2 强信号） | 弱化（灰斜体） | 全不标 | 高频正式（容缺） |
| `书信` | 书信 | 书信 | 成段书信/密函全文（称谓起、落款收） | 信笺样式 | 实体可标；事件不核实 | 低频正式 |
| `告示` | 告示 | 告示 | 榜文/檄文/朝廷文书独立成段 | 文书样式 | 同书信 | 观察类 |
| `口诀` | 口诀 | 口诀 | 武功口诀**全文** | 口诀样式 | 技术名可标（01g FAQ Q14） | 观察类（全文罕见） |
| `说书` | 说书旁白 | 套语 | "看官"式说书插入语独立成段 | 旁白样式 | 可标；不抽事件 | 观察类（实测 1 次） |

📌 **文本模式枚举说明**：01g 最低枚举（正文/回目/诗词/歌词/口诀/书信/告示）**只增不减**；本文新增"套语"一类承载回末套语与说书旁白——若套语归"正文"，04f 负规则十三的过滤就退化为词表逐条排查，分母必被污染。此为对 01g 的**扩展而非冲突**。无围栏叙事段：块类型=正文段、文本模式=正文。

**候选类型取舍**（实测裁决，禁止照搬任务清单假设）：

- ❌ **"有诗为证"引语**：实测 0 次，不设类型（水浒型说书套语在梁书缺位）；
- ❌ **回目对联围栏**：回目行是标题层（§2.2），对句文学性由回目元数据承接；
- ✅ **密函并入 `书信`**：密函=私信公文，触发、渲染、可信状态处理与书信同构，不另设类型；
- ✅ **告示/口诀/说书设观察类**：存在但低频/罕见，正式晋升走试点数据（附录 B）。

**观察类语义**：枚举保留、试点期遇真实案例才启用并逐例登记；观察类内容**暂不计入**正式统计口径，晋升评审通过后回溯。禁止批量预围栏。

### 4.2 围栏通用铁律

1. **围栏必须成对闭合，且不跨回**（一回一文件，即不跨文件；若启用 `##` 可选层，围栏还须在标题前关闭——继承史记"区块不跨节"）；
2. **围栏不嵌套**：信中附诗、词前小序等一律并入宿主围栏类型，不另开内层围栏；
3. **围栏整体一 PN**（§3.3）；
4. **围栏内禁半角标点**（继承史记赞文排版检查精神）；
5. **可逆性**：剥除 PN 与围栏行后必须逐字符还原锁定底本——标注只增不删改，包括"欲如"这类疑似讹字**一律保留原样**。

### 4.3 行内引语与成段围栏的分流规则

实测：书信多为行内引语（样本乙），楹联多见于叙述句内。分流三判据（书信/对联/诗通用，**全部满足才围栏**）：

1. **成段**：引文独立成段（前后有空行），不是嵌在叙述句内的引号片段；
2. **完整**：书信有称谓与落款两端，或对联/诗是完整两联/完整篇章，非截引；
3. **自称文体**：去除引文后叙述句仍自足成立（引文是"插入物"而非句子的宾语成分）。

**正误对照**（样本乙）：

```markdown
❌ 错误（行内引语整体围栏）：
::: 书信
[8] 〖@王照希〗拆开岳父的信一看，信的前半段是催他赴京迎亲，后半段却说：
"京中武师，暗斗极烈，尤以宫廷之内，险象环生，望贤婿速来，愚正有事相商也。"
:::
（判据 1/3 均不满足：引文嵌在叙述句内，剥除引文后叙述句不自足）

✅ 正确：
[8] 〖@王照希〗拆开岳父的信一看，信的前半段是催他赴京迎亲，后半段却说：
"京中武师，暗斗极烈，尤以宫廷之内，险象环生，望贤婿速来，愚正有事相商也。"
（不围栏。段落文本模式=正文；引语的叙述模式按 01g"转述"处理；信中声称的内容
后续由实体/事件层按负规则十二降权，结构层只负责"不成段不围栏"）
```

成段长信 ✅ 示例（判据全满足）：

```markdown
::: 书信
[15] 贤婿台鉴：京中风云突变，宫廷之内暗斗极烈……（正文）

愚舅某某手书　某年某月
:::
```

⚠️ 边界：引文跨段但叙述句在中间续接（"信中又说：……"第二段引文）→ 整体仍属行内引语链，不围栏；只有叙述彻底退出、引文自成段落序列时才围栏（存疑进清单）。

### 4.4 围栏内标注边界细则（"围栏内不标注"的武侠版细化）

史记版"围栏内不标注"是粗粒度铁律；01g 原则零已定"文学内容不机械豁免"，本文细化为**三层规则**：

| 围栏类型 | 实体层（15 类符号） | 动词/事件层 | 结构层 |
|---|---|---|---|
| 词/诗/歌/对联/回末对 | **实指明确**的人物/门派/兵器/地名/作品可标；**意象泛指不标**（"魔影""剑光""浮云"） | **一律不标**（负规则十一：意象不当事实） | 围栏行与 PN 本身不标 |
| 回末 | 不标（无实指内容） | 不标（负规则十三） | — |
| 书信/告示 | 明确专有名可标；称谓/代词（"愚兄""贤婿"）不标 | 信内动词不标；信中声称的事件**不核实**，来源与可信状态由实体/事件层保留（负规则十二） | — |
| 口诀（观察类） | 技术名/招式名可标（对接 01g FAQ Q14） | 不标 | — |
| 说书（观察类） | 可标 | 不标 | — |

**正误对照**（改编 01g 负规则十一）：

```markdown
❌ 错误（意象当事实、诗行逐句编号）：
::: 诗
[20] 剑光如电斩浮云，[20.1] 千军辟易胆气豪。   ← 逐句编号 + "斩浮云"登记斩杀事件
:::

✅ 正确：
[20] 〖@玉罗刹〗朗声吟道：
（宿主引出句留在正文，动词层按 04f 标注，不入诗栏）

::: 诗
[21] 剑光如电斩浮云，千军辟易胆气豪。
:::
（诗整体一 PN；"斩"不标事件层符号，"浮云"是意象不标实体）
```

📌 正文段的动词层由 04f 符号（⊞⊠⊡⊟▣■）标注，本文不重复定义；本文只裁决**围栏内动词层不标/受限**这一边界。

## 五、韵文·词牌·对联检测

### 5.0 前置：文本清洗（规则，非代码）

检测前必须清洗候选文本，否则句长统计全错（史记教训：标注符号使 95% 韵文误判散文）。清洗序：

1. 剥除 PN 标记（`[N]`/`[N.M]`）；2. 剥除实体标记（`〖T 文本〗`→`文本`）；3. 剥除围栏行；4. 只保留汉字与中文标点。句界标点集 = `，。；！？：…`——**"？"计入句切分且不扣分**（词中夹问是常态，见 §5.3）。

### 5.1 合成决策树（文字化）

史记 verse_score 只认四言整齐句，长短句词牌必漏检（样本甲沁园春实测）。武侠版为**三支路合成决策树**（纯文字描述，不写代码）：

```
输入：候选文本块 + 上下文（位置：章首/回末/回中；前段后段）
第 0 步  预清洗（§5.0）
第 1 步  信号定位：
   a. 有词牌署名行（"调寄 X/右调 X"）→ 直入支路 B，署名计加分
   b. 行首"正是："           → 直入支路 C
   c. 候选块首为 但见/只见/却见 → 照常入支路 A，但触发降权（§5.2）
   d. 其余 → 按支路 A → B → C 顺序评分
第 2 步  支路 A 评分 → ≥0.6 → 韵文
第 3 步  支路 B 评分 → ≥0.6 → 韵文
第 4 步  支路 C 评分（先过门槛）→ ≥0.6 → 对句
第 5 步  0.4–0.6 → 存疑清单（人工裁决）；<0.4 → 散文
第 6 步  类型归派（韵文内部定 词/诗/歌/对联/回末对，§5.5）
```

### 5.2 支路 A：四言整齐（继承 verse_score 评分规则与阈值）

对清洗后**整组**文本按标点切句、统计句长分布：

| 条件 | 得分 |
|---|---|
| 四字句占比 > 50% | 0.95 |
| 3-5 字句占比 > 70% | 0.80 |
| 4-7 字句占比 > 70% | 0.70 |
| 平均句长 6-8 且句长方差 < 2.0（五言/七言诗：句长整齐） | 0.75 |
| 平均句长 > 10（明确散文） | 0.10 |
| 其他 | 0.30 |

**整组投票防御**（武侠新增，针对白话四字节奏）：判定以组为单位，候选组须 ≥2 行且 ≥6 句；单行四字串（≤5 句）不得直接判韵文——章回白话的"剑光闪闪，人影幢幢"式双音节词叠加是高频散文陷阱（史记"荆王王也，由汉初定"同型）。组内 verse_score 均值 > 0.6 → 韵文。

**引出词降权**：候选块首为 但见/只见/却见 时，支路 A 判定阈值上调至 ≥0.8 且须 ≥3 行（待试点校准）——这是 §6.2 伪信号规则在检测器的落点。

**正误对照**：

```markdown
✅ 正确（回中人物引前人诗，五言整齐 → 判韵文）：
[30] 十年磨一剑，霜刃未曾试。今日把示君，谁有不平事？
（句长全 5、方差 0 → 0.75 ≥ 0.6 → 韵文 → 归派"诗"）

❌ 错误（散文四字节奏误判韵文）：
::: 诗
[31] 但见剑光闪闪，人影幢幢，杀气腾腾。    ← 单行 3 句四字，整组投票不过 + 引出词降权
:::
（正确做法：保持 [31] 为正文段，句内四字串是描写套语）
```

### 5.3 支路 B：长短句词牌（新造）

四成分评分（无署名时也可达标——实测"调寄"仅 1 次，署名只作加分信号，不可依赖）：

| 成分 | 判据（清洗后） | 分值 |
|---|---|---|
| 长短句形态 | 全部句长 ∈ [2,9]、句长极差 ≥ 3、平均句长 ≤ 7 | 0.30 |
| 押韵 | 同阕内偶数句尾字落在同一韵组（容忍邻韵），押韵句占比 ≥ 1/2 | 0.30 |
| 阕对称 | 分两段时两段句长序列相似度 ≥ 0.7；单段长词按分句节奏重复性判断 | 0.20 |
| 词牌署名 | 独立署名行（"——调寄沁园春"式） | +0.20 |
| 章首位置 | 候选块为 `[0]` 后第一块 | +0.10 |

阈值 ≥ 0.60 → 词（待试点校准）。韵组表选用与维护属实现层决定，本文只定"同韵组配对"规则本身。

📌 **计分方式注记（自 v2 回收）**：上表"成分分+加分制"存在等价的归一加权表述——`0.4×长短句形态 + 0.4×押韵 + 0.2×(阕对称/署名)`，综合 ≥0.55 判词。两种表述是同一裁决的两种实现口径，试点校准时二选一定版，不得双轨并用。

**词中夹叙夹问防御**：问句号计入句界、不扣分——样本甲上阕"可得分明？是魔非魔？非魔是魔？"切句后均为 3-5 字句，长短句形态与押韵成分照常得分，**不得因问句密集降判散文**。

**正误对照**（样本甲）：

```markdown
✅ 正确：章首块"一剑西来……墨泼南溟。"+署名"——调寄沁园春"
   → 长短句形态(0.30) + 押韵(0.30) + 阕对称(~0.2) + 署名(+0.2) → 判"词"，围栏 ::: 词，
   署名行入围栏末行，整体 [1]。

❌ 错误：同一块因上阕连用问句、句长 3-7 字不等，被四言支路(支路 A)判 0.30 → 误归散文、不围栏
   （这正是史记版 verse_score 单支路的必漏检场景，武侠版必须走支路 B）。
```

### 5.4 支路 C：对联

**门槛**（全部满足才进入评分，白话对仗描写的第一道闸）：

1. 候选块为独立短段（≤2 行）；2. 块内无叙事框架成分（无第三人称主语引导的动作句）；3. 分句数 = 2（单联）或 4（两联式）。

**评分**：

| 成分 | 判据 | 分值 |
|---|---|---|
| 字数相等 | 上下句去标点后字数相等（**必备条件，不满足直接出局**） | — |
| 对仗 | 首二字+尾二字词性对应抽查，宽对即可 | 全对 0.6 / 宽对 0.4 / 不对 0.1 |
| 引出/位置 | 行首"正是：" +0.20；回末位置 +0.10；楹联语境词（"壁上/柱上/门旁"+联字样）+0.20 | 最高 +0.4 |
| 平仄 | 不检测（白话章回联多宽对，平仄苛检无益召回） | 0 |

阈值 ≥ 0.60 → 对句（待试点校准）。

**正误对照**（样本丙 vs 正文对仗描写）：

```markdown
✅ 正确：[41] 正是：笑语温言施毒手，路旁吓煞锦城侯。
   （门槛过：独立短段无叙事框架；字数 7=7；宽对 0.4 + "正是"+0.2 + 回末+0.1 = 0.7 → 对句）

❌ 错误：[32] 他剑法迅捷，身法灵动。
   （字数 4=4 且词性工整，但有主语"他"的叙事框架 → 门槛第 2 条不过，不进评分，
   保持正文段。若放行，正文里的对仗描写会被批量误围。）
```

### 5.5 类型归派规则

韵文判定成立后，按以下决策树归派围栏类型：

```
1. 回目行                       → 不围栏（回目模式，§2.2）
2. 章首块：支路 B 强             → 词
          支路 A 五七言/四言整齐 → 诗
3. 回末位置 + 行首"正是："       → 回末对
4. 回中：有 歌/吟/唱 引出词或句长口语化不齐 → 歌
        五七言/四言整齐          → 诗
        长短句（有/无署名）      → 词
        支路 C 对句              → 对联
5. 诗/歌两可                    → 诗（保守归派：两者统计口径相同，渲染差异小）
6. 书信/告示宿主内附诗           → 不另围栏，随宿主（§4.2 铁律 2）
```

## 六、结构套语信号词表

### 6.1 分级框架

词表是系统盲区的兜底（前人实验结论四），但**词面匹配 ≠ 结构判定**。分级三档 + 一个监视层：

- **强结构信号**：单信号即可触发结构动作（围栏、分块）；
- **弱信号**：必须第二确认信号成立才动作，否则只登记候选；
- **伪信号**：默认**不触发任何结构动作**，仅当上下文裁决（后接独立成段韵文/对联）时进入检测流程；
- **缺位监视**：水浒型套语实测 0 次，词表不收录，但试点期跨书扫描，出现即回填。

### 6.2 分级种子表（实测=《白发魔女传》32 回 grep）

| 词族（归一形） | 级别 | 结构含义 | 第二确认信号 | 实测频次 |
|---|---|---|---|---|
| `第N回`（行首） | 强 | 回目行标志 | 行首 + 章回号模式 | 32/32 |

| `正是`（行首） | 弱 | 对句引出词 | 后接对仗两联（支路 C 过门槛） | 31 |
| `调寄/右调 + 词牌名` | 弱 | 词牌署名 | 前接韵文候选块 | 1 |
| `且说`（行首） | 弱 | 场景/叙事线切换候选 | §7.3 双转移判定 | 29 |

### 6.3 变体归一规则（欲知/欲如）

**按词族收录，不按字面收录**。词族 = 固定框架 + 可替换槽位：

- 回末套语词族（实现口径，`scripts/symbols.py` 的 `TAOYU_HEAD_RE`/`TAOYU_TAIL_RE`）：头 `欲[知/如/看]` + 0-24 字槽位，尾 `[请听/且听/且看/要知]?下回[分解/再/见]?`；
- 检测层按词族模板匹配（槽位全枚举）；统计与 lint 按归一词族名（"回末套语"）；
- 归一方向：以高频形式"欲知后事如何"为词族规范形，"欲如/要知/请听下回"等登记为在册变体；试点期发现新变体即回填词族表并记版本日志；
- **2026-11-05 单源对齐**：生成器（`generate_pn_wuxia.py` 经 `detect_verse_wuxia.py`）与 lint E12 原先各持一套正则（lint 窄、生成器宽），导致新增回末围栏被 E12 误报；现已统一为 `symbols.TAOYU_*` 单一来源，E12 直接调用 `symbols.is_taoyu()`。对齐后 5 书 E12 告警行数 127→95（白发 9→3、江湖 21→3、七剑 15→7；塞外/冰魄余量为"无回末栏"容缺，非误报）。

**正误对照**：

```markdown

   → lint E12 连环误报"回末套语缺失"，标注员被迫手改原文 → 违反可逆性。
```

### 6.4 引出词三兄弟（正是/调寄/看官）

- **正是**：只做"引出词"，本身不是块——后接内容过支路 C 才围栏；回中出现同样处理（归派§5.5 第 3/4 条按位置分流）；
- **调寄**：署名行信号，入围栏末行不单独编号（§2.3）；无韵文块可附时（孤立"调寄 X"行）→ 存疑清单；
- **看官**：说书旁白候选，须独立成段才考虑 `::: 说书`（观察类）；句中出现（"看官须知，……"嵌在叙述里）不围栏。

## 七、场景小节与叙事线

### 7.1 裁决：`##` 场景小节降级为可选层（默认不生成）

**结论**：v1 骨架**不生成** `##` 小节；作为可选增强层预留规范（§7.2），试点后按判据决定是否回补。

理由：

1. **标题来源不可靠**：史记自动小节标题准确率约 60% 且靠"曰/年/战"类关键词；武侠回内场景靠"且说 X"硬切（"花开两朵"式显式分节套语实测 0 次），切点是场景边界而**非主题标题**，启发式命名质量必然更差；
2. **导航需求有替代**：回目页上下回导航 + 阅读器锚点已覆盖主需求；"回内某场景"粒度的问答需求属推测，未见数据支撑；
3. **后补不伤骨架**：`##` 标题不占 PN 号、不移动既有锚点——这是降级而非放弃的关键：先上线 PN+围栏，`##` 永远可以无损回补；
4. **MAX_SECTIONS_PER_CHAPTER=15 不构成障碍**：一回 1.2 万字约 2-5 个场景，15 上限够用；参数不是放弃的原因，标题来源才是。

**section_extract 类工具失效的替代**：场景导航候选由"套语驱动切换点"数据承接（§7.3 的判定输出：行首且说/却说 + 双转移成立的段号清单），按回导出供阅读器"跳到下一场景"实验；若试点证明问答/导航定位大量落在场景粒度（判据进附录 B），再按 §7.2 启用 `##` 层。

### 7.2 若启用：预留规范（约束先行，防回补时返工）

- 小节标题**不含编号、不含实体符号**（继承史记清理规则）；anchor 取该节第一个 PN；
- 标题来源 = 套语驱动候选边界 + **人工命名**（自动建议仅作草稿）；
- 小节边界优先取叙事线切换点；**一节内叙事线 ID 应唯一**——不唯一则不设小节；
- 一回小节建议 2-6 个，上限 15（沿用参数，待试点校准）。

### 7.3 叙事线 ID 的切换信号

叙事线 ID 是 01g 结构层字段，标注在**段落层**，不依赖 `##` 存在。切换判定（文字决策树）：

```
必要条件：行首"且说/却说"（回内；回首段不构成切换——回界本身即边界）
第二确认（至少两条成立）：
  a. 主人物集变化（前段主要人物不在本段前 20 字内）
  b. 地点转移（新地名/方位词出现）
  c. 时间推进标记（数月/次日/是夜/翌日……）
两条成立 → 叙事线切换成立；一条 → 存疑清单；零条 → 仅是行文衔接，不切换。
（阈值待试点校准；判定输出同时是 §7.1 场景候选数据）
```

**正误对照**（样本戊）：

```markdown
✅ 正确：[18] 且说〖@王照希〗读信之后，与〖@玉罗刹〗告辞，匆匆赴京，
   在路上走了数月，到了〖=京师〗，已是初春。
   （行首且说 + 人物转移 + 地点转移 + 时间推进 → 切换成立，本段起叙事线 ID 更新）

❌ 错误一：众人且说且行，不觉已到山下。   ← "且说"不在行首，非信号
❌ 错误二：把样本戊段判为"回忆"——且说推进的是当前主线，叙述模式仍是正常叙事
   （叙述模式是 01g 字段，切换信号不得混淆两类标注）
```

- 一回双线并行（两线交替推进）：PN 顺序=文本顺序，**与叙事线无关**，交替不破坏 PN 连续性；叙事线 ID 随段交替取值即可；
- 跨回连续叙事（上回末"欲知后事"与下回首段衔接）：PN 回内重置无冲突；叙事线是否跨回延续由 01g/04a 规则定，结构层不阻拦。

- 打斗/杀伐/传艺密度曲线 = 04f 触发词计数 ÷ 对应回正文分母（04f"数触发词，不数回合与实体"）；
- **韵文提及不计入打斗密度**（04f FAQ Q14）：`::: 诗` 块整块不计；宿主引出句（"朗声吟道："）在正文分母内，但其动词非打斗触发词，天然不影响；
- 套语段（文本模式=套语）既不进分母也不贡献触发词——这是新增"套语"枚举值的直接收益。

### 9.3 "不得臆推"红线清单（对接 01g/04f）

1. 回目预告不生成事件：回目对句中的"杀""震""扶"不是事件（负规则十三）；
2. 回末套语不抽事件："欲知后事如何"不生成下一回事实（负规则十三；04f 错误模式继承）；
3. 韵文意象不当事实：诗中"剑斩浮云"不登记斩杀（负规则十一；§4.4 围栏内动词层不标）；
4. 书信内容不自动核实：信中声称身亡不生成确定死亡（负规则十二；§4.4）；
5. 观察类围栏内容暂不入正式统计（§4.1），晋升前不得作为事件来源；
6. 检测存疑（0.4-0.6 灰区）不得自动定案——进存疑清单（§8.2）。

### 9.4 结构规则变更治理（简化三步）

1. **分级**：甲类=纯文档文字修订（不影响已产 PN/围栏判定）→ 直接修订版本文档；乙类=影响标记产出的变更（新增围栏类型、阈值改动导致判定翻转、编号规则调整）→ 进入第 2 步；
2. **迁移与回归**：抽样 ≥3 部书 30 回重放新规则 → 产出 diff 报告；若 PN/围栏标记变化，生成**旧锚点→新锚点映射表**随版本发布（站点层据此重定向）→ 全量 lint 回归清零；
3. **公告与冻结**：发布变更说明，7 天下游回归窗口（01g/03a/04f/04a 消费方确认），期间冻结新书回标注；窗口结束旧版本存档。

## 十一、错误模式库（首批 S01-S15）

**S01 围栏未闭合/跨回** — 错误模式：`::: 词` 开栏后接下一回内容或文件尾。正确做法：每栏在回文件内闭合，跨回内容断开分栏。典型语境：章首词与第一段叙述间漏 `:::`。

**S02 围栏内多 PN** — 错误模式：词文逐阕/逐句编号（`[1]`…`[1.13]`）。正确做法：整体一 PN 在内容首行（§3.3）。典型语境：照搬逐行韵文习惯。

**S03 长短句词被判散文** — 错误模式：沁园春式章首词因句长 3-7 不等、四言支路 0.30 分而漏检不围栏。正确做法：走支路 B（长短句+押韵+阕对称）。典型语境：样本甲型开篇；检测器只有四言单支路时必漏。

**S04 "但见/只见"描写串误围栏** — 错误模式：`::: 诗 [N] 但见剑光闪闪，人影幢幢……:::`。正确做法：正文段（§5.2 整组投票+降权、§6.2 伪信号）。典型语境：打斗场面高频词叠加。

**S05 回目对句被切 PN/围栏** — 错误模式：`[1] 铁矢神弓 [2] 少年扶巨宦` 或 `::: 对联` 包回目。正确做法：回目行零标注，对句入回目元数据（§2.2）。典型语境：把回目当韵文块处理。

**S06 回中"正是："误标回末对** — 错误模式：回中评点对句因"正是"行首直接归 `回末对`。正确做法：先核位置——回末两段内才可归回末对，否则归 `对联`（§5.5）。典型语境："正是：英雄出少年，宝剑赠烈士。"出现在回中转折处。

**S07 回末对与套语合并一块** — 错误模式：`::: 回末 [41] 正是：…… 欲如后事……:::`。正确做法：两块两 PN 两围栏（§2.4）。典型语境：样本丙型回末。

**S08 变体漏检连环误报** — 错误模式：词表只有"欲知"字面 → "欲如"漏检 → E12 误报 → 标注员改原文。正确做法：词族模板收录变体，原文永不动（§6.3）。典型语境：全部 34 部书推广时新变体频发。

**S09 行内书信引语整体围栏** — 错误模式：样本乙整段包 `::: 书信`。正确做法：三判据分流，不成段不围栏（§4.3）。典型语境：书信引语嵌叙述句。

**S10 成段长信漏围** — 错误模式：多页长信被当多段正文编号、进正文分母。正确做法：三判据成立即整信一 PN 围栏（§3.3/§4.3）。典型语境：密函、万言书独立成段序列。

**S11 无章首词回的 [1] 错位** — 错误模式：给叙事首段围 `::: 词`，或给缺词回留空 `[1]` 占位。正确做法：`[1]` 恒为回目后第一个文本块（§2.3）。典型语境：样本丁型回。

**S12 阕间空行切断围栏** — 错误模式：上阕后 `:::` 关栏、下阕另开一栏两个 PN。正确做法：阕间空行保留在栏内，整体一 PN（§2.3）。典型语境：上下阕结构词。

**S13 正文对仗描写误判对联** — 错误模式：`[N] 他剑法迅捷，身法灵动。` 因字数相等+词性工整被围 `::: 对联`。正确做法：支路 C 门槛第 2 条（无叙事框架）拦截（§5.4）。典型语境：白话对仗描写句。

**S14 词牌署名行处理不当** — 错误模式：`——调寄沁园春` 单独编号或留在栏外。正确做法：入围栏末行、不占号（§2.3）；孤立署名行进存疑清单（§6.4）。典型语境：样本甲型章首词。

**S15 场景小节标题带编号/实体符号** — 错误模式：`## [6] 且说王照希赴京`、`## 且说〖@王照希〗赴京`。正确做法：若启用 `##` 层，标题纯文字、anchor 取节内首 PN（§7.2）。典型语境：回补 `##` 层时照搬套语原文。

**S16 围栏内实体一律不标（过度豁免）** — 错误模式：把 01g 原则零执行成"围栏内全不标"，词中明确实指的人物、书信中的专有名全部漏标。正确做法：按 §4.4 三层豁免表执行——实指可标、意象泛指不标（"魔影""剑光""浮云"）、动词一律不标。典型语境：从史记版"围栏内不标注"粗粒度铁律直接平移。

## 十三、FAQ

**F1 回目对句里有人名/兵器（"金鞍宝马　大盗震虚声"），为什么不标实体？**
回目行是标题层，参与目录/检索/回目页数据，实体符号会污染导航数据（史记"标题清理实体标记"同理）；专名收益低（多为"少年/大盗"绰号式预告）；且回目预告不抽事件（负规则十三），标注只剩专名识别一项，得不偿失。对句文学性由回目元数据（分句拆分）承接（§2.2）。

**F2 某回没有章首词怎么办？**
常态，不处理。`[1]` 恒为回目后第一个文本块——无词时它就是正文首段，不补写、不占位、不空号（§2.3，样本丁）。

**F3 回中人物即席吟了一首完整绝句，用"诗"还是"歌"？**
五七言/四言整齐 → `::: 诗`；句长口语化不齐或有"歌曰/唱道/吟道"引出 → `::: 歌`；两可 → 诗（保守归派，§5.5）。整体一 PN，宿主引出句留在正文。

**F4 武功口诀全文出现时怎么处理？口诀内技术名标不标？**
`::: 口诀` 是观察类：试点期逐例登记，暂不进正式统计。技术名/招式名可标（对接 01g FAQ Q14），动词不标。"传了口诀"式叙述提及**永不**围栏（§2.5）。

**F5 书信全文里的实体和事件怎么标？**
明确专有名可标；称谓/代词不标；信内动词不标；信中声称的事件不核实、来源与可信状态由实体/事件层保留（负规则十二，§4.4）。行内书信引语则连围栏都没有（§4.3）。

**F6 "只见"出现 190 次，为什么不是结构信号？**
实测绝大多数是叙事动词（"只见〖@〗其人纵身而上"）。词面匹配≠结构判定，它被定为伪信号级：永不单独触发围栏/分节，只作检测降权信号与 E15 误围栏哨兵（§6.2）。"但见"同理。

**F7 "——调寄沁园春"这行要不要单独编号？**
不要。它是词的附属信息，入围栏末行，随词整体持一个 PN（§2.3）。孤立出现的署名行（前无韵文块）进存疑清单。

**F8 回末对句和"欲知后事"为什么是两个块？**
对句是韵文（进韵文统计、可被专栏引用），套语是结构公式（负规则十三过滤对象），下游消费完全不同；合并会使韵文统计混入公式、分母过滤误伤对句（§2.4）。

**F9 跨书锚点为什么用作品 ID 不用中文书名？回号为什么必须进锚点？**
作品 ID 唯一、稳定、URL 安全，中文书名是人类展示层由站点做别名映射；PN 回内重置，无回号的 `#pn-3.1` 在 1,378 回中歧义无穷，故回号以 `r{N}` 为锚点最外层（§3.5）。

**F10 回目预告能不能生成事件？**
不能。回目对句与回末套语都在"不得臆推"红线内（§9.3，负规则十三）："欲知后事如何"不生成下一回事实，回目里的"杀/震/扶"不是事件。

**F11 词里的问句（"是魔非魔？"）为什么不会被误判成散文？**
"？"计入句界标点且不扣分：切句后仍是 3-5 字短句，长短句形态与押韵成分照常得分。词中夹问是词牌常态（§5.3，样本甲实测）。

**F12 上阕/下阕之间的空行怎么处理？**
保留在围栏内，属围栏内允许的唯一结构性空行；不得因此断开围栏成两栏两 PN（§2.3；S12）。

**F13 "欲如后事如何"是错别字吗？要不要改成"欲知"？**
不改。可逆性铁律高于一切：检测按词族模板命中"欲如"变体，统计归一为"回末套语"，原文一字不动（§6.3）。改字会让剥标记还原失败，且底本讹字信息丢失。

**F14 跨回连续叙事怎么编号？叙事线要不要延续？**
PN 每回重置，无跨回编号问题；上回末套语与本回首段各自独立。叙事线 ID 是否跨回延续由 01g/04a 规则定，结构层不阻拦（§7.3）。

**F15 为什么不设"有诗为证"围栏类型？**
实测 0 次（连同"花开两朵各表一枝""不在话下"）——水浒型说书套语在梁书缺位。已登记为缺位监视项，其他书目试点期出现即回填词表（§1.4/§6.2），但不为 0 频信号预置结构类型。

**F16 正文分母到底怎么算？**
回内"块类型=正文段"的 PN 数。排除：回目、全部围栏块、套语段。节奏指纹=04f 触发词计数÷该分母；韵文块整块不计，其宿主引出句计入但不含打斗触发词（§9.2）。

## 附录 B · 待拍板决策清单

**B1 底本版本锁定**
问题：1,378 回的底本（初刊版/通行修订版/电子录入版）选择未定，而 PN 不可变性把底本选择放大为一次性决策。
建议方案：先行锁定单一底本并记录版本指纹，34 部书统一；换底本视为乙类变更走 §9.4 全量迁移。
**✅ G0 裁决（2026-11-03）：以 `章回版/<书>/` 为唯一锁定底本**；白发魔女传指纹已入 config（sha256:3843aeb3e2b0e4b4，32 回组合），其余各书指纹随标注启动逐书回填；其他版本只作互校参考。
理由：底本一换，段落切分与围栏边界全部漂移，PN 全废。
不裁决的后果：标注启动后被迫中途换本，前功尽弃。
影响面：全部结构层产出、实体/事件层的所有锚点。

**B2 书信围栏内动词标注粒度**
问题：01g 原则零"不机械豁免"只给原则，信内动词（"望贤婿速**来**"的"来"）是否彻底不标需终裁。
建议方案：信内动词一律不标，仅宿主叙述句的引导动词（"信中说"）按正文规则标。
理由：信内动作是"声称的行为"，事件不核实（负规则十二），标注徒增噪音。
不裁决的后果：标注员各自把握，书信内动词密度不可比。
影响面：书信/告示类围栏；04f 信源事件统计。

**B3 观察类晋升标准**
问题：告示/口诀/说书何时从观察类转正式类。
建议方案：任一观察类在试点 ≥5 部书中出现 ≥20 次且触发特征稳定 → 启动晋升评审（§4.1）。
理由：以跨书频次证明非孤本现象。
不裁决的后果：观察类无限期悬置或被随意转正。
影响面：围栏枚举、统计口径。

**B4 `##` 可选层启用判据**
问题：§7.1 降级裁决需要复活的量化条件。
建议方案：试点期统计问答/定位请求中落在"回内场景"粒度的比例 ≥20% → 启用回补。
理由：以真实消费数据而非直觉决定。
不裁决的后果：要么永远缺场景导航，要么过早回补浪费人力。
影响面：回目页/阅读器/问答三处导航。

**B5 lint 告警分级终裁**
问题：E11/E12/E14/E15/E17 定 warning 而非 error 是设计倾向，需人工确认。
建议方案：按本文分级试行一轮，看 warning 的实际处置率再定级。
理由：误报成本高的先降级，试点数据说话。
不裁决的后果：告警疲劳或漏报风险。
影响面：全部 1,378 回的质量门。

**B6 中文书名别名层责任归属**
