# W2 动作库（武侠版）—— 24 个原子动作的菜单

> **本文是什么**：Butler 的"动作菜单"。W1 决定"做什么"（队列），W2 决定"怎么做"（原子动作的前置/步骤/后置检查/预算），W3 决定"做到什么程度"（质量档），W4 决定"做完了收不收"（评估/回滚）。
> **上游依赖**：`skills/W1_资料地图_武侠版.md`（队列/素材）；`skills/W0_Butler定位_武侠版.md`（六不变量/边界）；`logs/qa/w_group_design_brief.md`（W2 设计）。
> **一句话**：**Butler 只能从这 24 个动作里选，不能自由发挥；新动作必须经 W5 反思追加并版本化。**
> **只读纪律**：动作只读 tagged/registry/references/docs/logs，产物只落 `content/` 与 `logs/w_group/`；不改原文、不改登记层。

## 二、动作执行通用纪律（六条）

1. **只读上游**：tagged/registry/references/docs/logs 只读；不写、不重算；
2. **diff ≤20 行/动作**（精品页例外）：只追加不替换；同一动作只改一个目标页；
3. **一动作一 commit/一记录**：actions.jsonl 一行一动作，可回滚；
4. **断言必有源**：页面上的每条事实按 W3 断言分级挂证据；
5. **引文必须过 W7**：`verify_quotes.py` hit/near 可接受，miss 拒绝写入；
6. **demo/脱敏隔离**：demo 卡/未过审内容不进正式页；R1/R2 脱敏纪律同样作用于 content。

## 五、动作 manifest（actions.jsonl）

```jsonl
{"ts":"2026-11-05T20:15:00+08:00","mode":"butler","action":"build_stub","target":"content/person/card.person.e0123.md","source":["registry/sku/cards.json#card.person.e0123"],"wu":5,"diff_lines":8,"rationale":"W1 队列 P1：stub 缺失","result":"accepted","commit":null,"quotes_verified":null}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| ts | 是 | 时间戳 |
| mode | 是 | butler/manual |
| action | 是 | 24 动作 ID（§三 编号） |
| target | 是 | 页面/产物路径 |
| source | 是 | 素材来源（路径#ID） |
| wu | 是 | 本次 WU |
| diff_lines | 是 | 改动行数（≤20；精品页例外） |
| rationale | 是 | 为何选此动作/目标（队列信号） |
| result | 是 | accepted/failed/rolled_back |
| commit | 否 | commit 号（若启用 git） |
| quotes_verified | 引文类动作必填 | W7 hit/near/miss |

## 九、检查清单

### 动作前
- [ ] 队列目标与动作匹配（W1）；
- [ ] 动作前置条件满足（素材/质量档）；
- [ ] diff 预算与 WU 预估。

### 动作中
- [ ] 只读上游；只改目标页；
- [ ] 只追加不替换（精品页例外走 W8）；

### 动作后
- [ ] 后置检查逐项过；
- [ ] actions.jsonl 字段齐全（含 WU/quotes_verified）；
- [ ] 交 W4 评估；
- [ ] 失败即回滚留痕。

## 十、FAQ（首批 6 问）

**Q1 为什么必须从 24 动作里选？**
防止 Butler 自由发挥导致不可审计；新需求走 W5 反思→新动作→版本化。

**Q2 diff 20 行包含精品页吗？**
不。精品页（动作 17）按 W8 全流程，可超 20 行；但需 W4 例外记录。

**Q3 引文块写多少字？**
引文 ≤60 字/段、连续不超 R2（W3 版权 L0 档）；必须过 W7。

**Q4 WU 怎么估？**
按 §4.1 表；新动作经 W5 定 WU 并写入本文件版本记录。

**Q5 动作失败了怎么办？**
W4 判 fail → 回滚（git restore/备份恢复）→ failures.jsonl；同因 ≥3 交 W5。

**Q6 content 页已 367 页，动作 1/2 还做吗？**
做：门/派/武功/名物/事件页型尚未铺开（W8 其余四类卡页型 1,169 待做），W1 队列按缺口排。
