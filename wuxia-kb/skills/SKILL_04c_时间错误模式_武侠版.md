
### 1.2 本文做什么

1. **错误分类**：三分裁决（直迁/改写/报废）+ N4 实测错误码（T01-T15/W1-W6）；

## 三、错误分类（T/W/E/未解析）

### 3.1 解析类错误码（N4 T01-T15，实测活跃项）

| 码 | 含义（N4 v0.1 口径） | 分级 | 处置 |
|---|---|---|---|
| T05 | 相对表达缺基准（裸时长/无锚） | warning | 补事件/年龄锚；或登记 low |
| T07 | 时令锚缺年份配合 | info | 与年份锚联动；单独时令只作 low |
| T11 | 年龄表达歧义（虚岁/约数） | warning | 按 04e 年龄细则复核 |
| T15 | 朝代锚×相对链冲突 | **error** | 按 D05 §2.5 规则 5：以朝代锚为主并登记（实测 4 处） |
| 其他 T 码 | N4 内置（解析失败/类型不符/管道异常等） | 视码 | 按 N4 报告逐条 |

> 实测基线（docs/56 §四）：5 书 T15×4、T05×3、T11×1、T07×2；未解析 187。

### 3.2 结构类错误码（W1-W6，时间结构）

| 码 | 含义 | 分级 | 处置 |
|---|---|---|---|
| W1 | 同线倒流（后文时点早于前文） | error（确认后） | 先查是否追叙/分叉 |
| W2 | 分叉未登记/登记错位 | warning | 确认叙述边界，登记 fork |
| W3 | 对白时间混入主线 | warning | N4 quote 隔离口径复核 |
| W4 | 同一 tp_id 跨回误并 | error | 拆 tp_id，按锚点证据重绑 |
| W5 | 时点键缺物理锚（无 pn） | error | 修结构层/回填 |
| W6 | confidence 越级（low 被当事实） | warning | 降档并记录 |

### 3.3 单调性违例（E1/E2/E4）

| 码 | 定义 | 分级（N4 实测 0/0） |
|---|---|---|
| E1 | 同线时间倒流（非追叙） | error |
| E2 | 时间跳跃无过渡（锚点断裂） | error |
| E4 | 分叉线内单调性违例 | warning |

> E1/E2 实测均为 0；若出现，优先怀疑 fork 未识别（W2）而非原文错误。

### 3.4 未解析清单（187 条）

处置三分：**可补锚**（有隐含事件/年龄锚）→ 改标注/补规则；**表达残缺**（原文即模糊）→ 接受 low；**跨回依赖**（基准在下文）→ 等前回解析后重跑。禁止为提升解析率编造锚点。

## 四、处置流程（分级→定位→三径→回归）

```text
① 分级：error/warning/info（硬矛盾/可疑/说明）
② 定位：逐条拉原文（书/回/段/PN/上下文），令牌化定位（防同字误位）
③ 三径分流：
   径 A 改标注：类型错（年号指人→@）、管道错（缺三管道）、锚点表达错（断句/边界）
   径 B 改解析：规则缺口（T05/T07）、基准缺失（默认基准规则）、换算边界
   径 C 登记待考：证据不足/原文即模糊/跨回依赖 → 记录层 + low 置信
④ 回归：重跑 N4；五门 lint + accept；错误数对比
⑤ 沉淀：可机械化→N4/N8；系统性→03c1；裁定→docs 记录
```

### 4.1 三径判定规则

| 现象 | 首选径 | 理由 |
|---|---|---|
| `%` 标签错误/缺失 | A | 标注层直接修 |
| T05 裸时长 | B（基准规则）或 C | 能定基准则 B，不能则 C |
| 年号指人误标 | A | 03b §8.3 |
| 追叙被当倒流 | B（fork 识别规则）+ C（登记） | 结构规则问题 |
| 同日跨回误并 | B（tp_id 绑定规则） | 解析规则 |
| 原文即模糊（"半晌会儿"） | C | 不硬造时间 |

### 4.2 回归与验收

- 重跑 N4 后：error 不增、warning 下降或持平、未解析不增；
- 5 书 accept（hard 0、judgment 不升）+ 五门 lint；
- 时间类 N8 检查（`registry/consistency/`）不出现新增 error；
- 变更记录：错误码/处置/证据 loc/批准人。

## 九、FAQ（首批 6 问）

**Q1 43 种错误模式都要在本 SKILL 重列吗？**
不用。完整表在 D05 §六（权威）；本文只做"可检项分类 + 处置流程"，并给 T/W/E 映射（附录 A）。

**Q2 E1/E2 为 0 是不是没问题？**
说明当前 5 书主线单调性健康；但 171 个闪回/分叉候选仍待逐条复核（W2），别把"0 error"当"时间轴已完善"。

**Q3 追叙导致的时间"倒流"要改吗？**
不改。登记 fork 即可；原文倒叙是文学结构，不是错误。

**Q4 未解析 187 条要清零吗？**
不强求。目标是"可解释"：补锚/降 low/登记待考；清零靠编造锚点不可接受。

**Q5 改解析规则会不会影响其他书？**
会。规则改动须 5 书全量回归（N4 --all）+ accept 复跑，不能只测单书。

**Q6 与 N8 的边界？**
N4 管"时间能不能解析/是否单调"；N8 管"时间结论与设定（年龄/死亡/习得）是否矛盾"；本文管"错误如何分级处置"。

## 结语

时间错误模式的处置精髓是**分清"原文的模糊"与"体系的缺陷"**：原文模糊就登记 low，体系缺陷就改规则；追叙不是错误，单锚才是风险。43 条模式不必背，但"分级—三径—回归—沉淀"必须走完。
