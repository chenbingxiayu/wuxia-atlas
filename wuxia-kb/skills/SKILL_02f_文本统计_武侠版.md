## 二、统计分母纪律（武侠新增核心）

### 2.1 正文模式分母（引用 02ab §9.2 定义，原文照录）

> **正文分母 := 块类型=正文段 的 PN 数（回内）**
> **排除：回目[0]；全部围栏块（词/诗/歌/对联/回末对/回末/书信/告示/口诀/说书）。**

配套三条（02ab §9.2 原文要点，逐条核对一致）：

- **套语段（文本模式=套语）既不进分母也不贡献触发词**——这是 02ab 新增"套语"枚举值的直接收益；
- 韵文提及不计入打斗密度：`::: 诗` 等围栏整块不计；宿主引出句（"朗声吟道："）在正文分母内，但其动词非打斗触发词，天然不影响；
- 观察类围栏（告示/口诀/说书）内容**暂不计入正式统计口径**（02ab §4.1），晋升评审通过后才回溯。

**为什么排除**：回目对句是韵文预告、围栏块是插入文体、套语是结构公式——任何一类混进分母，密度曲线就被非叙事文本稀释，34 部对比失去可比性。02ab §4.1 文本模式枚举说明的原话可作总注："若套语归'正文'，04f 负规则十三的过滤就退化为词表逐条排查，分母必被污染。"

### 2.2 密度口径（引用 04f 统计口径）

> **打斗/杀伐/传艺密度曲线 = 04f 触发词计数 ÷ 对应回正文分母**（02ab §9.2）。
> **04f 口径："数触发词，不数'回合'与实体"**（SKILL_04f 武侠版 §9 FAQ：`"三百回合"是数量绝不入触发词`；纯状态句不造触发词）。

执行细则（与 04f 条文逐条核对一致）：

1. 密度分子是 04f 六域触发词令牌数（⟦⊞⊠⊡⊟▣■⟧），按域分列；招式名 `〖☆〙` 照标但**不计入动词密度**（04f §6.1：密度统计只数触发词，不数实体）；
2. 连续交锋按 04f §6.1 合并标注后的**起止与关键结果**计数——逐招轰炸会把密度统计撑爆（V1-1 错误模式），曲线失真即由此来；
3. 否定、条件、未发生的操作不入分子（04f §3.6 / 01g 负规则六）：`欲杀`、`若能夺得` 不进打斗密度；
4. 回末套语段与围栏块内出现的动词字样一律不进分子（与分母排除对称）；
5. 密度合理性自检沿 04f 经验区间：每段触发词 1-6 处正常，>10 处回头查逐招误标。

### 2.3 出入账总表（一眼判分母）

| 文本身份 | 进分母？ | 进分子？ |
| --- | --- | --- |
| 正文段（文本模式=正文） | ✅ | 按触发词实数 |
| 回目 `[0]` | ❌ | ❌ |
| 词/诗/歌/对联/回末对（围栏） | ❌ | ❌（整块不计；宿主引出句在分母内） |
| 回末（套语） | ❌ | ❌（既不进分母也不贡献触发词） |
| 书信/告示（围栏） | ❌ | ❌（信内动词不标，04f/02ab §4.4） |
| 告示/口诀/说书（观察类） | ❌ | ❌（暂不入正式统计，晋升后回溯） |

### 2.4 lint 钩子（02ab §9.1 的统计前哨）

- **E14** 韵文密度异常：单回韵文块 >5 或韵文段占比 >20% → warning（阈值待试点校准）；
- **E17** 正文分母完整性：正文段占比 <50% → warning（阈值待试点校准）；
- 两项告警的处置路径：先查围栏/套语误判（漏围、错围），再查 PN 结构——**统计异常多数是结构错误的投影**，禁止在统计层"调阈值消警"。

## 三、34 部跨书对比（体裁对比的武侠化）

### 3.1 分书统计

史记版按五体分组对比；武侠版 34 部书是平行语料，对比单位是**书**。书目唯一来源是 `config.py` 的 `books()`（多书注册表，禁止脚本自行拼路径扫目录）。`compute_annotation_coverage.py`（C12）已改造为分书统计，`extract_yunwen.py`（C14）分母改分书——产出逐书指标表：

```bash
# 分书覆盖率与字数（缺省扫 config.DIR_TAGGED 全部书）
python scripts/compute_annotation_coverage.py

# 单书
python scripts/compute_annotation_coverage.py --book 白发魔女传
```

### 3.2 对比纪律

1. **用率不用量**：34 部回数悬殊（几十回至百馀回），对比一律用率（每回均值、每千字密度），禁止用总量排名；
2. **回数不齐不插值**：缺回/未标书在表中显式标"未达"，不做补齐估算；
3. **围栏类型分布是书风指纹**：词牌密度（章首词有无）、书信占比、口诀出现次数在书间差异巨大，是"说书体浓度"的量化入口；
4. **观察类单列**：告示/口诀/说书计数与正式类分开列示并注明"观察类暂不计入正式口径"（02ab §4.1），晋升后回溯追认；
5. 跨书对比发现的结构异常（某书 E14/E17 集中告警）→ 回投 02ab 存疑清单，不在统计层裁决。

## 七、FAQ

**Q1：为什么实体密度现在不报？**
实体层尚未铺完，分子残缺；用部分数据报全量指标会得出"某书实体密度低"的伪结论（实际只是没标完）。启用时点见附录 B-1，启用前对应行保持"规划"状态。

**Q2：密度曲线和 04f 的"每段 1-6 触发词"经验区间是什么关系？**
两者同源不同层：04f 的区间是**标注质检**（单段逐招误标的回头检查线），本文的密度曲线是**回级统计**（触发词总数 ÷ 正文分母）。曲线异常先回查 04f 标注质量，再查分母污染（E14/E17 告警），最后才考虑文学风格解释。

**Q3：为什么禁止用总量排名？**
34 部回数悬殊（几十回至百馀回），总量天然偏向长书；只有率（每回均值、每千字密度）在书间可比。这一条与"回数不齐不插值"（缺书显式标"未达"）共同构成跨书对比的两条铁律。

**Q4：观察类围栏（告示/口诀/说书）的数量能不能先统计着看？**
可以**单列观察**，不能计入正式口径（02ab §4.1：暂不计入正式统计，晋升评审通过后回溯）。表中原样计数并注明"观察类"，晋升后回溯追认——数据可以先行，口径不许先行。

## 结语

史记版统计教的是"让数字说话"；武侠版先补了一课：**先说清楚数字是怎么数的**。正文分母排除回目、围栏与套语，分子只数触发词——口径钉死之后，34 部书的密度曲线才可比、节奏指纹才可信、穿帮雷达才不会把结构错误当文学风格。统计层的每一个数字，都要能沿着锚点走回原文。
