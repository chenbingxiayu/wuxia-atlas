# SKILL 04f: 武侠动词标注（动词域与动词-实体联动规范）

> **核心原则**：动词触发词是事件入口，不是事实本身；结果决定主域；招式名是实体，出招才是动作；联动生成候选，不生成定论。

> **上游契约**：六大动词域符号（⊞⊠⊡⊟▣■）、外层括号 `⟦⟧`、触发词边界原则、事件五状态字段、outcome 五值均由 SKILL_01g 武侠版（v0.3-draft）定版。本文件在其上细化收词边界、语法细则、联动规则与词表框架，不改动符号体系。

> **版本状态（v0.3-draft）**：本版由 v1/v2 两稿评审合并而成（v1=GLM 全量提示词稿、v2=deepseek-v4-flash 上下文适配提示词稿，对比与裁决见 `docs/07-SKILL_04f双稿对比分析与合并说明.md`）。以 v1 为骨架（连续交锋合并标注、"结果决定主域"速查表、方向字段、V0 纪律），自 v2 回收：点穴语境三分、旧"擒控救援"落位表、分型卡"模板/安全条件"列、招式判定句式补充、联动建议档行、FAQ 补充、未遂判据操作化；修复 v2 的词表重复、附录 A 史记域数错误、单字词高置信档误置，修复 v1 的示例标注纯度。种子词表来自《白发魔女传》章回版抽样与设计推演，未经语料全量验证；所有"自动补标"档位在试点标注前只作候选召回，不直接批量执行。

## 一、技能定位

动词标注是**事件构建与关系构建的桥梁**。武侠叙事中，一场比武、一次传艺、一趟押送都是围绕动词组织起来的；标注动词等于给事件留入口，标注动词的邻近实体等于给三元组留候选。

**在管线中的位置**：

```
SKILL_01g 武侠版（实体与符号宪法，已定版）
├── 实体层 〖TYPE〗 ── 提供主语、宾语
SKILL_04f 武侠版（当前：动词层 ⟦TYPE⟧）
    ↓
SKILL_04a 事件识别（武侠版，待建）── 消费触发词 + 事件状态字段
SKILL_05a/05b 关系构建（待建）── 消费联动三元组候选
    ↓
侠谱评分 / 行踪地图 / 神兵谱 / 武功传习链 / 穿帮雷达 / 江湖问答
```

**为什么放在实体层之后、事件识别之前**：

1. **依赖实体标注**：动词触发联动的对象是实体（练成→☆武功、赠→•器物），主语宾语由实体层提供；
2. **支撑事件提取**：动词触发词 + 事件状态字段是事件识别（SKILL_04a）的直接输入；
3. **铺垫关系抽取**：主语-动词-宾语是三元组候选的来源（SKILL_05a/05b）；
4. **先于事件定版**：史记版动词标注是"先实体后动词"的补标工程；武侠版把动词层放在事件识别之前定版，因为联动表直接决定事件字段（参与者、对象）与三元组候选的生成方式。

**与史记版 04f 的定位差异**：

| 维度 | 史记 04f（v3.2，4 域） | 武侠 04f（本文件，6 域） |
|------|------------------------|--------------------------|
| 体系状态 | 130 章已标注完毕（6,257 处），规范是追认 | 零标注存量，规范先行，首轮标注即带全约束 |
| 动词语言 | 文言单字主导（伐/诛/拜/赐） | 白话双音节主导（打败/杀死/救活/抢走） |
| 词表状态 | 核心词表 92 词，多年迭代 | 种子词表约 140 词，三档分级，待语料验证 |
| 密度环境 | 史传叙事动词密度低 | 武打段动词密度极高，须有合并标注策略 |
| 特有问题 | 动词 vs 制度名词（⟦◉杀⟧ vs 〖[斩首〗） | 招式名 vs 出招动作（〖☆怪蟒翻身〗 vs ⟦⊞刺⟧） |
| 联动规范 | 无显式联动表 | 动词-实体联动表是核心交付物 |

### 2.1 ⊞ 战斗交锋

**定义**：交战、比武、攻击、防御性对抗、战斗控制及明确战斗结果（01g 定版）。核心是**对抗性武力交锋**。

**包含**：
- 单挑动词：交手、过招、拆招、动手、出手（战斗语境）、切磋、领教；
- 群战动词：围攻、混战、群殴、掩杀、冲阵、突围（脱离子型）；
- 比武动词：比武、较量、比试、较技、挑战、应战；
- 攻击动作：刺、劈、斩（向人）、扫（向人）、打、踢、拍、抓、锁拿；
- 偷袭伏击：偷袭、伏击、暗算（施行动作时）；
- 防御对抗（有独立战术结果时）：格挡、招架、封、截、反击；
- 战斗控制：点穴（战斗语境）、点倒、震住、制住、擒拿、拿下；
- 胜负结果补语：击败、打退、逼退、战败、击退、压倒。

**排除（看似像但不归此域）**：
- 致死致残结果 → ⊠（"斩为两截"主域 ⊠）；
- 兵器毁损 → ⊟（"断门刀真个断了"是 ⊟）；
- 战斗中的姿态调整 → 不标（跃起、侧身、退半步、翻滚——01g 负规则七）；
- 战斗总述状态句 → 登记状态，不强造触发词（"僵持不下""难分胜负"）；
- 未发生的约战 → 不标（"三日后比武"是计划）；
- 演武（非对抗性演示）→ 观察档，默认不标。

**与相邻域裁决**：见 §2.0 总表。要点：**攻击行为归 ⊞，杀伤结果归 ⊠**——"一剑刺中"与"一剑刺死"分属两域；同一句两事实分别标；战斗现场的脱离（逃出重围、突围）→ ⊞ 子型"脱离"，跨地域逃亡 → ■。

**正误对照**：

| 场景 | ✅ 正确 | ❌ 错误 |
|------|---------|---------|
| 单挑 | 两人⟦⊞交手⟧数十回合 | 每一招都标一个触发词（密度爆炸，见 §6.1） |
| 刺中 vs 刺死 | ⟦⊞刺⟧中（⊞）；⟦⊠刺死⟧（⊠） | 一律标 ⊞ 或一律标 ⊠ |
| 点穴 | 他抬手⟦⊞点⟧了那汉子〖^穴道〗 | 把"点"标为 ■ 或不标 |
| 格挡 | 她⟦⊞格⟧开这一刀，⟦⊞反击⟧得手 | 姿态性"闪过"也标 ⊞ |
| 约战 | "三日后与你比武" → 不标 | 未发生的比武入已发生统计 |
| 总述状态 | "双方僵持不下" → 登记状态，不标 | 给状态句强造 ⟦⊞⟧ 触发词 |

### 2.2 ⊠ 生命健康

**定义**：出生、死亡、杀伤、致残、中毒、治疗、救活及健康状态变化（01g 定版）。核心是**生命状态变更**。

**包含**：
- 死亡：杀死、斩杀、击毙、丧命、送命、气绝、自尽、自刎、服毒、病逝、遇害；
- 杀伤委婉语（叙述者使用时）：结果了他、送他归天、超度了他；
- 致残：挑断手筋、打断腿、刺瞎、废（指身体时）；
- 中毒：中毒、毒发、下毒、投毒、下蒙汗药（致害成立时）、解毒、驱毒；
- 治疗恢复：疗伤、治伤、救活、救治、接骨、运功疗伤；
- 出生与生命状态：出生、诞生、夭折；
- 受伤结果（达阈值时）：负伤、重伤、中剑、晕厥、苏醒、痊愈。

**受伤阈值裁决**：武侠打斗中"中了一剑"是高频常态。**以"改变后续行动能力"为标注阈值**——中剑后退出战团、倒地、需要疗伤、伤重难支 → 标 ⊠；被扫一鞭继续缠斗 → 只作 ⊞ 交锋的局部结果，不标 ⊠。信号词：负伤、重伤、鲜血、退出战团、倒地、再也提不起剑。（阈值细节见附录 B-1）

**疑似诊断裁决**（v2.1，2026-11-04 P3-5，006 回 [21] 定例）：人物或叙述者**依据现场迹象作出的疑似诊断**（似是中毒/像是被掌力所伤/想必是……）→ 标事件＋`|疑似，未确证` 注记（似是⟦⊠中毒|疑似，未确证⟧）。要点：
- "似是"类推断不等于纯否定，也不等同于已确证——注记保留推断状态；
- 同段后文叙述直接修正的不回改首标（首标记录"人物当时的判断"这一事实）；
- 不得由未提供的跨回后文自行补成事实。

**下毒分流裁决**（v2 回收确认）：

| 情形 | 归属 | 说明 |
|------|------|------|
| 毒物入酒/食物，人未饮 | ⊟ 观察档 | 物件被污染，无生命事实 |
| 下毒且人中毒 | ⊠ 主域（子型投毒） | 被害人 @ 强制联动 |
| 解毒/解救 | ⊠（恢复） | 可关联投毒事件 |

**废武功双事实裁决**（武侠特有）：
- 身体路径："挑断手筋""打断经脉" → ⊠（致残），技术能力丧失作为关联登记；
- 技术路径："化去他一身内力""废去武功" → ▣（技术能力剥夺子型），身体伤害另标；
- 原文一句话同时含两事实 → 按表述拆两个触发区间分标，**同一字符不得作两个域的触发词**（否决 v2 的 `⟦⊠废⟧⟦▣废⟧` 方案）。

**正误对照**：

| 场景 | ✅ 正确 | ❌ 错误 |
|------|---------|---------|
| 委婉杀 | 叙述者写"结果了他" → ⟦⊠结果|杀死⟧ | 因是委婉语而漏标 |
| 威胁 | "我要杀你" → 不标 | ⟦⊠杀⟧ 入已发生统计 |
| 受伤阈值 | 中一剑继续缠斗 → 不标 ⊠ | 每次兵刃相交都生成 ⊠ 事件 |
| 攻击动作 | 他⟦⊞刺出⟧一剑（未中） | 把"刺出"标 ⊠ |
| 毒发 | ⟦⊠毒发⟧，强制 @ 被害人 | 只标 ⊟ "酒里有毒" 完事 |
| 废武功 | ⟦▣废去⟧〖@某人〗〖$一身功力〗 | 把"废"标成 ⊠ 杀 |
| 运功疗伤 | 盘膝⟦⊠疗伤⟧ | 把"运功"本身当 ▣ 修习事件 |
| 状态句 | 伤者昏迷不醒 → 状态登记 | "昏迷"高频泛标 |
| 疑似诊断 | 似是⟦⊠中毒\|疑似，未确证⟧（006[21]） | 按"似是"就不标，或当确诊标 ⟦⊠中毒⟧ |
| 固化动宾 | 他真胆大，⟦⊟劫⟧书⟦⊠害命⟧（006[16]） | 把"害命"拆成 ⟦⊠害⟧命（受控例表词项不适用宾语外置） |

### 2.3 ⊡ 社会关系

**定义**：拜师、结义、婚姻、任命、继任、入派、叛离、结盟等关系建立或变更（01g 定版）。核心是**人际/组织关系变更**。

**包含**：
- 师承：拜师、拜他为师、收徒、投师、逐出师门、叛出师门；
- 结社：结义、结拜、结盟、毁盟、反目、歃血为盟、归附；
- 婚姻：成亲、完婚、娶、嫁、订婚、退婚、悔婚、纳妾、**提亲（已实施的婚约请求，⟦⊡提出|提亲⟧——P3-8；未实施的意向不标）**；
- 任职：任命、委任、继任、接任、传位、让位、禅让、废立；
- 组织成员：入派、入门、加入、退出、脱离、叛离、被逐、**遣散/解散（实际解除雇佣/家役/组织成员关系——P3-7；单纯使人散去不标）**；
- 拘押关系：囚禁、关押、劫囚、营救（解除拘禁子型）、释放、收监、点穴定身（非战斗制服）——**拘押注记分型（P3-6）**：司法拘押（⟦⊡囚禁|司法拘押⟧）与私人禁锢（绑票/扣肉票等私人扣留：⟦⊡关进|私人禁锢⟧⟦⊡关|私人禁锢⟧）同归 ⊡、注记区分；
- 收养收留：收留、认作义子。

**排除**：
- 礼貌性拜见（拜年、拜谢、拜见前辈）→ 不标；
- 单次传授 → ▣（拜师是 ⊡ 建立关系，学艺是 ▣ 技术事件）；
- 对话中的称谓（"师父在上"）→ 不标；
- 名义关系不改实质（假意结盟按叙述登记，可信状态存疑）。

**正误对照**：

| 场景 | ✅ 正确 | ❌ 错误 |
|------|---------|---------|
| 拜师 | 他⟦⊡拜师⟧，紫阳道长⟦⊡收徒⟧ | 拜师事件自动生成"已学会武功" |
| 拜见 | 他上前拜见师父 → 不标 | 礼貌"拜"入 ⊡ |

### 2.4 ⊟ 物件变化

**定义**：制造、取得、赠借、买卖、夺取、返还、丢失、毁损等物件状态或归属变化（01g 定版）。核心是**物件状态/归属变更**。

**包含**：
- 制造：铸、锻、炼制、打造；
- 取得：得到、获得、拾得、夺得、抢走、缴获、偷、盗、赢取（以物为注）；

**排除**：
- 秘籍内容的学习 → ▣（取得剑谱 = ⊟ 物件；练成剑谱武功 = ▣ 技术，两个事件）；

**定义**：传授、修习、偷学、悟得、练成、失去或恢复技术能力（01g 定版）。核心是**武功/技艺掌握状态变更**。

**包含**：
- 传授：传授、授艺、传艺、教（技艺义）、指点（子型单次指点）、传功、渡功、灌输内力；
- 修习：学、习练、修习、勤练、研习、参详、揣摩（进行中）；

- 偷学：偷学、偷看（并学会）、窃艺；
- 剥夺：废去武功、化去内力、散功；
- 恢复：恢复功力、重练；失传（技术消亡，观察档）。

**习得阶段字段**（01g：看过/听过/记住/修习/练成是不同阶段）：

| 阶段 | 动词例 | 是否标 ▣ | achieved 字段 |
|------|--------|----------|---------------|
| 接触 | 看过、听过、翻阅 | 否（内容接触） | — |
| 记忆 | 记住、默记 | 否（观察档） | — |
| 修习中 | 学、练、修习 | 标，子型修习 | achieved=false |
| 完成 | 练成、学会、悟出 | 标，子型完成 | achieved=true |
| 精通 | 已得全部秘奥、登峰造极 | 登记状态句，无触发词也可 | — |

**传功双事实裁决**：传功 = 授方输出 + 受方获得，**授、受各作一个触发区间**分别标 ▣；原文明写授方内力耗损（"元气大伤""内力大减"）→ 另标 ⊠；未写耗损只标 ▣。隔空渡功、灌顶同理。

**单次指点 vs 正式授艺**：教几招、指点一二 → ▣ 子型"指点"，**不生成师承关系**（01g §9.2：正式师承与单次传授分开）；授艺、收归门下随授随教 → ▣ 子型"授艺"，师承关系仍以 ⊡ 拜师事件为准。

**排除**：
- 拜师 → ⊡；
- 战斗中施用已会武功 → ⊞（"使出"在战斗语境是攻击行为；招式名标 ☆ 实体）；
- 演武给外人看 → 观察档；

**正误对照**：

## 三、动词标注语法细则

### 3.1 触发词边界与"结果决定主域"

01g 已定：最小连续单位；保留结果补语（杀死、夺走、救活、练成）；不含主宾语、程度副词、标点；否定/条件/未来在外但入状态判断；一个触发区间一个主域。

**判别三问**（本文件定版）：

1. **结果落在哪个域？**——补语是主域内结果 → 整词标：`⟦⊞打退⟧`、`⟦⊠打死⟧`、`⟦⊟夺走⟧`、`⟦▣练成⟧`；
2. **是否两个连续独立事实？**——是 → 拆分分标：`⟦⊞击倒⟧对手，随后⟦⊠杀死⟧了他`；
3. **拆开后另一部分是否仍独立成立？**——"打死"拆成 ⟦⊞打⟧⟦⊠死⟧ 后"死"依附于"打"，不独立 → 不拆；"击倒+杀死"是先后两事实 → 拆。

**结果决定主域速查表**（统一原理：触发词 = 动作 + 主域内结果补语，主域由结果定）：

| 动词+补语 | 主域 | 整词示例 |
|-----------|------|----------|
| 动+死/亡/命/残/伤（致害成立） | ⊠ | ⟦⊠打死⟧ ⟦⊠打残⟧ ⟦⊠杀伤⟧ |
| 动+退/败/倒/赢/开（战斗结果） | ⊞ | ⟦⊞打退⟧ ⟦⊞击倒⟧ ⟦⊞逼开⟧ |
| 动+走/回/来/去（物件归属） | ⊟ | ⟦⊟夺走⟧ ⟦⊟抢回⟧ ⟦⊟送还⟧ |
| 动+成/会/透（习得完成） | ▣ | ⟦▣练成⟧ ⟦▣学会⟧ ⟦▣参透⟧ |

**"打死"四语境**（v2 回收）：

| 语境 | 标注 | 理由 |
|------|------|------|
| 他一拳打死了一头猛虎 | ⟦⊠打死⟧ | 单一动作单一结果，整词 |
| 他打了他一顿，然后把他杀了 | ⟦⊞打⟧……⟦⊠杀⟧ | 两个连续事实，拆分 |
| 他被打死 | ⟦⊠打死⟧ | 被动式，结果补语保留 |
| 他打不死我 | "打不死"不标（否定+能性） | 否定在外；能性补语非结果 |

**触发词不吞宾语**：`⟦▣传授⟧〖☆某剑法〗`，不写 `⟦▣传授某剑法⟧`（01g 已定）。

### 3.2 复合动词与整词清单框架

**整词条件**（语义黏合、单一事件；仿 04f1 §V7）：武侠首批整词框架——

- ⊠：杀死、打死、斩杀、毒杀、自杀、自刎、追杀（致死实现于一句时）；**害命（固化动宾，P3-4）**；
- ⊞：偷袭、围攻、反杀、击败、逼退、点倒、擒住、突围；
- ⊟：夺走、抢回、送还、劫走（夺物义）、买下、当掉；
- ▣：练成、学会、悟出、偷学、传功、废功；
- ■：押解、潜入、逃亡、远遁。

**拆分条件**（两个独立事实）：击倒+杀死；取得+修习（得谱→练成）；擒住+押走（⊞→■）；劫囚（⊡）+出城（■）。

**固化动宾受控例表**（v2.1，2026-11-04 P3-4 项目裁定）：语义完全固化、宾语不指称具体对象的动宾词项**整体收录**，"不吞宾语"规则对其不适用——⟦⊠害命⟧（006[16]）、⟦⊞下杀手⟧（006[1] 痛下杀手）、⟦⊞拼命⟧（006[7]）。词表落盘 `wordlists/fossil_verb_objects.json`；新增词项须有回内证据并经项目裁定，不得在标注时现场自造。

**边界错切警觉**（04f1 §E11 经验）："前置字+动词"可能是错切的复合词（自〖[杀〗→自杀式事故）；武侠对应："欲自废武功"中"自废"是整词，不拆"自+废"。

### 3.3 消歧语法

**格式**：`⟦TYPE动词|消歧说明⟧` 沿用（如 `⟦⊞走|败走⟧`）。一词多域时必须消歧；消歧说明写该次出现的具体语义，不得与禁标语境混写。

| 动词 | 应标语境 | 禁标语境 |
|------|---------|---------|
| 走 | 逃走/败走（战斗）→⊞ 脱离；赶路（行程）→■ | 行走、走路 → 不标 |
| 教 | 教武功（技艺义）→▣ | 令使（"教他去做"）→ 不标 |
| 夺 | 夺物 →⊟；夺命 →⊠ | 夺路（通道义）→ ⊞ 脱离或不标 |
| 退 | 退敌/逼退 →⊞；退出门派 →⊡ 观察档 | 退步（姿态）→ 不标 |
| 打 | 战斗攻击 →⊞；打死 →⊠ 整词 | 打水/打伞/打点 → 不标 |
| 放 | 放暗器（施放攻击）→⊞；释放囚犯 →⊡ | 放置物件 → 不标 |
| 接 | 接任掌门 →⊡ | 接住劈来的剑（战斗）→ ⊞ 格挡或不标 |
| 断 | 刀断了 →⊟ 毁损；打断腿 →⊠ 致残 | 恩断义绝 → ⊡ 离线（见 §4.3） |

高频多义动词的完整分型卡见 §5.3。

### 3.4 招式名 vs 出招动作判定决策表

> 01g 已定：招式名类型取决于技术指称，引号只是标点。本表补齐**动词侧**——同一句里什么标 ☆ 实体、什么标动词触发词、什么不标。

| 句式模式 | 标注方案 | 示例 |
|----------|----------|------|
| 使出/使一招+"X"（战斗中） | X 标 〖☆〗；同句另有攻击动词则该动词标 ⊞；"一招""使出"本身一般不标 | 使出一招"〖☆怪蟒翻身〗" |
| "X"的招数+斩/扫（动作另述） | X 标 〖☆〗；斩/扫 标 ⟦⊞⟧ | 以"〖☆旋风扫叶〗"的招数⟦⊞斩⟧向敌手下盘 |
| 按照……的招数 | "按照"不标；招数名标 〖☆〗 | 按照〖☆七十二手连环剑〗的招数 |
| 纯名词意象招式无动作动词 | 只标 〖☆〗，事件按上下文登记；战斗语境下"使出"可作 ⟦⊞⟧ | 他使出了〖☆天外飞仙〗 |
| 招式名作受事（中了他的"X"） | X 标 〖☆〗；伤情按 ⊠ 阈值判定 | 中了他一招〖☆开碑手〗 |
| 招式名被习得（学/练成） | X 标 〖☆〗；学/练成标 ⟦▣⟧ | ⟦▣练成⟧〖☆七十二手连环剑〗 |
| 招式名是兵器/人物同形 | 按 01g 同形异类判定先行 | 〖@小李飞刀〗/〖☆小李飞刀〗/〖•小李飞刀〗 |
| 招式名含数字 | 数字是名称成分，不拆 | 〖☆降龙十八掌〗 |

**判定信号**：招式名前后有"使、出、一招、按照、的招数"→ 技术实体 ☆；同句另有明确攻击动词（刺斩扫劈）→ 该动词是 ⊞ 候选，招式名不重复承担动作义；**同一字符不得既标 ☆ 又标 ⟦⊞⟧**；同句只有招式名没有攻击动词且语境是交锋 → "使出/递招"可作 ⊞ 触发词。

**正误对照**：

```text
✅ 使出一招"〖☆怪蟒翻身〗"
✅ 他一招〖☆旋风扫叶〗，⟦⊞扫⟧向敌手下盘（招式实体 + 相邻动作动词）
✅ 使的是武当派〖☆七十二手连环剑法〗（无引号同规则）
❌ 使出一招⟦⊞怪蟒翻身⟧（招式名误标为动词）
❌ 使出一招〖☆怪蟒翻身〗⟦⊞怪蟒翻身⟧（同一字符双标）
```

### 3.5 嵌套禁令

照搬参考件（史记 04f 规则 5 / 02e1 嵌套检查）：

- 动词标注 `⟦⟧` 内部不得包含任何其他标注；
- 已标注实体内部不得拆出动词标注；
- 实体名与动词事件分界：`〖•断门刀〗⟦⊟断⟧了`——"断门刀"是名称，"断"才是事件；
- 武侠高频误模式：〖☆劈空掌〗内拆 ⟦⊞劈⟧；〖@追命〗（人名）内拆 ⟦■追⟧；〖•惊天一剑〗（兵器）内拆 ⟦⊞刺⟧。

### 3.6 否定、条件与未发生的操作细则

01g §2.2.3a 落到动词域：

| 情形 | 动作标注 | 状态字段 | 例 |
|------|----------|----------|-----|
| 已发生 | 标 | 发生=已发生/完成=完成 | ⟦⊠杀死⟧ |
| 已发动但被中断（未遂） | 标 | 完成=未遂 | ⟦⊞刺⟧了一剑，没刺中 |
| 正在发生 | 标 | 发生=正在发生 | 两人⟦⊞交手⟧正酣 |
| 威胁/意图 | 不标 | —（可入言语行为记录） | "我要杀你" |
| 条件 | 不标 | — | "若他敢来，我就废了他" |
| 计划/约定 | 不标 | —（登记层观察档） | "三日后比武" |
| 传闻声称 | 标 | 来源=转述，可信=来源声称 | "听说他已⟦⊠身亡⟧" |
| 回忆/梦境 | 默认不标 | 叙述模式 | 梦中比武不入事实 |
| 险些 X | 不标（X 未发生） | — | "险些丧命" |
| 委婉实现 | 标 | 按实际语义消歧 | 叙述者"结果了他"→ ⟦⊠结果|杀死⟧ |

**未遂判据**（v2 回收，定版）：**已发动但被中断 → 标 + 记未遂**；仅计划、意图、能性否定（打不死）→ 不标。"已发动"的信号：动作已出手/已上路/已入口，有可观察的物理起点。

**委婉与反讽**：叙述者使用的委婉杀语照标（消歧说明）；人物对话中的夸张（"一掌拍死你"）按威胁不标——**信息来源字段决定同一串词的不同命运**。

### 4.2 联动三铁律

1. **联动生成候选，不生成定论**：`⟦⊞点⟧穴`旁出现〖^膻中穴〗→ 候选"点穴(甲,乙,膻中穴)"；仍需核验施受方向，被动句（"被点了穴"）施受反转必须解析；
2. **强制档缺失即降级**：缺强制实体的动词标注保留在语料中，但事件记录打 `待审` 标记，不进 KG 确定性问答、不进评分统计；
3. **四类人物关系不进联动**：情感/恩义/背叛/主仆是登记层离线表（01g §9.2），动词层**不为其设触发词、不为其造行内符号**；`报 X 之仇`类句式只作离线抽取的候选素材，不作行内标注依据。

**防共现误推**（01g §9.2 对齐）：一次交手不自动成为永久敌对；`⟦⊞交手⟧` 只生成战斗事件，敌对关系需多次交手或明示（登记层）；师父与人物同桌吃饭不生成任何三元组。

### 4.3 联动正误对照

| 场景 | ✅ 正确 | ❌ 错误 |
|------|---------|---------|
| 联动方向 | 她⟦⊠救活⟧了他 → 治愈(她,他) | 施受不核验，方向颠倒 |
| 强制缺失 | ⟦▣练成⟧（无武功名）→ 事件待审 | 挂到上下文最近的剑法上 |
| 防共现误推 | "师父与他同桌吃饭" 不生成任何三元组 | 从共现推断师承 |
| 离线关系 | "我与你恩断义绝" 不标 ⟦⊡⟧ | 给情感决裂造行内触发词 |

## 五、词表框架与三档运营法

### 5.1 词表外置 JSON Schema（verbs-v1）

对齐本仓 `kb/招式表.json`（moves-v1）的 evidence/status 思想：

```json
{
  "surface": "点穴",
  "domain": "⊞",
  "subtype": "擒控",
  "tier": "auto",
  "senses": [
    {"pattern": "战斗语境+人身对象", "domain": "⊞", "note": "安全条件：有战斗对手"},
    {"pattern": "非战斗制服", "domain": "⊡", "note": "安全条件：无战斗语境"}
  ],
  "complements": ["倒", "住"],
  "collocations": [
    {"type": "^", "strength": "strong", "predicate": "点穴"}
  ],
  "evidence": [{"book": "白发魔女传", "loc": "2:23", "kind": "正文"}],
  "status": "auto"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| surface | string | 词形（含双音节动词与整词复合） |
| domain | enum | ⊞⊠⊡⊟▣■ 之一；多义词在 senses 分型，主条不填 |
| subtype | string? | 域内子型（擒控/投毒/解除拘禁/剥夺/指点/脱离…） |
| tier | enum | auto（高置信）/ review（多义待审）/ watch（观察） |
| senses | array | 多义分型：`{pattern 语境模式, domain, note 安全条件}` |
| complements | array | 常见结果补语（用于识别"打+死"类整词与"动+补语"主域判定） |
| collocations | array | 联动实体：`{type 实体码, strength: strong\|common, predicate 谓词}` |
| evidence | array | 书:回 出处（章回版抽样） |
| status | string | auto / 待审 / 已核准（运营状态） |

**档位纪律**：**单字高频多义词一律不入 auto 档**——或降 review/watch，或拆入 `complements`（如"死"作补语成分而非独立触发词）。这是 04f1 第三档"不建议批量"教训的武侠化（史记"将"字 236 处过半为"将军"前缀的教训）。

### 5.4 双轨架构与三档运营法（仿 04f1 §V.5，文字规划）

**双轨架构**：人工维护源词表（`wordlists/verbs_source.md`，人只改这里）+ 派生机读 JSON（`wordlists/verbs.json`，脚本生成）。派生过程不冲掉人工条目；批量补标只消费 `tier=auto` 且 `status=已核准` 的条目。

| 档 | 处理 | 验证 |
|----|------|------|
| auto（高置信） | 词形专一，可批量补标 | 批量前后动词计数只增不减；剥标还原 0 差异；抽查 10 处确认语境正确 |
| review（多义待审） | 按分型卡语境逐条判定，禁无条件批量 | 每词独立跑一次、独立验证；争议条目双人复核 |
| watch（观察） | 不批量，试点标注积累语料后复核 | 入观察清单随反思轮更新 |

**执行纪律**（照搬 04f1 V0 红线精神）：已标注的动词格式不得在反思任务中顺手迁移；迁移由专项工具按映射表推进；补标前备份、记录基线计数、补标后核对差异数为 0，否则立即停止审查。

**词表定位**：词表是"候选召回器"不是"自动定类器"（01g 封闭性原则）——词表召回候选，上下文与分型卡定类。

## 六、标注工作流程

**Phase 1 文本分析**：确认场景类型（打斗/传艺/行旅/宴饮/文书）；确认叙述模式（正文/回忆/转述/书信）——决定默认生产策略（01g §2.2.3a）。

**Phase 2 域判定决策树**：

```
动作出现 → 是威胁/计划/条件吗？ → 是：不标（状态留给登记层）
         → 是战斗行为或其胜负结果吗？ → 是：⊞（致害结果转 ⊠）
         → 是生命状态变化吗（死/伤/毒/疗）？ → 是：⊠
         → 是组织/关系/身份变更吗？ → 是：⊡
         → 是物件归属或存毁变化吗？ → 是：⊟
         → 是技艺的传授/习得/剥夺吗？ → 是：▣
         → 是行程级位置变化吗？ → 是：■
         → 都不是：不标
主域定后 → 结果补语归并（§3.1 三问） → 多义则消歧 ⟦⊞X|说明⟧
```

**Phase 3 联动检查**：对照 §4.1 总表核查邻近实体；强制档缺失 → 标注保留 + 事件待审。

**Phase 4 质检**：嵌套检查；边界检查（不吞宾语不跨句）；状态字段齐备；**密度合理性**（见 §6.1）。

### 6.1 连续交锋合并标注（武侠特有的密度规则）

武打段的动词密度是史传的十倍以上。若逐招标注，"左荡右挥，连扫带扎"会把密度统计撑爆。规则：

1. **同一交手单元**（双方未分开、无胜负/场景切换）内，逐招动词不逐个标；标**交锋起止**（交手/跳出圈外）与**关键结果**（中剑/负伤/兵刃脱手/点穴得手）；
2. 总述句（"大战三百回合""斗了半日"）登记战斗持续时长，不造触发词；状态句（"僵持不下"）登记状态；
3. 招式名照标 ☆（密度统计只数触发词，不数实体）；
4. 主干叙事每段动词触发词经验区间 **1-6 处**；超出 10 处 almost certainly 是逐招误标，回查本条 1。

**正误对照**（样本甲改编）：

```text
✅ 那卫士一口刀横扫直劈……居然是"〖☆五虎断门刀〗"的上乘刀法……〖@王照希〗⟦⊞力战⟧，
   那使熟铜棍的卫士⟦⊠中了一剑⟧，跳出圈外……蓦地横刀扫去，一招"〖☆凤凰展翅〗"，径斩对手上盘。
   （交锋起始 + 受伤结果；逐招"横扫直劈""凤凰展翅一招"不逐个造触发词，招式实体照标）

❌ ⟦⊞横扫⟧⟦⊞直劈⟧……⟦⊞挥剑⟧⟦⊞力战⟧⟦⊞荡⟧⟦⊞扎⟧……（逐招轰炸，密度爆炸）
```

### 7.1 SYSTEM_PROMPT

```markdown

## 六域与格式（只能用这六个符号）
⊞ 战斗交锋：⟦⊞交手⟧ ⟦⊞打退⟧ ⟦⊞点穴⟧（战斗控制、胜负结果）
⊠ 生命健康：⟦⊠杀死⟧ ⟦⊠疗伤⟧ ⟦⊠毒发⟧（死伤毒疗、致残、出生）
⊡ 社会关系：⟦⊡拜师⟧ ⟦⊡结义⟧ ⟦⊡劫囚⟧（师承结义婚任、拘禁解除）
⊟ 物件变化：⟦⊟夺得⟧ ⟦⊟借给⟧ ⟦⊟折断⟧（归属转移、制造毁损）
▣ 技术传习：⟦▣传授⟧ ⟦▣练成⟧ ⟦▣偷学⟧（授受习成、废功）
■ 行踪迁移：⟦■抵达⟧ ⟦■押解⟧ ⟦■逃亡⟧（行程级抵离押迁）
消歧格式：⟦⊞走|败走⟧。

## 硬规则
1. 只标已发生的动作；威胁/条件/计划（"我要杀你""三日后比武"）不标；已发动被中断的未遂照标并记未遂。
2. 结果决定主域：打死→⊠整词；打退→⊞整词；夺走→⊟整词；练成→▣整词。同句两个独立事实拆开分标。
3. 招式名标 〖☆〗（如 〖☆怪蟒翻身〗），动作另找触发词；"一招""使出"一般不标；同一字符不双标。
4. 连续交锋不逐招标：标交锋起止 + 关键结果；"大战三百回合"不造触发词。
5. 触发词不吞宾语：⟦▣传授⟧〖☆剑法〗，不写 ⟦▣传授剑法⟧。
6. 实体名内不拆动词：〖•断门刀〗断了 → 断是 ⊟；〖☆劈空掌〗内没有动词。
7. 多义词必须消歧；拿不准的词不标（漏标可回填，错标污染下游）。
8. 每段动词触发词 1-6 处为正常密度；超过 10 处回头检查是否逐招误标。

## 示例一（打斗·合并标注，样本甲乙改编）
原文：那个伏在门后的卫士，似乎是个头目……居然是"五虎断门刀"的上乘刀法……王照希挥剑力战……那使熟铜棍的卫士中了一剑，跳出圈外……蓦地横刀扫去，一招"凤凰展翅"，径斩对手上盘。……一抖手，三柄飞刀连翩飞出，上中下三路一齐打到，那名卫士惨叫一声，身上顿时添了三个窟窿。
标注：那个伏在门后的卫士，似乎是个头目……居然是"〖☆五虎断门刀〗"的上乘刀法……〖@王照希〗⟦⊞力战⟧……那使熟铜棍的卫士⟦⊠中了一剑⟧，跳出圈外……蓦地横刀扫去，一招"〖☆凤凰展翅〗"，径斩对手上盘。……一抖手，三柄飞刀连翩⟦⊞飞出|暗器掷出⟧，上中下三路一齐打到，那名卫士惨叫一声，身上顿时添了三个窟窿。
（逐招不标，只标交锋与结果；招式实体照标；"添了三个窟窿"是状态句，伤情由登记层记录，不强造触发词。）

原文：紫阳道长正想找寻一个有根基的少年继承衣钵……动了收徒之念。卓继贤……一口答允。紫阳道长把他带回山中，全心教授……卓一航已得了七十二手连环剑和九宫神行掌的全部秘奥。
```

## 十、FAQ

**Q1：疗伤、运功、行功调息归哪域？**
A：疗伤/治伤/救活/解毒 → ⊠（治疗）；运功疗伤 → ⊠（本质是治疗，方式入登记层）；日常行功、调息、打坐 → 不标（微动作）；运功御敌按主要结果归 ⊞ 或 ⊠。

**Q2：点穴怎么标？**
A：战斗语境 → ⊞（战斗控制），被点名穴道标 〖^穴道〗 并联动三元组；非战斗制服（防其逃脱）→ ⊡（拘禁子型）；被点住不能动的状态入事件"被控制状态"；解穴 → ⊠（恢复）。

**Q3：传功是 ▣ 还是 ⊠？**
A：技术传习 ▣ 为主域，授、受两个触发区间各标；明写授方耗损（元气大伤）→ 另标 ⊠；未写耗损不加。传功不自动建立师承。

**Q4："把他废了"标什么？**
A：看路径。挑断手筋/打断腿 → ⊠ 致残；化去内力/废去武功 → ▣ 剥夺；一句双事实按表述拆两个触发区间分标，同一字符不得双触发。

**Q5：借剑、还剑、赠剑的方向怎么保证？**
A：⊟ 强制方向字段（借给/借自；还他/还于）；神兵流转链依赖方向，方向未知必须记未知，不按上下文猜。

**Q6：追杀、寻仇、报仇怎么标？**
A：追杀作为持续行为 → ⊞ 子型"追击"，致死实现的那一刻 → ⊠；"杀父之仇""寻仇"是名词性提及，不标事件（作离线恩怨表素材）。

**Q7："我要杀你""待我练成之日"标吗？**
A：不标。威胁与计划不入事实事件；言语行为分析是未来独立层。

**Q8："大战三百回合"怎么标？**
A："大战/交手"可作交锋起点触发词（标记事件发生）；"三百回合"是数量绝不入触发词；纯状态句（"僵持不下"）不造触发词；统计口径数触发词，不数"回合"。

**Q9：使出天外飞仙——"使出"标不标？**
A：招式名标 〖☆天外飞仙〗；"使出"在战斗语境可作 ⟦⊞⟧（攻击行为），非战斗演示则不标；不要既标 ▣ 又标 ⊞，同一字符不双标。

**Q10：传了几招、指点一二算不算授艺？**
A：▣ 子型"指点"，不生成师承三元组；师承以 ⊡ 拜师事件为准（01g §9.2）。

**Q11：劫囚、营救为什么在 ⊡？**
A：01g 定版——救出被囚者主域 ⊡（解除拘禁）；随之的出城/赶路是 ■；打斗是 ⊞；一句多事实分标。

**Q12：闭关十年标 ▣ 吗？**
A：闭关本身不必然标；明写"练成某功/功力大进"→ ▣；出关 → ■；"十年"标 〖%时长〗（实体层）。

**Q13：下毒怎么标——毒在酒里还是人在喝？**
A：人未饮、毒仅入酒 → ⊟ 观察档（物件被污染）；下毒致害 → ⊠（子型投毒），被害人强制联动；解毒 → ⊠（恢复）。

**Q14：比武点到即止、胜负未分怎么记？**
A：比武/较技 → ⊞（交手行为发生）；结果按 outcome 五值记"平"或"未决"——必须指定参照方；"点到即止"是结果描述，不是触发词。

**Q15：围攻、混战、群殴怎么标？**
A：→ ⊞ 群体战斗；参与者记阵营级/代表级，不逐人展开（01g 群组战绩不自动传播成员）；"混战正烈"进行中记发生状态。

**Q16："断门刀"真个断了——兵器名同形怎么处理？**
A：〖•断门刀〗是名称整体标器物；"断了"是 ⊟ 毁损事件。名称与事件分界：实体名内不拆动词。

**Q17：明摆着的招式交锋，为什么只标一两处？**
A：见 §6.1 密度规则——同一交手单元只标起止与关键结果；招式名照标 ☆ 但不计入动词密度；逐招标注会让"节奏指纹"页失真。
