## 三、联动候选：04f 27 行表怎么用

### 3.1 联动表结构（引 04f §四）

| 列 | 含义 | 例 |
|---|---|---|
| 动词域 | 六域之一 | ⊟ 物件变化 |
| 触发词 | 产生联动候选的动词 | 赠/递/交予/夺得 |
| 作用对象类型 | 客体应是哪类实体 | `•` 器物 / `@` 人物 |
| 候选谓词 | 期望关系谓词（D06） | 赠予/持有/夺取 |
| 约束 | 方向/唯一性/排除条件 | 施→受；排除"递茶"类服务性对象 |

### 3.2 候选生成规则

1. **同段优先**：动词与实体在同一 PN 段内才算候选；
2. **邻接约束**：施者（动词前最近 @）、客体（动词后首个目标类型实体或物）；
3. **双实体唯一性**：同段出现多个同类型实体且无法判定 → 不入候选（或 weak）；
4. **否定/计划/假设语境**：按 03a v1.8 计划否定规则——不产生"已发生"关系边（最多记 weak 候选）；
5. **围栏内**：书信/口诀等处动词不标（02ab §4.4），不产边。

## 四、谓词判定（D06 §8.4 语式表）

### 4.1 判定顺序

```text
① 语式直证："A 拜 B 为师"→师承（方向 B→A）
② 动词域+对象类型：⊟ 赠 + • → 赠予
③ 上下文唯一性：同段仅两实体、动作链清晰
④ 多谓词歧义 → 候选池（不硬选）
⑤ 无匹配 → 放弃（记原因）
```

### 4.2 实体关系子类与谓词示例（引 D06 §三/§七）

| 子类 | 判定要点 | 谓词例 | 备注 |
|---|---|---|---|
| 地点关系 | 人物-地点/地点-地点 | 位于/属于/发生于 | 地点用 gazetteer id |
| 制度关系 | 人物-组织/职衔 | 隶属/统属/任职/师承（门派） | "掌门"是职衔（;）非人名 |
| 事物关系 | 人物-器物/文书 | 持有/赠予/夺取/失落 | 神兵表 chain 对齐 |
| 异名关系 | 绰号↔本名 | 异名 | 直接落 03b 别名映射，不重复建边 |
| 武功层级 | 招式∈武功∈心法 | 属于/源自/包含 | 层级归 D08 树，边只记直接关系 |

### 4.3 方向与对称（D06 §八）

- 师承：师→徒（不对称）；结义/婚约：对称（双边记录或对称标记）；赠予：施→受（不对称）；
- 交手：对等（双向可记一次或对称标记）；杀害：施→受；
- 方向反了=RE-03，必须拆边重记。

## 五、五项验证属性（落库门槛）

| 属性 | 判定方法 | 不过处置 |
|---|---|---|
| 方向性 | 动词语义方向 vs 主语/宾语位置 | 拆边 |
| 对称性 | 谓词对称表（婚约/结义对称；师承/赠予不对称） | 补反向 |
| 可传递性 | 师承可链式否？血缘可传递否？（D06 逐谓词定义） | 不推导 |
| 互斥性 | 婚约 vs 仇怨可并存；师承 vs 叛门需时序 | 记时序 |
| 时序约束 | 门派存续/生死/职任期间 | 记 loc 与时间锚（N4） |

> 五属性不过 ≠ 删边：可降 weak 并记"验证未过"原因；strong 边五项全过。

## 六、产物 schema 与落库

### 6.1 edge schema（relations-v0.1 必填）

```json
{"subject":"卓一航","subject_type":"@","predicate":"师承","object":"晦明禅师","object_type":"@",
 "confidence":"ok","loc":"baimo#pn-r12.3",
 "evidence":{"level":"E1","rule":"R-SHICHENG-01","snippet_short":"拜…为师"},
 "params":{"direction":"师→徒","symmetric":false,"transitive":"limited"}}
```

- 必填：subject/predicate/object/subject_type/object_type/confidence/loc/evidence/rule；
- `params` 记验证属性与方向；`derived` 标记派生边（同门）；
- 放弃记录：`dropped[{reason,count,examples}]`。

### 6.2 落库流程（N5）

```text
候选生成 → 谓词判定 → 五项验证 → 置信分级 → 去重/合并（同 S-P-O）→ 写 JSON（断言唯一）
```

- 去重键：subject+predicate+object（方向敏感）；
- 同段多候选 → 取最高置信，其余入候选池；
- 写后断言：edge 字段齐全、类型码合法、loc 可解析。

## 十一、FAQ（首批 6 问）

**Q1 动词"赠"一定产生赠予边吗？**
不一定。"递茶/递剑"可能是服务动作（不产边）；要看语式与对象语义（赠予/借/还/夺分治）。

**Q2 "他是武当掌门"怎么落？**
人物-组织关系：隶属/任职；"掌门"是职衔（;），不是人名（03a L101 纯衔规则）。

**Q3 同一段有 3 个人怎么办？**
同类型多实体无法唯一定向 → weak 候选或不产边；交 03b 消歧后再判。

**Q4 异名关系要建边吗？**
不重复建边；异名=绰号↔本名映射，走 03b 别名系统。

**Q5 为什么 weak 不发布？**
D07 §3.4：发布层单一权威值；weak 只作候选，避免"共现当关系"污染图谱。

**Q6 无事件层导致仇怨落不了库怎么办？**
记"无事件层"放弃原因；04a/E5 事件层落库后重跑，不在本文硬编因果。

## 结语

关系动词的难点在"克制"：动词只是入口，谓词才是断言；方向、对称、时序任何一环不清，边就不该落。宁可记候选，不可编图谱。
