## 一、技能定位与边界

### 1.1 工序位置（登记层执行件）

```text
实体索引（15 类符号 + refs 上下文 + canonical）
        ↓
S-03i 分类登记（本文）：定实体类 → 定树值（≥2 信号）→ 属性赋值 → 多值主值 → 挂叶 → 边界裁定
        ↓
登记行（JSON/表格同构）── N9 lint_taxonomy 校验（挂叶率/结构/漂移）
        ↓
下游：页面筛选 · 关系图着色 · 门派页 · 武功谱系 · WL-15~19 词表 · gazetteer
```

- **前置**：五树定稿（D08）、S-03h 元方法可用、实体消歧（S-03b）完成、N9 可运行。
- **后继**：S-06e 颗粒度审查、页面/关系图消费、词表叶子表同步。
- **现行事实（2026-11-05）**：N9 报告 error 0 / warning 70 / info 35；**挂叶 0/70**（70 个 ◆ 组织未挂叶=warning），本技能首要任务即把这 70 条登记完并复跑 N9。

### 1.2 本文做什么（六件事）

1. **路由**：按 15 类符号把实体分到五树之一（或"不归本任务"放行）；
2. **定树值**：逐条核对该叶判定信号，≥2 独立信号方可定值；
3. **赋属性**：真实性/邪正/品类/存续/江湖活跃状态，默认值文化；
4. **多值主值**：身份 ≤3、地点主值+兼值，主值按各树优先序；
5. **挂叶检查**：只挂叶；挂不进 → 边界裁定；
6. **出登记行**：可序列化 JSON + 可读表格同构，供批量入库与复核。

### 1.3 本文不做什么（边界，越界即错）

- **不改树结构**：新增叶/合并叶走 `SKILL_03h_实体子类_武侠版.md` 与 S-03k；
- **不做同一性消歧**：同名异人/跨书归并走 `SKILL_03j_同形异义_武侠版.md` 与 S-03b；
- **不加行内符号**：登记只写登记层字段，不改 tagged 语料；
- **不设"其他"兜底叶**：挂不进叶 → 边界裁定 → "未定"入查证清单（D08 T17）。

## 二、快速开始（八步操作序）

> 目标：对一批实体跑完"路由 → 定树值 → 属性 → 主值 → 挂叶 → 边界 → 登记行 → 复验"。命令只读或写报告。

```powershell
cd C:\Users\YANG Ruosong\Documents\workspace\Wuxiaxiaoshuo\wuxia-kb
$env:PYTHONIOENCODING='utf-8'

# Step 1 取表达：实体索引 + 上下文（concordance 可查出现回/变体）
python -X utf8 scripts\build_entity_concordance.py --book 白发魔女传

# Step 2 定实体类：按 15 类符号路由五树（器物/丹药类不出本任务）
# Step 3 定树值：逐条核对判定信号，≥2 独立信号方可定值；不足→"未定"入查证清单
# Step 4 属性赋值：真实性/邪正/品类/存续/状态（默认未定，宁未定勿错定）
# Step 5 多值主值：身份≤3；地点主值+兼值；主值按各树优先序
# Step 6 挂叶检查：确认挂叶；挂不进→边界裁定（三问/升级/跨树/通名连锁）

# Step 7 写登记行（附录 A 模板）→ 交登记层入库
# Step 8 复验：N9 结构/挂叶/漂移
python -X utf8 scripts\lint_taxonomy.py --registry registry\entities.json --out-dir logs\taxonomy
python -X utf8 scripts\wordlist_compiler.py --check
```

**判读口径**：Step 8 的 N9 报告看 `挂叶` 率（目标 100% 实体有叶值）与 warning（未挂叶条目按类型列出）；`taxonomy_violations.json` 是逐条违规清单。

## 三、路由与登记行格式

### 3.1 15 类 → 五树路由表

| 类型码 | 实体类 | 去向 | 备注 |
|---|---|---|---|
| `=` | 地点 | 地点树 | 真实性=属性；gazetteer 另管定位 |
| `;` | 职衔 | 职衔树 | 朝廷轨/江湖轨双轨；任命动词测试 |
| `#` | 身份 | 身份树 | 与 `;` 正交：任命职位 vs 社会身份 |
| `◆` | 组织 | 势力树 | 邪正/存续=属性 |
| `☆` | 武功技艺 | 武功谱系树 | 层级四分；品类=属性 |
| `@ ◎ & ~ • + { ^ % $` | 人物/群组/家族/族群/器物/生物/文书/概念/时间/数量 | **不出本任务**，放行 | 器物树/其他树另案 |

### 3.2 登记行格式（表格与 JSON 同构）

```text
名称 | 树值(叶) | 属性字段(真实性/邪正/品类/存续/状态) | 多值与主值 | 依据引文 | 备注(裁定法/升级/跨树触发)
```

```json
{
  "name": "练霓裳",
  "tree": "身份树",
  "leaf": "绿林豪杰",
  "attributes": {"邪正": "未定", "江湖活跃状态": "活跃"},
  "multi_value": {"values": ["绿林豪杰", "武学门派掌门"], "primary": "绿林豪杰"},
  "evidence": [{"book": "白发魔女传", "loc": "1:12", "quote": "…"}],
  "note": "身份主值按公开角色优先；掌门为组织角色另挂势力树关系边"
}
```

> 两种形态字段一一对应，不双轨维护；JSON 供批量入库，表格供人工复核。

## 四、五树登记要点

### 4.1 逐树判定信号与常见错法

| 树 | 判定信号要点 | 常见错法（D08 T 系列） |
|---|---|---|
| 地点树 | 功能/地貌单维度；"X中/里/内"场所指代看语境；真实性属性四值 | T4 真实性当树枝；T15 陌生地名默认"真实" |
| 职衔树 | **任命动词测试**（任命/授/封/升/贬→`;`）；朝廷轨/江湖轨并行 | T7 职衔身份互串（镖师标 `;`、掌门标 `#`） |
| 身份树 | 社会角色/处境四分支；`#`=社会身份/处境，非任命职位 | T6 贬称当身份（女魔头/妖女）；T8 性别当类型；T9 状态当类型 |
| 势力树 | 组织形态三分支；"派/门/教/帮/会/寨/局/世家/山庄"信号 | T1 通名入树（武林/江湖/绿林道）；T16 组织与个体跨类互挂 |
| 武功谱系树 | 层级四分（心法/武功/招式/阵法）；品类=属性 | T3 层级升判随意；T13 品类当层级（轻功当心法） |

### 4.2 属性赋值纪律

| 属性 | 取值 | 默认 | 反例 |
|---|---|---|---|
| 真实性（地点） | 真实/虚构/真实原型改造/未定 | **未定** | 陌生地名默认"真实"（T15） |
| 邪正（身份/势力） | 正/邪/中立/未定 | **未定** | 由绰号/阵营默认判邪 |
| 品类（武功） | 剑/掌/内功/轻功/身法/…（必填主品类） | 必填 | 以品类建树枝（T13） |
| 存续状态（势力） | 存续/隐世/已灭/未定 | 未定 | 建"灭派残门"叶（T9） |
| 江湖活跃状态（人物） | 活跃/隐退/死亡/未定 | 未定 | 以状态建身份叶 |

> **默认值文化**：宁未定，勿错定；"确认无所属"与"信息缺失"是两种缺省态，分开登记（散修 vs 未明门派）。

### 4.3 多值与主值

- 身份多值上限 ≤3；地点"主值+兼值"（如"天山"兼"山脉/门派驻地"）；
- 主值按各树优先序：身份=**公开角色 > 潜伏处境**；地点=**功能主用途 > 兼用**；
- 身份变迁（先邪后正/由官入寇）按**分段**登记（时段+叶值），不并列无序（T12）；
- 多值场合必须显式写主值，不得让图谱着色随机取。

### 4.4 边界裁定顺序（挂不进叶时）

1. **三问裁定法**（`SKILL_03k_类型扩展_武侠版.md`）：是类型吗？已有类型能表达吗？实例 ≥10 吗？
2. **升级判定**（武功）：招式是否达升级三信号（≥2 独立信号）；
3. **跨树指认**：暗器（器物）vs 暗器手法（武功层）等；
4. **通名连锁**：悦来客栈类通名按 D08 §2.5 分实例+连锁边；
5. 仍无法裁决 → 上报 D08 附录 B 或"未定"入查证清单。

## 八、成功标准（Success Criteria）

1. **挂叶率**：五树覆盖实体 100% 有叶值（或显式"未定"入查证清单）；N9 未挂叶 warning 清零。
2. **信号合规**：抽样 30 条，≥2 独立信号率 100%；无单信号硬归。
3. **属性纪律**：默认值偷懒（真实性/邪正默认"真实/正"）= 0；品类必填率 100%。
4. **多值合规**：身份 ≤3；主值显式率 100%；变迁分段无并列无序。
5. **可复核**：每条登记行有依据引文与定位；JSON/表格可 diff 复跑。
6. **零越界**：兜底叶 = 0；行内符号改动 = 0；属性入树 = 0。
