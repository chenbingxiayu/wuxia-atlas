## 一、三层标注框架（照搬）

| 层次 | 括号 | 本质 | 武侠示例 |
| --- | --- | --- | --- |
| 实体层 | `〖〗` | 指称世界中的对象 | `〖@王照希〗`、`〖=武当山〗`、`〖☆五虎断门刀〗` |
| 修辞层 | `〘〙` | 语言自身的固化单元 | `〘※快意恩仇〙` |
| 事件层 | `⟦⟧` | 世界中的行为动作 | `⟦⊞交手⟧`、`⟦⊠中毒⟧` |

**关键区别**（承史记版论点）：`快意恩仇` 不指称江湖中的任何具体对象，是白话武侠词库中的固化多词单元（multiword expression），标注的是**语言本身**。符号定版以 `symbols.py` 为唯一来源（`RHETORIC` 表），文档与脚本不得各自另立字符。

## 二、类型系统

### 2.1 当前启用（仅 ※）

| 符号 | Unicode | 类型 | 定义（01g §2.2.2） |
| --- | --- | --- | --- |
| `※` | U+203B | 固定表达 | 成语及经核定的固定熟语，不直接指称内部人物或地点 |

**格式**：
- 基本：`〘※固定表达〙`
- 消歧：`〘※原文形式|规范形式〙`（分隔符 = ASCII 管道符 `|`，与实体消歧 `〖@显示名|规范名〙` 同一管道体系）

**启用纪律**（01g §2.2.2 使用规则照录要点）：后置启用，不影响实体和事件主任务完成；**不把所有四字词都当成语**；武功名优先作为技术实体，不重复标修辞；实际讲述历史人物时，不以成语形式掩盖真实指称。

### 2.2 消歧规则

**何时不加消歧**：原文形式即通行规范形（如 `〘※血海深仇〙`）。

**何时必加消歧**：

| 情形 | 武侠示例 |
| --- | --- |
| 字序/字形变体 | `〘※同归于尽\|一同归尽〙`（底本变体，原字保留） |
| 字数不同 | `〘※冤有头债有主\|冤各有头债各有主〙` |
| 口语化长形对规范形 | `〘※君子报仇十年不晚\|君子报仇十年不迟〙` |
| 江湖切口的通语换算 | `〘※风紧\|风头紧，速走〙`（切口措辞登记为子型后按此格式换算） |
| 点校确立 | 用户点校裁定的变体 → 规范形 |

底本变体**原字入标**（"欲如"式可逆性纪律同理）：变体写进 `|` 左侧，规范形写右侧，谁也不许改谁的字。

### 2.3 预留扩展（子型登记制——对齐 01g §2.2.2 扩展治理，与史记版的差异点）

史记版预留 `✦典故 / ✧谚语 / ⁂其他修辞` 三个符号位；**武侠版不采纳新符号**，按 01g §2.2.2 扩展治理执行：

| 子型 | 处置 | 依据 |
| --- | --- | --- |
| 典故 | 可登记为修辞**子型**（字段区分，不新设符号） | 01g §2.2.2：典故、谚语、切口措辞可以登记为修辞子型，暂不分别设置新符号 |
| 谚语/武学谚语 | 同上（子型） | 同上；识别门槛见 02k 熟语种子表 |
| 江湖切口措辞 | 措辞归修辞子型；**切口制度本身归专门概念（`^`）**——两者不是同一对象 | 01g §2.2.2 |
| 其他修辞句式（比喻/排比） | **不标注**——句式修辞属写作分析，不属固化单元 | 01g 只定固化表达；句式层不设符号 |

史记版三符号（✦✧⁂）在武侠库为**未启用候选**，见附录 B。

## 三、固化单元分流表：修辞层 vs 结构层围栏（武侠新增核心）

武侠章回体有一批"看起来像修辞"的固化文学单元。01g §2.2.2 定了总原则：**对联、诗词、歌词优先属于结构层**。本文按 02ab §4 围栏枚举逐项分流：

| 固化单元 | 去向 | 具体约定 | 依据 |
| --- | --- | --- | --- |
| **回目对句** | 结构层（标题优先） | **不围栏、不切 PN、不标任何实体/修辞符号**；对仗文学性由**回目元数据**承接（全角空格拆分句，前半上联后半下联，存回目元数据不写进标注文件） | 02ab §2.2 |
| **回末对**（行首"正是："） | 结构层 | `::: 回末对` 围栏 + 独立 PN；实体限实指；**不抽事件** | 02ab §2.4 / §4.1 |
| **对联**（回中楹联/门联） | 结构层 | `::: 对联` 围栏 + 独立 PN；分流三判据（成段/完整/自称文体）见 02ab §4.3 | 02ab §4.1 / §4.3 |
| **武功口诀**（全文） | 结构层（观察类） | `::: 口诀` **观察类**围栏：试点期遇真实案例才启用并逐例登记，暂不计入正式统计口径；技术名可标（01g FAQ Q14） | 02ab §2.5 / §4.1 |
| 叙述提及（"传了口诀"） | 正文 | 禁止见"口诀"二字就围栏 | 02ab §2.5 |
| **行内固化表达**（对白/叙述中的成语熟语） | **修辞层（本文领地）** | `〘※〙` 标注——它们不独立成段，进不了围栏 | 01g §2.2.2 |

**分流判据一句话**：独立成段的固化文学单元找 02ab 的围栏类型；嵌在句子里不独立成段的固化表达才归 `〘※〙`。两者互斥：围栏内不再套 `〘※〙`（对联/回末对的文学性由围栏类型承载，逐字成语抽取属 02k 词表层事务，不在标注上叠符号）。

**正误对照**：

```markdown
❌ 错误一（回目对句标修辞/围栏）：
# [0] 第一回　铁矢神弓　少年扶巨宦　金鞍宝马　大盗震虚声
::: 对联
〘※铁矢神弓〙　〘※金鞍宝马〙
:::
（回目行是标题层，行内零标注；对句文学性入回目元数据，02ab §2.2）

❌ 错误二（武功名当成语）：
他使出〘※白虹贯日〙，剑势陡变。
（白虹贯日此处是招式名——武功名优先技术实体 〖☆白虹贯日〙，不重复标修辞，01g §2.2.2）

✅ 正确：
# [0] 第一回　铁矢神弓　少年扶巨宦　金鞍宝马　大盗震虚声
（回目元数据：上联=铁矢神弓/少年扶巨宦，下联=金鞍宝马/大盗震虚声）

✅ 正确：
他使出〖☆白虹贯日〗，剑势陡变。

✅ 正确（行内熟语才归 ※）：
江湖儿女，讲究的就是〘※快意恩仇〙四个字。
```

## 四、互斥原则（照搬）

**三层标注绝对互斥，不得嵌套**（01g 三层独立外括号策略 + 禁忌清单）：

| 情况 | 规则 |
| --- | --- |
| 固定表达内部有实体成分 | ❌ `〘※〙` 内不得嵌 `〖〗`（如 `〘※〖@王照希〗之辈〙`） |
| 固定表达内部有动词 | ❌ `〘※〙` 内不得嵌 `⟦⟧` |
| 已标实体的文字 | ❌ 不可重叠 `〘※〙` |
| 已标动词的文字 | ❌ 不可重叠 `〘※〙` |

```text
❌ 〘※〖@管辂〗之交〙       （固定表达内嵌实体）
❌ 〘※〖=华山〗论剑〙       （内部地名特指 → 见 02k 可替换性判据裁决）
✓ 〘※莫逆之交〙            （整体作固定表达）
✓ 〖=华山〗论剑            （华山特指 → 标地名；"华山论剑"作为事件称名归 04a 事件层，不标 ※）
```

遇冲突如何抉择（整体成语还是保留实体）→ **可替换性判据见 02k §3.3**；本文只管"互斥不得嵌套"这条形式铁律。检测落点：`lint_text_integrity.py --check-nested`（嵌套检测）与 `lint_symbol_conflicts.py`（嵌套/跨标点六项检查）；误标清理走 `fix_nested_annotations.py`。

## 六、渲染语义（概念，不含实现）

- **朱批圈点风格**（承史记版设计）：`〘※〙` 内容以赭石色加重呈现，括号字符以浅色弱化——成语是"圈点批注"而非正文强调；
- **消歧形式的展示**：`〘※原文形式|规范形式〙` 在章节页显示原文形式（底本原字），规范形式作 tooltip；索引页以规范形式为条目名、注明"底本作 X"；
- **索引页**：成语索引由渲染管线从标注文本提取生成；史记版 `render_chengyu_html.py` 的"已标注 + 总结性"双轨合并思路保留，脚本**未移植**（02k §五的词表双轨先行，见附录 B）；
- 渲染层只消费剥标前的标注文本与提取 JSON，不自行解析 `|` 管道语义——语义归 `symbols.py` 单一定版。

## 八、检查清单（形式合规）

- [ ] 使用 `※` 符号（U+203B），非 `*` 或 `＊`；
- [ ] 括号为 `〘〙`（U+3018/3019），非 `【】` 或 `⟦⟧`；
- [ ] 固定表达内部**无**任何 `〖〗` 或 `⟦⟧`（`--check-nested` 通过）；
- [ ] 消歧分隔符为 `|`（ASCII 管道符），左侧恒为底本原字；
- [ ] 固化表达边界完整（不拆分、不截断）；
- [ ] 武功/技艺名未误入 `〘※〙`（优先 `〖☆〙`，01g §2.2.2）；
- [ ] 回目对句/回末对/对联/口诀未误标 `〘※〙`（§三分流表，02ab §4 围栏枚举承载）；
- [ ] 去标注后的纯文本与锁定底本逐字一致（`lint_text_integrity.py` 通过）。

## 结语

修辞层是三层标注里最"轻"的一层，但边界最容易被踩糊：往上是围栏里的诗词对联（结构层领地），往里是招式名（技术实体优先），往外是切口的制度本身（专门概念）。本文把每一块都钉回它的定版出处——符号找 `symbols.py`，围栏找 02ab §4，判据找 02k——〘※〙只做一件事：给嵌在句子里的固化表达套上可剥离的圈点。
