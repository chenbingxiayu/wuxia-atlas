## 三、三层关系体系（引 D06）

### 3.1 事件关系（§二，9+3 类型）

| 类型 | 说明 | 例 |
|---|---|---|
| sequel / causal / cross_causal / part_of / opposition / cross_ref / co_person / co_location | 8 类直迁（D06 §二） | 先拜师后学艺=sequel |
| concurrent | 重定义为"书内时序对齐" | 同回两线并行 |
| **传承关系**（新增） | 武功/称号/门派传承源 | 晦明→传人 |
| **伏笔-回收**（新增） | 武侠特有叙事结构 | 前回伏笔后回兑现 |
| **跨书设定引用**（新增） | cross_book_ref（实体同名不建，D07 §4.7） | "参见拙著《…》" |

### 3.2 实体关系（§三，三分 + 扩展）

| 子类 | 内容 | 谓词示例 |
|---|---|---|
| 地点关系 | 练功地/山门/决战地/归属 | 位于/属于/发生于 |
| 制度关系 | 门派等级/隶属/职衔 | 隶属/统属/任命 |
| 事物关系 | 兵器持有链/秘籍归属/异名 | 持有/赠予/异名（=绰号映射） |
| 武功层级（补写） | 招式∈武功∈心法 | 属于/源自/包含 |
| 兵器-持有链 | 神兵表 chain 模式 | 持有/交予/失落 |

### 3.3 人物关系（§四，五类 + 4 离线接口）

师承（拜师/逐出/叛门/自立）、结义（八拜/反目）、情缘（夫妻/恋人/单恋/情敌）、仇怨（灭门/夺爱/夺秘籍，须关联因果事件）、同门（同师/同辈分）+ 情义层离线接口（救/叛/赠/辱/爱恨）。

## 四、55 谓词总表（D06 §七 结构，本文只用不重列）

### 4.1 组织方式

| 维度 | 内容 |
|---|---|
| 总数 | 55 条 SPO 谓词（D06 §七 定版） |
| 命名 | 中文谓词；施者/受者方向显式（"施者→受者(物)"） |
| 与 04f 关系 | 04f 动词域 → 联动候选 27 行 → N5 谓词判定（04f 是触发词，关系层是断言） |
| 派生 | 同门可由"同师"派生（N5 实测 +16 同门派生边） |
| 新增纪律 | 新谓词必须回写 D06 §七（用户/Lead 拍板），N5 不私自扩 |

### 4.2 谓词落层规则（哪条边归哪层）

```text
有事件锚点（04a event_id/PN 事件）→ 事件关系层
实体间持久结构（隶属/持有/层级/异名）→ 实体关系层
人物间社会关系（师承/结义/情缘/仇怨/同门）→ 人物关系层
情感/恩义/背叛（无稳定 SPO 结构）→ 情义层离线表（05c）
```

## 五、五项验证属性（落库门槛，引 D06 §八）

| 属性 | 问法 | 不过时 |
|---|---|---|
| 方向性 | 施者→受者方向是否唯一 | 降置信/拆边 |
| 对称性 | 该谓词是否应双向（结义/婚约对称；师承不对称） | 补反向或纠正 |
| 可传递性 | 是否允许链式推导（师承可传？血缘可传？） | 不推导，只记直接边 |
| 互斥性 | 是否与另一谓词互斥（婚约 vs 仇怨不必互斥；师承 vs 叛门需时序） | 按时序裁定 |
| 时序约束 | 边的成立/失效时间（门派存续、生死） | 记 loc/时序证据 |

### 5.1 置信分级（N5 口径）

| 档 | 条件 | 用途 |
|---|---|---|
| strong | 明示语式/直接动词+唯一性 | 可展示 |
| ok | 联动候选+上下文唯一 | 可展示（抽检） |
| weak | 弱语式/多候选 | 只作候选，不展示（D07 §3.4 发布层纪律） |

## 八、错误模式库（RE 系列）

## 十一、FAQ（首批 6 问）

**Q1 55 谓词都要用吗？**
不。当前只用 16 种（N5 实测）；其余待事件层/证据成熟。未用不等于废弃。

**Q2 weak 边能发布吗？**
不能（D07 发布层纪律）；只作候选/复核池。

**Q3 为什么有些关系落不了库？**
N5 放弃 1,145：无事件层（仇怨/毁损需事件锚）、证据不足、谓词不匹配；分别转 04a/候选池/D06 讨论。

**Q4 同门为什么是派生边？**
同门=同师派生（D06 定），N5 实测 +16 派生；不人工逐条标。

**Q5 05c1/05c2/05c3 子技能存在吗？**
不存在（docs/05 §2.4 已确认仅规划名）；由本文+05b+05c 覆盖，不单设。

**Q6 旧站 90 条武功考订边怎么办？**
D06 无对应谓词，EX-4 不导出并记 field_gaps；是否新增谓词由 D06 拍板。

## 结语

关系层的价值不在"边多"，而在**每条边都知道自己属于哪一层、用哪个谓词、凭什么证据、哪几项验证过了**。三层结构定归属，55 谓词定语言，五项验证定质量——三者齐了，关系图才可信。
