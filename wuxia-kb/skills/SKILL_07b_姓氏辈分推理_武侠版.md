## 一、定位与边界

### 1.1 工序位置

```text
03a/03b 实体/规范名 · 03b §六 同名异人 · 05c 双树 · N5 师承树/lineage_labels · N10 SKU
        ↓
07b 姓氏辈分推理（本文）→ 辈分假设/lineage 标签 → 05c 辈分标签升档 · SKU seniority/teachers
        ↓
07c 称谓辈分检查（N8）· 07a 跨书年代（师承代数）· 关系页谱系展示
```

### 1.2 本文做什么

1. **辈分字/排行字推理**（R8）：人名首字/排行（伯仲叔季）作为候选信号；
2. **师承传播**（R4/R5）：师承链代距→师叔/师祖/同门/第几代弟子；
3. **门派归属推理**（R2）：字辈+武功+活动范围→门派；
4. **阻断规则**（R6）：叛门/逐出/改投师门中断传播链（类比改氏阻断）；
5. **绰号→本名传播**（新增）：以 03b 别名映射为基础扩散候选；
6. **武功标志推理**（新增）：独门武功→某派传人（弱证据，须 E1 武学归属佐证）；
7. **输出**：辈分假设表 + lineage 标签建议 + 置信（weak/low 为主）。

### 1.3 本文不做什么

| 不做 | 归属 |
|---|---|
| 跨书年代对齐 | 07a（本文只供师承代数） |
| 双树边的落库/派生 | 05c/N5 |
| 称谓穿帮裁决 | 07c/N8 |
| 同名异人限定 | 03b §六（本文消费） |
| 亲属关系抽取 | 05c/N5（血缘树当前未产出） |

### 1.4 与 D05/D06 的关系

- D05 §五 M6：师承代数×25-30 年是**年代**用途（07a）；本文是**谱系位置**用途（辈分/同门/门派），同源不同目标；
- D06 §五：双树同构（血缘+师承）——本文的传播/阻断/推导规则直接复用双树结构；
- N5 实测：师承树浅、lineage_labels 全 weak——本文输出以 weak/low 为主，**不强行升档**。

## 三、推理模式（五步骨架，照搬 07b）

### 3.1 骨架

| 步 | 原义（史记） | 武侠转写 |
|---|---|---|
| 1 种子 | 姓氏/国氏起点 | 明示的师承/门派/字辈/绰号映射（E1/E2） |
| 2 多路径传播 | 父系/封邑/迁徙 | 师承链、门派归属、绰号映射、武功传承 |
| 3 置信衰减 | 每跳降档 | 每多一跳降一档（strong→ok→weak→淘汰） |
| 4 反向约束 | 不与已知冲突 | 与明示师承/门派/同名异人冲突即排除 |
| 5 迭代扩圈 | 扩到新实体再传播 | 新确认者作为种子继续传播，直到收敛/冲突 |

### 3.2 规则映射（docs/05 §2.4 指定）

| 原规则 | 武侠转写 | 说明 |
|---|---|---|
| R2 邦国→人物归属 | **门派归属推理** | 字辈/武功/活动范围→门派（弱证据） |
| R4 父系传播 | **师承传播** | 师→徒→再传，方向严格 |
| R5 母系/姻亲传播 | **师门旁系传播**（同门/师兄弟） | 旁系不等同直传，降档 |
| R6 改氏阻断 | **叛门/逐出/改投阻断** | 结构同构：身份变更断链 |
| R8 人名首字→姓氏 | **辈分字/排行字推理** | 首字/排行作候选，非定案 |

### 3.3 新增两条（武侠特有）

1. **绰号→本名传播**：消费 03b 别名映射（WL-01 词表）——已知绰号↔本名的，扩散到新出现的称谓形式；**反向（本名→绰号）需自名/叙述判同证据**；
2. **武功标志推理**：独门武功（如"××剑法"）出现→某派传人候选（E3）；但"会使独门武功"可能来自偷学/奇遇/秘籍（02ab 负规则十一/04a 叙述模式），须 E1 武学归属或师承明示才升级。

## 四、辈分/排行推理细则（R8）

### 4.1 信号类型与强度

| 信号 | 例 | 强度 | 处置 |
|---|---|---|---|
| 明示师承 | "拜××为师" | 强（E1） | 直接入树 |
| 同门明示 | "师兄弟""同门" | 强 | 建同门 |
| 法号/字辈 | "慧"字辈、"玄"字辈 | 中（E3） | 候选；需同门/门派佐证 |
| 排行字 | 伯/仲/叔/季、老大/老二 | 中 | 候选；同族/同门语境 |
| 门派字辈谱 | 少林"玄慧法"式 | 中 | 需门派字辈表（词表缺失） |
| 自称/称呼 | "师叔""师兄" | 中 | 需双方身份与方向核对 |
| 武功标志 | 独门武功 | 弱（E3→E4） | 仅候选 |

### 4.2 辈分推导规则（与 05c 双树一致）

| 关系 | 推导 | 置信 |
|---|---|---|
| 师祖/师伯/师叔 | 师承树代距 2/1 | ok（明示）/weak（推断） |
| 同门/师兄/师弟 | 同师 + 入门先后 | ok（同师明示）/weak（先后不可判） |
| 第 N 代弟子 | 从开山祖师代距 | weak（根节点不明时 low） |
| 侄辈/孙辈（跨门） | 双树联合 | weak/low |
| 跨书辈分 | 系列身份+双树+07a 年代 | **low** |

### 4.3 反向约束（必须做）

- 与明示师承冲突 → 排除候选；
- 与同名异人（两个"铁掌"）冲突 → 分树，不并；
- 与"叛门/逐出"状态冲突 → 断链或降档；
- 一人多师：需时序+门派限定，否则 weak。

## 五、阻断规则（R6，武侠版核心）

| 阻断事件 | 效果 | 证据 |
|---|---|---|
| 叛门 | 该师承链的**传播**中断（历史师承仍存在，但不外推） | 明示"叛出师门" |
| 逐出师门 | 同上；同门关系解除 | 明示"逐出" |
| 改投门派 | 旧门派归属终止（历史保留），新归属另行推理 | 明示"改投" |
| 死亡 | 关系不传播（不因死亡推给后人） | 事件/正文 |
| 同名异人 | 不同树，互不传播 | 03b §六 |

> 与 05c 一致：阻断是**状态事件**，不改"曾拜师"事实；但推理传播链到此为止。

## 十、FAQ（首批 6 问）

**Q1 "玄"字辈能直接定辈分吗？**
不能。字辈是候选信号（E3），需同门/门派明示佐证；否则只入候选池。

**Q2 师承树和 N5 lineage_labels 什么关系？**
N5 从师承边推导标签（当前全 weak）；本文补充候选/阻断/门派维度并给升档建议，不覆盖 N5。

**Q3 叛门之后还算同门吗？**
历史师承保留，但推理传播断链；关系页显示叛门状态。

**Q4 跨书辈分为什么只能 low？**
跨书需身份归并+系列年代+双树多跳，假设层数多；07a 同纪律。

**Q5 武功标志推理靠谱吗？**
仅候选。独门武功可能来自偷学/奇遇/秘籍；需 E1 武学归属或师承明示才升。

**Q6 血缘树什么时候能用？**
当前未产出（27 行联动无亲属触发）；本文的亲属辈分推理暂缺，附录 B 标注。

## 结语

姓氏辈分推理的关键是**承认证据的层级**：字辈是线索，师承是骨架，阻断是边界。骨架清楚、边界守住，辈分推断才不会变成"按名字猜门派"的玄学。
