## 一、何时使用

- 对新回首次铺熟语标注（试点期以书为单位冷启动）；
- 对已有标注反思：发现"本该是熟语但标了实体"、"标了太短非熟语"等错误；
- 审视 `wordlists/` 熟语种子表条目与原文的对应关系；
- 用户点校指出某处应/不应为固定表达，需同步更新词表与标注文件。

## 三、熟语种子表冷启动（武侠新增核心）

### 3.1 为什么冷启动

史记版有前人整理的《史记成语典故》权威词表（约 350 条）做轮 1 底料；武侠库没有对应资产——网络流传的"武侠小说成语表"既不权威也无锚句。因此词表必须**从试点标注中反向累积**，而不是先造一张大表再找原文。

### 3.2 种子表三子类

| 子类 | 定义 | 武侠示例 | 注意 |
| --- | --- | --- | --- |
| **四字格**（成语型固定表达） | 四字或多字固化熟语，意义不完全从字面推导 | 快意恩仇、恩断义绝、寸步不让 | 收录判据走 §4 三问法 |
| **武学谚语**（武谚） | 关于武理武德的固化格言，多为口语句 | 拳怕少壮、一寸长一寸强、练拳不练功到老一场空 | 多字散句也可收录（对齐史记"桃李不言，下自成蹊"式非四字熟语） |
| **江湖切口**（措辞层） | 固定的行话措辞（不是切口制度本身） | 风紧（=速走）、并肩子（=同伴）、踩盘子（=探路） | **切口制度归专门概念 `^`，具体措辞归修辞子型**——两者不是同一对象（01g §2.2.2） |

### 3.3 种子表结构建议（对齐 wordlist_compiler.py 双轨铁律与 D09 八字段）

人工源 `wordlists/chengyu_source.md`（简单表格式，C0d 可编译）建议列：

| 字段 | 说明 | 取值/示例 |
| --- | --- | --- |
| `surface` | 底本原形（锚句中实际字串） | `风紧` |
| `canonical` | 规范形（消歧右侧；与 surface 同则留空） | `风头紧，速走` |
| `subkind` | 三子类 | `四字格` / `武学谚语` / `切口`（字段名待与 02j 附录 B-1 一并定稿） |
| `type` | 修辞码 | `※`（固定表达，对齐 symbols.RHETORIC） |
| `tier` | 三档 | `auto`/`review`/`watch` |
| `conf` | 置信 | `strong`/`ok`/`weak` |
| `evidence` | 锚点证据，`书:回` 多条空格分隔 | `白发魔女传:3 七剑下天山:17 …` |
| `status` | `auto`/`待审`/`已核准` | 编译产物纪律同全局 |
| `note` | 备注变体/出处判语 | 变体归一说明 |

编译：`python scripts/wordlist_compiler.py --name chengyu` → 产出机读 `wordlists/chengyu.json`（**禁止手改**，改源重编译）；`--check` 供 CI 校验。互不冲掉：编译不删人工条目，人工源不经派生产回写（C0d 双轨铁律照搬）。

### 3.4 收录门槛：试点期 3+ 案例才收录

**硬门槛（本文定版）**：一条熟语进入种子表正式收录（`tier=auto` 或 `review`），须满足**至少 3 处独立案例**——evidence 列 ≥3 条 `书:回` 锚点，且分属不同回（同回重复只计 1）。

- **不足 3 例**：登记 `tier=watch`（观察档），只在标注文件就地标注、不进正式词表——防"单回偶发四字串"污染词表；
- **满 3 例**：升 `review`，人工核锚句与判据（§4）后定 `已核准`；
- **跨书重复优先**：3 例中含 ≥2 部书的条目置信天然更高（共享宇宙的通语，非单书风格），可直取 `conf=strong`；
- `auto` 档消费纪律沿用全局：`tier=auto 且 status=已核准` 才允许批量补标（wordlist_compiler auto_ready 纪律）。

**正误对照**：

```text
❌ 错误（单例收录）：第 5 回出现一次"剑气纵横"（实为描写套语）→ 收入种子表 → 批量补标 34 部
   → 34 处误标全是描写性四字串（可逐字理解，§4.1 不标项）。

✅ 正确："剑气纵横"登记 tier=watch，只标本回；试点期跨书扫描满 3 例且过三问法再升档。
```

## 四、识别决策规则

### 4.1 什么算固定表达

✅ **标**
- 四字固化熟语（快意恩仇、恩断义绝）；
- 非四字但固化的熟语/谚语（拳怕少壮、留得青山在不怕没柴烧）；
- 江湖切口固定措辞（风紧、并肩子——修辞子型，符号仍 ※）；
- 通行汉语中固化的成语在武侠对白/叙述中的惯用（见 §4.4 与负规则十的边界）。

❌ **不标**
- 普通可逐字理解的短语（上门挑战、联手对敌、拔剑出鞘）；
- 2-3 字名词或短语，非固化熟语（真气、轻功、秘籍——归 〖☆武功技艺〗 等；掌门——归 〖;职衔〗）；
- 武功/招式名（五虎断门刀、白虹贯日——**武功名优先 〖☆〙技术实体，不重复标修辞**，01g §2.2.2）；
- 描写性四字节奏串（剑光闪闪、人影幢幢——02ab §5.2 已证明这是散文高频陷阱，词表层同理不得收录）；
- 书名/诗词内部字串（围栏与回目单元按 02j §三分流，不在句中叠 ※）。

### 4.2 三问法（照搬）

1. 后世汉语/武侠语料中是否有此固化表达？
2. 意义是否不能完全从字面推导？
3. 在本处是否为固化惯用（而非逐字实指）？

任意两问为"是"即倾向标注；倾向标注仍须过 §3.4 案例数门槛。

### 4.3 可替换性判据与冲突优先级（照搬 + 武侠化）

规则：**固定表达优先于实体与动词**（语言层整体 > 局部指称），**武功名例外优先**。

- 判断标准：内部专名能否替换为另一具体专名而语义自然？
  - `快意恩仇` → 不能（泛指）→ 固定表达；
  - `华山论剑` → "华山"能换成别山则语义崩坏——实指地名 → `〖=华山〗论剑`，事件身份归 04a（事件称名），不标 ※；
  - `白虹贯日` → 武功/招式语境下优先 `〖☆〙`（01g §2.2.2 使用规则 + 负规则五武功意象不拆对象）。
- 例外（同史记版）：内部实体在本段承担**实质性指称功能**时，标实体不标固定表达。

冲突示例：

```markdown
✓ 〘※毛遂自荐〙（对白中引史事作惯用语，不拆内部人物——负规则十）
✓ 〘※三顾茅庐〙（同上）
✗ 〖@毛遂〗自荐（把惯用语拆成人物指称——误标）
✓ 他使出〖☆白虹贯日〗（招式名优先技术实体，同一区间不得又标 〘※白虹贯日〙——01g §2.2.2 原例）
✓ 〖=泰山〗之巅（泰山实指具体地点，标地名不标固定表达）
```

### 4.4 与 01g 负规则十的一致性（引用声明，不重复定义）

01g §8.4 负规则十：**成语内部假指称不标**——`毛遂自荐、三顾茅庐、项庄舞剑，作为惯用表达时` 不标内部实体；**例外**：实际历史叙述按真实指称处理。本文的落地口径：

- 对白中引史事成语（"你这是毛遂自荐"）→ 惯用表达，整体 `〘※〙`；
- 叙述中实指历史/典故人物活动（书中人物真在讲毛遂其人的生平）→ 真实指称，按实体规则标；
- 两者判据仍是 §4.3 可替换性：拿掉成语框架后该专名是否承担本段指称功能。

### 4.5 符号与格式边界

本文只决定"标不标"；怎么写（括号、消歧 `|`、子型字段）一律引用 02j §二——格式争议不进本文裁决。

## 五、工作流：四轮反思（照搬骨架 + 武侠版改造）

### 轮 1：批量初标（基于种子表直查）

**输入**：`wordlists/chengyu.json`（编译产物，auto_ready 清单内条目）。
**脚本**：批量初标脚本**规划中**（移植史记 `annotate_chengyu.py`；未落地前由 agent 按词表在标注文件中人工直查落标）。**策略**（照搬三策）：
- A. 直接搜 `canonical` → 干净文本中找到且未被占用 → 标注；
- B. canonical 不在原文，但 `surface`（≤10 字）在原文 → `〘※surface|canonical〙`；
- C. 被整个实体括住且实体文字 == 固定表达 → 删实体，改 `〘※〙`。

**试点期覆盖预期**：无权威词表底料，首轮量远小于史记（150-180 条）；冷启动以 §3.4 门槛累积为主，不追求首轮覆盖数。

### 轮 2：反思与清理

**诊断**（规划中）：基于"去标注纯文本 + 位置映射"查找被实体/动词标注分割的熟语（移植 `reflect_chengyu_round2c.py` 思路）。
**现有落点（已移植脚本先跑）**：
- `lint_text_integrity.py --check-nested`：抓 `〘※〖...〗〙` 嵌套违规；
- `lint_symbol_conflicts.py`：嵌套/跨标点/旧符号六项；
- `fix_nested_annotations.py`：嵌套清理（外层保留）。

**修复策略**（照搬安全机制，脚本落地时必须继承）：扩展边界使括号对平衡；扩展后剥标文本 == canonical 才执行；右→左扫描避免位置错乱；写入前后 `lint_text_integrity.py` 纯文本一致比对。短标清理沿用史记 INVALID_SHORT_TAGS 思路：2-3 字"熟语"（自建表收录门槛已挡一轮，此层兜底）。

典型案例（史记版教训的武侠投影）：

```markdown
快〖=华山〗论剑（地名割裂惯用候选）→ 判据裁决：实指地名 → 保留 〖=华山〗论剑，不转 ※
〖@小丫头〗不知天高地厚 → 〘※不知天高地厚〙（成语跨实体边界且整体匹配 → 吸收重写）
```

### 轮 3：用户点校（增量）

用户以 `片段 -> 规范形式` 指示修正。典型动作（照搬三类）：
- 添加消歧：`风紧 -> 风头紧，速走` → `〘※风紧|风头紧，速走〙`；
- 新增标注：`恩断义绝` → `〘※恩断义绝〙`（并按 §3.4 登记 evidence）；
- 修复误标：`留得〖=青山〗在 → 留得青山在` 型实体割裂 → 裁决后改 `〘※留得青山在，不怕没柴烧|留得青山在〙`。

每次点校后必须：1. 修改对应 `tagged/<书>/NNN.struct.md`；2. 同步更新 `wordlists/chengyu_source.md`（evidence 补锚点）；3. 重编译 `wordlist_compiler.py --name chengyu`；4. 重跑 lint 三件套。

### 轮 4：总结性补充（不逐字标注但保留条目）

有些固定表达**无法逐字锚定**：
- 书中描述了典事情节但从未出现熟语字面（"韦小宝式浑水摸鱼"叙事在先、成语从未落字）；
- 字序颠倒且无连续锚句（叙述性概括）。

处置（照搬双轨思想）：这类条目留在源表并标 `note=总结性`，**不影响回内标注**；索引/检索层后续合并展示（渲染脚本未移植，见 §八）。目标纪律同史记版：总结性条目的锚句验证脚本落地后，`unverified = 0`。

## 六、验证四分类（照搬，脚本规划中）

`verify_chengyu`（移植 `verify_summarized_chengyu.py` 思路）对每条种子表条目分类：

| 状态 | 含义 | 处理 |
| --- | --- | --- |
| **tagged** | 回内已有 `〘※canonical〙` 或 `〘※surface|canonical〙` | 进入已标注清单，从总结表排除 |
| **verbatim** | surface（规范化后）直接在纯文本中 | 可补标，或留作总结 |
| **partial** | 分段锚句至少一段可证 | 留作总结 |
| **narrative** | 原文栏是叙述概括 | 留作总结，展示层打"叙事性总结"徽章 |
| **unverified** | 纯文本中完全找不到锚句 | **必须处理**：删条目（非本库表达/单例误收）或订正锚点 |

**规范化**（照搬思路）：全半角标点统一去除；常见异体/繁简形合并（武侠底本繁简混排风险高于史记，映射表待试点书定）。每次修改源表后必跑校验，目标 `unverified = 0`。

## 七、排除清单（武侠版误入面）

**伪固定表达**（不标，按性质归位）：
| 类型 | 例 | 归位 |
| --- | --- | --- |
| 武功/招式名 | 五虎断门刀、白虹贯日、天外飞龙 | `〖☆〙`（优先技术实体） |
| 武功类普通名词 | 真气、轻功、内力、秘籍 | `〖☆〙` / `〖{秘籍书名〗`（按 01g 类型表） |
| 描写性四字节奏串 | 剑光闪闪、杀气腾腾、身形一晃 | 不标（散文节奏，02ab §5.2 同源陷阱） |
| 可逐字理解动宾短语 | 上门挑战、联手对敌、拔剑出鞘 | 不标（动词短语，04f 触发词域管动作） |
| 切口制度条目本身 | "切口/黑话制度" | `^专门概念`（措辞才归修辞子型） |

**单例条目**：evidence <3 的候选一律 `watch`，不进正式表（§3.4 门槛即排除清单的第一道闸）。

**回目/围栏字串**：回目对句、回末对、对联、口诀内的字串不走 〘※〙（02j §三分流），本表不收录围栏内来源条目。

## 九、检查清单

**识别前**
- [ ] 种子表条目 evidence ≥3 条 `书:回` 锚点（不足 3 例只准 watch）；
- [ ] 锚句在对应回去标注纯文本中可定位；
- [ ] 确认不是武功名/描写性四字串/可逐字短语（§七排除清单）。

**识别中**
- [ ] 跨实体/动词边界的候选：先过可替换性判据（§4.3），再选整体还是保留实体；
- [ ] 武功名语境一律 `〖☆〙` 优先（白虹贯日正误例）；
- [ ] 字序/字形与规范不同：需要消歧 `〘※surface|canonical〙`，原字不动；
- [ ] 切口措辞与切口制度分层（措辞 ※ 子型，制度 `^`）；
- [ ] Markdown 标题行（回目）不标注。

**识别后**
- [ ] `lint_text_integrity.py --check-nested` 通过，剥标文本与底本逐字一致；
- [ ] 源表已同步（evidence/变体/note），`wordlist_compiler.py --check` 通过；
- [ ] 锚句验证（脚本落地后）`unverified = 0`。

## 结语

史记版成语识别是"拿权威词表对号入座"；武侠版没有那张表，反而把工艺逼回了本质：**固化度靠三问法判，真实性靠锚句证，普适性靠 3+ 案例扛**。种子表一例一例长出来，慢，但每一条都带着 `书:回` 的证据链——这正是冷启动换取的东西：词表从第一天起就可验证、可回溯、可跨书。
