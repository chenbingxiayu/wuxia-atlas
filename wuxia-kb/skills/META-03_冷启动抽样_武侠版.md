# META-03 冷启动抽样（武侠版）

---

## 快速开始

1. **选试点**：优先选"已有结构 + 有人工种子 + 体量可控"的书做 pilot（白发经验：32 回范围、001/004 结构已建、旧管线 692 人工种子）。
2. **preflight**（§二阶段 1）：语料/结构/PN/围栏/指纹五查，缺项先补结构再谈标注。
3. **试点 1 回**：单回跑通"标注→五门→accept→qa"，再放量；试点回不得选全书最难的围栏回。
4. **批次切分**：按回数均分 3-4 worker（江湖 48 回/4、七剑 31 单元/3、塞外+冰魄 40 回/4）；每 worker 独立报告目录与 patches 子目录。
5. **抽样复核**：10% 确定性抽样（§三）+ 8 类风险全扫；抽样结果与金标准比对，偏差超阈值回炉。
6. **机械修正+验收**：围栏/token 类批量修正 → 五门 lint → accept → qa 审计 → 统计入 META-02 总表。

> 成功标准：新书从 preflight 到 accepted 全绿 ≤ 2 个工作日；hard 0；抽样复核偏差 ≤ 5%。

## 二、六阶段冷启动流程（照搬框架）

| 阶段 | 动作 | 产物 | 门禁 |
|---|---|---|---|
| 0 选型 | 定试点书/回范围/worker 数/预算 | 批次计划（写范围表） | 书已入库、底本可用 |
| 1 preflight | 语料完整性/结构树/PN/围栏/指纹 | preflight 报告 | 五查全绿或缺口已登记 |
| 2 试点 | 单回标注→五门→accept→qa | pilot 报告 + 基线指标 | hard 0 或已知可修 |
| 3 批次 | 3-4 worker 并行标注 | tagged/patches/report | 每 worker 产物独立可回滚 |
| 4 机械修正 | 围栏/token/空说明批量处置 | delta 报告 | 剥标还原 100% |
| 5 验收 | 五门 lint → accept → qa | acceptance JSON | accepted 全绿、hard 0、unsourced 0 |
| 6 统计 | 总表/轨迹/成本/覆盖率 | META-02 行 + 日志 | 数据可溯源 |

> 纪律：阶段 3 放量前必须有阶段 2 的基线指标；阶段 5 不通过不得进入阶段 6，也不得开下一本书。

## 三、抽样策略（10% 确定性 + 8 类风险全扫）

### 3.1 10% 确定性抽样

- 比例：每批抽 10%（回数向上取整，最少 2 回）；
- 种子：`seed = hash(书名 + 回号 + 固定盐 20261104)`，**同一批重跑抽样结果一致**，便于复核对账；
- 抽样单位：整回（不做段级抽样，避免上下文断裂）；
- 复核内容：逐令牌对照规则文本/种子，统计误标/漏标/边界错误三类；
- 偏差阈值：误标率 >5% 或漏标率 >10% 时回炉整批（不许只修抽样回）。

```python
# 确定性抽样（同批可复现）
import hashlib
def sample_chapters(book: str, chapters: list[int], ratio=0.10, salt="20261104"):
    def key(ch):
        return hashlib.md5(f"{book}|{ch}|{salt}".encode()).hexdigest()
    k = max(2, round(len(chapters) * ratio))
    return sorted(sorted(chapters, key=key)[:k])
```

### 3.2 8 类风险全扫（不抽样，必须全量）

| # | 风险类 | 检查 | 来源 |
|---|---|---|---|
| 1 | 围栏/韵文 | 围栏内令牌按类型豁免，回末预告段不标 | 02ab §4.4 |
| 2 | 计划/否定语境 | plan_negation_verb 全量过 judgment | 03a v1.8 L127 |
| 3 | 时间/数量边界 | time_boundary、quantity_boundary 全量 | 03a §二 |
| 4 | 称谓/敬称 | `#` 与 `◆` 混淆、称谓连写 | 03a DEF 库 |
| 5 | 管道 | 闭括号/吞字/空说明/占位符 | 03a DEF-01/02/14 |
| 6 | 时代通称 | 帝王/年号/通称（皇上/掌门） | 03b + registry context_notes |
| 7 | 结构层 | 围栏数/PN/楔子编号/首行书名行 | 五门 lint |
| 8 | 跨书 canonical | 与系列其他书同人/同名异人 | SKILL_03b 双层 canonical |

### 3.3 复核包与金标准比对

- 复核包：抽样回 tagged + 规则快照（版本锁）+ 种子清单 + 抽样脚本输出（可复现）；
- 金标准比对：有金标准的书（白发 692 人工种子）直接比对；无金标准的书用"双人独立标 + 分歧裁决"；
- 记录：抽样回号、种子值、偏差计数、裁决结论，落 `logs/qa/` 供下批引用。

## 五、并发组织（写范围互斥）

### 5.1 写范围分配（开工前必须建表）

| 资源 | 分配方式 | 冲突后果 |
|---|---|---|
| annotate 报告 | `logs/annotate/<书>/` 按书隔离 | 报告互覆 |
| patches | `config.patches_dir` 按书子目录 | 越界 TSV（034-048 事故） |
| registry | id 在合并时 `max+1` 顺延，幂等 | id 冲突/重号 |
| mapping | 每 worker 快照，合并时按书串行 | canonical 分歧 |
| accept/qa | `--mapping-file/--registry` 显式传参 | 读到别书数据 |
| site/data | Lead 串行收口 | 构建产物互覆 |

### 5.2 并发纪律

1. **一写者一文件**：同一文件同一时刻只允许一个 worker 写；跨 worker 共享文件由 Lead 串行改。
2. **先快照后开跑**：每 worker 启动时记录 mapping/registry/规则版本快照，产物带快照 hash。
3. **产物独立可回滚**：每 worker 输出独立目录，失败只回滚该目录。
4. **Lead 串行收口**：registry/mapping/site 的合并由 Lead 单线程做，合并后跑唯一性断言与二次 apply 幂等测试。
5. **并行上限**：标注 worker 4 个（API 限流与成本可控）；文档/SKILL 类任务可 8 路（docs/57 实证：8 路并行，P2 十份 SKILL lint 全 PASS 100/100）。

## 六、换书差异清单（preflight 必查）

| 差异 | 表现 | 处置 |
|---|---|---|
| 楔子/序章 | 七剑 000 楔子使章号整体偏移 | 章号按底本实际，全书偏移断言 |
| 底本首行 | 7 部书首行书名行格式不一（待修） | 结构层首行规则 + PN 重算 |
| 标点/空格 | 半角标点、全角空格、缩进丢失 | 统一规范化后再切段 |
| 空映射/registry | 新书无 legacy mapping，registry 无条目 | preflight 生成空模板 + 首批补条目 |
| 回末套语 | TAO 词族因书而异（续书预告段） | 收窄 `TAO_RE` + 围栏类型判定 |

| 时代通称 | 帝王/年号指向随书/回变化 | 帝王本名优先 + (书,回) 作用域 |
| 系列层 | 同系列 canonical/互文跨书 | 双层 canonical + 跨书互文表 |

## 九、成功标准

1. 新书 preflight→accepted 全绿 ≤2 个工作日；
2. pilot 回 hard 0 且指标与同系列基线偏差 ≤20%；
3. 抽样复核误标率 ≤5%、漏标率 ≤10%；
4. 并发批次产物零覆盖事故、二次 apply 幂等；
5. 每书批次结束 24h 内更新 META-02 总表行与成本。
