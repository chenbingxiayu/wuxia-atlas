## 触发词边界
1. 最小连续单位：结果补语保留在内（⟦⊠害死⟧⟦⊠遭横死⟧⟦⊞捉着⟧⟦⊟射断⟧）；方式修饰留在外面（纵马⟦■过来⟧、迈步⟦■入内⟧、飞⟦■跑⟧）；不吞宾语（⟦▣传授⟧某剑法 ✓，⟦▣传授某剑法⟧ ✗）——例外：固化动宾受控例表词项整体标（⟦⊠害命⟧ ✓，P3-4，见 wordlists/fossil_verb_objects.json）。
2. 一个区间一个主域。速断：处死/死亡→⊠；砍断器物→⊟；战斗擒住→⊞；拘押判刑→⊡；强制迁移（劫/绑架/押送）→■；救出被囚→⊡；救活→⊠；传授→▣。
3. **省略谓词入口（v1.4）**：`一剑/一掌`允许作省略式动词入口（方式词"反手"等外置）；
4. 动词管道＝完成状态或词义注记：⟦⊞抢上来|劫夺未遂⟧⟦■跃过|越河避险⟧⟦⊡问|判处缳首之刑，执行状态未明⟧。

## 事件状态（动词提及 ≠ 已核实事件）
- 已发生动作照标；同一事件的再次提及照标（两处"劫祖父"都标）。
- 纯计划/意图/条件/否定不标：蓄意内侵、作势欲扑、想谋叛、欲杀、回宫调养吧。
- **命令/要求句中的动作不标**（"将那名叛贼押上来"——命令内容），随后实际执行另标（兵丁⟦■推上⟧）。
- 规范/制度语句中的假想动作不标（祖训条款）；实际执行的同一动作照标（"削爵囚禁"）。
- 传闻/书信声称的动作可标（可信=来源声称）但不升为事实；已施行未遂可标＋注记。
- **疑似诊断（P3-5）**：人物或叙述者依现场迹象作出的疑似诊断（似是中毒/像是被掌力所伤）标事件＋`|疑似，未确证` 注记，不由跨回后文补成事实或回改；同段内被叙述直接修正的不回改首标（006[21]）。
- 文书层分野：第一手往事记录（日记且后文验证）实体动词照标；他人转述声称不升为事实。

## 三、执行流程（六阶段）

### 阶段 1 · 文本准备与上下文包
1. `generate_pn_wuxia.py --book <书> --chapter <N> --verify` → `tagged/<书>/NNN.struct.md`
   （可逆性不过不进标注）。
2. **分块**：优先段界切分；"字"＝Unicode 字符数（含标点，不含段号前缀），上限 700；
   单段超限时按句界细分为子块，保留"段号-子块"映射（`chunk_id = 回.段.子块`），
   输出按段合并后逐段验证；few-shot 的 ≤800 字是独立约束，与块上限无关。
3. **上下文包**（随每块注入 user 消息；映射粒度 v1.2 裁定：**回级文内证据可用**——映射在本回后文建立的，凭回级证据挂管道，如 应大哥→应修阳、天都居士→霍天都；带姓泛称挂管道，如 姓郑的/姓岳的/练姑娘；跨回已核准映射直接可用）：书名/回号/块号 + **《已核准映射表》**
   （人物别名→规范名；初始表＝两粒种子人工核准映射：玉罗刹→练霓裳、神宗→朱翊钧、
   火灵猿→朱宝椿、翻山虎→周同、卓总督→卓仲廉等；登记表建成后由 S-03b 供给）+
   规则版本号（见"版本锁定"节）。

### 阶段 2 · 标注（LLM）
- `temperature=0`，system=§二提示词，user=上下文包+块文本；
- 逐块产出立即过阶段 3；失败废稿重标，重试 2 次后升级人工；
- 断点续传：`progress.json`（批处理 ≥1 回时启用）；
- **A1/A2 两遍 fallback 契约**（困难章）：A1 按 §二实体部分产出实体标记并过结构与语义验收；
  **A2 只新增动词标记，不得修改 A1 已验收的实体标记**（动词区间不得与实体区间重叠，
  触发词不吞实体显示串）；发现实体问题走单独修订流程；合并结果仍与原始基线逐字对账。

### 阶段 3 · 结构校验（三关）
1. **语法合法**：严格解析标记/类型码白名单/管道/闭合关系，禁止嵌套与重叠；
2. **原文保真**：`strip(parsed_output) == source` 逐字符（含空白、换行、标点）；
3. **结构完整**：段号、围栏、段落顺序与输入一致。
- 相似度指标仅用于**失败诊断**，不作为放行门（回锚以 `chunk_id+段号+surface` 表示）；
- **括号归一化政策**：允许的确定性修复仅限"已识别标记内的误写闭合符"；修复后必须重跑
  全部结构检查；原始错误数与修复数分列统计；严禁对正文字符做任何全局替换。

### 阶段 4 · 五门 lint（结构合格门）
`lint_markdown` / `lint_symbol_conflicts` / `lint_text_integrity`（对锁定底本逐字对账）/
`lint_fence_format` / `lint_purple_numbers` 全 0 → 状态 `structurally_valid`。

### 阶段 5 · 语义验收（新增，`structurally_valid → accepted` 的唯一通道）
- **高风险项全查**：含管道标签的映射正确性；■/⊡/⊠ 域归属（拘押/判刑/强制移动/处死）；
  时间宽口径边界；数量新口径边界；D1/D2 应用；计划/规范语句动词误标。
- **抽样**：随机抽 10% 段落做全类型检查（每类实体、每域动词至少覆盖）；
- 不通过 → 该块升级人工全查并回写 §四.2 缺陷库；通过 → `accepted`。
- 两粒种子的语义验收＝人工复核（最高级别），其裁定记录见 docs/21、docs/22、docs/24。

### 阶段 6 · 统计与移交
实体/动词按类型计数写入回级报告；语料移交 S-03b 消歧与登记表（`config.DIR_REGISTRY`）；
新裁定先入种子复核、再入 few-shot（§五.3）。

> 起因（2026-11-05，李钦差案例，docs/47 §7.3）：E0047「李钦差」曾以「全书 40.4 万字散文检索

**纪律（对一切「X 是否某人 / 本名是否揭示 / 两名是否同一人」类考订，三面证据缺一不可）**：

1. **散文面**：全书 `NNN.struct.md` 正文检索（现有做法）；
2. **管道面**：全书 `NNN.tagged.md` 的 `〖@显示串|规范名〗` 管道注释检索——管道是过审
   人工标注的一部分，其映射即已核准的考订结论（grep 模式：`显示串[｜|]`）；
3. **映射面**：`registry/entities.json` + `logs/mapping_frozen_*.json` 逐条核对同名/近名条目。

**判定规则**：
- 三面一致 → 结论成立；
- 管道/映射与散文检索矛盾时，**管道优先**（人工过审 > 自动检索），除非能给出管道错误的
  文内证据（如 028 回 〖@晦明禅师|镜明长老〗 错挂，由相认段证伪——错误管道修正须附证据
  并回写 docs）；
- 收口「本名未揭示」类结论时，必须显式声明「已检三面」，禁止只引散文检索。

**登记侧**：两名同人合并时，保留信息更全者为主实体（id 不变），另一 canonical 降为别名；
`surface→canonical` 全表冲突自检必须为 0 后才允许落盘（`registry_backfill_ch20_32.py` 尾部
自检为可复用实现）。
