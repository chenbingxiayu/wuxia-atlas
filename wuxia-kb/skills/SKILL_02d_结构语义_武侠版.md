## 二、四层语义关系类型学（照搬 + 武侠化）

史记版四层类型学与排版映射思想整体保留，示例与识别方式武侠化。**只降级有领域冲突的层，不新增层**（01g 结构层最低字段纪律）。

### 2.1 第一层：句间关系

句子与句子之间的逻辑连接，最细粒度语义单元。

| 关系类型 | 白话信号词/模式 | 排版语义映射 | 武侠示例 |
| --- | --- | --- | --- |
| **因果** | 因为/所以/于是/这才/顿时 | 原因正常，结果缩进+左边线 | 卓一航泄露行藏 → 官军围山 |
| **并列** | 一边…一边… / 先是…继而… | 横向对照（flex/grid） | 一路向上，一路断后 |
| **递进** | 更/何况/不但…反而… | 缩进+左边线 | 不但剑法精绝，内力更是深不可测 |
| **转折** | 但/可是/却/谁知 | 对比色或转折标记 | 明知山有虎，偏向虎山行 |
| **对举** | 正反对照句式 | 两列并排（grid） | 名门正派未必白，魔教中人未必黑 |
| **总结** | 可见/由此可见/这正是 | 背景色块+左粗边线 | 这正是武当七侠的名号 |

信号词表是**白话初值**：武侠白话的句间连接词远比文言松散，同一词族（于是/这才/顿时）按模板收录，变体试点期回填——方法论同 02ab §6.3 词族归一，本文不另建词表。

### 2.2 第二层：段间关系

| 关系类型 | 识别方式 | 排版语义映射 |
| --- | --- | --- |
| **叙事推进** | 时间标记递进（数月/次日/是夜/翌日——02ab §7.3 时间推进标记集） | 时间轴左边线 |
| **叙事线切换** | 行首且说/却说 + 双转移判定（02ab §7.3：人物集变化/地点转移/时间推进至少两条） | 分隔线 + 叙事线 ID 更新 |
| **对话往返** | 多说话人交替（对话拆分裁决归 02ab §3.4，本文只标关系不拆段） | 交替缩进 |
| **插叙/背景** | 打断当前主线的背景说明（叙述模式=回忆/梦境，01g 字段） | 浅灰背景 |
| **悬念递延** | 段末抛出未解之局，后文隔段揭晓 | 脚注式交叉引用 |

### 2.3 第三层：区块间关系（围栏宿主与围栏内容）

史记版"太史公曰/赞 vs 正文"武侠化为**围栏宿主与围栏内容**的关系。围栏类型枚举只认 `symbols.py` 的 `FENCE_ALL`（7 正式 + 3 观察类，02ab §4.1）。

| 关系类型 | 场景 | 排版语义映射 |
| --- | --- | --- |
| **引出** | 宿主引出句 + 词/诗/歌围栏（"朗声吟道："） | 宿主在正文，围栏居中硬换行 |
| **引出（对句）** | 行首"正是：" + 回末对/对联 | 居中对联样式 |
| **插入文书** | 书信/告示围栏嵌在叙事流 | 信笺/文书样式，事件不核实（负规则十二） |
| **章末收束** | 回末对 → 回末套语 → 回终（C23 已内置 chapter_closing） | 弱化灰斜体 |
| **旁白插入** | 说书围栏（观察类）面向读者 | 旁白样式，不抽事件 |

引出词三兄弟（正是/调寄/看官）的行为规则**引用 02ab §6.4**，不重复定义：正是只做引出词本身不是块；调寄入围栏末行不单独编号；看官须独立成段才考虑围栏。

### 2.4 第四层：章间关系 → 跨书互见（接口，不展开）

史记版第四层（互见/前后呼应/矛盾/系谱承接）在共享宇宙武侠库**升级为两段**：

**书内章间关系**（保留，锚点用 `{作品ID}#pn-r{N}.{X}`）：

| 关系类型 | 场景 | 排版语义映射 |
| --- | --- | --- |
| **前后呼应** | 上回末悬念下回首段接续 | 脚注式交叉引用 |
| **回目预告兑现** | 回目对句预告 vs 正文兑现（预告不抽事件，负规则十三） | 回目页标记 |
| **矛盾** | 同书前后冲突记载 | 红色标记+对比面板（穿帮雷达书内线索） |

**跨书互见**（升级项，只留接口）：34 部共享宇宙中，同一事件/物件/人物关系的跨书记载互见，由 **D07 跨书治理**（`SKILL_跨书治理_武侠版.md` v0.3-draft）全权治理——同一性证据四级分级、`series_identities` 归并表、bare 互文分流。本文的接口义务仅三条：

2. 跨书关系条目**不携带置信判断**——置信归 D07 证据分级，本文只登记"此处与彼处互见"这一事实；
3. 归并裁决变更时（D07 附录 B 撤销协议），本文只更新锚点指向，不重判关系本身。

## 三、结构信号词：引用 02ab §6.2，不重复定义

### 3.1 分级框架（引用声明）

结构层信号词的**唯一词表源**是 02ab §6.2 分级种子表（实测=《白发魔女传》32 回 grep），四级框架：**强结构信号**（单信号触发结构动作）/ **弱信号**（须第二确认）/ **伪信号**（默认不触发）/ **缺位监视**（0 次不收录、试点期跨书扫描回填）。本文引用其结论为句间/段间判读的哨兵，**词族明细一律以 02ab 为准**：

- `欲知/欲如后事如何` + `下回分解` 词族 = **强**信号（回末套语，回末标志）；
- `正是` = **弱**信号（对句引出词，须支路 C 过门槛）；`调寄/右调` = **弱**（词牌署名）；
- `且说/却说`（行首）= **弱**信号（叙事线切换候选，须 §7.3 双转移第二确认）；
- `但见/只见` = **伪**信号（叙事动词，永不单独触发结构动作，仅作 N2 降权与 E15 告警哨兵）；
- 有诗为证/花开两朵各表一枝/不在话下 = **缺位监视**（梁书实测 0 次）。

### 3.2 与 rel: 标注的分工

| 段落身份 | rel: 标注纪律 |
| --- | --- |
| 正文段 | 正常标注句间/段间关系 |
| 围栏块（词/诗/歌/对联/回末对/书信/告示/口诀/说书） | 不标句间 rel（内部不切句）；只允许宿主侧标**引出**关系 |
| 回末套语段（文本模式=套语） | **不标任何 rel**——套语既不进正文分母也不参与语义网络（02ab §9.2 直接受益） |
| 回目 `[0]` | 不标（标题层，预告不抽事件，负规则十三） |

### 3.3 正误对照

```markdown
❌ 错误一（伪信号当关系信号）：
<!-- rel:scene-shift -->
[18] 只见山道上来了一行骑士，当先一人白马上悬着一口宝刀。
（"只见"是叙事动词（02ab §6.2 伪信号级，实测 190 次），不构成叙事线切换，删此注释）

✅ 正确（弱信号 + 双转移第二确认）：
<!-- rel:scene-shift -->
[19] 且说〖@王照希〗读信之后，与〖@玉罗刹〗告辞，匆匆赴京，在路上走了数月，到了〖=京师〗。
（行首且说 + 人物集变化 + 地点转移 + 时间推进 → 切换成立；叙事线 ID 更新归 01g 字段）

❌ 错误二（套语段标关系）：
::: 回末
<!-- rel:cliffhanger -->
[42] 欲如后事如何？请听下回分解。
:::
（回末套语是结构公式，不进语义网络；章末收束关系已由 extract_paragraph_structure.py
按围栏类型自动给出 chapter_closing，无需人工补标）

✅ 正确（真实悬念递延标在正文段）：
<!-- rel:suspense -->（段末抛局）
[37] 那少女却不答话，剑光一闪，人已在两丈之外。
```

## 四、rel: 注释格式（照搬史记版）

### 4.1 格式

在 `struct.md` 中，语义关系用 HTML 注释标注——**不影响 strip_markup 与剥标对账**（`lint_text_integrity.py` 剥除规则天然覆盖注释行；`lint_markdown.py` 的实体/PN/标题检查不受注释干扰；关系名拼写合规由本清单与存疑清单纪律把关，专项校验脚本随 rel 数据产出立项，见附录 B-2）：

```markdown
<!-- rel:causal -->
[12] 卓一航酒后失言，泄露了行藏。
<!-- rel:effect -->
[13] 官军当夜便围了武当山庄。

<!-- rel:parallel:2 -->
[24] 一路佯攻主峰，昼夜擂鼓不停。
[25] 一路绕后，断其粮道。
```

关系名使用小写英文常量（causal/parallel/escalation/contrast/summary/scene-shift/suspense/quote-intro/book-letter/chapter-closing…），注册新增关系名走 02ab §9.4 结构规则变更治理（甲类文字修订或乙类迁移流程）。

### 4.2 与既有体系的相容性

- PN 不可变纪律不受影响：rel: 注释不占编号、不移动锚点，删除后剥标文本不变；
- 围栏块只允许宿主侧标 `quote-intro` 类关系，围栏内部零注释（E8-E10 检查围栏结构，注释可读不违警，但内容纪律照守）；
- `<!-- rel:... -->` 与 01g 三层标注括号（〖〗⟦⟧〘〙）无符号交叠，不进 `lint_symbol_conflicts.py` 冲突面。

## 五、关系识别方法

### 5.1 规则驱动（高精度）

- 因果：检测"因为/所以/于是/这才"连接词族；
- 并列：检测"一边…一边…"等成对框架；
- 总结：检测"可见/由此可见"句式；
- 叙事线切换：行首且说/却说 + 02ab §7.3 双转移判定（这条已在 N 系/结构层落地，本文只消费其输出）；
- 章末收束：围栏类型驱动（C23 已内置，无需规则新增）。

### 5.2 LLM 驱动（高召回）

输入一个段落（剥标显示串，取自 structure.json 摘要字段），让 LLM 标注相邻句对的关系类型，输出结构化条目（sent_pair + relation + signal 三元组），**落 rel: 注释前须过 §5.3 存疑纪律**。LLM 判读只作候选，不得直接改动 PN 或围栏。

### 5.3 存疑清单纪律（引 02ab §8.2）

- 存疑清单是**一等公民产出**：每条含位置、候选关系、倾向、理由，供人工批次裁决；
- 禁止凭语感就地定案——判读灰区（规则与 LLM 分歧、双转移只中一条）一律进清单；
- 不得臆推红线：回目预告不生成关系兑现断言、书信内容不自动核实、韵文意象不当事实（01g 负规则十一/十二/十三在关系层的投影）。

## 六、排版映射（概念，不含实现）

### 6.1 关系类型 → 渲染语义

史记版 CSS 类映射思想保留为**渲染契约表**（实现归渲染层/09a 语法高亮辅助阅读，本文不写样式代码）：

| rel: 值 | 渲染语义 |
| --- | --- |

| parallel:n | n 路横排对照 |

### 6.2 可开关设计

语义排版必须是**可整体关闭**的渲染层开关（关=全部恢复连续段落），数据与样式分离：rel: 注释是数据，渲染语义是皮肤。这一条承自史记版 `.semantic-off` 开关思想，落实现时仍守此契约。

### 6.3 输出落点

- rel: 注释写在 `tagged/<书>/NNN.struct.md`（人读层）；
- `extract_paragraph_structure.py` 重跑后 rel 信息随段落结构汇入 `registry/structure/<书>/NNN.structure.json`（机读层）；
- 渲染层/问答层只消费 JSON，不解析 struct.md 原文——两层经 PN 锚点无损互查。
