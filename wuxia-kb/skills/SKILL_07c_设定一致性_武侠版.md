# SKILL 07c 武侠版：设定一致性 — 在虚构宇宙里判断"这是不是破绽"

> **上游声明**：本文从 shiji-kb `SKILL_07c_反常推理` 移植重造（🔵 中度 55:45），移植依据见 `docs/05-管线技能与脚本逐项改造分析.md` §2.4（**§七常识提取六轮流程（3+ 案例才保留/假阳性分档）整体照搬为武侠常识库方法论**；"反常"语义质变：史实存疑→设定破绽/OOC 检测/夸张修辞识别；**注意阈值方向反转**（武侠"行千里一夜"是设定内合理）；G9 武侠常识基准库为新数据资产）。
> **设计源（权威）**：`SKILL_常识与设定一致性_武侠版.md`（D11）§1.4 方向反转总声明、§2.1 四区定版、§3.1-3.4 **34 条种子规则**（W9/S10/J8/T7）、§4.1-4.6 五项检查、§5 OOC 检测、§7 反常三分流、§6 A-E 评级。
> **现有产物接口**：N8 `scripts/lint_consistency.py`（1,100+ 行；34 条 IF-THEN + 五项检查 → 39 条规则；`--selftest` 20）→ `registry/consistency/<书>.json`（schema `wuxia-consistency-v1`；5 书命中 44：error **0** / warning 28 / info 16；豁免 2；A-E 分布 B3/C5 无 D；docs/57 §五）；消费 N4 `registry/time` + N5 `registry/relations`。
> **核心原则**：**先问"设定内是否合理"，再问"前后是否矛盾"。** 武侠的常识阈值与历史现实相反（一夜千里是设定、闭关十二年不是穿帮），误报比漏报更伤信任。


### 1.2 本文做什么

1. **四区常识库**：武学/门派/江湖/时代 34 条种子规则的口径与维护；
2. **五项检查**：年龄跨回自洽、习得顺序、门派存续、死亡再现、称谓辈分；
3. **分级与豁免**：error/warning/info、叙述模式豁免（04a §七）、方向反转豁免；
4. **OOC 边界**：弱信号只记录不断言；
5. **反常三分流**：设定破绽 / 夸张修辞 / 有意翻案——三类判别信号与处置；
6. **N8 产物复核**：violations/rule_coverage/exemptions/A-E 字段。

| 区 | 条数 | 逻辑 | 示例（种子） |

### 3.1 规则维护（六轮提取流程，引 D05 §七/07c 上游）

- 新规则需 **≥3 案例** 才保留（D11 准入）；
- 假阳性分档：设定内合理 / 修词夸张 / 叙述不可靠 → 豁免或降级；
- 规则资产化：词形→`wordlists/`，设定→`registry/` 或 reference；脚本只消费不存储（META-10 §十）；
- 规则变更走版本（rule_version），N8 产物记录版本。

## 四、五项检查（D11 §4，N8 落地）

| # | 检查 | 逻辑 | 依赖 |
|---|---|---|---|
| 1 | 人物年龄跨回自洽 | 年龄 + 时间流逝 = 一致 | N4 time_points/年龄锚 |
| 2 | 武功习得顺序（未学先使） | 习得事件早于使用 | 04a 事件 + 04f 传习动词 |
| 3 | 门派存续期（灭派后再出场） | 门派存在区间 vs 出场回 | 05 组织关系 + 事件 |
| 4 | 死亡角色再出场 | 死亡事件 vs 后续出场 | 04a 死亡/伤情事件 |
| 5 | 称谓辈分错乱 | 双树辈分 vs 称谓 | N5 师承树/辈分标签（05c） |

### 4.1 分级

| 级 | 定义 | 处置 |
|---|---|---|
| error | 硬矛盾（死亡后明确出场、年龄倒退） | 复核→记录→报告 |
| warning | 可疑（缺时间锚、叙述模糊） | 记录；补证据后降/升 |
| info | 说明性（多源并存、修订信号） | 记录层 |

### 4.2 叙述模式豁免（04a §七）

**声称/转述/传闻/回忆/梦境**中的内容不自动作为事实矛盾：
- "据说他早已死了"（传言）≠ 死亡事实；
- "当年我见过他"（回忆）需核对回忆对象；
- 梦境/幻觉不进一致性检查；
- 豁免须登记 `exemptions`（含理由/证据），不得静默跳过。

## 五、OOC 检测边界（D11 §5）

- OOC（性格/行为跨章跨书不一致）是**弱信号**：只记录、不断言；
- 检测信号：对话风格突变、行为选择反常、价值观反转；
- 与"人物成长弧"区分：成长是资产（01g §9.8 红线反向）；
- OOC 结论需 3+ 案例与人工复核，进"观察清单"而非 error；
- 跨书 OOC（同一人在不同书性格漂移）由 D07 系列视角补充。

## 六、反常三分流（D11 §7，本文核心裁定）

| 类 | 判别信号 | 例 | 处置 |
|---|---|---|---|
| **设定破绽**（要修/记录） | 与既有设定直接冲突，无叙述解释 | 人物年龄倒退；死者明确复出 | 记录（不改文）→穿帮雷达 |
| **夸张修辞**（要识别不改） | 文学性夸张（"快如闪电""一夜千里"） | 轻功夸张；"千军万马" | 不报/豁免 |
| **有意翻案**（是资产） | 后书明文推翻前说/修订自陈 | 修订版改年龄；后书"传言有误" | 记翻案关系（D07 R4） |

### 6.1 判别顺序

```text
① 是否叙述模式（声称/传闻/回忆/梦）？是→豁免/记录
② 是否设定内合理（方向反转清单）？是→夸张/不报
③ 是否有后书/修订明文翻案？是→翻案（资产）
④ 否则按设定破绽记录（分级 error/warning/info）
```

> 方向反转清单（D11 §1.4）：一夜千里、闭关十二年、驻颜术、内力返老还童、独战千军等默认**不扫描**；新增豁免须登记（META-10 §零 要求）。

## 十一、FAQ（首批 7 问）

**Q1 "一夜千里"要不要报穿帮？**
不报。武侠设定内合理（D11 §1.4 方向反转）；这是本文与历史 QC 最大的方向差异。

**Q2 传闻说某人死了，后文出现算矛盾吗？**
不算。叙述模式（声称/传闻）不自动作为事实；豁免登记。

**Q3 N8 现在为什么没有 error/D 级？**
证据链止于 C（N4 推算/N5 推导），事件层未落库；等 04a/E5 补证后可升级。

**Q4 OOC 为什么只记录？**
OOC 是弱信号且与人物成长难分；3+ 案例+人工复核才可进观察结论。

**Q5 新规则怎么加？**
≥3 案例 + 六轮提取 + 规则资产化 + rule_version；N8 只消费。

**Q6 与 07a 跨书年代冲突怎么办？**
单书内矛盾=本文；跨书年代矛盾=07a（回本文只作跨书一致性提示）。

**Q7 有了矛盾要不要改原文/标注？**
不改原文（版权+校勘红线）；记录、分级、报告、沉规则。

## 结语

设定一致性检查的成败不在"抓到多少条"，而在**分清三类"反常"**：设定内的夸张不是错，叙述声称不等于事实，真正的破绽要记录而非改文。方向反了，工具越强，误伤越大。
