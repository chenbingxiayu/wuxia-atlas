# SKILL 09d 武侠版：故事创作 — 用知识库"重讲"，不"复写"

> **上游声明**：本件属本批 C1 应用组新划定 09d；对应 docs/03 §3.10 原 09e 故事创作（中度 60-65：映射法/开关架构/六法则照搬；武侠 IP 自带故事传统）。**无专属设计稿**：由 01g §9.10 发布边界、07c 设定一致性、07e 评级、W7 引文核验、N10 SKU/EX-5 事件接口综合而成（v0.1 框架）。
> **接口**：N10 `registry/sku/cards.json`（人物/门派/武功/兵器/秘籍卡）、EX-5 `registry/events/<书>.json`（22,978 事件）、N5 `registry/relations`（910 边）、N4 `registry/time`、EX-7 `universe.json`/`atlas`；W7 `scripts/verify_quotes.py`。
> **核心原则**：**创作是"基于知识库的原创派生"，不是"对原文的改写/续写/拼贴"。** 用结构化事实做骨架，用原创语言讲故事；任何引文/原文片段必须过 W7，任何新情节必须声明"原创派生"。

## 一、定位与边界

### 1.1 工序位置

```text
知识库（SKU/事件/关系/时间/设定）→ 09d 故事创作 → 原创派生内容
        ↓
07c 一致性/07e 评级（设定与事实门控）→ W7 引文核验（如有引文）→ 发布/脱敏
```

### 1.2 本文做什么

1. **素材分层**：可用（实体/边/事件/设定/统计）、慎用（人物性格推断、冲突说法）、禁用（原文正文/连续片段/未核实事实）；
2. **创作模板**：说书人专栏/人物小传/门派史话/事件演义四类；
3. **一致性门控**：设定（07c）、人物（OOC 弱信号）、跨书（07a low）；
4. **标注与来源**：所有派生内容标注"原创派生"+数据来源+版本；
5. **W7 挂点与版权边界**。

### 1.3 本文不做什么

| 不做 | 归属 |
|---|---|
| 续写/改写原文 | 禁止（版权+校勘红线） |
| 改知识库数据 | 上游工序 |
| 原文引用 | 禁（W7/01g §9.10）；可"概括+回锚" |
| 同人版权定性 | 项目权利审核（本文明规则，不做法律判断） |

### 1.4 关键约束

- **零原文**：不得复制/改写原文连续片段；人物对话若必要，用"概括式转述"并回锚；
- **事实可核**：故事中的实体/关系/事件必须能在知识库找到来源；
- **原创声明**：每篇标注 `derivative_type=原创派生`、数据版本、rule_version；
- **不得冒充原著**：不得声称"作者佚文/未刊稿"；
- **发布边界**：遵循 01g §9.10 + SKU 脱敏 R1-R5。

## 三、素材分层

### 3.1 可用素材

| 素材 | 来源 | 用法 |
|---|---|---|
| 人物卡字段 | N10 SKU person（brief/identity_tags/arts/teachers/ending） | 人物小传骨架 |
| 门派卡 | SKU faction（lineage/members/history） | 门派史话 |
| 事件 | EX-5 events（类型/参与方/outcome/时间） | 事件演义/说书段子 |
| 关系边 | N5 relations（师承/结义/情缘/仇怨） | 人情线 |
| 时间轴 | N4 time（相对刻度/锚点） | 叙事时间安排（参考） |
| 设定 | 07c 34 规则/01g 类型 | 世界规则一致性 |

### 3.2 慎用素材

| 素材 | 风险 | 用法 |
|---|---|---|
| 人物性格推断 | OOC | 只作弱信号，不写"他一定会…"式断言 |
| 多源冲突（07c） | 版本差异 | 双记/注明"一说" |
| 跨书年代（07a low） | 伪精度 | 只作"参考"不写具体年数 |
| 统计（03l） | 口径误用 | 附口径声明或避免具体数字 |

### 3.3 禁用素材

- 原文正文/连续片段（01g §9.10）；
- 未核实却当事实的设定（07e D/E）；
- 读者推断（E4）；
- 从原文可逐步还原的片段数据。

## 四、四类创作模板

### 4.1 说书人专栏（推荐首发）

```text
结构：引子（钩子）→ 故事主体（事件链，原创叙述）→ 说书人点评（原创分析）→ 出处与版本（回锚）
纪律：可"演义"事件，不可改写原文；点评须标"原创分析"；不冒充作者按语。
```

### 4.2 人物小传

```text
结构：人物档案（卡字段）→ 生平线（事件链）→ 关系网（N5）→ 设计注记（来源/缺口）
纪律：字段与卡一致；冲突双记；未知不编。
```

### 4.3 门派史话

```text
结构：门派渊源（faction 卡）→ 世系/掌门（N5 师承树）→ 关键事件（EX-5）→ 存续状态
纪律：门户关系以 N5/05c 为准；不把同名异人并入门派。
```

### 4.4 事件演义

```text
结构：事件概述（EX-5 类型/参与方/outcome）→ 过程演绎（原创）→ 结果与影响 → 出处
纪律：outcome 与数据一致；低置信事件标"传说/一说"。
```

## 五、一致性门控与 OOC

### 5.1 设定门控（07c）

- 稿件中的时间/年龄/门派存续/死亡/称谓必须过 07c 五项检查口径；
- 冲突处双记，不得为故事张力硬改设定。

### 5.2 人物一致性（OOC 边界）

- OOC 是弱信号（07c §5）：只作创作提示，不写"官方定性"；
- 人物成长弧是资产：允许合理演进，但需标注"基于事件链的合理推演"。

### 5.3 跨书门控（07a/07d）

- 跨书同人须说明系列关系（low 参考）；
- 设定传播/呼应可作素材（07d 溯源链），但标注证据级。

## 十、FAQ（首批 5 问）

**Q1 能不能写"续集/番外"？**
可以写原创派生故事，但不得冒充原著续作、不得改写原文情节链作"官方设定"；必须标"原创派生"。

**Q2 人物对话能不能引用原著台词？**
不建议；若必须，须过 W7 且尽量短、且不得形成可还原片段；优先概括转述。

**Q3 可以给人物编新经历吗？**
可以，但须声明"原创推演"，且不得与既有事件/设定硬冲突（07c 门控）。

**Q4 同人版权怎么办？**
本技能只定工程/内容规则；法律定性交项目权利审核（01g §9.10 版权所有方需确认）。

**Q5 说书人点评和原文"作者按语"怎么区分？**
点评标"原创分析/说书人评论"，不得冒充作者按语（01g §9.8 说书人专栏纪律）。

## 结语

故事创作的红线只有一句话：**用好知识库的"事实"，讲自己的"故事"**。原文不碰、来源可查、声明在前、门控在后——这样创作才能既好看又安全。
