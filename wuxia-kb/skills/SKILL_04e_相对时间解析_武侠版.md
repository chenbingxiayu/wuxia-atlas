# SKILL 04e 武侠版：相对时间解析 — 把时间词落到书内刻度

> **上游声明**：本文从 shiji-kb `SKILL_04e_年份消歧` 移植重造（🔴 合并级 20:80），移植依据见 `docs/05-管线技能与脚本逐项改造分析.md` §2.3（与 03g 合并为"书内时间标记→相对时轴"；"上古年份只做索引不强求绝对年"经验正是武侠方案原型）与 `docs/17-技能脚本改造实现图与拓扑排序.md`（S-04e 属 18 个"设计已备"节点，←D05）。
> **设计源（权威）**：`SKILL_时间体系_武侠版.md`（D05）§五 定年方法（M1-M7/师承代数）、§七 `%` 三管道与内联消歧、§二 时点键、§四 单调性/分叉、§八 confidence。

## 四、相对表达规则表（解析核心）

| 表达型 | 例 | 基准 | 运算 | 置信 |
|---|---|---|---|---|
| 绝对纪年 | 万历四十三年 | 朝代/年号锚 | 区间映射 | high（区间级） |
| 干支纪年 | 甲申年 | 朝代锚 + 干支循环 | 就近匹配（±60 年内唯一） | medium |
| 明确日期 | 八月十五 | 年份基准 | 定日 | medium |
| 时令 | 中秋/元宵/黄昏 | 邻近时点/年份基准 | 定位季节/时段 | medium/low |
| 相对点 | 五年前/第二日/次日 | 前文最近时点（同线） | ±时长 | medium |
| 相对量 | 三年后/十年 | 前文基准 | +Δ | low（Δ 可能约量） |
| 连年/多年 | 连年来/这几年 | 前文区间 | 区间拉长 | low |
| 年龄 | 十八岁/五十余岁 | 人物出生年/年龄锚 | 年龄→时点 | medium（约数降 low） |
| 同时 | 与此同时/同一日 | 当前时点 | 相等 | medium |
| 追叙 | 三年前（回忆句） | fork 基准 | 独立刻度 | low |
| 对白 | 人物说"明天" | 对白语境隔离 | 不进主线 | — |

### 4.1 基准选择顺序

1. **同线最近前文时点**（默认）；
2. **回内明确年份/时令锚**；
3. **人物年龄锚**（"十八岁那年"）；
4. **事件锚**（"泰山大会之后"——需 04a 事件落库互证，未落库降 low）；
5. 无基准 → 未解析/low（**禁止**默认用出版年/作者年）。

### 4.2 年号/干支换算口径（与 03b §8.3 分工）

- 年号+年/年间/元年 → `%`（03b 已定）；本文负责把年号映射为**区间**（年号元年+年数），不承诺精确公历日；
- 干支：以朝代锚限定 60 年窗口内**唯一**匹配才 high，否则 medium/low；
- 朝代区间锚（如"东汉 25-220"）：N4 实测 low 置信（区间级），仅作约束不作事实。

### 4.3 年龄锚规则

- 年龄是武侠强锚点（N4 实测 244 处）："十八岁那年"→与前文出生/年龄锚联动；
- 约数（"十八九岁""五十余岁"）→ 区间，置信降一档；
- 虚岁/实岁不明确 → 不硬换算，标 medium/low 并登记口径；
- 年龄与时间互推：已知年龄+相对时长→时点；已知时点+年龄→出生年（供 07a 跨书）。

## 五、隔离与分叉（解析关键边界）

### 5.1 对白隔离

- 人物对白中的时间表达（"我明日便来""三年前我见过他"）属于**引述世界**，不进入叙述主线；
- N4 以 quote 标记隔离（`quote` 上下文内的 `%` 解析独立）；
- 若对白揭示事实（"其实我三年前就来了"），需事件层另核，不自动改主线时间。

### 5.2 追叙/闪回 fork

| 信号 | 解析处置 |
|---|---|
| "原来/当年/回想/记得/多年以前" + 长段倒叙 | 建 fork 刻度，独立基准；不判主线倒流 |
| 追叙中再套追叙 | 允许两层，超出交人工 |
| 梦境/幻觉 | 不进主时间轴（04a §七） |

### 5.3 多线并行

- "花开两朵，各表一枝"（02ab §6.2 套语）→ 两条叙事线各自刻度，汇合时对齐；
- 同一回内多线 → 时间点带线标记（N4 主轨/分轨）。

## 六、产物 schema（time_points 消费）

```json
{"tp_id":"jianghu-T012","pn":"jianghu#pn-r12.3","display":"五年前",
 "type":"relative_point","granularity":"year","anchor":{"kind":"event","ref":"jianghu-T007"},
 "t": -5.0, "basis":"同线最近事件锚", "confidence":"medium", "fork": null}
```

| 字段 | 语义 | 复核要点 |
|---|---|---|
| `type` | absolute/relative_point/relative_duration/age/solar/season/unknown | 与 03g 三管道一致 |
| `granularity` | year/season/month/day/period 五级 | 粒度不得虚高 |
| `anchor` | 锚类型+引用（tp_id/事件/年龄） | 锚须有原文证据 |
| `t` | 书内相对刻度（0=基准） | 跨回可比较 |
| `confidence` | high/medium/low | 按 §4 规则 |
| `fork` | 分叉 id 或 null | 追叙必填 |

```json
{"pn":"…","display":"半晌","reason":"纯模糊修饰（03g 负规则）","status":"accepted_low"}
```

## 十一、FAQ（首批 7 问）

**Q1 为什么不用出版年做基准？**
出版年是现实时间，不是书内时间；用它会制造系统性伪锚。书内时间只用文内锚点。

**Q2 "三日后"怎么算？**
找同线最近时点 t0，+3（日粒度）；若 t0 不确定则 low。

**Q3 年号能算到公历日吗？**
不承诺。武侠只到"年份/区间"；精确公历日属超出规范（无天文历法依据），04e 只给区间+置信。

**Q4 年龄"十八九岁"怎么处理？**
区间 [18,19]，置信降一档；虚岁/实岁不明登记口径，不硬换算。

**Q5 对白里的"三年前"要不要改主线时间？**
不要。对白隔离；若揭示事实由事件层另核。

**Q6 追叙里的时间轴怎么排？**
建 fork 独立刻度，不与主线比较；汇合点记录。

**Q7 解析率卡在 90% 正常吗？**
正常。剩余多为原文模糊/跨回依赖；目标是可解释而非 100%。

## 结语

相对时间解析的核心不是"换算"，而是**建立可比较的秩序**：有基准就加相对量，没有就留白；对白不污染主线，追叙不制造倒流。解析率是结果，可解释性才是验收标准。
