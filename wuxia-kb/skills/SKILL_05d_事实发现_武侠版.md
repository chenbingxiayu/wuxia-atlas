# SKILL 05d 武侠版：事实发现（SPO 抽取与原子化）

> **上游声明**：本文是 D06 关系体系（`SKILL_关系体系_武侠版.md`）的**事实发现执行件**，不重定义谓词与验证规则。55 条谓词总表（§7.2）、证据三级（§8.1）、候选→核验→入表流程（§8.2）、传闻降权（§8.3）、语式表（§8.4）由 D06 定版；事件事实由 `SKILL_04a_事件识别.md`（D03）供给；动词触发与联动候选由 `SKILL_04f_动词标注.md`（D02）供给；时间坐标由 `SKILL_时间体系_武侠版.md`（D05）与 N4 定版。

## 一、技能定位与边界

### 1.1 工序位置

```text
tagged 语料（实体+动词标注）
   ↓ 04f 联动候选（27 行）/ 04a 事件记录（参与方语义角色）
S-05d 事实发现（本文）：
   Step A 事实候选抽取（高信号动词 + 语义角色 + 定位）
   Step B MD 人工校对（原子性/方向/时间/证据）
   Step C JSON 结构化转换（SPO + ctx.time + evidence）
   ↓
N5 relation_validator（谓词核验/五属性/置信/落库）
   ↓
registry/relations/<书>.json ── 下游关系图/问答/档案
```

- **前置**：实体消歧（03b）完成、动词标注（04f）完成、事件记录或至少事件边界可用、N4 时间轴可用。
- **后继**：N5 核验、S-05 关系层总览（`SKILL_05_关系分析总览_武侠版.md`）、S-05e 战争专项。
- **现行事实（2026-11-05）**：N5 5 书实跑——候选 1,820 → 落库 910 边（+16 同门派生）、放弃 1,145；16 种谓词；hard 0。**无事件层支撑的谓词（仇怨/毁损等）只记候选放弃**（docs/56 §五 遗留），这是 05d 与 04a/05e 的接口缺口。

### 1.2 本文做什么（五件事）

1. **两步法定型**：候选抽取（可自动化）与人工校对（MD）分离，JSON 由脚本转换，人工只改 MD；
2. **原子化**：把复合叙述拆成"一事实一原子"，给拆分判据与正误例；
3. **SPO 规则**：主语/谓语/宾语、施受方向、三元参数、谓词选择（55 表）、共现禁令；
4. **时序重构**：`ctx.time` 从史记的绝对年改为**书内相对时序**（tp_id/偏移/事件锚），与 N4 对接；
5. **高信号动词表**：武侠版触发词→谓词→角色槽映射，作为候选抽取词表。

### 1.3 本文不做什么（边界，越界即错）

- **不重定义谓词**：谓词选择以 D06 §7.2 为准；本文只给"触发词→谓词"的候选映射；
- **不建关系边**：事实发现产出"事实候选/事实清单"，正式边由 N5 核验后落 `registry/relations/`；
- **不做人工裁决**：传闻/自述/冲突的降权与人工覆盖规则属 D06 §8.3/§8.5，本文只标注候选状态；
- **不改语料**：MD 校对稿在 `logs/qa/`（或事实工作区），不写 tagged。

## 三、事实发现两步法（本文核心工序）

### 3.1 两步法定型（承史记 05d，武侠化）

| 步 | 名称 | 执行者 | 输入 | 输出 | 判据 |
|---|---|---|---|---|---|
| A | 事实候选抽取 | 脚本/规则（可自动化） | tagged + 高信号动词表 + 04f 联动 | 候选事实清单（含定位） | 触发词命中 + 语义角色可解析 |
| B | MD 人工校对 | 人工/LLM 复核 | 候选清单 + 原文 | 校对稿（`logs/qa/facts_<书>_<回>.md`） | 原子性/方向/时间/证据/谓词 |
| C | JSON 结构化转换 | 脚本 | 校对稿 | 结构化事实（SPO + ctx.time + evidence） | 字段 schema 校验 |

> **纪律**：人工只改 **MD**，不手改 JSON；JSON 由转换脚本从 MD 生成（可复跑、可 diff）。MD 校对稿是事实发现的**审计底稿**，与 JSON 一并存档。

### 3.2 候选抽取信号（Step A）

1. **04f 联动候选**：27 行联动（`⟦⊠救活⟧`+伤者 → 治愈候选）直接作为种子；
2. **高信号动词表**（§七）：事件入口动词（杀/救/赠/夺/拜/逐/婚/擒/押/到/离…）命中；
3. **事件记录参与方**：04a 事件的参与方语义角色（施事/受事/对象）直接映射 SPO 槽；
4. **关系语式表**（D06 §8.4）：结为兄弟/拜师/报X之仇/叛出师门 等；
5. **反例过滤**：对话贬称、格言（一日为师终身为父）、共现（同席/同行）**不生成候选**。

### 3.3 人工校对四问（Step B）

对每条候选，人工只回答四问：

1. **原子性**：这条候选是否只含一个可判定事实？复合叙述是否该拆？
2. **方向**：subject 是否施事/持有者/上位方？被动句（"被点了穴"）是否反转？
3. **时间**：`ctx.time` 是否可挂（tp_id/偏移/事件锚/未知）？叙述模式是否回忆/传闻？
4. **证据**：E1 明文/E2 动作+共现/E3 推导？名分类是否有明文？

> 四问任一不过 → 候选进 `dropped` 并记原因；不得"先落库后补证"。

## 四、原子性原则与事实拆分

### 4.1 一事实一原子（承 05d1 原子性原则，武侠化）

- **一个原子事实 = 一个谓词 + 一组确定的主宾（+参数）+ 一个时间/定位**；
- 复合叙述按"谓词不同/时间不同/参与方不同"三判拆分；
- 拆分后的原子共享同一 `loc`（原文位置），但各自独立可核。

### 4.2 拆分判据表

| 场景 | 处理 | 正例 |
|---|---|---|
| 一句两动作（"夺过剑来刺死他"） | 拆 2 原子：转移(夺) + 杀害 | 转移边 mode=夺；杀害边凶手=施事 |
| 一事件多参与方（群战） | 交手边按"两侧"记，个体施受明确的另记 | 交手(A,B) 与 杀害(凶手,死者) 并存 |
| 动作+结果（"一剑刺中，重伤倒地"） | 若达受伤阈值：⊞事件 + ⊠事件两条；否则只 ⊞ | 04f 受伤阈值 |
| 因果（"因夺谱而杀人"） | 两原子 + causal 候选（事件层） | 不把因果塞进谓词 |
| 并列同谓词（"赠甲一柄剑，又赠乙一匹马"） | 两条转移原子 | 不合并成"赠两人" |
| 否定/计划/条件（"欲杀之""若他动手"） | 不生成事实原子（或标计划态候选） | 04a 五状态 |
| 传闻（"听说他杀了人"） | 候选 conf≤弱，veracity=传闻 | D06 §8.3 |

### 4.3 原子性与事件记录的关系

- 事件记录（04a）是"情节单元"，事实原子是"关系事实"；一个事件可拆多条事实（战斗 → 交手+杀害+毁损）；
- 事实原子的 `event_ids` 回链事件，用于"所属战斗/事件链"与下游问答；
- 无事件层时（当前 N5 现实），事件事实类谓词仍可落边（杀害/治愈/交手），但**仇怨/毁损等依赖事件语义的谓词只记候选放弃**（docs/56 §五）。

## 五、SPO 抽取规则

### 5.1 主谓宾与类型

- subject/object 必须是**已消歧 canonical**（03b），类型码取 15 类实体码（@◎=◆&~;#☆•+{^%$）；
- 谓词取 D06 55 条总表，**层别不混**（事件层/实体层/人物层分表）；
- 三元谓词用"二元 SPO + 参数"表达：`转移(赠者,受者)`＋物/mode；`传授(师,徒)`＋武功；`押送(押者,被押者)`＋讫地；`点穴(施者,受者)`＋穴道。

### 5.2 施受方向（最容易错）

| 场景 | 正确方向 | 反例 |
|---|---|---|
| 被动句"被点了穴" | 点穴(施者=点穴者, 受者=被点者) | 把被点者当施者 |
| "我师父" 类领属 | 师承(徒=说话者, 师=所指) | 方向反写 |
| 赠/借/还 | 转移(出赠者→受赠者)，mode 区分 | 方向不明时不猜 |
| 杀/救 | 杀害(凶手→死者)；治愈(医者→伤者) | 施受颠倒 |
| 押送 | 押送(押者→被押者, 讫地) | 缺讫地仍可落边但参数标未知 |

### 5.3 谓词选择纪律

- 事件动词（夺/毁/铸/败）**不作** SPO 谓词：夺→转移(mode=夺)；毁→毁损（事件层）；铸→制造；
- 师承≠传授：拜师明文才建师承；"传了剑法"只建传授；
- 交手不自动敌对；一次救助不自动友盟；杀害本身不自动仇怨（仇怨须 event_ids 定位结怨事件）；
- 名分类（师承/结义/配偶/收养/婚约）必须 E1 明文，E2 动作+共现不得确立。

### 5.4 共现禁令（D06 §8.1 铁律）

co_person/co_location 只供检索，**永不直接推人物关系**；"同桌吃饭/同路而行/同门聚会"不生成师承、结义、敌对、亲属边。

## 六、`ctx.time` 重构：书内相对时序（最大工程改造点）

### 6.1 从"绝对年"到"书内相对时序"

史记 05d 的 `ctx.time` 挂绝对纪年；武侠版必须重构为**书内相对时序**：

```json
"ctx_time": {
  "tp_id": "bainv-T214",
  "time_raw": "是夜三更",
  "anchor_type": "事件锚·强",
  "offset": {"value": 0, "unit": "日"},
  "t_days": 11024,
  "precision": "日内级",
  "narrative_mode": "正常叙事",
  "fork_id": null,
  "confidence": "high"
}
```

### 6.2 挂接规则

1. 优先挂 **tp_id**（N4 已解析时点）；无 tp 时挂**事件锚**（回指已排轨事件）＋偏移；
2. `time_raw` 照录原文（含"是夜"），解析值只进 `t_days/precision` 等字段（时间体系错误模式 29）；
3. 回忆/梦境/假想/戏中戏：`narrative_mode` 必填，`fork_id` 指向分叉；**不进主轨**；
4. 未知时间显式 `status=unknown` + `unknown_reason`（原文未给/多解/分叉内/跨书矛盾），**不得留空**；
5. 事实的时间**不新建 tp**：回指型事实指向首叙事件时点（时间体系 §2.4）。

### 6.3 与 N4 的对齐校验

- 事实的 `ctx_time.tp_id` 必须存在于 `registry/time/<书>.json`；
- 事实的时序（如"叛门晚于拜师"）由 N5 用 tp/t_days 校验；无 tp 时按事件锚先后校验；
- 时间冲突不静默改值：登记冲突（D05 §4.6），事实保留双值待裁决。

## 八、候选 → 核验 → 入表（N5 接口）

### 8.1 落位分流（D06 §8.2）

| 候选类型 | 落位 | 条件 |
|---|---|---|
| 事件事实类（杀害/治愈/交手/转移/掌握/到达/离开/任职…） | SPO 登记层（N5 边） | 语义角色明确，E2 可入 |
| 名分类（师承/结义/配偶/收养/婚约） | SPO 登记层 | **E1 明文**才可 |
| 情感/恩义/背叛/主仆 | 离线表（人工裁定） | 不进 SPO |
| 传闻/自述/歧义 | 候选池（dropped 或待人工） | conf≤弱，不直接入正式表 |

### 8.2 N5 产物字段（`registry/relations/<书>.json`）

- `counts`：候选/落库/放弃/派生；
- `edges[]`：subject/subject_type/predicate/object/object_type/confidence/evidence_type/rule/rule_row/subtype/params/notes/evidence/count/loc/chapter/para/derived/veracity/books/locs/layer/direction/id；
- `derived[]`：同门/辈分等推导边（带规则号）；
- `dropped[]`：放弃候选 + 原因（缺事件层/缺角色/传闻/方向不明/重复/低置信）；
- `validation`：hard_errors/警告；
- `rows_stats`：谓词分布。

### 8.3 放弃原因分类（必须逐条可解释）

| 原因 | 含义 | 处置 |
|---|---|---|
| no_event_layer | 谓词依赖事件语义（仇怨/毁损），当前无事件层 | 记候选，待 04a 事件表接入 |
| missing_role | 缺强制语义角色（死者/伤者/物） | 事件/事实降级待审 |
| rumor | 传闻/自述未印证 | 候选池，veracity=传闻 |
| direction_unknown | 施受方向不明（被动/互指） | 不猜，留候选 |
| duplicate | 同键重复 | 合并到首条，count 累加 |
| low_confidence | 证据不足 | 候选池 |

## 十二、成功标准（Success Criteria）

1. **原子化**：抽样 10% 无复合未拆；拆分判据可复核。
2. **方向正确**：被动/互指句抽查 100% 正确。
3. **时间可溯**：事实 tp_id 有效率 100%；未知项全部有原因。
4. **证据合规**：E1 名分类 100%；传闻/贬称/格言生关系 0。
5. **闭环可解释**：候选→落库/放弃链路 100% 可解释，dropped 有负样本库价值。
6. **可复跑**：同语料重跑事实发现+N5，产物幂等；MD→JSON 转换可重复。
