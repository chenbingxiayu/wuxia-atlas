# W10x 页面维护（武侠版）—— 24 件内务清单

> **本文是什么**：W 组**页面维护（内务）**的总清单。shiji W10 把 wiki 维护拆成 1 个主循环 + 23 个原子维护件（H1-H25）；本文件把它们适配到武侠的**站点（site/dist）+ 内容资产（content/）+ 数据资产（registry/tagged/references）**，用**一个文件**汇总 24 件的职责/接口/优先级/验收，不逐件拆 SKILL（逐件拆分见附录 B-1）。
> **上游依赖**：`skills/W10_健康度_武侠版.md`（六类指标与红黄绿→派单）、`skills/W2_动作库_武侠版.md`（动作 18-24 是内务执行器）、`skills/W5_新动作_武侠版.md`（新维护件提案）、W7 `scripts/verify_quotes.py`、N9 `scripts/lint_taxonomy.py`、N8 `scripts/lint_consistency.py`。
> **一句话**：**W10 看仪表盘，W10x 修仪表盘上的红点；每周期只取 2-3 件，一件一件修，修完复扫。**
> **只读纪律**：维护扫描与方案只读；实际写页面走 W2 动作/生成器；不得改 tagged/registry/site/data（站点修复走 site/src 对应任务、数据修复走 N/EX 任务）。

## 三、逐件要点（按功能组）

### 3.1 去重与消歧（W10a / W10b / W10m）

- **W10a 去重合并（P0）**：优先处理 **display 双实体**（玄烨/康熙、朱由检/崇祯、福临/顺治、胤禛/雍正、哈玛雅/飞红巾）——当前 site 存在 5 对同名展示页（URL 各 canonical）；先做"互链+页内提示"（不合并 canonical），canonical 归并属 S-03b registry 层。验收：同名页互链 100%、用户误点下降、W10 `disc_coverage` 上升。
- **W10b 消歧义（P1）**：帝王通称（皇上/先帝）、跨书同名（李治/李思永）、别名（允祯/晦明禅师/董鄂妃）→ 消歧页/页内限定词；依赖别名表与 `display_canonical`。验收：高频歧义 0 未提示。
- **W10m 重复整合（P1）**：节级重复块抽取到单一处，保留引用；不丢内容、链接重定向。

### 3.2 链接与路由（W10c / W10d / W10f / W10x）

- **W10c 词汇链接化（P1）**：正文实体名→目标页存在才链（避免 404）；display/canonical 双匹配，URL 用 canonical。验收：新增链接目标 0 缺失。
- **W10d 重定向（P1）**：display/别名 → canonical URL（B-1/B-2 配套）；禁止重复内容页。
- **W10f 断链新建（P0）**：404 扫描 → 高频缺页实体建 stub；一次性/群称改纯文本。验收：404 归零/逐条说明（当前 0/33,407，保持）。
- **W10x 详细参见（P2）**：章节页→专题页 seealso（时间线/汇总/分析）；不强行关联。

### 3.3 溯源与核验（W10e / W10l / W10s）

- **W10e 原文溯源增补（P1）**：给字段/句补 PN 指针（只存指针，不贴原文；≤60 字/段且过 W7 才算引文块）。
- **W10l 引文 PN 一致性（P0）**：W7 已输出 actual anchor；本件加"cited PN vs actual PN"比对（warning/error 分级，wrong PN 记 W10l）；**是 W7 的下一步挂点**（脚本 `scripts/verify_quotes.py`）。验收：PN 一致性 ≥99%；wrong PN 清单闭环。
- **W10s 正文断言核验（P1）**：非引文事实句→registry 边/事件 ID/PN；无源断言删除/降级（W3 断言分级）。

### 3.4 质量与模板（W10h / W10k / W10r）

- **W10h 精品页增补（P1）**：W3/W10 选 premium 候选 → W8 流程（featured 标准见 W3/W8）；验收：晋升后 W3 档位+W7 全过。
- **W10k 页面错误反思分诊（P0/P1）**：W4 failures/W6 问题按类型分诊→W9 模板修正或 W5 规则提案；不直接改页面。
- **W10r Stub 扩展反思（P2）**：stub 聚集类型→模板补充/W2 扩写；防"永远 stub"。

### 3.5 分类/列表/语义块（W10i / W10j / W10q / W10y / W10u）

- **W10i 标签分类（P1）**：页面 tags 对齐 N9 五树 64 叶（16/:12/#18/◆11/☆7）；multi-value ≤3；验收 N9 复跑无 error。
- **W10j 列表页（P2）**：类型/门派/时代/榜单列表；数据源与口径声明（W12）。
- **W10q 章节语义块（P2）**：回目页摘要块（事件/人物/节奏），数据来自 EX books/chapters。
- **W10y 时间线页（P2）**：人物/事件/跨书时间线（site universe/timeline 已具雏形）；依赖 N4 时点键。
- **W10u 首页精品页（P1）**：首页/入口模块用已上线精品内容，不新增事实；改 site/src 由站点 owner 执行。

### 3.6 引文/格式/清理（W10p / W10m 已列）

- **W10p 语法标注清理（P1）**：页面/资产中的 02ab 围栏残留、半角标点、符号错误（lint 报告驱动）；不碰 tagged。
- **W10m/W10p 边界**：W10m 处理"内容重复"，W10p 处理"语法/符号"；二者都不改上游语料。

### 3.7 洞察与地图（W10t / W10v / W10w）

- **W10t 洞察队列（P2）**：维护 W14 insight_queue，转新页/增补。
