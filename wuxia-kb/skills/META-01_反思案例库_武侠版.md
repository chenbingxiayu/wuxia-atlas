# META-01 反思案例库（武侠版）—— G2 反思产出的案例沉淀

---

## 快速开始

1. **收集素材**：本批 tagged 产物 + 五门 lint 报告 + coverage/qa 报告 + accept judgment 清单 + 工具缺陷记录。
2. **按 schema 归档**：每个"现象—根因—修法—回归"完整的案例写一条 `RC-xxx`（§一 schema），一条只讲一件事。
3. **分类**：按 §二六类（口径/边界/工具/流程/跨书/验收）归类；跨类时以"根因所在层"为准。
4. **复盘四问**（§四）：遗漏/冲突/新增/合并，四问各写一句结论，禁止只写"已修复"。
5. **回填**：规则成文（03a/04f）→ 种子更新 → few-shot 重生成 → 回归复跑；未成文的进"待回填"清单，不得静默消失。
6. **与 S-03c 接口**：逐回反思记录（S-03c）产出案例草稿；案例库（本件）负责去重、定级、回填；规律库（03c1）只收已成文的规则条目。

> 成功标准：每条案例可从案例编号追到证据文件与复跑命令；回填闭环率（已成文/应成文）≥ 90%。

## 一、案例 schema（照搬骨架，武侠字段化）

| 字段 | 说明 |
|---|---|
| `case_id` | `RC-###`，全局递增，不复用 |
| `category` | 口径 / 边界 / 工具 / 流程 / 跨书 / 验收（§二） |
| `title` | 一句话现象（≤30 字） |
| `phenomenon` | 可观测现象（含计数/位置，如"七剑 judgment 99 条 plan_negation_verb"） |
| `root_cause` | 根因层：提示词 / 规则文本 / 词表 / 工具 / 流程 / 数据 |
| `evidence` | 证据文件:行号（docs/xx、registry/acceptance JSON、logs/qa、tagged 定位符） |
| `ruling` | 裁定与修法（谁裁、依据哪条规则、改了什么） |
| `regression` | 回归方式（复跑命令/断言/指标）与结果 |
| `reusable` | 可复用性：全库通用 / 同系列 / 单书个例 |
| `related` | 关联 DEF-xx / V-x / G-xx / R-xxx / docs 编号 |
| `status` | 已闭环 / 待回填 / 挂起 / 撤销 |

## 二、六类分类（武侠新增"跨书"一类）

| 类 | 判定 | 典型 | 回填去向 |
|---|---|---|---|
| 口径 | 规则文本与种子/裁定不一致 | 计划否定误标、数量裸词、时间宽窄 | SKILL_03a/04f 正文 + 种子 |
| 边界 | 实体/动词边界与切分 | 管道吞原文、称谓连写、招式名边界 | 03a §四 DEF、04f §八 |
| 工具 | 脚本误报/崩溃/性能 | lint 假阳性、loader 性能、accept 硬编码 | 脚本修复 + 自检/断言 |
| 流程 | 批次组织/版本/回填纪律 | 版本锁漂移、自报不实、报告覆盖 | 流程文档 + 检查清单 |
| 跨书 | 多书同一性/时代/canonical | 皇帝时代错置、飞红巾/哈玛雅、registry 校准 | SKILL_03b + registry + 互文表 |
| 验收 | 验收口径与状态机 | judgment 分类、accepted 判定、抽样覆盖 | accept_batch 规则 + docs/45 口径 |

> 分类纪律：**一条案例只归一类**；若根因跨类（如"口径未成文导致 judgment 大量误报"），以"最终修法所在层"归类，另一层写入 `related`。

## 三、首批案例库（RC-001~RC-010，全部来自 5 书 G2 反思）

### RC-001 计划/否定/假想语境动词被误标（口径类，最大类）

- **现象**：白发 020-032 judgment 85 条中 plan_negation_verb 35 条；七剑 213 条中 99 条（占 46%）；江湖 268 条中 116 条。
- **根因**：提示词只给"触发词=事件入口"总则，未把"计划/意图/条件/否定/命令/假设"的**未发生**语境写成可判定负规则；检测器按近旁关键词共现判定，把"正待/正想/若不/还未/就要"后的动词误判为已发生。
- **证据**：docs/45 §二/§三（85→58 修/27 保留）；docs/47-江湖 §6.3（remove 139）；docs/48 §九（99→76 删/23 保留）；tagged 定位如 020[4] `⟦■下山⟧`。
- **裁定/修法**：SKILL_03a v1.8 L127 明确"纯计划/意图/条件/否定/命令内容不标"；04f §3.6 同步；accept 将 plan_negation_verb 列为 judgment（不阻塞 accepted），由裁决流程逐条过。
- **回归**：三书删标后重跑 accept，judgment 降至 27/97/105（白发/江湖/七剑），hard 0，剥标零差异。
- **可复用**：全库通用；新书批次必查项。
- **关联**：DEF-04（亲属词旧规）相邻类；R-007 梦境层整体不标。

### RC-002 裸数词/裸量词误标 `$`（口径类）

- **现象**：白发 13 条 quantity_boundary；七剑 15 条删标（张/杯/枝/颗/根/把/双/三/两）；江湖 21 条。
- **根因**：金标准旧口径"见数就标"与 v1.8"信息承载计数原则"分裂；提示词未给"事件量/习语量/纯泛指不标"负例。
- **证据**：docs/45 §三（13 条全修）；docs/48 §九（quantity_boundary 归零）；docs/39 §1.2（裸文标注率）；docs/47-020 §7.1（W4 信息承载计数 302 处）。
- **裁定/修法**：R-009 信息承载计数原则成文 03a §二；负例：一个/一声/一掌/千里迢迢/第七节序数；C25 W4 只补"数+量+名"信息承载子集。
- **回归**：七剑 quantity_boundary 归零；白发/江湖 accept 复跑 judgment 不升高。
- **可复用**：全库通用；数量口径变更须先金标准标定（docs/39 S1 纪律）。

### RC-003 时间宽窄口径与 `%`/`$` 域边界（口径类）

- **现象**：七剑 time_boundary 24 条：删 4（"一会"×2、"千里迢迢"）、改域 4→`$`（五六十招/十余二十里路/六尺/三尺）、保留 17（东汉/新正/三十出头/五十大寿/明亡之后/明早/甲申后五年）。
- **根因**：宽口径规则未给"时点/时长/年龄"三值边界与"数词+量词"改域先例；"宽口径"被误读为"凡模糊时间都标"。
- **证据**：docs/48 §九 time_boundary 行；docs/26 R-006/R-016；SKILL_03a v1.8 % 行。
- **裁定/修法**：% 只收时点/时长/年龄；数量归 `$`；宽口径示例入种子（"明晚/前日/半夜/忽然一日"零规则增量正确执行——R-016 正面确认）。
- **回归**：七剑改域后 `$` 计数与既有先例一致（〖$七丈〗〖$五六十回合〗）；accept judgment 降。
- **可复用**：全库通用；时间类误报优先查"是否把数量当时长"。

### RC-004 动词域归属与阈值（口径类）

- **现象**：白发 85 条中 verb_domain_risk 16 条（保留 14）；七剑 16 条（保留 14：押/驱逐=■、刺/劈/戳=⊠）；江湖 34 条；改域 4 处（刺 ⊠→⊞、重伤 ⊞→⊠、逐出宫/逐出 ■→⊡）。
- **根因**：攻击动作 vs 致害结果、强制移动 vs 拘押/社会处置的边界未写成可判定阈值；词表单主域导致"合法多义"被报 error。
- **证据**：docs/45 §二（改域 4 处）；docs/48 §九（verb_domain_risk 保留 14）；docs/46 §8（N3 词表域冲突降 warning）。
- **裁定/修法**：04f §2.2 受伤阈值（行动能力）+ 域码速查表；N3 默认 `W-WL-DOMAIN` warning，`--wordlist-strict` 恢复 error；词表补 senses 后再升门禁。
- **回归**：N3 复跑 error 0 / warning 317（白发）；三书 judgment 不升高。
- **可复用**：全库通用；词表 senses 是根治项（META-02 收敛数据可追踪）。

### RC-005 围栏"限实指"与回末套语（边界类）

- **现象**：七剑 fence_entity_real_only 10 条全保留（018[1] 诗围栏实指、023[80] 对联江南/塞外实指）；白发 13 回围栏新增；塞外/冰魄回末续书预告段误标（TAO hard）。
- **根因**：围栏类型规则（回末全不标/回末对限实指/诗词语）未与结构层检测同步；回末套语词族窄，导致续书预告段未入围栏。
- **证据**：docs/48 §九（10 条保留）；docs/47-江湖 §2.3（tao_token 修复）；docs/49 §2.4（两书回末边界摘标）；docs/54 §二（围栏漂移 64→67/29→54）。
- **裁定/修法**：02ab §4.4 围栏负规则 + accept `TAO_RE` 收窄（欲知后事/详情/究竟/端的/如何 + 下回分解 + 且听/请看/请听/请续看）；结构层缺口归 N1/N2（另行修复）。
- **回归**：accept tao_token 归零；五门 lint 全 0。
- **可复用**：全库通用；围栏类问题先判"结构层是否识别"再判标注。

### RC-006 时代依赖通称与跨书 canonical（跨书类）

- **现象**：白发 022/023/024/028 皇帝/皇上→朱翊钧 32 处时代错置（应为由校，030 万历回忆保留朱翊钧）；江湖 82 条 pipe_unsourced（崇祯/康熙/顺治/雍正等帝王本名缺失）；飞红巾/哈玛雅、晦明禅师/岳鸣珂双层 canonical 分歧。
- **根因**：registry/mapping 为全局单值字典，无 (书,回) 级作用域；帝王年号/庙号与通称（皇上）在不同书/回指向不同人；跨书 canonical 未建。
- **证据**：docs/47-020 §一 P4.2、§四（35 warnings）；docs/55 §1.1（82→0）；docs/56 §一（loader 回级 A/B 0 差异）；SKILL_03b 附录 B。
- **裁定/修法**：loader 回级作用域（条目级 chapter/chapters/scope + registry context_notes；查找 (书,回,显示串)→(书,显示串)→全局）；S-03b 三层消歧；帝王本名优先（B-1 推荐）；registry 校准 458→454→452。
- **回归**：5 书 pipe_unsourced 全 0；accept A/B 0 差异；qa 管道问题 21/134/167/0/0。
- **可复用**：全库通用；换书批次必查"时代通称"。

### RC-007 工具误报/崩溃与自检缺失（工具类）

- **现象**：lint_symbol_conflicts 旧式 @X@ 检测未剥令牌 → 004 报 170 处假阳性（DEF-11）；find_candidate_entities KeyError 使 candidates 阶段必崩；accept 报告硬编码"无来源 0 条/032[31]"；C19 首字匹配潜在误映射；C20 selftest 依赖真实 registry 非 hermetic。
- **根因**：检查器在未剥令牌原文上运行；测试未覆盖批处理路径；报告文案写死；自检依赖外部数据。
- **证据**：docs/26 §四（DEF-11）；docs/42 §九（C6 修复）；docs/46 §二/§七/§八（P1/P2 修复清单）。
- **裁定/修法**：检测前剥令牌；统一 `chapter_id()` 键；报告全数据驱动；C19 仅末字匹配；C20 内置 mock registry/WN；pipeline `run_stage` 异常捕获。
- **回归**：candidates 阶段 exit 0；5 书 accept 输出 A/B 0 差异；`--selftest` 全 PASS。
- **可复用**：全库通用；工具类案例必须附"回归命令 + 指标"。

### RC-008 结构层围栏漂移（流程/结构类）

- **现象**：白发代码输出 67 围栏 vs 现存 struct 64；七剑 54 vs 29（含楔子 000）；塞外缺 5 处围栏、冰魄缺 2 处。
- **根因**：N1/N2 检测树迭代后未对既有 struct 重生成+回灌；结构层与标注层版本不同步。
- **证据**：docs/54 §二（白发 64→67、七剑 29→54，PN 不变/2394→2392）；docs/47-江湖 §6.1（围栏 56→98）；docs/49 §五.1。
- **裁定/修法**：重生成 struct（`--all --verify`）+ `rebuild_tagged_from_struct.py` 回灌（内容行序列不变断言）+ 围栏内令牌按类型豁免 + 五门复跑 + accept 重跑。
- **回归**：围栏数/PN/令牌 delta 报告；5 书 accepted 全绿。
- **可复用**：同系列/全库；结构层改动必须"重生成+回灌+复跑"三步。

### RC-009 registry 校准与 E12 单源对齐（跨书/工具类）

- **现象**：江湖 82 unsourced 归零过程 registry 458→454→452；E12 告警 127→95；display_canonical 展示层分歧（飞红巾/哈玛雅）。
- **根因**：registry 由多批任务增量写入，canonical/别名与 tagged 管道、E12 生成器三处口径未单源。
- **证据**：docs/55 §1.3/§二；docs/56 §二；docs/57 §三。
- **裁定/修法**：现读现写+唯一性断言+备份；E12 与生成器单源对齐；display_canonical 双层（系列层展示 vs 书内 canonical）。
- **回归**：5 书 accept 不变（hard 0、unsourced 0、judgment 不升高）；站点构建 exit 0。
- **可复用**：全库通用；registry 每次写后必须唯一性断言。

### RC-010 并发批次的组织性缺陷（流程类）

- **现象**：并行批次曾出现 034-048 越界 TSV（书号冲突）、accept review_package 被并发覆盖、registry id 冲突风险、报告目录互相覆盖。
- **根因**：共享目录无书级命名空间；id 在提案时分配；报告路径写死单书。
- **证据**：docs/47-020 §7.5（越界 TSV）；docs/47-江湖 §6.6（review_package 死参数）；docs/48 §十（id 延迟分配）；docs/57 §一（写范围互斥）。
- **裁定/修法**：patches 按书子目录（`config.patches_dir`）；annotate 报告 `logs/annotate/<书>/`；registry id 合并时 max+1 顺延+幂等；写范围互斥、Lead 串行收口 site/data。
- **回归**：并发两批产物互不覆盖；二次 apply 0 变更（幂等）。
- **可复用**：全库通用；并行批次开工前先写"写范围表"。

## 四、复盘四问（照搬结构，武侠化输入）

```markdown
# 按章/按书反思任务

## 输入
1. 本批 tagged + struct（定位符 `书#pn-r{回}.{段}`）
2. 五门 lint + coverage + qa 报告
3. accept judgment 清单（分类/计数/定位）
4. 工具缺陷记录与外部复核意见（Qwen 等，须先程序核验）

## 四问
1. 遗漏：哪些应标未标？属 15 类/6 域中的哪类？是否词表/负规则缺口？
2. 冲突：哪些标注与规则文本/种子/裁定冲突？属口径、边界还是跨书？
3. 新增：是否需要新增规则/词表/工具检查项？给出候选 + 影响回数 + 成本。
4. 合并：是否有规则可合并/降级（如词表单主域→senses、judgment 类合并）？
```

> 纪律：四问任一问"无结论"须写明理由；反思产出必须落 RC 案例或 DEF/V 编号，禁止只写在对话里。

## 五、与 S-03c / 03c1 接口

| 方向 | 内容 |
|---|---|
| 输入 | S-03c 按章反思记录（逐回：边界/动词/围栏/漏标候选）；accept judgment 全量；lint/coverage 报告 |
| 本件职责 | 案例去重、定级、分类、回填状态跟踪（RC 库是"案例层"，不是规则层） |
