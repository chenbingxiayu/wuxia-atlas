## 三、战争级 vs 战斗级 vs 事件级

### 3.1 三档判定（规模/主体/叙述结构）

| 档 | 判据 | 典型 | 主类型 |
|---|---|---|---|
| **战争级** | 参与方达政权/军队规模；多场次、有战线或阶段；战役级叙述 | 义军起事攻城、朝廷大军平叛 | T09 起义战争 |
| **战斗级** | 一场次冲突（连续时空、同一冲突目的）；双方可辨；有 outcome | 单挑、围攻、伏击、守山 | T01/T02/T08 等 |
| **事件级（非战斗）** | 无对抗性或对抗只是背景 | 拜师、行踪、婚约 | 其他类型 |

### 3.2 五类冲突类型学（武侠化重划，承 docs/05）

| 类 | 定义 | 与 04a 13 类映射 | 备注 |
|---|---|---|---|
| **决斗** | 双方约定或遭遇的一对一/少数对少数对抗 | T01 比武较技（有规则）/T02 生死杀伐（无规则） | 刺杀亦入此类，不因"暗杀"排除 |
| **门派火并** | 门派/帮会间有组织的群体冲突 | T02（死伤为主）/T08（若官府主体） | 灭派过程 T02，结局另记 T07 |
| **武林大会** | 多方齐聚、多场比武与盟举的大场面 | T13 容器 + T01 子事件 | 容器门槛见 04a §3.4 T13 |
| **围剿** | 官府/朝廷为主体的军事行动 | T08 朝廷剿抚 | 未达战争级；达战争级升 T09 |
| **起义战争** | 战争级武装冲突 | T09 起义战争 | 收容各役为子事件 |

> **边界重划（重要）**：史记 05e 的"暗杀不属于战争"条款**作废**——刺杀是武侠核心事件，按 T02 生死杀伐记录，战斗类型可选"追杀/处决"或按情节另立；不得因"非正面战场"而降级或漏记。

### 3.3 战争级扩展判定（在 T09 内）

- **战线/阶段**：≥2 个时空分离的战役阶段 → 母容器（T09）+ 阶段子事件；
- **参战方**：政权/军队/义军/门派联盟（〖◆〗主体）＋双方高手名录；
- **叙述结构**：战役级叙述（多回/多场次/有战略目的），不是单场遭遇；
- **结局**：战争 outcome（胜/负/平/未决/未知）＋参照方（哪一方），局部战役 outcome 分记。

## 四、战斗记录 Schema

### 4.1 骨架（04a §6.1）

**战斗记录 = 事件记录的战斗模板实例**，主类型 ∈ {T01 比武较技, T02 生死杀伐, T08 朝廷剿抚, T09 起义战争}；骨架三层：**战斗（记录）／阶段或回合（阶段子事件）／动作（触发词，04f 管）**；结果分局部效果与整场 outcome 两层。**battle_id=event_id**。

### 4.2 字段表（04a §6.2 + 战争级扩展 ★=必填）

| 字段 | 必填 | 说明 |

| battle_id（=event_id） | ★ | 不设第二套编号 |

| 见证人 | 可选 | 语义角色"见证人"的战斗面 |
| outcome＋参照方＋判定依据 | ★ | 五值；必须指定参照方；依据可引原文 |
| 死伤 | ◐ | 逐名引用＋计数；与独立 ⊠ 死亡记录关联 |
| 用武 | 可选 | 〖☆〗招式/武功/阵法列表 |

## 五、13 种战斗类型（04a §6.3，判定一句话）

| 类型 | 判定一句话 |
|---|---|
| 单挑 | 一对一约战或遭遇，两侧各一人 |
| 比武 | 有规则场合的正式较量（擂台/大会规则） |
| 围攻 | 多打一或多打少，两侧人数不对等 |
| 混战 | 多方卷入、无固定两侧 |
| 车轮战 | 一人连战数敌，必用阶段列表 |
| 夜袭 | 乘夜突击，攻方主动 |
| 伏击 | 预设埋伏的攻击 |
| 守山 | 据守方明确的攻防战 |
| 劫狱劫镖 | 以劫夺为目的的战斗（与 ⊟ 劫夺事实并立） |
| 追杀 | 移动中的持续杀伐 |
| 处决 | 一方已失反抗能力的杀戮 |
| 群殴 | 低组织度群体互殴 |
| 突围 | 被围方以突破包围为核心目的；突围成功≠对方整场负，outcome 分侧记 |

> 枚举可扩展（水战/火攻/毒战等冷僻型试点后增补，见 04a 附录 B2）。**类型判定优先于事件名称**：名称可文学化，类型必须一句话可判。

## 六、多阶段与拆分裁决

### 6.1 核心裁决（04a §6.5）

> **一个战斗记录＋阶段子事件列表；禁止一个记录多 outcome。** 每阶段记独立局部 outcome（含参照方与判定依据），整场 outcome 按最终局面判，依据必须可引原文。

- **阶段判据**：同一场次（连续时空、同一冲突目的）内的轮换 → 阶段；时空分离或冲突目的独立 → 独立战斗事件＋母容器或事件链。
- ✅ 车轮战："大盗连战王氏三兄弟" → 一场"车轮战"记录，三阶段各记局部胜负，整场按末局判；
- ✅ "三战三捷"跨三日三地 → 三个独立战斗事件＋母容器"三战三捷"；
- ✅ 对手无名且无独立情节的车轮战（"连败十八名强盗"）→ 阶段子事件可合并为计数描述（"强盗〖$十八名〗，逐一败之"）；
- ❌ 一个事件记录里填"先胜、再平、后败"（多 outcome 违例）；
- ❌ 同场车轮战拆成三个互不关联的战斗（整场战绩断裂）。

### 6.2 战争级拆分

- 战争（T09 容器）→ 战役（阶段/子事件）→ 战斗（战斗记录）→ 动作（04f 触发词）；
- 每层都要有 outcome（战争/战役/战斗各自参照方），不得跨层借用；
- 跨回大战（一场大战打了三回）按 04a §2.5 处理：同一战斗跨回 → 一个记录多区间定位；不同战斗 → 事件链。

## 七、死伤与独立死亡记录

### 7.1 核心裁决（04a §6.6）

> **独立 ⊠ 死亡记录＋战斗关联**（落实 01g 主域裁决"杀死某人主域 ⊠，可关联所属战斗"）。死亡走独立事件记录（T02/T11），其"所属战斗"槽位指向战斗；战斗记录的死伤字段为**汇总视图**（引用死亡记录＋计数）。

理由：穿帮雷达"死亡一致性"消费独立死亡记录；问答"谁杀了 X"直接命中死亡记录——若死亡只藏在战斗死伤栏里，两个下游同时断供。

### 7.2 死伤字段结构

- 逐名引用（死者/伤者 canonical）＋计数；群体无名可计数描述（"卫士〖$二名〗"）；
- 伤情：按 04f 受伤阈值（改变后续行动能力）区分"受伤事件（⊠）"与"战斗局部结果"；
- 与 T11 生死救治衔接：战后疗伤/救活另记 T11，不并入战斗记录；
- **不得只在战斗记录死伤栏写"卫士×2"而不建死亡记录**。

### 7.3 与关系层的衔接

- 每条死亡记录 → 事实层"杀害(凶手,死者)"候选（D06 #47）；
- 死者亲属的仇怨**候选**（D06 #44，event_ids 必填）→ 人物层边（人工裁定）；
- 交手边（D06 #53）由战斗记录生成，**一次交手不自动敌对**；多次+明文才升仇怨候选。

## 八、outcome 五值、参照方与评分衔接

### 8.1 五值与判定依据（04a §5.1 字段 22-24）

| outcome | 判定 |
|---|---|
| 胜 | 原文明说一方胜/对方败/被击退至失去战力 |
| 负 | 同上反向 |
| 平 | 原文明说"不分胜负/平手/两败俱伤" |
| 未决 | 战斗中断/被叫停/双方脱离且无胜负陈述 |
| 未知 | 原文未给结果 |

- **参照方必填**：胜负相对谁而言（"甲胜"→参照方=甲；"逼退乙"不判乙负，除非原文明确）。
- **判定依据必填且可引原文**：✅ 原文明说"甲胜乙"；❌ "甲被逼退三步"便判败（01g §9.7）；❌ 由"逃走"倒推"败"（逃走≠负，按原文）。
- **manner**：压制/险胜/点到即止（可选，但不替代 outcome）。

### 8.2 评分衔接（E9，未接）

- 评分消费 outcome 五值 + 参照方 + 条件标记（偷袭/以多打少/带伤…）——**条件不同不可直接比较**；
- 当前父仓库 `build_ratings` 仍用旧五值映射，**未接 D03**（docs/50 §三 E9 待决策）；
- 评分不得使用「来源声称/存疑/相互冲突」格的战斗（04a §7.1 消费矩阵：评分只取已核实）。

## 九、总述句、回合数与时长

### 9.1 纪律（04a §6.4）

- "大战三百回合""斗了半日"：**不造触发词、不数回合**；战斗记录的时长描述字段保留原文表达；
- 若总述句独立出现、无既有战斗记录可挂，则建**最小战斗记录**（名称＋参战方＋outcome=未知/未决，锚点动词区间记总述句位置）；
- ✅ "斗了半日，不分胜负" → outcome=平，依据=原文"不分胜负"；
- ✅ "大战三百回合" → 时长描述=原文，不拆 300 事件；
- ❌ 由"三百回合"倒推细拆回合级事件。

### 9.2 招式与兵器

- 招式名（〖☆〗）每现必标（04a §3.4 T05 边界、04f §2.1），但**招式≠事件**；
- 兵器折断/被夺 → 另触发 ⊟ 独立事实（转移/毁损），不并入战斗 outcome；
- 阵法（〖☆〗）作为用武字段，结阵迎敌归 ⊞。

## 十二、成功标准（Success Criteria）

1. **层级正确**：抽样 10% 冲突，战争级/战斗级/事件级判定准确率 ≥90%。

5. **多阶段合规**：无"一记录多 outcome"；车轮战/三战三捷拆分正确。
6. **下游可用**：E5/E9 接入后可直接消费（字段与 id 契约通过）；交手/杀害边可回链。
