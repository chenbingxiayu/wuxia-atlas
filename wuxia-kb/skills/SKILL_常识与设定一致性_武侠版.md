# 一、技能定位

## 1.1 本技能是什么

武侠常识基准库与设定一致性检查规则，是"梁羽生武侠宇宙"知识库的**设定一致性 QA 体系**：

- **常识库**（第二至三章）：四区常识条目 + 34 条 IF-THEN 种子规则，回答"什么在武侠世界里是正常的"；
- **检查清单**（第四章）：五项跨数据一致性检查（年龄/习得/存续/死亡/称谓），回答"这部书内部是否自洽"；
- **评级与分流**（第六至七章）：A-E 一致性评级与"破绽/修辞/翻案"三分流，回答"发现的问题该怎么处置"。

它是穿帮雷达 /audit 的**规则引擎数据源**：雷达报告的每一条（年龄矛盾/死亡再现/习得时序/门派存续/称谓辈分）都由本文件的规则与检查清单驱动。

## 1.4 方向反转总声明（本任务最重要的领域差异）

武侠的"常识"与史书的"常识"**阈值方向相反**。凡与史记参考件相反处，本文档一律加星号并显式声明；逐条对照见附录 A。

| 维度 | 史记标准（07c/07e） | 武侠标准（本文件） | 声明 |
|---|---|---|---|
| 行进速度 | 数日跨千里=时间异常 | 轻功一夜千里=设定内合理，**上不封顶** | ★方向反转（W1） |
| 巅峰年龄 | 将领出征通常 <65 岁，70+ 罕见 | 按武林标准：内功修为延展战力年限，高龄宗师出战常态，不设上限；"巅峰 20-40 岁"仅作当打之年参考，非检验阈值 | ★方向反转（W3） |
| 高龄与寿命 | 高龄行为超出生理极限=反常 | 驻颜、闭关、百岁出手均设定内合理 | ★方向反转 |
| 单人战力 | 无"以一敌百"实录 | 一人破百人军阵=设定内合理 | ★方向反转 |
| 亲情/同门 | 父杀子、手足相残=行为反常 | 同门火并、骨肉仇杀=高频母题资产 | ★方向反转（S8/J2） |
| 财富 | 赏赐超国力=异常 | 江湖钱物=叙事道具，整体豁免现实校验 | ★方向反转（J5） |
| 史实校验 | 以史实校文本之真伪 | 史实为背景板，小说即权威（演义自由） | ★方向反转（T3） |
| 时代器物 | 以出土/文献为据校记载 | 同为真实历史锚：清代火枪=合理，"手枪"=穿帮 | 部分反转（T1-T2：锚内合理、锚外穿帮） |
| 传言校验 | 传闻必校、孤证不立 | 江湖传言是悬念手段，传言≠事实（04a 来源声称层） | ★方向反转（J8） |

反转的统一判据：**设定内合理 ≠ 现实合理**（01g 已定原则）。凡武侠母题（轻功、内力、闭关、驻颜、寻仇、灭门）默认豁免现实校验，只查两件事——(a) 书内自洽（前后矛盾），(b) 设定锚冲突（与明文设定或时代锚冲突）。

## 2.4 与 01g"设定内合理≠现实合理"原则的边界

- **武学区**：一切生理/速度/年龄阈值以武林标准为准，禁用现实医学/体育标准（★反转核心区）。校验只对书内自洽（前后数值打架）与设定锚冲突（明文设定"非二十年不成"却被三年练成且无解释）。
- **门派区**：门派规模、存续年限不做现实组织学校验；只校验门内自洽（辈分序列、师承代距、明文门规与行事一致）。
- **江湖区**：镖程、悬赏、经济数字整体豁免现实校验（★反转）；只校验同类惯例在书内前后一致。
- **时代区**：**唯一双向区**——以真实历史锚为基准：锚内器物/官职/纪年=合理，锚外=穿帮。此区不反转，与 07e"以客观标准校文本"同向；但"历史人物言行与正史有出入"仍属演义自由（T3 反转）。

# 三、种子规则库（Q2）

共 34 条 IF-THEN 种子（W 区 9、S 区 10、J 区 8、T 区 7）。每条含：条件-结论、阈值、检测信号、反例（不触发条件）、严重度、入库门槛、lint 关系、正误例。**全部正误例均为自造语境的规则演示，不作为作品证据。**

**双稿来源注记**：各条标题后〔 〕标注双稿来源——〔v1〕=v1 原条直定；〔v1⊕v2〕=v1 条为基并入 v2 要点；〔v2 回收〕=自 v2 新设。v2 另有 15 条并入既有规则（并入点见各条注记）、15 条经裁决废弃，逐条理由见 docs/15 §4。

入库门槛统一规则（照搬 07c §七六轮流程）：**任何种子规则须在实战验证中命中 3+ 案例（跨章或跨书）方可转正入库；不足 3 案例者标"候选"，只跑不判**。转正另须假阳性率 <20%（第八章流程）。

## 3.1 武学常识区（W1-W9）

**W1　轻功远程奔袭（★方向反转示范）**〔v1⊕v2：v2 WU-002 的">1000 里=异常"上限为方向回归，不采；其一流/二流分层依赖未建模等级数据，亦不采〕
- IF 轻功赶路单日行程 ≥300 里 THEN 记 info「武侠加速」，不判异常（≥1000 里仍为 info 备案，**不封顶**）。阈值：凡人脚程 ≤100 里/日；轻功奔袭 300-1500 里/日（数值待语料定版）。**与史记"数日跨千里=时间异常"方向相反：行千里一夜=设定内合理。**
- 检测信号：#4 移动类事件的距离/耗时字段。反例（不触发）：明写借马、船、车代步；明写"行了三日方至"；人物被设定不识武功。
- 严重度：info｜门槛：3+ 案例｜lint：可自动（数值比对）。
- 例（演示，非作品证据）：正——主角一夜掠出八百里赴约，正常叙事，不报；误——前文自述"从未习武"者当夜行八百里，属书内自洽冲突，转第四章检查项一，不与现实标准比。

**W2　内伤/内力恢复速度**〔v1⊕v2：并入 v2 WU-001（重伤未运功短时复元）与 WU-007（内力耗尽刻钟级复元）两触发〕
- IF 内力耗尽/受内伤 AND 无灵药、疗养、他人渡功、运功调息明写 AND ≤1 日内恢复如常 THEN warning。阈值：轻伤全愈 ≥半日、重伤 ≥3 日、内力耗尽 ≥7 日（数值待语料抽样定版）；运功调息可大幅缩短（设定内合理）。
- 检测信号：#4 伤势事件+相邻事件时点差（#5）。反例：服丹、温泉疗伤、师父输功、运功调息均有明写。
- 严重度：warning｜门槛：3+ 案例｜lint：半自动（需读伤势描述）。
- 例（演示）：正——受掌伤"将养旬月"，不报；误——昨夜经脉尽断今晨生龙活虎且无任何解释，warning。

**W3　高龄高手出战（★方向反转）**〔v1〕
- IF 年龄锚 ≥60 岁人物仍有单打独斗情节 THEN 不标记。**与史记 07c"将领 70+ 出征=异常"方向相反：武侠按武林标准，内功修为可延展战力年限，百岁宗师常见，不设年龄上限。**
- 检测信号：#5 年龄锚+#4 战斗事件（本条为豁免性规则，默认不进扫描）。反例：无（豁免性规则）。唯一 info 情形：文本自称"年老力衰"后又写超常战力且无解释——那属书内自洽问题。
- 严重度：info（仅备案）｜门槛：3+ 案例｜lint：无需。
- 例（演示）：正——八十岁老掌门出手退敌，不报；误——若疑点实为"他六十年前 20 岁、书中却说那是三十年前"，是年龄数字跨回问题，走第四章检查项一，不判"太老不能打"。

**W4　神功速成**〔v1〕
- IF 文本明写某武功"非 X 年不能有成" AND 角色习得后 <X/3 年大成 AND 无奇遇明写 THEN warning。阈值：X 取文中明示年限；无明示年限时不触发（禁臆造标准）。
- 检测信号：#4 习得事件+大成事件时点差（#5）。反例：奇遇（服异果、得传功、悟性设定）有明写。
- 严重度：warning｜门槛：3+ 案例｜lint：半自动（识别"非 X 年不可"句式）。
- 例（演示）：正——"此功二十年方有小成"，主角六年练成且文中解释服食朱果，不报；误——无任何解释六年大成，warning。

**W5　武功相克反转**〔v1〕
- IF 文本明写"甲功克乙功" AND 后文乙胜甲 AND 无"破法/境界差距"解释 THEN info 待人工。阈值：以明文相克关系为准，隐含克制不触发。
- 检测信号：#6 武学相克关系边+战斗结果事件。反例：明写"以快打慢，不拘克星"或境界悬殊设定。
- 严重度：info（可能是有意翻案，转第七章三分流）｜门槛：3+ 案例｜lint：半自动。
- 例（演示）：正——设定"玄功克剑法"，后文剑客凭新悟剑意取胜且有专段解释，翻案候选（资产）；误——无解释直接反转，info 记录。

**W6　轻功/剑气数值夸饰（修辞识别）**〔v1〕
- IF 出现"一跃十丈""剑气百丈""顷刻千里"类大数 AND 该数值无情节依赖（不用于逃生/追逐/胜负判定） THEN 归类夸张修辞，识别不改。阈值：以"数值是否被后续情节引用"为分界。
- 检测信号：修辞标志词（百丈/千军/顷刻/宛如/犹如/但见/仿佛）+数值引用追踪。反例：数值被情节依赖（"恰能跃过城墙"且墙高此前明写）→转查证。
- 严重度：info（修辞标签）｜门槛：3+ 案例｜lint：可自动（标志词）+人工复核。
- 例（演示）：正——"剑光起处，百丈内血雨腥风"，写意修辞，不报；误——"墙高五丈"却"一跃三丈而过"，情节依赖冲突，转破绽候选。

**W7　内力外放设定边界**〔v1〕
- IF 人物档案设定"不会内功/内力平平" AND 后文隔空伤人、剑气及人 THEN warning。阈值：以 #6 武学边登记的武功设定为准；**不设通用"攻击距离上限"**（"剑气百丈"类走 W6 修辞识别，避免双标）。
- 检测信号：#6 武学-人物边+战斗描写事件。反例：两者之间存在习得新功事件（成长弧，合法）。

- 检测与备案：①作品明写改变重大史实走向→标注"架空声明"资产条目，供问答与专栏引用，不判穿帮；②历史人物生卒年与正史偏差→info 备案（演义自由推定），不设"偏差 >5 年=异常"的现实校验；仅当书内自身纪年体系前后矛盾时转 T4/检查项一。
- 检测信号：历史人物边+史实对照（人工）。反例：无（默认豁免）。
- 严重度：info（资产标注）｜门槛：3+ 案例｜lint：人工。
- 例（演示）：正——康熙与虚构侠客论剑，不报；误——书明写虚构人物签了某个条约，标"架空声明"资产而非穿帮。

**T4　纪年自洽**〔v1〕
- IF 同一部书内纪年体系冲突（万历三十年与崇祯元年相邻且无跨时叙述） THEN error。阈值：跨时叙述须有明确时序标志（"话说二十年前"）。
- 检测信号：#5 时点键+纪年字段。反例：倒叙/插叙有时序标志。
- 严重度：error｜门槛：3+ 案例｜lint：可自动。
- 例（演示）：正——"话说二十年前，崇祯初年……"回溯段，不报；误——同一场景两段分别标万历、崇祯且无解释，error。

**T5　兵器谱年代**〔v1〕
- IF 器物属武侠通用兵器（剑刀枪棍鞭暗器） THEN 跨朝代通用，不校验。阈值：白名单管理，白名单外走 T1。
- 检测信号：兵器词表白名单。反例：无（白名单内一律豁免）。
- 严重度：—｜门槛：3+ 案例｜lint：可自动。
- 例（演示）：正——唐代的"神兵"与清代的"宝刀"同制式描述，通用兵器不校验。

**T6　称谓与服饰时代感**〔v1⊕v2：并入 v2 ERA-006（跨朝代服饰）〕
- IF 古代背景出现现代称谓（"主席/同志"类）或跨朝代服饰（明代背景着"马褂"类清装且非"前朝遗风"明写） THEN warning 候选（先查叙述模式排除戏中戏、说书人口吻），确认后可升 error。阈值：以 #9 称谓/服饰词表为准。
- 检测信号：称谓/服饰词表+叙述模式。反例：戏中戏、译名注释、说书人插话、"前朝遗风"明写。
- 严重度：warning（查完叙述模式后可升 error）｜门槛：3+ 案例｜lint：可自动+人工。
- 例（演示）：正——清代侍卫称"皇上""大人"，不报；误——明代侍卫口称"领导"且无戏中戏语境，error 候选。

**T7　修订版权威**〔v1；v2 6.3 自造"正典/外传/草稿"层级非 #7 词汇，废弃〕
- IF 同一设定初版与修订版冲突 THEN 以修订版为准（#7 权威层级，T11 合同口径"修订版赢"），初版差异记"版本对照"资产，不入穿帮雷达。阈值：版本字段可用。
- 检测信号：版本字段+设定冲突检测。反例：修订版自身内部矛盾（照常走检查清单）。
- 严重度：info（资产）｜门槛：3+ 案例｜lint：可自动（版本比对）。
- 例（演示）：正——某门派创派年代修订版改定，以修订版入档案，不报；误——修订版内部 A 章与 B 章自相矛盾，照常报 error。

# 四、设定一致性检查清单（Q3）

五项检查是穿帮雷达 /audit 的核心引擎，消费 #4（事件+叙述模式）、#5（时间）、#6（关系）与 01g 登记层。每项含：定义、检测信号、严重度分级、豁免条件、上游数据接口、正误例（演示，非作品证据）。

## 4.1 检查项一：人物年龄跨回自洽

- **定义**：同一人物在全书时间轴上年龄不得"越活越回"（跨回）或无故停滞；检查对象是**年龄数字**，不是容颜描写。
- **检测信号**：读 #5 年龄锚（人物-时点-年龄），对同一人物任意两个时点做差：年龄差 ≠ 时点差（±1 年容差）即候选；04a 叙述模式字段用于过滤豁免；#5 时间扭曲标记（闭关/驻颜）照记但**不豁免数字自洽**。
- **严重度**：error=两处"已核实"级年龄锚互相矛盾（跨回 >1 年）；warning=一处"来源声称"级与"已核实"级冲突；info=约数转述偏差 ≤3 年。
- **豁免条件**（04a 分层）：回忆/梦境/假想/戏中戏内的年龄陈述（转述者记不准本身是刻画）；传言转述年龄（可靠性=来源声称）；**闭关一十二年、驻颜术按 #5"标注层照记、解释归设定"：年龄数字照记不豁免自洽校验，但"容颜与年龄不符"类描写不做检查**（驻颜只改容颜，不改数字）。
- **上游接口**：消费 #5 年龄锚、时点键、时间扭曲标记；消费 #4 事件叙述模式字段；消费 01g 可信状态（分级依据）。
- **例（演示）**：正——20 岁出场，10 年后档案记 30 岁，自洽；误——出场 20 岁、"五年后"处记 22 岁，error 候选；若"五年后"系回忆中他人估算，降为 warning 并按来源声称重估。

## 4.2 检查项二：武功习得顺序（未学先使）

- **定义**：人物使用某武功的时点不得早于其习得时点，除非存在其他习得途径且有事件铺垫。
- **检测信号**：#4 习得事件（武功-人物-时点）与使用事件（招式-人物-时点）比对；使用时点 <习得时点即候选；"偷看学会""梦中授艺"须有对应铺垫事件；跨书场景先经 #7 归并表确认同一人物，再核跨书武功传承（前书已学会的武功后书使用=合法）。
- **严重度**：error=主角核心武功无任何习得事件先于使用；warning=有模糊铺垫（"近日与他拆解"）但无明确习得事件；info=同门通用基本功（"本派弟子人人会使"）。
- **豁免条件**：梦境授艺明写（04a 梦境=设定内合法）；偷学有事件铺垫（边界案例裁定：合法）；**家传武功（默认已学，档案师承可证）**；传言"他从没学过这路剑法"（传言≠事实，可被后文推翻）；戏中戏中人物的招式不算本体习得。
- **上游接口**：消费 #4 事件类型=习得/使用、参与人物、时点键；消费 #6 武学-人物边；消费 #12 武功卡传人链（待建）；消费 04a 叙述模式。
- **例（演示）**：正——第 5 回偷观剑阵，第 12 回使出剑意，铺垫合法，不报；误——全书无习得记录，第 12 回直接使出独门绝技且旁人惊问"他几时学的"，error 候选。

## 4.3 检查项三：门派存续期（灭派后再出场）

- **定义**：门派被明文灭派后，不得在无重建事件的情况下整建制再现。
- **检测信号**：#4 灭派事件（时点、范围=总舵/分舵/传言）与重建事件；#6 门派-成员边在后文时点的活跃度；后文出场是否"整建制"（有掌门、有弟子、有山门）；#12 门派卡兴衰时间线（待建）。
- **严重度**：error=主线门派明文灭派（已核实级）后整建制再现且无重建；warning=背景门派同类冲突，或"灭派"记载本身为存疑/来源声称级；info=个别幸存者传人（"遗孤"母题，合理）。
- **豁免条件**：传言灭派（04a 传言≠事实——边界案例"传言某派已被灭"裁定不触发，见 J8）；灭的是分舵；明写"改组重建/开宗立派"；戏中戏中该派重现。
- **上游接口**：消费 #4 门派事件字段（灭派/重建/继任/范围）；消费 #6 组织边；消费 04a 叙述模式与可靠性矩阵。
- **例（演示）**：正——总舵被屠后有"遗孤重立门户"专章，合法重建，不报；误——"阖派尽灭"后十年该派率众亮相且无重建交代，error 候选。

## 4.4 检查项四：死亡角色再出场

- **定义**：01g 登记为死亡的角色，不得在正常叙事中再出场；**回忆/梦境/假想/戏中戏出现不算复活（01g 已定）**。死亡登记是本检查消费的原始数据。
- **检测信号**：01g 死亡登记（状态=死亡，含死亡事件时点与模式）+后续 #4 出场事件+04a 叙述模式逐条过滤；#5 时点键用于排序；**死亡方式与再出场形态矛盾加查**（"斩首/尸首在手"级死亡后完整出现，比"坠崖/失踪"级存疑死亡后出现严重度高一级）；#12 人物卡结局字段（待建）。
- **严重度**：error=正常叙事中活体行动（说话、战斗、被目击互动）且无解释；warning=正常叙事中出现但疑似静态（画像/牌位/遗容，需人工辨析），或"坠崖/尸首未见"级存疑死亡后出场无解释；info=他人转述其言行（传言层）。
- **豁免条件**：回忆/梦境/假想/戏中戏；"假死"明写（龟息/金蝉脱壳）；**翻案——后文明写"原来当日未死"（边界案例裁定：转第七章三分流判为作者有意翻案=资产，撤回 error）**；传言"某人已死"（传言≠事实，见 J8）。
- **上游接口**：消费 01g 死亡登记层状态字段；消费 #4 出场事件与叙述模式；消费 #5 时点键。
- **例（演示）**：正——第 3 回"重伤身亡"，第 20 回其独子在回忆中思及父亲，不报；误——第 20 回正常叙事中本人赴宴并出手且无解释，error 候选；若第 19 回明写"原来当日坠崖为怪藤所托、养伤至今"，转翻案资产。

## 4.5 检查项五：称谓辈分错乱

- **定义**：称谓使用不得违背 #6 辈分关系（徒呼师名、逆辈称呼、跨辈乱序），除非剧情明文豁免。属弱信号检查。
- **检测信号**：#6 关系边（师徒/父子/同门代际）+对话称谓字段；比对称谓方向与代际差；跨书场景先经 #7 归并确认同一人物/同一门派，再比称谓体系。
- **严重度**：error=已核实级关系边与称谓**系统性**冲突（同一对人物一处登记师徒、一处登记同辈，且均为已核实级；或跨书同门辈分整体颠倒且无交代）；warning=单次直呼师名、逆辈称呼且无豁免情节（弱信号，与第五章 OOC 联动观察）；info=同辈泛称（"兄弟"）、反语讽刺、外人不通门派辈分、谦敬客套。
- **豁免条件**：决裂明写（边界案例裁定：合法）；戏中戏角色扮演；假想场景；武林通称（"英雄/前辈"不按门派辈分）；传言中的错误称谓（传言者本不通内情）。
- **上游接口**：消费 #6 关系边（类型、代际、称谓字段）；消费 04a 叙述模式。
- **例（演示）**：正——决裂弟子当面直呼师父姓名且文中明写恩断义绝，不报；误——亲密徒弟无端连名带姓称呼师父，warning 弱信号。

# 五、OOC 检测维度（Q4）

## 5.1 定位与强度约束

OOC（性格/行为跨章跨书不一致）信号弱、误报率高，按评审要点取最保守设计：**弱信号只记录、不断言；不进穿帮雷达 error/warning 级；问答与评分不消费**。首版仅用于人物档案的"一致性提示"展示（info 级）。不设百分比置信（人物性格一致性无量化基础），档位只分"候选/非候选"。

## 5.2 检测信号（三类）

1. **对话风格突变**：语体（文白/雅俗）、自称与他称、口头禅在同一人物身上无铺垫地整体切换。
2. **行为选择违背既定性格**：与档案性格标签直接冲突的重大决策（"从不伤人"者滥杀、"淡泊名利"者强夺掌门），且无转变事件。
3. **能力突变无习得事件**：与第四章检查项二联动——若习得检查触发且人物同时性格大变，合并为一条候选（避免重复报）。

## 5.3 与"人物成长弧"的区分（成长是资产，不是 OOC）

| 判别信号 | 成长弧（资产） | OOC 候选 |
|---|---|---|
| 铺垫 | 有习得事件/重大变故/他人点化/顿悟明写 | 无任何铺垫 |
| 动机 | 转变有合理动机且与事件因果相连 | 动机缺失或与既定动机矛盾 |
| 方向 | 沿既有性格逻辑延伸（或事件推动的转向） | 与核心性格标签反向突变 |
| 渐进 | 多场景渐进推进 | 单场景内突变完成 |
| 复现 | 转变后稳定保持 | 忽前忽后摇摆 |
| 叙事标记 | 文本有"他变了"类标记或明写转折 | 无任何叙事标记 |
| 跨书 | 两书之间有明文过渡（后传交代） | 两书行事完全相反且无交代 |

**判别口诀：有铺垫的转变为成长，无铺垫的突变为 OOC 候选。**

跨书场景先排除三项再立候选：作者创作阶段差异（早期/晚期笔法）、世界观差异（不同书江湖规则不同）、同名异人（消歧错误）。

## 5.4 置信处理

- 立条条件：三类信号中 ≥2 类同时出现 + 跨 3+ 场景复现 → 立"OOC 候选"档案条目（confidence=low）；任何单信号不立条。
- 消费约束：候选条目仅在人物档案展示（info 级）；问答回答时**不得引用为定论**；穿帮雷达 /audit 不报 error/warning；说书人专栏引用时必须写明"候选"。
- 豁免：易容/附身/被人控制明写；戏中戏；假想；成长弧判定通过者。

## 5.5 例（演示，非作品证据）

- 正——豪迈大侠经灭门之变后沉郁寡言，转变事件明写，成长弧，不立条；
- 误——同一章内前后两种语体且无任何交代，立弱信号记录（不断言，不进报告正文）。

# 六、设定一致性评级（Q5）

## 6.1 A-E 五级（07e 认识论转写：从"记载真伪"到"与系列设定的一致程度"）

| 级 | 定义 | 判定信号 | 用途 |
|---|---|---|---|
| A | 与设定库完全一致，无任何冲突信号 | 四区常识无违反 + 上游"已核实"级数据支持 | 问答直答、档案直展 |
| B | 设定内合理（有明文解释的边缘情形） | 触发豁免/方向反转条款：闭关、驻颜、奇遇、演义自由、传言推翻 | 展示并注明解释依据 |
| C | 存疑 | 弱信号/单源记载/需额外假设才能自洽；上游状态=来源声称或存疑 | 降权展示，标注"存疑" |
| D | 疑似穿帮 | 与"已核实"数据冲突 + 三分流初判为破绽候选 | 待人工复核，不入正答 |
| E | 确认穿帮 | 人工复核确认 + 各版本均无解释 | 穿帮雷达展示；"这符合设定吗"类反问**拒答** |

## 6.2 分层评估（照搬 07e，武侠化三层）

同一出场/事件三层可各得一级，展示时并列（如"情节经过 A / 细节对话 C"）：

| 层 | 武侠化内容 | 从严程度 |
|---|---|---|
| 主线设定层 | 武功体系与门派格局（习得体系、相克关系、门派存续） | 最严（error 容忍 0） |
| 情节经过层 | 人物命运（死亡、际遇、结局） | 严，但保留翻案通道 |
| 细节对话层 | 日常言行（称谓、钱物、吃穿） | 宽（info 为主） |

**综合单值规则**（仅问答等需要单一值的场景）：取三层最低级，且主线设定层权重最高——主线设定层 E 级直接触发拒答，不受其他层拉高；档案展示默认仍并列，不合并。

**例（演示，非作品证据）**：某配角之死——情节经过层与全书死亡登记一致（A）；其临终对话称谓与辈分数据有一处弱信号（C）。档案并列展示两层，不合并。

## 6.3 与上游字段的映射（不重复定义，只写映射）

| 本文件评级 | 01g 可信状态（前提约束） | #7 冲突类型学（判定依据） | #5 时间体系 |
|---|---|---|---|
| A/B | 已核实 | 无冲突，或属呼应/翻案（正向资产） | 时间扭曲归设定解释层 |
| C | 来源声称/存疑（**评级上限 C**） | 冲突未定谳 | 时点模糊 |
| D/E | 已核实+冲突确认 | 穿帮（判别信号通过） | 时间自洽校验失败 |

规则：评级上限受 01g 状态硬约束——"来源声称"级记载最高 C；**"未知"≠穿帮**（未知按 01g 未知原则处理，不得据此定 E）；"相互冲突"走 #7 流程定谳前一律 C；修订版冲突以修订版为准后重评（T7）。#7 的词汇只有"呼应/翻案/穿帮"，不引入"正典/外传/草稿"等未经定版的层级名。

# 七、反常的三分流规则（Q6）

## 7.1 三分判别信号表（与 #7 冲突类型学一致化）

| 信号维度 | 设定破绽（要修） | 夸张修辞（识别不改） | 作者有意翻案（资产） |
|---|---|---|---|
| 后文解释 | 无任何解释 | 无需解释（文学夸饰自明） | 有明文改写/补叙（"原来当日…"） |
| 数值形态 | 精确数值与既定设定冲突 | 模糊大数+修辞标志词（百丈/千军/顷刻/宛如/犹如/但见/仿佛） | 新设定成体系、前后一致 |
| 复现形态 | 零散、无规律、互相打架 | 母题化反复、不依赖情节 | 系统性呼应新版架构 |
| 版本史 | 各版本均如此 | 各版本均如此 | 修订版系统性改动（对照可见） |
| 叙述模式 | 正常叙事 | 正常叙事（写意段落） | 正常叙事+明文声明 |
| #7 对应 | **穿帮**（共用判别信号与命名） | 不入 #7 冲突表（语用层新增） | **呼应/翻案**（对应 #7 正向关系；档案记录时细分"呼应（有意互文）/翻案（改写旧设定）"两标记） |

**一致化声明**：本表"破绽"列与 #7 冲突类型学之"穿帮"共用判别信号与命名；"翻案"列对应 #7 之"呼应/翻案"正向关系；"修辞"为 #7 之外的语用层新增，只打展示标签不入冲突表。三者命名一一对应，不得另造同义词。

## 7.2 判别流程（顺序执行，命中即分流）

```
冲突信号
  ▼
① 叙述模式过滤（04a）── 非正常叙事（回忆/梦境/假想/戏中戏）→ 豁免，不进分流
  ▼
② 可靠性过滤 ────────── 传言/传闻（来源声称）→ 不进分流，标注可靠性
  ▼
③ 修辞检测 ──────────── 修辞标志词 + 无情节依赖 → 夸张修辞（识别不改）
  ▼
④ 翻案检测 ──────────── 有明文解释/补叙，或修订版对照显系统性改动 → 有意翻案（资产）
  ▼
⑤ 设定破绽候选 ──────── 穿帮雷达待修清单（经 3+ 案例门槛+人工复核后定 E 级）
```

## 7.3 每类正误例（示例为规则演示，不作为作品证据）

**设定破绽（要修）**
- 正例（应判破绽）：某配角第 3 回正常叙事中"中剑身亡、当场气绝"，第 20 回正常叙事中与其对话，全书无假死或翻案补叙——破绽候选，进待修清单。
- 误例（不应判破绽）：同上场景，但第 19 回有"原来当日护心镜挡了剑锋、他借死脱身"补叙——翻案资产，不是破绽。

**夸张修辞（识别不改）**
- 正例（应判修辞）："老侠客一剑挥出，百丈之外血雨腥风"——写意段落，数值未被任何情节引用——修辞标签，识别不改。
- 误例（不应判修辞）："城墙高三丈，他一跃而过"，前文明写墙高、数值被逃生情节依赖——数值自洽查证对象，不得以"修辞"豁免了事。

**作者有意翻案（资产）**
- 正例（应判翻案）：前书设定"此功练者必走火"，后书主角练成且书中专段明写"前人未得其法，今悟正途"——翻案资产，入"梁羽生的自我矛盾与有意翻案"专栏选题。
- 误例（不应判翻案）：后书主角练此功走火，与前设定一致——无翻案可言；若练成却无任何解释且与旧设定精确冲突——破绽候选而非翻案（翻案须明文）。

# 八、工作流程：六轮常识提取（照搬 07c §七骨架，武侠化）

**【第 1 轮：案例收集】**
- 输入：第 3.4 节边界案例种子集 12 条 + 已有穿帮候选 + 抽样章回（首批：《白发魔女传》等）。
- 操作：从 #4/#5/#6 结构化数据与原文双轨提取候选反常。
- 输出：候选案例清单（每条附原文句+数据指针）。

**【第 2 轮：普适性检验】**
- 操作：逐条三问——是否适用多个案例？有无明确朝代/母题边界？是否可量化？
- 门槛：**3+ 案例才保留；仅适用单一案例者丢弃；无法验证者标"推测性"。**
- ★武侠化必答"方向反转检验"：此条是否与史记式直觉相反？若相反且为武侠母题，则显式声明反转，转为豁免性规则（如 W3/S8/J2/J8），并写入第 1.4 节反转总表。

**【第 3 轮：来源标注】**
- 操作：标注来源（文本归纳/研究文献/领域共识）与置信（高/中/低）；禁用无来源臆造。
- 输出：规范化常识条目（第 2.3 节卡片格式）。

**【第 4 轮：规则化编码】**
- 操作：数字类→阈值规则；惯例类→违规规则；缺口类→缺失规则；标注 lint 关系（可自动/半自动/人工）。
- 纪律：**只产出规则卡片，不写实现代码**；规则依赖的字段必须在上游 schema 存在，否则降为人工或挂签待建。

**【第 5 轮：实战验证】**
- 操作：34 部全集批量扫描，统计候选数与假阳性率。
- 判定：假阳性 <20%→规则有效录入；20-50%→调阈值重验；>50%→重新设计（20% 门槛照搬 07c 直迁，不因领域放宽）。
- ★武侠化要点：假阳性三大来源为**修辞误判、回忆当穿帮、传言当事实**——统计前先跑第七章三分流前四步，剔除已分流条目再算假阳性。

**【第 6 轮：持续更新】**
- 操作：季度审核（照搬 07c；语料为静态全集，无"月度持续产出"之需）；新案例回流第 1 轮；修订版对照更新（#7 权威层级）；上游 schema 变更时回写第 4.6 节接口表；记录变更日志。

# 十二、FAQ

**Q1：为什么"行千里一夜"不算穿帮？**
方向反转原则：轻功奔袭是武侠母题，属设定内合理。本体系对行进速度只查书内自洽（前文明写"三日方至"后文当日达）与设定锚冲突，不做现实地理校验，**上不封顶**（W1）。

**Q2：死亡角色在回忆里出现，算复活吗？**
不算。01g 已定：回忆/梦境出现不算复活，死亡登记状态不变。穿帮雷达只对**正常叙事**中的活体再现报 error（第四章检查项四）。

**Q3："一剑挥出百丈"为什么不上穿帮雷达？**
夸张修辞：模糊大数+修辞标志词+无情节依赖，归语用层打标签，识别不改，不入 #7 冲突表（W6、第七章）。

**Q4：初版与修订版设定打架，听谁的？**
听修订版（#7 权威层级，T11 合同口径"修订版赢"）。初版差异记为"版本对照"资产，不入穿帮雷达；修订版自身内部矛盾照常走检查清单（T7）。

**Q5：传言"某派已被灭"，后文该派又出现，算穿帮吗？**
不算。传言属 04a 可靠性矩阵的来源声称层，传言≠事实，可被后文推翻，不触发灭派存续检查（J8、S3 反例、检查项三豁免）。

**Q6：徒弟直呼师父名字，一定是辈分错乱吗？**
不一定。决裂明写、戏中戏扮演、反语讽刺、外人不通辈分均豁免；无豁免情节时只记 warning 弱信号，不断言；仅关系边数据系统性冲突才升 error（检查项五）。

**Q7：八十岁高手还能打吗？巅峰年龄怎么定？**
按武林标准（★方向反转）：内功修为延展战力年限，高龄出战不设上限，"巅峰 20-40 岁"仅作当打之年参考而非检验阈值；年龄检查只查数字跨回自洽，不查"太老不能打"（W3、检查项一）。

**Q8：为什么钱物数字整体豁免？**
武侠经济是叙事道具（★方向反转），现实购买力校验必然大面积误报；只查同一关键物前后价差且差价涉情节时记 info（J5）。

**Q9：OOC 为什么不进穿帮雷达？**
性格一致性信号弱、误报率高。设计为：≥2 类信号+3+ 场景复现才立候选条目，confidence=low，仅档案提示，问答与评分不消费，/audit 不报 error/warning（第五章）。

**Q10：种子规则什么时候转正？**
三条件同时满足：3+ 案例（跨章或跨书）、实战假阳性 <20%（剔除已分流条目后统计）、人工复核通过。未达标者标"候选"，只跑不判（第三章、第八章）。

**Q11：时代常识和架空怎么区分？**
锚内合理、锚外穿帮：清代火枪=合理，"手枪"=穿帮（T1）。作品明文改写重大史实走向=架空声明资产（T3）；无声明而器物/官职/纪年错配=穿帮。

**Q12：本技能与"矛盾检测"类技能的分工？**
矛盾检测关注两处记载互相打架；反常识别关注单条记载令人意外；本技能关注**与设定库和跨数据的一致性**。三者互补：本技能的五项检查消费矛盾检测与反常识别的产出，再做三分流定处置。

**Q13：跨书检查怎么做？**
34 部共享宇宙，五项检查默认开跨书模式：同一人物/门派/武功先经 #7 跨书归并表确认同一实体，再做 #5 时间轴对齐与 #6 关系比对；同名异人（消歧错误）是第一大假阳性来源，先消歧再判矛盾（C13）。
